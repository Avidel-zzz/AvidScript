# P42.0 UE Reflection Binding Generator 架构

状态：Done

## 本组结论

Phase 42 选择“版本化 Binding Descriptor + WAMR raw native trampoline + Runtime 缓存反射调用计划”架构。

当前每增加一个 UE API 都要手改 C# facade、Reflection spec、VM binding enum、WAMR NativeSymbol wrapper 和 Runtime switch。Phase 42 的首要验收标准是消除这条扩展链，而不是继续增加几个 Actor 函数。

## 已确认的底座

- Phase 31 已能从 `UClass/UFunction/FProperty` 生成确定性 schema，并处理 unsupported property 和 manifest 契约。
- Phase 41 已能从 C# Roslyn semantic artifact 生成 Guest IR 与确定性 WASM。
- 本地 WAMR 2.4.4 提供 `wasm_runtime_register_natives_raw`、raw argument macros 与 native attachment。
- Runtime 已有 slot/generation UObject registry、Session lifecycle、WAMR guest memory 验证和 host dispatcher。

## 选定调用路径

```text
generated C# proxy
  -> generated WASM import/frame
  -> VM-private raw trampoline
  -> package-local ordinal attachment
  -> generic host dispatcher
  -> cached UFunction/FProperty invocation plan
  -> UObject handle resolve + ProcessEvent
  -> out/return marshal
```

Reflection 名称解析、property 遍历、默认参数和 frame layout 只在 package load 时执行。BeginPlay/Tick/Event 调用阶段使用 ordinal 数组索引和不可变缓存，不读取 JSON，不构造查找 key。

## 模块职责

- Editor：Reflection 扫描、policy、descriptor 和 C# 生成。
- Bindings：descriptor runtime model、handle、marshalling、cached ProcessEvent plan。
- VM：raw native 注册、attachment、guest memory 和语言无关 HostCall。
- Runtime：session load 时校验 package hash 并组合 VM/Bindings。

WAMR 类型继续只存在于 VM Private；UObject/UFunction 不进入 VM Public；Editor generator 不进入 Runtime 热路径。

## Descriptor v2 核心

- canonical identity 包含 owner path、function、return 和有序参数方向/类型；
- stable id 使用完整 SHA-256；
- package 内按稳定排序分配紧凑 ordinal；
- descriptor、C# source、WASM manifest 共享 package hash；
- schema/hash/ordinal 错配时加载失败关闭；
- allowlist 是安全选择策略，不再携带手写 import signature/projection。

## 首批范围

支持 scalar、enum、UObject handle、FVector、FRotator、FTransform、公开非 latent UFunction、value/const ref/out/ref/return。FString、容器、delegate、latent、interface 和完整 UStruct 递归投影后续分批加入。

P42.1-P42.2 先生成 descriptor 与 C# facade，并允许由生成结果复用现有 10 个 import 形成首个自定义 C# gameplay 切片。P42.3-P42.4 随后接入通用 raw registry 和 cached reflection invocation，新增 API 不再进入 VM enum 或 Runtime switch。

## 分组与时间

- P42.1：Descriptor v2 与类型投影。
- P42.2：C# facade 与 package 发布。
- P42.3：WAMR raw native registry。
- P42.4：Runtime cached reflection invocation。
- P42.5：自定义 profile/生命周期闭环。
- P42.6：覆盖、性能、完整验证和收尾。

首个可编写自定义 C# 脚本验证的生成切片预计 4 至 6 小时；Phase 42 v1 完整收尾预计 16 至 28 小时，不包含移动端打包和所有 UE 容器类型。
