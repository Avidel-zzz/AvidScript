# Phase 42.1：Binding Descriptor v2

## 阶段结论

P42.1 已建立从 UE5.8 Reflection 选择项到确定性 Binding Descriptor v2 的生成链。选择输入只包含 `owner class path + UFunction name`，import 名称、WASM signature、类型方向、size/alignment、stable id 与 package ordinal 均由反射元数据和统一类型策略生成。

本阶段解决的是“新增 API 的描述与 ABI 不再手写”。C# facade、WAMR raw native 动态注册和 Runtime cached `ProcessEvent` 仍分别属于 P42.2、P42.3、P42.4，因此此时还不能把任意新 UFunction 直接用于游戏脚本。

## 实现组成

- `FAvidScriptEditorBindingDescriptorGenerator`：解析选择策略、生成 canonical identity、stable id、package hash、ordinal 与 descriptor JSON。
- `FAvidScriptEditorReflectedTypePolicy`：从 `FProperty` 生成 canonical type、参数方向与 WASM ABI。
- `FAvidScriptHash`：位于 `AvidScriptCore` 的平台无关 SHA-256，避免依赖 UE5.8 未实现的平台哈希入口。
- v1 Schema 保持不变；v2 使用独立生成器并继续兼容现有 Phase 31 读取与测试。

## Descriptor v2 契约

- schema：`2`
- source：`ue_reflection`
- stable id：canonical identity 的完整小写 SHA-256
- selection hash：排序后 `owner.function` 选择集合的 SHA-256
- package hash：package、generator、UE 版本、类型、函数 ABI 与默认参数共同参与
- ordinal：按 canonical identity 稳定排序后，从 `0` 开始连续分配
- host module：`avidscript`
- dispatch mode：`cached_process_event`

Canonical function identity 包含 owner path、真实 UFunction 名称、return type，以及按反射顺序排列的参数名称、方向和类型。默认参数不改变函数 stable id，但会改变 package hash，防止旧调用计划与新默认值混用。

## 首批类型策略

当前支持：

- `bool`、`float`、`double`
- 有符号/无符号 8、16、32、64 位整数
- `UEnum`
- generation-checked UObject handle
- `FVector`、`FRotator`、`FTransform`
- `value`、`const_ref`、`ref`、`out`、`return`

状态码统一作为 host import 的 `i32` 返回值。实例方法先接收 `{slot, generation}`；非 void 返回值通过 guest 输出地址传递。首批基础结构按既有 AvidScript guest ABI 投影，Runtime 在 P42.4 负责 native/guest 转换。

尚未支持 `FString`、容器、任意递归 UStruct、delegate、latent、custom thunk 和 editor-only 调用；选择到这些类型或函数时生成器失败关闭，不发布部分 JSON。

## 默认 package

`avidscript.engine.core` 当前从反射选择 8 个安全函数：

- `AActor.GetActorLocation`
- `AActor.GetActorRotation`
- `AActor.GetActorScale3D`
- `AActor.SetActorScale3D`
- `AActor.GetRootComponent`
- `AActor.GetDistanceTo`
- `USceneComponent.GetComponentLocation`
- `USceneComponent.GetComponentRotation`

这组函数用于验证 Actor、SceneComponent、对象 handle、`FVector`、`FRotator`、输入与返回投影。`USceneComponent.SetVisibility` 作为默认参数测试夹具，验证 `bPropagateToChildren=false` 被写入 descriptor 并绑定 package hash。

## 失败关闭

生成失败会清空输出 JSON，并返回稳定分类，包括：

- `package_name_missing`
- `selection_empty`
- `duplicate_selection`
- `class_missing`
- `function_missing`
- `function_not_callable`
- `function_not_allowed`
- `unsupported_property`
- `duplicate_stable_id`
- `serialize_failed`
- `write_failed`

文件发布使用同目录临时文件替换；失败不会覆盖上一个可用 descriptor。

- TDD RED：缺少生成器头文件时模块编译失败，证明测试先于实现。

- `AvidScript.Editor.BindingDescriptor`：4/4，通过确定性、投影、默认参数和失败路径。
- `AvidScript.Editor.BindingSchema`：3/3，Phase 31 v1 回归通过。
- 完整 `AvidScript` UE5.8 Editor 自动化：146/146。
- `AvidScriptEditor` 与 `AvidScriptCore` 均通过 UE5.8 模块级增量编译，未清理 Editor Target。
- `CheckAvidScriptArchitecture.ps1`：通过。

## 问题记录

本阶段暴露并写入 `AGENTS.md` 的经验包括：UE unity 匿名命名空间符号冲突、平台 SHA-256 入口在真实 Editor 中断言、`TArray` 自引用扩容断言、依赖模块 DLL 未显式重链导致 Windows 127，以及 PowerShell fallback 的集合拼接问题。

## 下一阶段

P42.2 将从同一 descriptor 生成确定性的 C# reference source、public proxy 和 internal Native 层，并以同一 package hash 事务式发布。完成后才能开始用生成 facade 替代 ActorLifecycle 示例中的手写 API 表面。
