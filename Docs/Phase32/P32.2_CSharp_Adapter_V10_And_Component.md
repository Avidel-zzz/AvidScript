# P32.2 C# Adapter v10 与组件闭环

状态：Done

## C# 写法

```csharp
public static void BeginPlay()
{
    UE.SetTimer(0.05f, 7);
}

[UnmanagedCallersOnly(EntryPoint = "avid_on_timer")]
public static void OnTimer(int callbackId, int timerHandle)
{
    UE.Self.AddActorWorldOffset(new FVector(0.0f, 0.0f, 50.0f));
}
```

`BuildCSharpActorLifecycle.ps1` 生成 `actor_lifecycle_v10` direct ABI WASM，包含 14 个 imports 与 4 个 lifecycle exports。未声明 `OnTimer` 的旧脚本会获得 no-op `avid_on_timer`，保持向后兼容。

`UAvidScriptComponent` 现在记录 Timer callback 次数、最后 callback id 与 handle。Reload session 可查询 live runtime 的 pending Timer 数和 callback 数，用于验证拒绝 Reload 保留旧状态、成功 Reload 隔离旧状态。

当前 source adapter 已暴露 `UE.CancelTimer(int)`，但尚不支持用 C# `int` 字段保存 `SetTimer` 返回的 handle；完整取消工作流留给后续整数状态/正式 C# 前端阶段。
