# P32.1 Timer Runtime 与测试

状态：Done

## 实现范围

- 新增 `env.timer_set_once(f32 delaySeconds, i32 callbackId) -> i32 handle`。
- 新增 `env.timer_cancel(i32 timerHandle) -> i32`。
- Timer 由 `FAvidScriptWasmRuntimeInstance` 持有，Unload 与成功 Reload 会清空旧实例状态。
- Tick 在调用 guest Tick 前快照到期 handle，在 guest Tick 后按 handle 顺序调用 `avid_on_timer(callbackId, timerHandle)`。
- guest Tick 或 Timer callback 内新建的零延迟 Timer 最早下一帧执行。
- 单实例最多保留 1024 个待触发 Timer，超限返回 0。

## 错误语义

- callback export 缺失：`missing_export`。
- callback 内 trap：`trap`，并标记 export 为 `avid_on_timer`。
- 一次性 Timer 在进入 callback 前移除，失败不会造成同一任务反复触发。

## 测试

`AvidScript.Runtime.Timer` 共 4 项，覆盖注册/取消、容量、到期、Unload、缺失 export、trap 和下一帧重入语义。
