# P32.0 Timer / guest callback 范围

状态：Done

Phase 32 提供 runtime-instance-owned 单次 Timer。C# 在 BeginPlay 调用 `UE.SetTimer(delaySeconds, callbackId)`，宿主在后续 Tick 调用 `avid_on_timer(callbackId, timerHandle)`。

Timer 不依赖裸 UObject 指针，也不把 UE delegate 指向 WAMR 内存。实例 Unload 即清空全部 Timer，因此 EndPlay 和成功 Reload 不会留下旧回调。

本阶段提供取消 ABI，但 C# source adapter 暂不支持把返回 handle 保存到 `int` 字段；该语法将在整型状态/完整 Roslyn 前端阶段补齐。
