# P28.1 类型化 Actor Rotation RED 测试

状态: Done

## RED 契约

- Actor binding 测试要求 `GetActorRotation`、`SetActorRotation` 和结构化 `Rotation` 结果。
- runtime direct handler 测试要求 rotation read/write 与 missing-context fail closed。
- C# 样例要求 `FRotator`、Get/SetActorRotation 和局部旋转加法。
- manifest 测试要求 `actor_lifecycle_v7`、`actor_get_rotation` 和 `actor_set_rotation`。

## RED 证据

- C++ 模块构建报 `C2039`：`GetActorRotation`、`SetActorRotation`、`HandleActorGetRotationImport`、`HandleActorSetRotationImport` 不存在。
- 旧 source adapter 无法解析 rotation 语句，fallback 报缺少 `FRotator` 与 AActor rotation methods，结果为 `direct_abi_unsupported`。

失败与 Phase28 目标一一对应，没有依赖无关环境故障。
