# P28.0 类型化 Actor Rotation 范围

状态: In Progress

## 目标

在 Phase27 Actor location 读改写基础上，增加 `FRotator`、`GetActorRotation()` 和 `SetActorRotation()`，让 C# Tick 能同时驱动 Actor 位移与旋转。

## 约束

- 对象继续使用 slot/generation handle，不暴露 `UObject*`。
- struct read 继续使用经过范围验证的 guest linear memory。
- rotation write 继续受 host write policy 控制。
- adapter 仍是显式受限 C# 子集，manifest 必须准确声明能力。

## 非目标

`FTransform`、scale、SceneComponent、Spawn、输入、Timer、碰撞事件、通用反射与移动端打包不进入本阶段。
