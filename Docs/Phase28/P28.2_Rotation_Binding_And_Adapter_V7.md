# P28.2 Rotation Binding 与 Adapter v7

状态: Done

## C++ binding

`FAvidScriptActorBinding` 已增加 `GetActorRotation` / `SetActorRotation`：

- 使用 object registry slot/generation 解析 Actor。
- rotation write 继续经过 `EAvidScriptActorWritePolicy`。
- 写入后读取实际旋转并进行容差验证。
- 失败返回结构化 category、message 和 next action。

## WAMR imports

新增：

```text
actor_get_rotation(i32 slot, i32 generation, i32 out_ptr) -> i32
actor_set_rotation(i32 slot, i32 generation, f32 pitch, f32 yaw, f32 roll) -> i32
```

get import 验证 12 字节 guest memory 范围后，按 Pitch/Yaw/Roll 写入三个 f32。canonical `avidscript` 和兼容 `env` 模块共同注册，不暴露宿主指针。

## Adapter v7

- `FVector` 与 `FRotator` 共用三分量 value local/expression/codegen。
- 支持 `FRotator.Zero`、局部 rotation、分量加法和 Get/SetActorRotation。
- imports 索引 5/6 为 set/get rotation；生命周期索引为 7/8/9。
- manifest subset 为 `actor_lifecycle_v7`，准确声明 rotation types/calls/imports。
