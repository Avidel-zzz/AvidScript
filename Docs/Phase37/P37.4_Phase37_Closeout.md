## 完成内容

Phase 37 完成 Runtime 热路径、Timer scheduler、typed Transform batch contract 和可重复 benchmark：

- Timer 使用 absolute deadline min-heap、active map、tombstone compaction。
- Tick 复用 DueTimerScratch，空闲 Timer 不再逐帧线性扫描。
- Runtime 返回边界统一 CopyObservableStateToResult，正常 Tick 只同步一次可观察状态。

- Batch 具有确定顺序、fail-fast、FailedIndex 与失败输出清空语义。
- Performance 使用 20 samples、3 warmups，并包含 Timer 与 scalar/batch Transform 指标。
- VM 继续不依赖 UE gameplay 类型；WAMR guest memory adapter 留在下一独立小组。
