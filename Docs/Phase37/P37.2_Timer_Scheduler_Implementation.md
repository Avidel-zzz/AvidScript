# P37.2 Timer Scheduler 实现记录

状态：Done

## 范围

本组完成 Runtime Timer 的数据结构与 benchmark 改造：

- PendingTimers 线性数组替换为 ActiveTimers 句柄表与 TimerHeap deadline 最小堆。
- Timer 使用 session 绝对时钟和 DueTimeSeconds，不再每帧遍历并修改全部剩余时间。
- DueTimerScratch 由 Runtime 实例持有并复用，Tick 不再创建临时 due handle 数组。
- cancel 从线性查找改为 active map 删除，并通过 tombstone threshold 重建堆。
- 新增同 deadline 确定顺序、1024 容量取消后复用测试。
- Performance 自动化从 5 个样本扩为 20 个样本，并新增 Timer Scheduler benchmark。

## 复杂度

- 注册：O(log n)，句柄占用检查为均摊 O(1)。
- 取消：常规路径均摊 O(1)，压缩触发时为 O(n)。
- Tick：无到期 Timer 时不再扫描全部 active timers；处理 k 个到期项为 O(k log n)。
- 同一 deadline 按 handle 升序执行。
- callback 中新建的零延迟 Timer 保持下一帧执行语义。

## 剩余风险

- tombstone 压缩是摊销策略，极端取消模式仍会出现单次 O(n) 重建。
- benchmark 是当前机器和 Development Editor 的工程基线，不代表打包 Shipping 或移动端结果。
- Timer session clock 当前随 Runtime 生命周期重置，热重载状态迁移仍不包含 Timer 队列。
