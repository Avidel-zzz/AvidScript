- cancel 变为均摊 O(1)，并限制 tombstone 增长。
- Tick 复用 due scratch、减少重复 result copy。
- benchmark 扩大样本并增加 Timer 压力维度。
- 首个 transform batch ABI 只在正确性和性能均有证据时落地。
