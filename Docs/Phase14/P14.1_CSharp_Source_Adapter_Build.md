# P14.1 C# Source Adapter 构建

## 状态

- 状态: 完成
- 日期: 2026-07-06

## 已实现

`BuildCSharpActorLifecycle.ps1` 现在会优先尝试 C# source adapter。只有 adapter 无法处理当前源文件时，才进入 .NET WASI 诊断路径。

构建命令：

```powershell
powershell -ExecutionPolicy Bypass -File Plugins/AvidScript/Build/BuildCSharpActorLifecycle.ps1
```

观察到的成功结果：

```text
[AvidScript][CSharp][Build] result=direct_abi_built compiler=avidscript-csharp-source-adapter
```

生成产物：

- `Saved/AvidScriptCSharpGuest/ActorLifecycle/actor_lifecycle.csharp_adapter.wasm`
- `Saved/AvidScriptCSharpGuest/ActorLifecycle/actor_lifecycle.avidscript.json`
- `Saved/AvidScriptCSharpGuest/ActorLifecycle/actor_lifecycle.csharp.report.json`

## Report 契约

report 现在使用以下字段表达成功路径：

- `result = direct_abi_built`
- `direct_abi_supported = true`
- `toolchain.compiler = avidscript-csharp-source-adapter`
- `observed_exports` 包含 `avid_on_begin_play` 和 `avid_on_tick`
- `artifacts.manifest_file` 指向生成的 manifest
- `artifacts.wasm_file` 指向生成的 adapter WASM

## 备注

脚本仍会检测并记录 .NET CLI，但 adapter 成功时会在 `dotnet publish` 之前退出。这样常规 C# 样例构建不会再被之前 WASI 路线里的 `chmod` 失败或网络 vulnerability-index 警告影响。
