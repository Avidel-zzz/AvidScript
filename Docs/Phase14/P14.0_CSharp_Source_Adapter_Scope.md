# P14.0 C# Source Adapter 范围

## 状态

- 状态: 完成
- 日期: 2026-07-06

## 目标

Phase 14 的目标是把 Phase 13 的 C# 样例从“只能诊断工具链”的产物，推进成真正的 AvidScript direct ABI WASM 产物。

本阶段选择的路线是受限 C# source adapter：

- 读取 C# 生命周期源文件
- 提取 `BeginPlay()` 和 `Tick(float deltaSeconds)`
- 将支持范围内的 `Actor.SetLocation(...)` 语句编译成小型 direct ABI WASM 模块
- 写出标准 `.avidscript.json` manifest
- 保留 .NET/WASI 路径作为 fallback 诊断路线，而不是默认成功路径

## 为什么采用这条路线

Phase 13 已经证明当前本机 .NET WASI 产物不会导出 `avid_on_begin_play` 或 `avid_on_tick`。如果等待完整 .NET direct export 工具链，会阻塞 UE 交互验证。

source adapter 让用户侧仍然先用 C# 写 gameplay 语法，同时输出当前 runtime 已经支持的 WASM ABI。这样可以更早验证“C# 脚本 -> WASM -> UE Actor”的核心闭环。

## 当前支持子集

当前支持：

- static `BeginPlay()` 生命周期方法
- static `Tick(float deltaSeconds)` 生命周期方法
- `Actor.SetLocation(float x, float y, float z)` 调用
- `100.0f` 这类数值 float 字面量
- `deltaSeconds`
- `deltaSeconds * 数值字面量`
- 支持表达式加法，例如 `100.0f + 120.0f * deltaSeconds`

当前 self 绑定：

- 生成的 WASM 调用 `env.actor_set_location`
- owner/self Actor 暂时表示为 slot `1`、generation `1`
- 这匹配当前 smoke test 使用的“每个脚本会话先注册 owner Actor”的模型
