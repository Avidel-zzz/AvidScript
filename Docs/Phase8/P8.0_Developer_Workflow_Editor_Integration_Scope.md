# P8.0 Developer Workflow And Editor Integration Scope

日期: 2026-07-05
状态: Done

## 1. 目标

Phase 8 把 P7 的 `.avid` frontend build 能力包装成稳定工作流入口, 输出 JSON report, 并为后续 Editor command、watcher、IDE 和 CI 集成建立共同契约。

目标链路:

```text
.avid source
-> InvokeAvidScriptFrontend.ps1
-> BuildAvidScriptActor.ps1
-> JSON report + wasm + manifest
-> future Editor reload handoff
```
