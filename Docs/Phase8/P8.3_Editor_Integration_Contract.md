# P8.3 Editor Integration Contract

日期: 2026-07-05
状态: Done

## 1. 目标

本文档定义后续 Editor command、watcher、IDE 和 CI 如何消费 Phase 8 frontend workflow。P8.3 不新增 Unreal Editor module, 只固定 handoff contract, 防止未来 UI 直接解析临时 stdout。

## 2. 输入

Editor 或外部工具调用 wrapper 时提供:

```text
SourcePath: .avid source file
BindingsPath: optional typed binding declaration path
OutputRoot: optional artifact output directory
ReportPath: required or generated JSON report path
Ldc2Path / ToolchainRoot: optional D/WASM toolchain location
SkipCompile: optional diagnostics-only / generated-D-only mode
```

推荐 PC Editor 默认:

```text
SourcePath = Plugins/AvidScript/Samples/AvidScript/ActorSetLocation/actor_set_location.avid
BindingsPath = Plugins/AvidScript/Bindings/ActorHostBindings.avidscript.json
ReportPath = Saved/AvidScriptReports/<module>.frontend.report.json
OutputRoot = Saved/AvidScriptGenerated/<module>
```

## 3. 输出

Wrapper 输出三类结果:

```text
JSON report
Generated D source
WASM artifact + .avidscript.json manifest, when compile succeeds
```

JSON report 是 UI/CI 的首要读取对象。Manifest 是 runtime reload 的首要读取对象。

## 4. Success Handoff

成功路径:

```text
InvokeAvidScriptFrontend.ps1
-> report.succeeded == true
-> final build_events result is generated or built
-> if built: manifest exists and sha256 matches wasm
-> FAvidScriptWasmReloadManifestLoader validates manifest
-> reload staging session loads wasm
-> runtime swaps live module only after validation succeeds
```

Editor UI 期望状态:

```text
Build: Success
Diagnostics: empty
Artifact: report build_events[-1].fields.output
Manifest: raw_output manifest line or known OutputRoot manifest path
Next action: Reload
```

## 5. Failure Handoff

失败路径:

```text
InvokeAvidScriptFrontend.ps1
-> report.succeeded == false
-> diagnostics contains one or more error entries
-> Editor shows diagnostics by line/column
-> Runtime reload is not attempted
```

Editor UI 期望状态:

```text
Build: Failed
Diagnostics: list code/severity/line/column/message
Artifact: ignore
Next action: Fix source or binding declaration
```

## 6. Diagnostic Mapping

| Code | Meaning | Editor behavior |
| --- | --- | --- |
| ASL1001 | source missing | Show file-level error, no source location jump. |
| ASL1100 | parse failed | Show grammar error at line 1 column 1 until parser improves. |
| ASL1201 | binding manifest invalid | Show binding declaration error. |
| ASL1202 | unknown binding | Jump to reported line/column. |
| ASL1203 | invalid argument count | Jump to call site line/column. |
| ASL1204 | invalid literal | Jump to argument line/column. |
| ASL1301 | missing toolchain | Show setup action for LDC path/toolchain root. |
| ASL1302 | compiler failed | Show compiler output and report path. |
| ASL1303 | artifact missing | Show artifact output path and rebuild action. |

## 7. Reload Guardrails

- Editor integration must not call runtime reload if `report.succeeded` is false.
- Editor integration must not call runtime reload when compile was skipped and only generated D exists.
- Editor integration must validate manifest path and hash through existing runtime loader.
- Runtime rollback remains owned by `FAvidScriptWasmReloadSession`; UI only initiates staging.
- Report and manifest should be treated as build artifacts under `Saved/`, not source-controlled content.

## 8. Next Implementation Step

A future Editor module can start with a single command:

```text
Build Current AvidScript Source
```

That command should call `InvokeAvidScriptFrontend.ps1`, read the report, then call the existing manifest reload path only on success.
