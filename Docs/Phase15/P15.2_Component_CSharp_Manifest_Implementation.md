# P15.2 组件级 C# Manifest 实现

## 状态

- 状态: 完成
- 日期: 2026-07-06

## 已实现

`UAvidScriptComponent` 现在支持 manifest 文件路径：

- 新增 `ScriptManifestFile` 可编辑属性。
- 新增 `SetScriptManifestPath` / `GetScriptManifestPath`。
- 新增 manifest 路径解析，支持项目相对路径与绝对路径。
- 新增 `LoadConfiguredScriptModule`：
  - 路径为空时加载 embedded smoke module。
  - 路径非空时通过 `FAvidScriptWasmReloadManifestLoader` 读取 manifest 和 WASM。
  - 加载 WASM 后校验 manifest 要求的 exports。
  - 在 BeginPlay 前注入 host context。

组件 host context 当前使用：

- `ObjectRegistry = &ObjectRegistry`
- `ActorWritePolicy = AllowWrites`

这让 C# 生成的 `env.actor_set_location` 可以在组件生命周期内修改 owner Actor。

## 兼容性

旧的 `AvidScript.Component.OwnerHandleLifecycleSmoke` 和 `AvidScript.Component.RuntimeTickSmoke` 继续使用 embedded smoke module，不需要 manifest 路径。
