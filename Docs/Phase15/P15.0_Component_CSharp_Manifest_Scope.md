# P15.0 组件级 C# Manifest 生命周期范围

## 状态

- 状态: 完成
- 日期: 2026-07-06

## 目标

Phase 15 的目标是把 Phase 14 生成的 C# direct ABI WASM + manifest 接入 `UAvidScriptComponent`，让脚本可以在 UE 组件生命周期中运行，而不是只在独立 runtime/reload 测试里验证。

本阶段优先支持 PC Editor 路径，继续保持移动端意识但不做移动端验证。

## 设计范围

本阶段实现：

- 在 `UAvidScriptComponent` 上提供可编辑的 manifest 文件路径。
- manifest 路径为空时保留旧的 embedded smoke module 行为。
- manifest 路径非空时，在 `BeginPlay` 加载 manifest 与 WASM。
- 给 WASM runtime 注入组件自己的 owner `ObjectRegistry`。
- 允许组件脚本通过 `Actor.SetLocation` 写 Actor 状态。
- 在 `TickComponent` 调用 `avid_on_tick`。

## 仍然不做

- 不在本阶段实现 Editor 一键“选择 C# 源文件并自动挂到组件”。
- 不扩展 C# source adapter 的语言子集。
- 不解决多对象/多组件 self 绑定协议；当前 adapter 仍依赖 slot `1`、generation `1`。
- 不做 packaged/mobile 验证。
