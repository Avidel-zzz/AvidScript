# P21.2 C# Profile 模板服务

## 完成内容

本小组在 `FAvidScriptEditorCSharpProfileService` 中加入默认 profile 模板生成能力。

新增结果结构:

```cpp
FAvidScriptEditorCSharpProfileTemplateResult
```

该结构记录模板写入是否成功、是否创建了新文件、错误分类、下一步提示、profile 路径、默认 source/project/build script/output/report/manifest/module/artifact/configuration 等信息。

新增服务 API:

```cpp
FAvidScriptEditorCSharpProfileService::WriteDefaultProfileTemplate(...)
FAvidScriptEditorCSharpProfileService::WriteProfileTemplate(...)
```

## 默认模板字段

默认 profile path:

```text
Saved/AvidScriptCSharpProfiles/default.csharp-profile.json
```

默认 source:

```text
Plugins/AvidScript/Samples/CSharp/ActorLifecycle/ActorLifecycleScript.cs
```

默认 module/artifact:

```text
module_id: csharp_profile_actor_lifecycle
artifact_stem: profile_actor_lifecycle
```

默认 output/report/manifest root:

```text
Saved/AvidScriptCSharpGuest/Profiles/profile_actor_lifecycle
```

## 行为约束

- `ProfilePath` 为空时 fail closed, 返回 `profile_path_empty`。
- 目标文件已存在且 `bOverwrite=false` 时返回成功, 但 `bCreated=false`, 不改写用户已有内容。
- 写入前创建父目录。
- JSON 序列化失败、目录创建失败、文件写入失败均返回明确 error category 和 next action。
- 写出的 JSON 可以直接被 Phase20 的 `LoadProfile(...)` 映射为 `FAvidScriptEditorCSharpBuildConfig`。
