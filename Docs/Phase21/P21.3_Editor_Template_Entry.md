# P21.3 Editor 默认 C# Profile 入口

## 完成内容

本小组把 P21.2 的模板生成服务接入 `FAvidScriptEditorModule`, 作为 Editor 菜单和测试可调用的稳定入口。

新增 module API:

```cpp
FAvidScriptEditorModule::GetCSharpProfileTemplateEntryName()
FAvidScriptEditorModule::MakeCSharpProfileTemplateMenuEntryConfig(...)
FAvidScriptEditorModule::ExecuteCreateCSharpProfileTemplate(...)
```

新增菜单 entry:

```text
Tools > AvidScript > Create Default C# Profile
```

内部 entry name:

```text
AvidScript.CreateDefaultCSharpProfile
```

该入口调用 `FAvidScriptEditorCSharpProfileService::WriteDefaultProfileTemplate(Result, false)`。如果默认 profile 已经存在, 会记录 ready 日志并保持文件不变; 如果写入失败, 会记录 error category、message、next action 和 profile path。

## 与 Phase20 的关系

Phase20 已提供:

```text
Build And Bind C# Profile Script
```

Phase21 新增的入口解决“第一份默认 profile 从哪里来”。用户可以先点击 `Create Default C# Profile`, 再点击 `Build And Bind C# Profile Script`。默认 profile 指向现有 ActorLifecycle C# 样例, 因此不改 JSON 也可以先完成一次端到端验证。
