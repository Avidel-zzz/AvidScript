# P21.1 C# Profile 模板 RED 测试

## 目标

本小组先用测试描述 Phase21 需要补上的能力: 用户不再手写完整 `default.csharp-profile.json`, Editor/profile service 能生成一份默认 C# profile 模板, 并且生成后的文件可以继续走 Phase20 的 `LoadProfile(...)` 和 build-and-bind 链路。

## 新增测试

- `AvidScript.Editor.CSharpProfileService.DefaultTemplateSmoke`
  - 要求 `FAvidScriptEditorCSharpProfileTemplateResult` 存在。
  - 要求 `FAvidScriptEditorCSharpProfileService::WriteProfileTemplate(...)` 能创建模板文件。
  - 验证默认 source、module id、artifact stem 和 output root。
  - 验证生成文件能被 `LoadProfile(...)` 读取。
  - 验证第二次生成时默认不覆盖已有文件。

- `AvidScript.Editor.Module.CSharpProfileTemplateSmoke`
  - 要求 `FAvidScriptEditorModule::ExecuteCreateCSharpProfileTemplate(...)` 存在。
  - 要求 module API 能生成模板并被 profile service 读取。

- `AvidScript.Editor.Module.SampleCommandConfigSmoke` 扩展检查:
  - `FAvidScriptEditorModule::MakeCSharpProfileTemplateMenuEntryConfig(...)`。
  - Entry name 固定为 `AvidScript.CreateDefaultCSharpProfile`。
  - Label、tooltip 和 execute action 均有效。

## RED 结果

新增测试后先运行 `AvidScriptEditor` module build, 构建按预期失败, 主要缺失符号包括:

- `FAvidScriptEditorCSharpProfileTemplateResult`
- `FAvidScriptEditorCSharpProfileService::WriteProfileTemplate(...)`
- `FAvidScriptEditorModule::MakeCSharpProfileTemplateMenuEntryConfig(...)`
- `FAvidScriptEditorModule::ExecuteCreateCSharpProfileTemplate(...)`

这说明测试确实锁定了 Phase21 的新增行为, 而不是复用旧实现误通过。
