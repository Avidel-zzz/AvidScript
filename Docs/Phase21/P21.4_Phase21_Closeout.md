## 用户现在可以做什么

1. 在 Editor 中点击 `Tools > AvidScript > Create Default C# Profile`。
2. 生成或确保存在 `Saved/AvidScriptCSharpProfiles/default.csharp-profile.json`。
3. 选中一个 Actor。
4. 点击 `Tools > AvidScript > Build And Bind C# Profile Script`。
5. 默认 ActorLifecycle C# 样例会生成 profile 专属 WASM/report/manifest, 并绑定到该 Actor 的 `UAvidScriptComponent`。
