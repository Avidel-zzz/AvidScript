# Phase 56 融合调用帧实施计划

> **Agent 执行要求：** 按仓库 `AGENTS.md` 的 Simplified Parallel Phase Workflow
> 执行。测试代码随功能编写，UE 构建、Automation 与正式 benchmark 只在阶段末统一运行。

**目标：** 用 callback-epoch fused host cell、prepared VM export 与 `TickHot`
生产入口压缩 scalar、property 和 lifecycle callback 固定成本。

**技术栈：** Unreal Engine 5.8、C++20、C ABI、Wasmtime 45 Cranelift、C# Guest、
PowerShell 7 benchmark orchestration。

## 全局约束

- 普通 `UFUNCTION` 的 semantic reflection fallback 不得缩减。
- 不增加 fixture-specific 或逐 UE API 手写入口。
- Runtime 不包含 Wasmtime/WAMR 私有类型，VM 不包含 UObject。
- Journaled write、reload、ownership、Game Thread 与 reentrant unload 语义保持不变。
- PC Win64 先实现，WAMR 与移动端允许显式回退，不允许静默错误。
- 受保护用户文件不修改、不暂存、不提交。

## P56.1 Callback-epoch fused host cell

### 交付接口

在 Bindings 增加：

```cpp
enum class EAvidScriptPreparedHostEffectMode : uint8
{
    Rejected,
    DirectRead,
    DirectWrite,
    Journaled
};

EAvidScriptPreparedHostEffectMode ResolvePreparedHostEffectMode(
    const FAvidScriptPreparedGeneratedBinding& Binding,
    const FAvidScriptBindingInvocationContext& Context) const;
```

Runtime cell 保存 `ValidatedCallbackEpoch`、`ReceiverHandle`、`Receiver` 和
`EffectMode`。`TryResolveFusedReceiver` 在首次命中完整验证，fast hit 只验证 epoch、
handle 和 receiver validity。

### 实施步骤

- [ ] 将静态 effect policy 从 `PrepareGeneratedHostEffect` 中抽出为无副作用推导。
- [ ] 给 prepared cell 增加 epoch 与 receiver cache，禁止跨 callback fast hit。
- [ ] 统一 scalar/getter/setter 三个 dispatch 使用一个 receiver/effect helper。
- [ ] Journaled mode 每次调用现有 prepare，其他 mode 不重复 lease/policy 检查。
- [ ] 增加 fast-hit、revalidate、journal-slow-path instrumentation。
- [ ] 添加 nested epoch、Destroy、reload、write denied、journaled write 的聚焦测试代码。
- [ ] 运行 `git diff --check` 和架构静态检查，不运行 UE 全量构建。
- [ ] 提交 `perf(runtime): fuse generated host call frames`。

## P56.3 Lifecycle hot result

    float DeltaSeconds,
