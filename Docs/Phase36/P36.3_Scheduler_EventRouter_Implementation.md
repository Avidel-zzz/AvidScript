# P36.3 Scheduler 与 EventRouter 私有策略

状态：Done

## 实现

- 新增 `Private/Session/AvidScriptRuntimeScheduler`，保存唯一 non-owning active runtime 执行视图。
- 新增 `Private/Session/AvidScriptRuntimeEventRouter`，只依赖 Scheduler，不重复缓存 runtime 指针。
- Session 在成功 owner swap 后 attach，新候选失败时不触碰 active view；Stop/旧实例释放前 detach。
- 热重载不伪造 UE `EndPlay`：候选启动成功后替换并直接卸载旧实例；真实 EndPlay 只由 Component/World 生命周期触发。
- Tick 与 Event 强制通过 Scheduler/EventRouter，架构脚本禁止恢复 `LiveRuntime->Tick/DispatchEvent` 直调。
- Scheduler 只检查是否 attach；Running/Faulted/Stopped 仍由 Runtime 状态机判定，避免热路径重复分支。

## 文件拆分

- `AvidScriptWasmReload.cpp` 只保留 manifest 与 WASM 文件校验。
- `Private/Session/AvidScriptRuntimeSession.cpp` 独立承担 Session/reload transaction。
- `AvidScriptWasmReloadTypes.h` 只声明 manifest/result/loader 类型。
- `AvidScriptRuntimeSession.h` 成为 Session 公共声明 owner。
- `AvidScriptWasmReload.h` 保留为兼容 umbrella，避免一次性破坏 Editor 与旧测试 include。
