# P36.1 Runtime Session 与 Reload Transaction

状态：Done
实现提交：`1136e3e`

## 实现

- 新增 `FAvidScriptRuntimeSession` 与 `FAvidScriptRuntimeSessionSnapshot`。
- 旧 `FAvidScriptWasmReloadSession` 保留为兼容别名。
- 增加统一的 `LoadEmbeddedSmoke`、`Tick`、`DispatchEvent`、`StopAndUnload` API。
- Reload 改为候选 runtime 先 Load/Validate/Begin；候选 Begin 失败时卸载候选并保留旧 runtime。
- `StopAndUnload` 只执行一次 EndPlay，并统一释放 runtime 与 manifest。

- 初始实例进入 Running。
- 候选 `avid_on_begin_play` 触发 `unreachable` trap。
- reload 被拒绝并记录 rejected count。
- 原实例仍是 active module，且后续 Tick 成功。
- StopAndUnload 后 snapshot 回到 Empty。
