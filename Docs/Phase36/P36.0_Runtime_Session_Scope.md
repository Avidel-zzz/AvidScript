# P36.0 Runtime Session 范围

状态：Done

## 目标

- 用 `FAvidScriptRuntimeSession` 统一持有 active runtime、manifest、host context、生命周期与 reload 计数。
- `UAvidScriptComponent` 与 `UAvidScriptWorldSubsystem` 不再直接持有 `FAvidScriptWasmRuntimeInstance`。
- 候选模块先完成 Load、ABI/Export 校验和 `BeginPlay`，成功后再提交 owner swap。
- Session snapshot 是外部唯一可读取的运行状态；组件统计只用于观测，不参与决策。

## 边界

当前事务保证的是 active runtime 的可用性：候选 `BeginPlay` trap 时旧 runtime 保持 Running 并可继续 Tick。它不承诺回滚候选脚本在 trap 前已经写入的任意 UE 世界副作用；完整状态迁移/补偿协议留给后续 reload state phase。

## 设计约束

- VM backend 与 WAMR 资源仍只属于 `AvidScriptVM`。
- typed UObject 操作仍只属于 `AvidScriptBindings`。
- Session 只负责 Runtime 组合、生命周期和 reload transaction。
- 不允许通过新增兼容 bool 恢复第二套生命周期状态。
