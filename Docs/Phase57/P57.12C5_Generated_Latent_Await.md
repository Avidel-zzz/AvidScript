# P57.12C5 生成式 UE Latent Await 闭环

## 状态

实现与产品门禁完成，正在冻结 clean candidate 架构证据。

P57.12C5 让满足冻结合同的 UE latent UFUNCTION 从 Reflection 直接生成 C# `FooAsync`，并复用
P57.12C1-C4 的 Session-owned Continuation、active/prepared 事务和 activation liveness fence。
首个已验证 API 是 `UKismetSystemLibrary.Delay`，实现没有按 `Delay` 函数名增加 VM 分支。

## C# 使用方式

```csharp
[UnmanagedCallersOnly(EntryPoint = "avid_on_begin_play")]
public static async void BeginPlay()
{
    UE.Self.SetActorScale3D(new FVector(1.0f, 1.0f, 1.0f));
    await UKismetSystemLibrary.DelayAsync(0.25f);
    UE.Self.SetActorScale3D(new FVector(1.25f, 1.25f, 1.25f));
}
```

完整样例位于 `Samples/CSharp/LatentGameplay`。

## Descriptor schema v12

Editor policy 识别 `Latent`、`LatentInfo` 与可选 `WorldContext` metadata，并只接受：

- Blueprint callable/pure、非 editor-only、非 delegate/network/custom-thunk；
- `void` 返回；
- 隐藏参数严格为 `FLatentActionInfo`，WorldContext 为可接收当前 UWorld 的对象参数；
- 公开参数不含 ref/out、delegate 或额外 `FLatentActionInfo`；
- completion-only，不把异步 payload 伪装成同步返回值。

隐藏参数不会进入公开 C# 参数或 Guest ABI。descriptor 冻结其名称、`latent_process_event` dispatch、
`continuation_producer` reload effect、`Async` 脚本名，以及末尾追加 callback `i32`、返回 token `i64`
的 import 签名。selection/package identity 同时绑定隐藏参数身份。

普通 package 继续使用原 schema；只有包含 latent binding 时提升到 v12。schema 11 delegate event
manifest provenance 在 v12 中继续保留，Build resolver 与 Runtime reload 都校验
`delegate_event_count`。

## Runtime 事务

prepared codec program 在加载期缓存 UFunction、隐藏 property 指针、公开参数 codec 和 callback
argument offset。每次调用执行：

1. 解码公开参数；
2. `BeginLatent(callbackId)` 分配 generational token 与独占 proxy；
3. 注入 `FLatentActionInfo` 和当前 World；
4. `ProcessEvent`；
5. `CommitLatent(token)` 确认 UE manager 已注册或已同步完成；
6. 返回 token，后续 completion 只进入 Session ready queue。

任一步失败都由 scope guard 调用 `AbortLatent`。UE 的 action 删除是延迟的，proxy 会先 disarm，
action 在下一次 manager pass 被真正删除，因此不会迟到重入 Guest。candidate discard、reload 替换、
owner generation 失效、World teardown 和 `EndPlay` 继续复用 C4 的整 lane 失效语义。

## C# 编译链

renderer 为受支持的 latent binding 生成：

- 带 `[AvidLatent(module, import)]` 的 `public static AvidDelayAwaitable FooAsync(...)`；
- 返回 `long` 且末尾带 compiler callback id 的私有 `DllImport`；
- 不包含隐藏 UE 参数的公开 facade。

Roslyn Semantic 只信任生成 reference source 中的 `[AvidLatent]`，用户源码伪造 marker 会被拒绝。
await site 使用 descriptor 产生的 module/import identity；Guest 根据实际使用的 producer 动态选择 import，
按公开参数顺序降低值，再追加 compiler callback。没有使用的 built-in continuation import 不会进入 WASM。

## 失败与安全验证

- profile regeneration 与直接 descriptor 生成复用同一 latent projection；
- Runtime 独立核对活动 UFunction metadata，隐藏字段篡改不能激活；
- 无 World、无 latent host、无法 reservation 或没有注册 action 时 fail closed；
- `ProcessEvent` 已注册但 commit 被拒绝时自动 abort；
- abort action 在下一 manager pass 删除，callback 保持 0 次；
- 每个 token 独占 callback target，单 token 取消不影响其他 action；
- prepared promotion/discard 与 teardown 已由 C5A producer core 覆盖。

## 当前边界

- 生成 C# facade 当前只开放静态 Blueprint Function Library latent；Runtime executor 已支持 instance
  receiver ABI，但复杂 receiver facade 留待后续类型扩展；
- 公开参数当前只开放 public/storage 类型一致的单 cell value：首批包括 `float`、整数等；
- bool、enum、UObject、USTRUCT、string、array、ref/out、delegate payload 暂时 fail closed；
- 不支持 latent completion payload、多执行输出 pin、取消句柄映射或进度回调；
- zero-spill async 限制仍保持，普通 local 不能跨 await；
- 本阶段没有更新性能 benchmark，`P57-D06-ControlledLeadership` 继续保持 `Fixing`。
