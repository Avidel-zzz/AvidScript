# P57.11B3 通用数组 Value Capability 实施计划

**目标：** 让符合安全类型合同的一维 `TArray<T>` 自动进入 schema、生成 C# `T[]` facade、
prepared dynamic executor 和 WAMR/Wasmtime Runtime，覆盖函数全方向、属性读写与显式释放，
不增加逐 API wrapper。

**架构：** schema v10 通过 `element_type_id` 复用统一类型图；每个 Runtime Session 持有 bounded
array capability heap；C# 编译器使用共享 length/load/store/release intrinsic；Bindings 负责
类型 codec 与事务输出，VM backend 只实现通用静态 host ABI。

## 全局约束

- 源码版 UE5.8 固定为 `C:\UnrealEngine`，禁止 clean Editor target；
- 面向人阅读的文档使用中文；
- 只暂存本阶段拥有的文件，三项用户受保护改动不得提交；
- 功能组完成后统一构建、测试与审查，非阻塞问题集中处理；
- 不为测试类、函数名、ordinal 或项目 API 增加生产特判；
- 未产生新数组 benchmark 前，不外推 scalar/Puerts 数据。

## Task 1：共享 Value Capability 与 bounded array heap

- [x] 新增进程唯一 `FAvidScriptValueCapability` allocator，并让 UTF-8 heap 复用，防止跨 heap token 冲突。
- [x] 新增 session-owned array heap，保存 type id、count、stride、alignment 与 canonical bytes。
- [x] 限制 `4096` elements、`1 MiB` payload、`65535` slots，并对所有 size/index 运算做溢出检查。
- [x] 实现 reserve/publish/resolve/read/write/release/reset 与可观测统计。
- [x] 覆盖跨 session、reset、伪造/stale token、越界、错误尺寸、预算耗尽和重复 release。
