# P57.10 Prepared Reflection Invocation Cell 实施计划

> **执行约束：** 阶段内自动推进；遵循 `AGENTS.md` 的集中 Gate 流程，不进行逐小任务 UE 构建或重复复审。

**目标：** 把 Adaptive Semantic 反射描述编译为不可变 typed invocation cell，并将通用 prepared 覆盖扩展到 scalar、property、FVector 与 UObject 形态。

**架构：** Bindings 拥有 shape compiler 和 UE invocation cell，Runtime 拥有 capability、guest memory 与 callback proof，VM 只提供固定签名 prepared callback。失败条件保留 strict ProcessEvent fallback，成功热路径不再进行 ordinal/plan array lookup。

**技术栈：** Unreal Engine 5.8 C++、UFunction/FProperty、Wasmtime 45 typed host C API、C# to WebAssembly、PowerShell benchmark contracts。
