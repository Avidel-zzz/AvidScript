# P57.12A 通用 Delegate/Event Subscription 实施计划

状态：已完成

## 范围

本批实现 `self` 动态多播委托的 descriptor 驱动闭环。接口以 `profile schema 8`、`descriptor schema 11`、生成式 `[AvidEvent]` 合同和 session-owned subscription owner 为准。

## 工作组

- [x] A：审计现有 profile/descriptor/facade 与 runtime lifecycle，冻结接口和风险边界。
- [x] B：实现 profile schema 8、delegate selection/policy、descriptor schema 11、canonical hash 和 slice preservation。
- [x] C：实现生成 facade contract、Roslyn 事件语义投影和类型化 WASM export lowering。
- [x] D：实现 prepared delegate codec、UE bridge UFunction、session-owned subscription lifecycle 和 runtime export dispatch。
- [x] E：增加真实动态多播 fixture，覆盖广播、重载、解绑、重入和非法签名。
- [x] F：一次集中代码审查与修复，一次统一 dotnet/UBT/Automation Gate。
- [x] G：更新中文实现文档、README/phase tracker，提交并推送 `main`。

## 非目标

- 不实现 C# `event +=`、lambda 或 closure；
- 不实现单播委托替换；
- 不实现任意 UObject 源的脚本动态订阅；
- 不为具体 UE 事件手写 API；
- 不在中途重复执行 Editor 构建或全量 Automation。

## 风险控制

- 运行时生成桥接 UFunction 仅在 game thread 发生，并按签名缓存；
- 事件 plan 在加载阶段预解析，广播热路径只做固定 codec 和 prepared export call；
- guest callback 内同步重入按非致命 `reentrant_operation` 诊断丢弃；
- 候选热重载订阅先准备、后提交，失败不触碰旧订阅；
- 不执行 Editor Target clean；受保护的既有本地改动不进入本阶段提交。
