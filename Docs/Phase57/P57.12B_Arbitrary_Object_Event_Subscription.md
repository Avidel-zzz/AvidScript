# P57.12B 任意 UObject 动态多播事件订阅

## 状态

P57.12B 已完成。AvidScript 的 Profile 授权动态多播事件不再只能绑定脚本宿主 `self`：
C# 可以把当前 Runtime Session 已授权的任意兼容 `UObject` facade 作为事件源，取得不透明
`AvidSubscription`，并在业务生命周期中显式取消。事件仍由 Reflection、descriptor 与生成器驱动，
没有增加按事件手写的 C++ wrapper 或 VM switch。

## C# 使用方式

事件 handler 合同保持与 P57.12A 兼容；新增的是强类型订阅 facade：

```csharp
using AvidScript;

public static class PickupScript
{
    [AvidTransient]
    private static AvidSubscription _subscription;

    public static void BeginPlay()
    {
        AActor source = UE.Self;
        _subscription = AvidSubscriptions.OnPickedUp(source);
    }

    [AvidEvent(AvidEvents.OnPickedUp)]
    public static void OnPickedUp(AActor instigator, int itemId, float value)
    {
        UE.Self.ApplyPickup(itemId, value);
    }

    public static void StopListening()
    {
        _subscription.Cancel();
        _subscription = default;
    }
}
```

`AvidSubscriptions.<事件名>` 的 source 参数由 descriptor owner class 生成，错误类型无法通过
C# 编译。token 使用 64 位不透明身份，只公开 `IsValid` 与 `Cancel()`。持久静态字段必须标记
`[AvidTransient]`，因为成功热重载会使旧 token 失效，并由候选脚本的 `BeginPlay` 重建订阅。

脚本可以提前取消，但不需要依赖 Guest `EndPlay` 做最终清理：Session 在 `EndPlay`、Unload、
HostContext 切换与 teardown 时统一解绑。

## 生成与执行链

1. Profile 继续用 `include_events` 显式授权动态多播属性，descriptor 为每个事件保留稳定 ID、
   owner class、ordinal、参数 ABI shape 与最大 8-cell codec。
2. C# renderer 生成 `AvidSubscription`、`AvidSubscriptions` 与两个共享 Runtime import；新增事件
   只增加 descriptor 数据和强类型薄入口。
3. Roslyn semantic 阶段拒绝把 subscription token 纳入热重载状态迁移；只有
   `[AvidTransient]` 字段可以保存 token。
4. `event_subscribe(slot, generation, ordinal) -> i64` 进入 Runtime Session；WAMR 与 Wasmtime
   共用同一 host contract。
5. Runtime 从当前对象 registry 解析 handle，并验证 session capability、world、事件 owner class
   与当前 event catalog。
6. 广播热路径通过 bridge-token 哈希索引直接取得 prepared event/export，不查找事件名、
   UFunction 名或项目 API wrapper。

## 生命周期与安全边界

- `self` 默认属于当前 session；其他 source 必须是 session owned 或 borrowed capability；
- source 必须来自当前 registry，slot/generation 过期、伪造 token 和重复取消均非致命失败；
- session 已知 world 时，world 为空或跨 world 的对象拒绝订阅；
- source 必须是 descriptor 记录 owner class 的实例或派生类；
- 候选 Runtime 在 `BeginPlay` 创建的订阅先进入 prepared 集合，候选失败会整体丢弃并保留旧
  Runtime、旧订阅和旧 token；成功提交后旧 token 失效；
- delegate 回调内取消当前订阅是安全的；回调使用稳定副本，数组重排不会产生悬空引用；
- 同步嵌套 Guest 操作继续按 `reentrant_operation` 非致命丢弃策略处理。

## 当前范围

本阶段只开放 Profile 授权且 descriptor 可表达的动态多播事件，不等于自动开放 UE 中所有
delegate。事件参数仍限 scalar、enum、UObject handle 与已支持的固定宽度结构体，合计最多 8 个
WASM ABI cell；string、array、ref/out、单播 delegate、C# `event +=`、lambda/closure 尚未支持。

P57.12B 没有新增性能 benchmark。当前性能结论继续引用 P57.11D、P57.11B1 与 P56 的冻结证据；
P57-D06 Wasmtime/V8 P95 controlled leadership 仍为 `Fixing`，没有因为功能完成而改写。
