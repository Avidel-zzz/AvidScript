# P57.0 Adaptive Semantic 性能合同

## 1. 目标

Phase 57 在不降低语义覆盖、不手写逐 API wrapper、不修改正式 workload 的前提下，
清零 Phase 56 转交的六项性能债务。优先主线是把反射描述符编译为
Adaptive Semantic prepared call-site，并在安全的 native UFUNCTION 上达到领先
Puerts Reflection 的正式门禁。

## 2. 冻结基线

`Docs/Phase56/P56.5_Fused_Call_Frame_Benchmark_Evidence.json`

## 3. 正式反射路径

正式 comparator 新增明确身份：

```text
lane_id = avidscript_wasmtime_adaptive_semantic
binding_invocation_policy = adaptive_semantic
```

`AdaptiveSemantic` session policy 是项目级统一授权。默认 policy 保持
`SemanticProcessEvent`，现有项目不会静默改变语义。

适合 native fast 的结构化 plan 进入 typed import + `UFunction::Invoke`；不满足资格、
运行时 guard 失败或失效的调用进入 strict `ProcessEvent` fallback。正式 evidence
必须分别记录：

- adaptive native plan/hit；
- strict fallback plan/hit；
- runtime guard reject；
- generated S1 hit/fallback；
- logical operation 和 host crossing count。

正式 eligible scalar lane 要求：

```text
adaptive_native_hit_count == logical_operation_count
adaptive_process_event_fallback_count == 0
generated_s1_hit_count == 0
```

## 4. 禁止修改

Phase 57 不得通过以下方式让结果变绿：

- 删除、替换或修改 controlled-runtime 的 12 个 kernel 字节；
- 修改正式 workload、seed、oracle、operation count 或 host-call count；
- 修改 warmup/timed/process 数量或 percentile 算法；
- 只选取有利进程或丢弃正确性失败 observation；
- 把 generated S1、Puerts Static 或 Native C++ 记为 adaptive reflection；
- 隐藏 fallback、trap、错误、reentrant unload 或 lifecycle failure；
- 提高六项阈值；
- 在 evaluator 中按函数名、fixture 名或候选 commit 特判；
- 用 benchmark-only backend 配置替代产品 Runtime 配置。

## 5. 公平性补充

正式 profile 保持冻结。另增加不替代 headline 的 equal-iteration diagnostic：

```text
8k / 64k / 256k
```

AvidScript Adaptive 与 Puerts Reflection 使用相同每 sample logical operations，报告
outer dispatch 摊销敏感度。该诊断用于解释结果，不能替代正式 gross gate。

## 6. 阶段关闭条件

Phase 57 只有在以下条件全部成立时才能关闭：

- 六项转交门禁按原阈值全部通过；
- 所有 observation 正确，host/logical operation count 匹配；
- strict fallback 覆盖 Blueprint、event、RPC、interface、script 和失效场景；
- Automation 的 `found == completed == succeeded >= 317` 且 `failed == 0`；
- clean candidate commit/tree 与 raw evidence、compact evidence、attestation 一致；
- README 和中文实现报告只引用 Phase 57 正式证据。

任一独立轴仍为红色时，Phase 57 保持打开并记录具体债务，不能发布“全面领先”。
