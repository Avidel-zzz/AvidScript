# P57.4 Prepared Generated Call Cell

## 1. 目标

本批次清理 Generated S1 的固定调用成本，并在同一份正式样本中复验
Adaptive Semantic。冻结的 ABI、workload、oracle 与性能阈值均未改变：

- `s1_scalar_ns <= 25.0`；
- `s1_property_ns <= 50.0`；
- `semantic_vs_puerts_reflection <= 0.80`。

实现仍由通用反射描述生成，不为单个 UE API 编写 wrapper。

## 2. 调用链重构

### 2.1 快速安全令牌

Generated Binding lease 在解析成功时缓存注册项地址、活动标记和 registry revision。
热路径只读取轻量令牌；注册表发生替换、注销或 reload 后 revision 改变，旧 lease 会
失效并重新解析，不延长 UObject 或模块的生命周期。

### 2.2 Prepared Wasmtime call cell

Wasmtime callback 在 import 首次准备时解析 shape、目标与生成入口，并把它们保存为
prepared call cell。后续调用直接进入已准备目标，避免重复进行 map 查询、shape 分派
和可变参数包装。

### 2.3 Trusted generated thunk

生成器同时输出 checked thunk 与 trusted prepared thunk：

- checked thunk 负责首次调用和普通入口的完整 class/shape 校验；
- Runtime 只有在 `ExpectedClass` 与绑定描述完全一致后才缓存 trusted 指针；
- trusted thunk 使用生成期确定的 `static_cast` 和定型参数调用；
- revision、活动标记或生命周期验证失败时不会进入 trusted thunk。

因此，快路径删除的是重复证明，不是安全约束。

### 2.4 Headless 生成入口

Editor 模块新增通用控制台命令：

```text
AvidScript.GenerateBindings <descriptor>
```

它委托既有 `FAvidScriptEditorGeneratedBindingService`，支持在 NullRHI/Unattended
候选工程中按声明的 `generated_source_package_hash` 重生成项目绑定。候选验证遵循：

```text
重链接公共 ABI 消费者 -> 启动生成器 -> 重生成 -> 再次重链接 -> 运行基准
```

这避免旧项目模块按旧结构读取新插件 ABI，也避免误用 runtime slice descriptor。

## 3. 安全不变量

- UObject class proof 仍在 prepared cell 建立前完成；
- 注册项被替换或注销后，revision 会使旧 cell 失效；
- reload 后旧 export、lease 与 prepared pointer 不可复用；
- 生成包的 descriptor、source package 与产物哈希可追溯；
- 反射 fallback 和 reject 计数在目标样本中必须为零；
- C# 公共 API 与现有 guest ABI 不变。

## 6. 路径完整性

正式结果额外验证了 300 个目标 lane 样本：

- host import 命中数等于 workload 预期；
- scalar generated hit 等于 iterations；
- property generated hit 等于 `2 * iterations`；
- fallback、reject、semantic 和 data-command 计数为零；
- fused fast hit 等于 `expected_hits - 1`，revalidate 恰为 1；
- call-site prepare 为 scalar 1 次、property 2 次；
- journal slow path 为零。
