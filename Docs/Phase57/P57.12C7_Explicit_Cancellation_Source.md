# P57.12C7 显式取消源闭环

## 目标

P57.12C7 把 C6D 冻结的取消设计落为可供游戏脚本直接使用的能力。脚本可以在 `BeginPlay`
创建一个 Session-owned 取消源，把同一 token 绑定到多个 `DelayAsync`、对象加载或生成式 latent
await，并在 `EndPlay`、状态退出或业务中断时统一取消。实现不依赖具体 UFUNCTION 名称，也不为
每个 UE API 生成 Runtime switch。

## C# 使用方式

```csharp
private static AvidCancellationSource LifetimeCancellation;

[UnmanagedCallersOnly(EntryPoint = "avid_on_begin_play")]
public static async void BeginPlay()
{
    LifetimeCancellation = AvidCancellationSource.Create();

    await UKismetSystemLibrary.DelayAsync(0.25f)
        .WithCancellation(LifetimeCancellation.Token);

    UE.Self.SetActorScale3D(new FVector(1.25f, 1.25f, 1.25f));
}

[UnmanagedCallersOnly(EntryPoint = "avid_on_end_play")]
public static void EndPlay()
{
    LifetimeCancellation.Cancel();
    LifetimeCancellation.Release();
}
```

推荐生命周期结束时使用 `Cancel()` 后接 `Release()`。`Cancel()` 负责终止尚未 dispatch 的 producer；
`Release()` 只移除 source 与 continuation 的关联，不隐式取消业务。

## ABI 与分层

新增四个固定框架 ABI：

| import | 签名 | 责任 |
| --- | --- | --- |
| `continuation_cancel_source_create` | `()I` | 创建独立的 i64 source token |
| `continuation_cancel_source_cancel` | `(I)i` | 同步取消 source 绑定的 Pending/Ready continuation |
| `continuation_cancel_source_release` | `(I)i` | 释放 source 并解除剩余绑定 |
| `continuation_bind_cancel` | `(II)i` | 原子绑定 source token 与新建 continuation token |

VM 层只负责通用 ABI 编目与 WAMR/Wasmtime 分派；Runtime 把调用转交给
`FAvidScriptSessionContinuations`；C# Semantic 只识别可信生成 facade 中的
`WithCancellation(AvidCancellationToken)` marker；Guest lowerer 在编译期发出 schedule 与 bind。

这四个 import 是异步框架基础设施，不是 UE API wrapper。任意通过 descriptor 生成的 completion-only
latent UFUNCTION 都复用同一条路径。

## 生命周期与竞态规则

- continuation token 与 cancellation source token 使用不同的高位 kind，错误互换会 fail closed。
- 每个 Session 最多持有 1024 个 source 和 4096 条绑定，避免脚本造成无界增长。
- source 与 continuation 必须来自同一 active/prepared lane 和 activation serial。
- source 已取消后再绑定：新 producer 会立即取消，bind 返回已处理，async 链静默终止。
- source 无效、跨 lane 或超过绑定上限：新 producer 会先被回收，随后 bind 失败并触发 Guest fail closed。
- Pending/Ready 与 source cancellation 竞争时取消获胜；Dispatching 已开始时完成获胜。
- prepared commit 会一起提升 source、绑定和 continuation；discard、reload、owner 失活与 teardown 会统一回收。
- token 表达式在 host schedule 之前求值，求值失败不会留下未绑定 producer。

## 当前边界

本阶段完成的是显式取消源，不包含 C6D 设计中的 completion payload。`AvidContinuationStatus.Cancelled`
已冻结数值 `3`，但正常 source cancellation 不恢复 async segment，因此不会向脚本投递取消回调。
latent ref/out、返回 payload、delegate payload、schema v13 result slot 和
`IAvidScriptLatentCompletionProvider` 仍属于 P57.12C8，不能宣称已经可用。

P57-D06-ControlledLeadership 仍为 `Fixing`。取消操作位于生命周期冷路径，本阶段没有修改或放宽
既有 Wasmtime/Puerts 性能门禁。
