# P57.12A 通用 UE 动态多播事件订阅

## 状态

P57.12A 已完成。AvidScript 现在可以从 UE Reflection 与项目 Binding Profile 生成事件合同，
把 C# 强类型 handler 编译为稳定 WASM export，并在 Runtime Session 内自动完成订阅、热重载
替换与解绑。新增事件不需要为每个 API 编写 C++ wrapper 或 VM switch。

## C# 使用方式

项目 Profile 在目标类规则中通过 `include_events` 显式选择动态多播属性。生成 facade 后，
脚本使用生成的事件常量声明 handler：

```csharp
using AvidScript;

public static class PickupScript
{
    [AvidEvent(AvidEvents.OnPickedUp)]
    public static void OnPickedUp(AActor instigator, int itemId, float value)
    {
        UE.Self.ApplyPickup(itemId, value);
    }
}
```

handler 必须是 `public static void`，参数必须与生成合同完全一致。编译器拒绝未知事件、重复
handler、错误签名、泛型方法和实例方法。P57.12A 不开放 `event +=`、lambda 或 closure。

## 生成与执行链

1. Profile schema 8 解析 `include_events` / `exclude_events`，只接受显式选择的
   `FMulticastDelegateProperty`。
2. Descriptor schema 11 在根对象发布 `delegate_events`，稳定身份覆盖 owner、member、参数
   类型和引用类型；canonical slice/regeneration 保留同一事件表。
3. C# facade 生成公开的 `AvidEventAttribute`、`AvidEvents` 常量和内部签名合同。
4. Roslyn semantic schema 9 校验 handler，并把它作为 reachability root；Guest lowering 生成
   `avid_on_delegate_<stable-id 前 16 位>` export。
5. Bindings 在加载阶段把最多 8 个 ABI cell 的参数编译为不可变 prepared codec；对象参数以
   borrowed handle 进入 Guest，并在回调返回后释放。
6. Runtime 为已实现 export 创建动态 UFunction bridge。未实现 handler 的事件不会订阅，也
   不产生广播开销。

## 生命周期与故障语义

- 订阅 owner 隶属于 `FAvidScriptRuntimeSession`，只在 game thread 绑定与解绑；
- 候选加载先准备新订阅，成功后一次提交并移除旧订阅；准备失败保留旧会话与旧订阅；
- HostContext 改变时旧源先解绑，再绑定新源；`EndPlay`、Unload 和显式 teardown 都会清空；
- Guest 回调中的同步重入返回非致命 `reentrant_operation`，本次事件被丢弃但 Runtime 继续运行；
- 稳定 ID 对应的动态 bridge 可跨热重载复用，兼容性按参数 ABI shape 比较，不依赖 UE 重挂接
  后的 class-relative property offset；真正的签名冲突仍失败关闭。

## 当前参数范围

事件参数当前支持 scalar、enum、UObject handle 与已支持的固定宽度结构体，合计最多 8 个
WASM ABI cell。不支持 string、array、ref/out、返回值、嵌套委托或 lambda。事件源固定为脚本
宿主 `self`；任意 UObject 源与显式 subscription token 进入 P57.12B。

## 阶段产出与下一步

主体实现候选 `7fda6b5` 新增 60 个文件变更、4836 行新增；生命周期修复候选 `54a573c`
补齐事务替换与动态 bridge ABI-shape 兼容。完整机器可读证据见

小型游戏 Demo 闭环。
