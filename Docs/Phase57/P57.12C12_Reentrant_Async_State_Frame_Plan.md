# P57.12C12 可重入 async 状态帧方案

## 状态

- 阶段组：`P57.12C12`
- 状态：已冻结并实现，等待阶段末证据归档
- 目标：让受控 C# `async/await` 在暂停后保留局部值，并继续执行 UE 游戏逻辑
- 非目标：CLR `Task` Runtime、任意 awaiter、异常展开、字符串或容器 spill
- 性能债：`P57-D06-ControlledLeadership` 继续保持 `Fixing`

## 问题

P57.12C3 至 C11 已经能够把 `async void` 生命周期导出切成编译器拥有的 CPS
segment，但普通 local 不能跨越 await。脚本要么把状态提升为静态字段，要么把逻辑压缩到
单个 segment；这不符合常规游戏脚本的书写体验，也限制了多个顺序 await 的实用性。

## 冻结合同

### 语义模型

1. Semantic schema 从 `14 / 1.14` 升级到 `15 / 1.15`。
2. 每个 await 独立计算活跃 local，而不是为整个方法建立并集帧。
3. 只有声明 segment 不晚于当前 await、且最后一次使用在后续 segment 的值进入状态帧。
4. 帧槽按 symbol id 确定性排序；每个 await 最多 64 个槽。
5. schema 14 继续可读，但不得携带状态帧。

### Guest 与 Host ABI

新增两项编译器内建 static import：

```text
env.continuation_state_store(i64 token, i32 address, i32 bytes) -> i32
env.continuation_state_read(i64 token, i32 address, i32 bytes) -> i32
```

WAMR 与 Wasmtime 使用同一 `(Iii)i` 签名。每个暂停边界最多发生一次整帧 store，
每个恢复边界最多发生一次整帧 read；禁止按字段增加 host import。

### 类型与容量

- 单帧上限：4096 字节。
- 小帧使用 `TInlineAllocator<128>`，避免常见状态的单独堆分配。
- 支持递归固定布局 scalar、enum、固定 `USTRUCT` 与对象 capability wrapper。
- `string`、数组、ref-like、动态布局或无法证明有界的值 fail closed。
- Guest 通过统一 data layout 生成 synthetic frame type，不为 FVector、Actor 或项目 API
  写专用状态代码。

### 生命周期

- 状态属于 Session continuation entry，而不是 VM 全局表。
- store 只允许对当前 lane 中尚未保存状态的新 entry 成功一次。
- read 只允许在匹配 continuation token 的回调分发期间成功一次。
- cancel、调度拒绝、热重载回滚、owner/World 失效、teardown 与回调完成都会回收状态。
- 若 store 失败，Guest 取消已经创建的 token 后 trap；若 read 失败，恢复立即 trap，
  不执行后续游戏副作用。

## 示例验收

ActorLifecycle 与项目模板必须能够表达以下结构：

```csharp
FVector offset = new FVector(0.0f, 0.0f, 25.0f);
await AvidContinuations.NextTickAsync();

AvidLoadedObject loaded = await AvidAssets.LoadObjectAsync(
    "/Engine/EngineMeshes/Cube.Cube");
await AvidContinuations.NextTickAsync();

if (!loaded.IsValid)
{
    return;
}
UE.Self.AddActorWorldOffset(offset);
```

该示例同时验证固定结构体、对象 capability、三个 await、结果 guard 与跨边界 local 恢复。

## 后续

C13 优先扩展 async 控制流，而不是继续增加 import：局部赋值/分支合流、循环与更完整的
结构化控制流需要在同一 per-await liveness 和 bounded frame 合同上演进。字符串、数组、
异常与 `try/finally` 必须另立所有权方案，不能借 C12 的固定字节帧静默放行。
