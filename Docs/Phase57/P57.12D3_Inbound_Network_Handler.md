# P57.12D3 入站 RPC 与 RepNotify C# Handler 完成报告

## 阶段结论

P57.12D3 已完成 UE 入站网络事件到 C# WASM 游戏逻辑的首个闭环。Binding Profile 可通过
`include_handlers` 显式选择项目 `AActor` / `UActorComponent` 上的 native RPC 或 RepNotify
`UFUNCTION`；生成器将其投影为 `AvidEvents` 常量和确定性 callback descriptor，Runtime 再按
`(UFunction, UObject)` 把 UE `ProcessEvent` 路由到当前 Session 的 C# export。

这条链路不需要按项目 API 手写 Host import、C++ wrapper 或轮询 replicated property。UE 继续拥有
NetDriver、callspace、复制条件、连接差异发送和 RepNotify 触发时机，AvidScript 只接管被显式授权对象的
本地函数实现入口。

## 已实现合同

- C# Profile schema 9 增加 class-level `include_handlers`。
- Binding descriptor schema 17 复用既有 callback ABI，以 `delegate_kind` 区分
  `multicast`、`network_rpc` 与 `rep_notify`。
- RPC 的 network mode/reliability、RepNotify 的关联 property 均进入 canonical identity、selection
  hash 与 package hash，篡改后失败关闭。
- 生成式 C# 继续使用 `[AvidEvent(AvidEvents.X)]`，没有新增 Host import 或 Runtime AST。
- private UFunction hook registry 每个 UFunction 只保存一次原 thunk，并以 `(UFunction, UObject)`
  隔离不同 Session/对象路由。
- `Prepare` 只构建 descriptor、codec 与 VM export；`Commit` 才在游戏线程原子切换 active route。
- C# export 缺失、对象不匹配、route 未激活或已卸载时执行原生实现；命中 active route 后采用
  `replace` 语义，不再执行原 `_Implementation` / OnRep。
- handler trap 或首批同 Session 重入会 fault/失败关闭，不在脚本可能已产生副作用后回退原实现，
  从而避免业务逻辑双重执行。
- EndPlay、reload 与 Session teardown 会先移除对象 route；最后一个 route 消失且 hook 所有权仍属于
  AvidScript 时恢复原 native pointer。

## C# 使用方式

Profile 显式选择 handler：

```json
{
  "class_path": "/Script/AvidScriptEditor.AvidScriptBindingRuntimeNetworkTestActor",
  "include_handlers": [
    "ServerSubmitValue",
    "OnRep_ReplicatedScore"
  ],
  "writable_properties": [
    "ReplicatedScore"
  ]
}
```

C# 直接编写游戏逻辑：

```csharp
[AvidEvent(AvidEvents.ServerSubmitValue)]
public static void HandleServerSubmitValue(int value)
{
    AAvidScriptBindingRuntimeNetworkTestActor self = UE.Self;
    self.ReplicatedScore = value;
}

[AvidEvent(AvidEvents.OnRep_ReplicatedScore)]
public static void HandleReplicatedScoreChanged()
{
}
```

可读样例位于
[InboundNetworkHandlers](../../Samples/CSharp/InboundNetworkHandlers/README.md)。该样例已经通过真实生产
C# profile 构建，WASM SHA-256 为
`09e87cbe4a05d52c07ce3b6095593193de5bf1d5e02498a5552303e7c148b549`。

## 首批支持范围

- native、非 static 的 `AActor` / `UActorComponent` RPC 与 RepNotify UFunction。
- 无 return、ref、out 或 latent 参数。
- 参数沿用 callback ABI 已支持的固定宽度 value/const-ref codec、UObject capability 与固定布局
  USTRUCT codec。
- RepNotify 必须由同 owner 的 `CPF_RepNotify` property 引用；支持零参数与 UE 允许的单个 old-value
  参数。
