# P57.11A Prepared Generic Bridge 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让现有所有 dynamic UFUNCTION import 绑定不可变 prepared target，移除成功路径中的 ordinal/package Dispatch lookup，并把通用 codec executor 从 4400 行入口文件中解耦。

**Architecture:** VM 只拥有 opaque dynamic target 合同；Runtime 复制 VM binding package 并把 target 绑定到 package-owned prepared cell；Bindings 把 descriptor 已验证的 invocation plan 编译为不可变 codec program。旧 artifact 或未绑定 target 继续走 dispatcher fallback。

**Tech Stack:** Unreal Engine 5.8 C++、UFunction/FProperty、Wasmtime 45 C API、C# to WebAssembly、PowerShell architecture contracts。

## Global Constraints

- 使用源码版 UE 5.8：`C:\UnrealEngine`。
- 禁止 clean Editor target。
- 不修改现有 descriptor schema、C# 公共 API 或 dynamic import signature。
- 不按 UFunction 名、fixture 名、benchmark commit 或 ordinal 值选择 prepared 行为。
- VM 不依赖 Bindings/Runtime，Bindings 不依赖 VM backend private implementation。
- 阶段内只处理阻塞性高风险问题；构建、Automation、合同和审查在 A 组完成后集中执行。
- 面向人阅读的文档使用中文。
- 只暂存本计划拥有的文件，保护现有用户修改。
