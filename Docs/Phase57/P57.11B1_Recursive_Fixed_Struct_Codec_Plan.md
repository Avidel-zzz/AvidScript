# P57.11B1 递归固定宽度 USTRUCT Codec 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让由安全固定宽度 child codec 组成的用户 `USTRUCT` 自动进入 schema 9、C# facade 和 prepared dynamic executor，覆盖 value/const-ref/ref/out/return 与 property get/set。

**Architecture:** Editor 产生稳定递归 wire graph；Bindings 在 package load 时把 graph 编译为不可变递归 codec program；C# 使用显式 wire layout 和地址 ABI。Runtime/VM 不认识具体 UStruct 字段，继续承担 capability、guest memory 和生命周期。

**Tech Stack:** Unreal Engine 5.8 C++ reflection、Core Wasm i32 guest-address ABI、C# NativeAOT interop、PowerShell architecture contracts。

## Global Constraints

- 源码版 UE 5.8 固定为 `C:\UnrealEngine`，禁止 clean Editor target。
- 不增加逐 API wrapper，不按 UFunction/fixture/ordinal/benchmark identity 选择 codec。
- schema 2-8 必须兼容；schema 9 identity 包含完整字段图。
- 递归深度上限 8、节点上限 128、wire size 上限 4096 bytes。
- 构建、Automation、性能回归和审查在实现完成后集中执行。
- 面向人阅读的文档使用中文；只暂存本批次拥有的文件。
