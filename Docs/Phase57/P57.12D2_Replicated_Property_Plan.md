# P57.12D2 Replicated Property 与 RepNotify 契约

## 目标

让 C# 通过现有生成式属性 facade 读取项目 replicated UPROPERTY，并只在 authority 上写入；写入成功后使用 UE5.8 Push Model API 标记活动 FProperty 的 RepIndex。属性复制条件、连接选择、差异发送与 native/Blueprint RepNotify 继续由 UE 网络栈负责。

## 本批边界

- descriptor schema 16 为每个 binding 固化 `property_replication` 与 `rep_notify`。
- replicated property 只接受声明于 `AActor` 或 `UActorComponent`、已进入活动 ClassReps 的运行时可见属性。
- getter 在 authority 与非 authority 都可用；setter 必须具备 authority 和宿主写权限。
- direct setter 与 BlueprintSetter 都在成功后调用 `UNetPushModelHelpers::MarkPropertyDirtyFromRepIndex`。
- replicated setter 禁止 Generated S1 和 candidate reload，避免绕过 authority/dirty gate 或产生不可回滚网络副作用。
- `CPF_RepNotify`、RepNotify 函数名与活动 Reflection 必须一致；本地 authority 写入不会伪造 OnRep 调用。

## 非目标

- D2 不用 Tick 轮询属性变化，不把轮询结果冒充 UE RepNotify。
- D2 不把 UE 入站 RepNotify 自动分发到 C# export；该通道与入站 RPC handler 一起进入后续网络批次。
- D2 不复制 `GetLifetimeReplicatedProps` 的条件判断，也不维护第二套 NetDriver/Iris 状态。
- D2 不开放 replicated container、custom delta、FastArray 或动态 subobject 的特殊写语义；类型仍服从既有 descriptor/codec 策略。

## 分层设计

1. `FAvidScriptBindingPropertyReplicationContract` 是 Bindings 的稳定值对象，统一解析 `none/replicated/rep_notify`。
2. Editor property policy 负责 owner、ClassReps、BlueprintSetter 和形状约束。
3. descriptor generator 把复制模式与 RepNotify 名称加入 canonical identity、selection hash 和 package hash。
4. Runtime loader 从活动 FProperty 重新解析合同，并把 FProperty 指针与复制合同放入 immutable invocation program。
5. prepared invocation 在解码和突变前做 authority/candidate preflight，在成功写入后按活动 RepIndex 标脏。

## 失败契约

- `binding_property_replication_contract_mismatch`：descriptor 与活动 FProperty flags、RepNotify 或 ClassReps 不一致。
- `binding_property_replication_owner_invalid`：receiver 不是 Actor/ActorComponent，或组件没有有效 owner。
- `binding_property_replication_authority_denied`：非 authority 尝试写 replicated property。
- `binding_property_replication_reload_effect_unsupported`：候选热重载尝试写入不可逆复制状态。

## 验收门禁

- schema 16 可确定性生成/解析，复制字段篡改 fail-closed。
- authority 可通过 direct setter 与 BlueprintSetter 修改 replicated property，且本地写入不直接调用 RepNotify。
- 非 authority 与 candidate reload 在属性突变前失败。
- C# facade 保持普通属性语法，不增加项目专用 Host wrapper。
- 阶段末统一执行固定 .NET、PowerShell、UE5.8 no-clean build、完整 Automation 与 clean architecture。
