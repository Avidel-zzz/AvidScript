# P57.12C14 嵌套 await Continuation CFG 方案

## 状态

- 阶段组：`P57.12C14`
- 状态：接口冻结，正在实现
- 目标：允许受控 C# async 导出在 `if/else` 与 `for/while/do` 循环体中直接 await
- 性能债：`P57-D06-ControlledLeadership` 继续保持 `Fixing`

## 核心决策

C14 使用编译期 continuation CFG，不在 Runtime 中加入 AST 解释器或通用程序计数器。每个 await
语法点拥有唯一 callback ID 和唯一恢复入口；callback 直接进入该 await 的后继 CFG block。分支未进入
await 的路径可以在当前 WASM 调用中继续执行，循环回边也留在 WASM 内。同一循环 await 在每轮使用
同一 callback route，但每次调度仍获得独立 continuation token，因此状态、取消和 teardown 继续隔离。

## 冻结 Semantic 合同

1. Semantic schema 保持 `15`，semantic version 升级为 `1.17`；`15 / 1.16` 与 `15 / 1.15`
   继续作为只读兼容输入。
2. 现有线性 `reentrant_zero_heap_cps` 产物保持不变；含嵌套 await 的方法使用
   `continuation_cfg` lowering。
3. CFG segment 使用显式终结器：
   - `goto`：一个同步后继；
   - `branch`：一个 bool condition 与 true/false 后继；
   - `await`：一个 producer 和唯一 resume 后继；
   - `return`：无后继。
4. segment ordinal 连续且唯一；方法显式记录 entry segment ordinal。所有目标必须落在同一方法内，
   不可达 segment、缺失终结器、错误 await/terminator 配对均 fail closed。
5. await 仍只接受直接表达式语句或单 local 初始化器；任意表达式内部 await、await 条件、for
   initializer/condition/increment await 继续拒绝。
6. 每个方法最多 16 个 await、64 个 CFG segment；模块最多 64 个 await。结构化语法深度仍为 8。

## 活跃性与状态帧

- 在 CFG 上求标准逆向不动点：`liveIn = use U (liveOut - def)`。
- branch 的 `liveOut` 为两个后继 `liveIn` 的并集；goto 使用单后继；return 为空。
- await 状态帧等于 resume 后继的 `liveIn`，再移除该 await 在恢复点定义的 result local。
- producer 参数与 cancellation token 在暂停前求值，因此计入 await block 的 `use`，但不自动进入帧。
- 局部简单赋值 kill 旧值；复合赋值、自增和自减保持 read/write；循环通过有限 local 集合求不动点。
- 帧布局、64 槽、4096 字节、一次 bulk store/read、token 匹配和回收合同沿用 C12/C13。

## Guest / WASM 合同

- 每个方法生成一个初始导出函数，每个 await callback 生成一个恢复函数。
- 每个函数只 materialize 从其入口经同步边可达的 CFG；遇到 await 时调度 producer、保存状态并 return，
  不沿 resume 边在当前调用中继续。
- 一个函数可以包含不同分支上的多个 await 调度点，但每个 callback route 仍唯一。
- 恢复函数先完成 token 匹配、状态恢复与 typed result 发布，再 branch 到该 await 的 resume segment。
- CFG block ID 由 method、function entry 与 segment ordinal 确定；相同输入必须生成相同 Guest IR/WASM。
- 不新增 Host import、Guest heap state machine、逐 local store/read 或按 UE API 名称分支。

## 代表性脚本

```csharp
public static async void BeginPlay()
{
    int movementCount = UE.Self.IsActorTickEnabled() ? 2 : 1;
    for (int index = 0; index < movementCount; ++index)
    {
        await AvidContinuations.NextTickAsync();
        UE.Self.AddActorWorldOffset(new FVector(10.0f, 0.0f, 0.0f));
    }

    if (movementCount > 1)
    {
        await UKismetSystemLibrary.DelayAsync(0.1f);
    }
    UE.Self.SetActorTickEnabled(false);
}
```

预期：循环 await 恢复后执行移动、increment 和下一轮 condition；循环结束后进入 if。if 为 false 时
同步越过第二个 await，为 true 时暂停并从其后继恢复。`movementCount` 与 `index` 的状态帧由 CFG
活跃性精确计算。
