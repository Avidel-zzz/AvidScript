# P57.12C14 分支与循环内 Await Continuation CFG 完成报告

## 结论

P57.12C14 已完成。AvidScript 的受控 C# `async void` 不再要求所有 await 都位于方法体顶层；
`if/else`、`while`、`do/while` 与 `for` 的语句体现在可以包含直接 await，并可配合
`break`、`continue` 与 `return` 编写实际游戏流程。

本阶段没有引入 CLR `Task` Runtime、Guest 堆状态机、Runtime AST 解释器、按 UE API 名称
分支或新的 Host import。现有 continuation token、Session transaction、owner generation、
World liveness、取消与 teardown 合同保持不变。

## 实现范围

### Semantic 1.17 continuation CFG

- Semantic schema 保持 `15`，semantic version 升级到 `1.17`；读取侧继续兼容 `15/1.16`
  与 `15/1.15`。
- nested-await 方法使用 `continuation_cfg` lowering，线性方法继续使用既有
  `reentrant_zero_heap_cps`，避免为简单路径增加结构成本。
- 每个 CFG segment 具有稳定 ordinal、源码 span 和显式 `goto`、`branch`、`await` 或
  `return` transfer；入口由 `entry_segment_ordinal` 明确指定。
- resume callback id 同时承担恢复程序计数器身份；循环可在每轮重新调度同一 await site，
  每次调度仍由不同 continuation token 隔离状态。
- CFG 段数上限为 64，结构化控制流深度上限为 8。超限方法稳定产生 `ASCS5417` 或
  对应深度诊断，不抛出投影异常。

### 精确活跃性与状态帧

- 状态分析对 CFG 执行确定性的逆向固定点计算，覆盖分支合流、循环回边和控制转移。
- 每个 await 的 frame 等于恢复目标的 `live-in`，减去该 await 自己定义的结果 local。
- producer 参数和 cancellation source 只在暂停前使用，不会被误放入跨边界 frame。
- 固定布局 scalar、enum、`FVector`、已授权固定 `USTRUCT` 与 UObject capability 继续沿用
  C12 的 bounded bulk state store/read ABI。

### Guest/WASM lowering

- 初始导出与每个 resume function 只物化从各自入口同步可达的 CFG segment。
- `await` segment 生成 producer、可选 cancellation bind、state store、schedule acceptance
  和 fail-closed trap；成功调度后立即返回 Host。
- resume 入口先执行 state/result consume-once 验证，再进入恢复目标；非法或重复 token
  不执行脚本副作用。
- branch condition、同步 helper reachability、debug map、Guest IR 与 WASM 输出均保持确定性。

## 可编写的 C# 形态

```csharp
[UnmanagedCallersOnly(EntryPoint = "avid_on_begin_play")]
public static async void BeginPlay()
{
    AvidLoadedObject mesh = await AvidAssets.LoadObjectAsync(
        "/Engine/EngineMeshes/Cube.Cube");
    if (!mesh.IsValid)
    {
        return;
    }

    FVector offset = new FVector(0.0f, 0.0f, 5.0f);
    for (int pass = 0; pass < 2; ++pass)
    {
        await AvidContinuations.NextTickAsync();
        UE.Self.AddActorWorldOffset(offset);
    }

    if (UE.Self.IsActorTickEnabled())
    {
        await AvidContinuations.DelayAsync(0.01f);
    }
}
```

ActorLifecycle 样例已采用“异步对象加载 -> 循环内 NextTick -> 分支内 Delay”的完整路径。

## 明确保留的边界

- await 必须是直接表达式语句或单一 local initializer；表达式嵌套 await 尚不支持。
- 条件表达式及 `for` initializer、condition、incrementor 中的 await 保持失败关闭。
- `switch`、`foreach`、`try/catch/finally`、异常传播、lambda/closure 与 async helper 调用链
  尚未进入冻结子集。
- string、array 等动态布局 local 尚不能跨 await；批量加载、进度与优先级尚未提供。
- Cook、Shipping、Android 与 iOS 仍未完成正式验收。
