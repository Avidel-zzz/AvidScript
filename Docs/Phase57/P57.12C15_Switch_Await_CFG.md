# P57.12C15 Switch 内 Await CFG 完成报告

## 结论

P57.12C15 已完成。受控 C# `async void` 现在可以在 integral/enum `switch` section 中直接
使用 await，支持常量 case、多个 label 共享 section、default、`break`、`return`，以及 switch
嵌套在循环中时指向外层循环的 `continue`。

该能力完全复用 C14 的 continuation CFG、精确 liveness、resume function 与状态帧 ABI；没有
增加 Host import、Runtime switch dispatcher、AST interpreter、Guest heap state machine 或按
enum/API 名称分支。

## 编译模型

### Semantic

- Semantic schema/version 保持 `15 / 1.17`，没有制造不必要的格式升版。
- governing expression 首批接受 integral/enum local 或 parameter 读取及无副作用转换。
- case label 必须是类型兼容的编译期常量；case 按源码顺序展开为 equality branch 链。
- 多个 case label 指向同一 section entry，default 作为所有 case 不匹配时的最终目标。
- 方法只要包含受控 switch，就选择 `continuation_cfg`，即使 await 本身位于 switch 外部。
- section `break` 使用 switch successor；section `continue` 保留外层 loop continue target。
- pattern、`when`、string switch、`goto case/default`、调用表达式 governing value 以
  `ASCS5418` 失败关闭。

### Guest/WASM

- switch 不增加新 Guest opcode，而是生成现有 `binary equals` 与 `branch_if`。
- 初始导出物化 case dispatch 与同步可达 section；每个 await 仍生成唯一 resume function。
- governing local 仅在业务后继真正使用时才由 CFG liveness 放入 await state frame。
- tampered branch condition 在 Guest lowering 前由 validator 拒绝。
- 相同 Semantic 输入生成 byte-for-byte 一致 Guest IR，并通过 WASM backend 编译。

## 示例

```csharp
int mode = SelectMode();
switch (mode)
{
    case 0:
        return;
    case 1:
        await AvidContinuations.NextTickAsync();
        break;
    case 2:
    case 3:
        await AvidContinuations.DelayAsync(0.01f);
        break;
    default:
        UE.Self.SetActorTickEnabled(false);
        break;
}
Consume(mode);
```

ActorLifecycle 与 ProjectWorkspace 默认模板已使用 switch section Delay await，UE workspace fixture
验证对象加载、循环 NextTick、switch Delay 与恢复后的对象使用顺序。

## 为什么 Foreach 仍未开放

`foreach` 循环体若包含 await，集合或 enumerator 通常必须跨暂停边界持久化。当前 bounded state
frame 只支持固定布局 scalar、enum、固定 USTRUCT 与 UObject capability；数组、字符串和任意
enumerator 的动态布局所有权尚未冻结。C15 没有把 enumerator 偷放到 Host，也没有生成逐元素
wrapper，因此 `foreach` 保持显式不支持，待动态状态帧阶段解决。

## 保留边界

- switch governing value 尚不接受调用、property getter 或其他可能有副作用的表达式；可先保存为 local。
- pattern、`when`、string switch 与 `goto case/default` 尚未支持。
- `foreach`、`await foreach`、`try/catch/finally`、异常传播和 async helper 调用链尚未支持。
- Cook、Shipping、Android 与 iOS 仍未完成正式验收。

## 性能说明

C15 没有新增性能 benchmark。switch dispatch 是 Guest 内普通 equality/branch，不增加 Host 往返，
但不能据此声称新的竞品领先结果。`P57-D06-ControlledLeadership` 继续保持 `Fixing`，性能表仍引用
P57.11D、P57.11B1 与 P56 的冻结正式证据。
