# P57.12C2 异步对象加载实施计划

状态：完成

## 目标

在 P57.12C1 已验证的 Session-owned Continuation 核心上接入第一个带结果的真实 UE 异步生产者：
`FStreamableManager::RequestAsyncLoad`。C# 脚本以 soft object path 发起加载，在 Session 安全 Tick
边界收到状态与通用对象句柄，然后可通过生成式类型代理继续调用 UE API。

本阶段不实现 C# `async/await` 状态机，也不把字符串路径自动加入 Cook 清单。PC Editor 与开发目标先
闭环；ABI、所有权和取消合同保持移动端可实现。

## 冻结的 C# 接口

```csharp
private const int MeshLoaded = 2;

[AvidTransient]
private static AvidContinuation PendingMesh;

public static void BeginPlay()
{
    PendingMesh = AvidAssets.LoadObjectAsync(
        "/Engine/EngineMeshes/Cube.Cube",
        MeshLoaded);
}

[AvidContinuation(MeshLoaded)]
public static void OnMeshLoaded(
    AvidContinuationStatus status,
    AvidLoadedObject loadedObject)
{
    if (status == AvidContinuationStatus.Completed && loadedObject.IsValid)
    {
        UStaticMesh mesh = UStaticMesh.TryCast(loadedObject);
    }
}
```

- `AvidAssets.LoadObjectAsync(string assetPath, int callbackId)` 返回现有不透明
  `AvidContinuation`，沿用 `Cancel()` 和 `[AvidTransient]` 规则；
- asset path 必须是非空、无 NUL、UTF-8 不超过 1024 字节的编译期常量；Runtime 再使用
  `FSoftObjectPath` 与长包名规则 fail closed；
- load callback 必须是 `public static void`，参数严格为
  `(AvidContinuationStatus, AvidLoadedObject)`；Delay/NextTick 继续允许零参数 handler；
- callback id 继续要求正整数、编译期常量、脚本内唯一且有对应 handler；
- `AvidLoadedObject` 是通用 slot/generation 句柄；生成对象代理增加
  `TryCast(AvidLoadedObject)`，不新增按资产类型手写 Host API；
- `Completed = 1`、`Failed = 2`。显式取消和 teardown 继续抑制 callback，不发送伪造的
  `Cancelled` 完成事件。

## 冻结的 ABI

新增 Host import：

```text
env.continuation_load_object(i32 utf8_value_ref, i32 callback_id) -> i64 token
WAMR signature: (ii)I
```

Schema 11 使用版本化 Guest export：

```text
avid_on_continuation_v2(
    i32 callback_id,
    i64 token,
    i32 status,
    i32 object_slot,
    i32 object_generation) -> void
```

旧 Schema 10 的 `avid_on_continuation(i32, i64, i32)` 保持可加载和可执行；不原地改变旧 export
签名。Semantic 合同升级为 `11 / 1.11`，Guest 输入验证继续接受 `10 / 1.10`。

## 所有权与生命周期

- continuation entry 统一持有 timer 或 async-load producer，token、active/prepared lane、activation
  serial、registration serial 和每 Tick 一个恢复项的顺序合同不变；
- `FStreamableManager` 回调只保存强对象并进入 ready queue，不直接进入 Guest，也不在 prepared
  lane 注册对象句柄；
- active completion 即将分发时才通过 Session ownership domain 借用对象句柄，候选失败不会泄漏
  registry capability；
- entry 在 Guest callback 返回后才 finalise，因此 callback 内取消自身仍返回 `false`，同时异步
  handle 与对象不会在调用中失效；
- callback 成功后对象由 continuation owner 强持有到 Session teardown，保证返回句柄可继续使用；
  相同 UObject 去重，单 Session 最多保留 1024 个异步加载对象；
- callback trap 会回滚本次新增的 borrowed handle，不保留结果对象，并进入既有 Session fault/teardown
  路径；
- cancel、prepared discard、热重载替换、HostContext 改变、EndPlay、Unload 和析构都会取消未完成
  `FStreamableHandle`、清空 ready 项和强引用；成功热重载保留已交付的 Session 资产。

## 模块边界

- `Continuation/AvidScriptAsyncObjectLoader` 封装 UE `FStreamableManager`，continuation owner 不直接
  依赖全局 AssetManager 细节，测试使用同一接口的可控 fake；
- VM 只登记静态 import 与 WAMR thunk；WAMR/Wasmtime 继续共享 Host dispatcher 语义；
- Semantic 拥有路径、callback id 与 handler shape 约束；Guest lowerer只消费已验证 callback payload；
- Editor renderer 生成框架 facade、通用 loaded handle 与对象代理转换；不扩散到业务类型手写 binding。

- C2 资产强引用在 Session teardown 统一释放，尚无细粒度 asset lease/release；

- 单对象结果先闭环，批量加载、进度、优先级和 bundle 归入后续资源层；
- P57.12C3 在本阶段结果 ABI 稳定后实现受控 C# `async/await` lowering；
- P57-D06-ControlledLeadership 继续开放，本阶段不修改反射热路径，也不新增性能领先结论。
