# P57.11C 数组批量传输实施计划

## 冻结目标

以共享 range ABI 将 N 个数组元素的 guest/host crossing 从 N 次压缩为 1 次，并建立不会与
pure runtime 或既有 reflection 数据混淆的数组专用性能证据。

## 工作组

### P57.11C1：Range ABI 与 capability heap

- [x] 扩展共享 import 六元组和完整授权合同；
- [x] 为 array heap 增加 bounded `ReadRange`/`WriteRange`；
- [x] 贯通 `FAvidScriptHostCall`、WAMR、Wasmtime static import 与 Runtime guest array borrow；
- [x] 覆盖 forged、stale、cross-session、空区间、边界和溢出。

### P57.11C2：C# facade 与双后端闭环

- [x] 生成每种唯一数组类型的 `AvidScriptArray.Snapshot`/`Flush` overload；
- [x] required imports 与 Binding Slice 精确包含两个 range import；
- [x] C# Semantic、Guest IR 与 Wasm backend 保持普通 typed import 调用，不增加 API 特判；
- [x] 真实 C# fixture 在 WAMR 与 Wasmtime 证明一次 bulk read、一次 bulk write 和显式 release。
