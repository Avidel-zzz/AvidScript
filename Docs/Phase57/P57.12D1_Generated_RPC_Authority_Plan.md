# P57.12D1 生成式 RPC 与 Authority 契约

## 目标

让 C# 脚本能够通过既有生成式 UE facade 调用项目自定义的 `Server`、`Client` 与 `NetMulticast` UFUNCTION，并由 AvidScript 在描述符加载和调用前验证网络语义。实际网络路由继续交给 UE `ProcessEvent` 与 `GetFunctionCallspace`，不维护第二套连接判断。

## 本批边界

- 描述符 schema 15 为每个 binding 固化 `network_mode` 与 `network_reliable`。
- 生成阶段只接受声明于 `AActor` 或 `UActorComponent` 的 RPC。
- RPC 必须是非静态、非 latent、无返回值、无 `ref/out` 参数，并固定使用 `cached_process_event`。
- 运行时重新读取 UFunction flags，拒绝描述符与活动反射快照不一致的包。
- 调用前使用 UE callspace 判定是否被吸收，并验证 Client/Multicast 只能由 authority 发起、Server RPC 在非 authority 上必须具备 Remote callspace。
- 候选热重载上下文禁止发出 RPC，因为网络副作用不可逆。
- 提供 C# 样例以及描述符、加载、authority、callspace、候选热重载自动化覆盖。

## 非目标

- D1 不实现 Replicated Property 与 RepNotify；归入 P57.12D2。
- D1 不实现 UE 收到 RPC 后回调 C# 导出函数；归入 P57.12D3。
- D1 不自行复制 UE ownership、连接或 NetDriver 规则。
- D1 不为每个 RPC 手写宿主 API；任意满足策略且被 profile 选中的项目 UFUNCTION 走同一反射管线。

## 分层设计

1. `EAvidScriptBindingNetworkMode` 是跨 Editor/Runtime 的稳定值对象，支持 `none/server/client/multicast` 文本映射。
2. schema 15 将网络模式、可靠性纳入 binding identity、selection hash 与 package hash。
3. Editor policy 负责静态形状约束，descriptor generator 负责从 UFunction flags 投影网络元数据。
4. Runtime loader 负责反射快照复核，并把网络契约复制到不可变 invocation program。
5. Prepared invocation 在参数解码完成、任何 `ProcessEvent` 发生前执行网络前置校验。

## 失败契约

- `binding_network_contract_mismatch`：描述符网络元数据与活动 UFunction 不一致。
- `binding_network_owner_invalid`：RPC receiver 不是 Actor 或 ActorComponent，或组件没有有效 owner。
- `binding_network_authority_denied`：Client/Multicast 由非 authority 发起，或 Server RPC 缺少合法 Remote callspace。
- `binding_network_call_absorbed`：UE 判定调用应被吸收。
- `binding_network_reload_effect_unsupported`：候选热重载试图发出不可逆 RPC。

## 验收门禁

- 描述符可确定性生成/解析 schema 15，篡改网络字段会 fail-closed。
- Standalone authority 可执行 Server/Client/Multicast 测试 RPC。
- 非 authority 的非法方向在 `ProcessEvent` 前被拒绝。
- 候选热重载在 `ProcessEvent` 前被拒绝。
- C# facade 无 RPC 特例语法，样例可直接调用项目自定义 RPC。
- 阶段末统一运行 .NET、PowerShell、UE Editor 增量构建与完整 AvidScript Automation。
