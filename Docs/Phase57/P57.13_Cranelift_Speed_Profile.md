# P57.13 Cranelift Speed 单变量性能结果

## 阶段结论

P57.13 将生产 Wasmtime compiler profile 的优化级别从 `speed_and_size`
单变量切换为 `speed`。Cranelift、backtracking regalloc、完整 inlining、
`x86-64-v3`、4 GiB wasm32 reservation、Spectre mitigation、并行编译和
Wasmtime v45 工具链均保持不变。

正式 12-kernel 对照显示：p95 几何均值相对 P57.9 改善约 2.55%，但 p50
几何均值没有实质改善，冻结领导力门禁仍未通过。因此
`P57-D06-ControlledLeadership` 仍未解决，并已带完整证据转移到 P59 独立 LLVM AOT
后端阶段；不得宣称纯 Wasm 执行层已全面领先 Puerts V8。

## 实现内容

- compiler profile 更新为 `cranelift-speed-x86_64-v3-inlining-v2`。
- C API wrapper 新增明确的 `speed` optimization 枚举并映射到
  `WASMTIME_OPT_LEVEL_SPEED`；兼容保留 `speed_and_size` 枚举，但生产 profile
  不再选择它。
- lock、schema、运行时 compiler identity、benchmark sidecar 和 VM Automation
  统一绑定 `opt=speed`，旧身份制品继续 fail closed。
- Spectre heap/table mitigation 保持开启，没有以降低安全边界换取分数。

## 性能结果

| 指标 | P57.9 `speed_and_size` | P57.13 `speed` | 冻结门槛 | 结果 |
|---|---:|---:|---:|---|
| p50 几何均值 | 0.979773 | 0.979973 | <= 0.95 | 未通过 |
| p95 几何均值 | 1.026728 | 1.000578 | <= 0.95 | 未通过 |
| p50 kernel 胜率 | 66.67% | 66.67% | >= 60% | 通过 |
| p95 kernel 胜率 | 41.67% | 41.67% | >= 60% | 未通过 |
| MAD 几何均值 | 0.923857 | 0.790124 | <= 1.25 | 通过 |

主要未通过项：

| kernel | p50 Wasmtime/V8 | p95 Wasmtime/V8 |
|---|---:|---:|
| `hashing` | 1.007531 | 1.028328 |
| `data_branch` | 1.001568 | 1.024188 |
| `simd128` | 1.008223 | 1.023970 |
| `parallel_integer` | 0.996693 | 1.019627 |
| `predictable_branch` | 1.009857 | 1.014290 |

`mixed_gameplay` 仍是最强项，p50/p95 分别为 `0.917773/0.943230`；这说明
Wasmtime 在组合型游戏计算中已有优势，但冻结门禁要求跨 kernel 的全面领导性，不能用
单一优势 workload 代替整体结论。

## 下一步

P57.13 证明继续枚举 Cranelift 通用优化小开关不足以跨越 5% 冻结领导线。P59 只接受
LLVM AOT 或等价独立 codegen 后端的可复现候选，继续复用完全相同的 12-kernel 协议；
P58 先推进通用 UE 类型系统，D06 的转移不表示解决，也不允许降低原门槛。
