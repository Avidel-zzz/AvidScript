# P57.12C13 结构化 async 控制流方案

## 状态

- 阶段组：`P57.12C13`
- 状态：接口已冻结，正在实现
- 目标：让受控 C# async 生命周期函数在 await 之间使用常规分支、循环、局部重赋值与控制转移
- 非目标：分支内 await、CLR `Task`、异常展开、`try/finally`、`switch`、`foreach`、任意 awaiter
- 性能债：`P57-D06-ControlledLeadership` 继续保持 `Fixing`

## 设计原则

1. 不增加按 UE API 或按语句种类划分的 Host import；C13 复用 C12 的整帧 store/read ABI。
2. 结构化控制流在 Semantic 层保持 C# 语义，在 Guest 层一次 lowering 为基本块，不在 Runtime 解释 C# AST。
3. local 合流使用函数局部存储槽；状态帧只承担 await 边界保存，不承担 segment 内分支调度。
4. 活跃性由逆向数据流计算，简单赋值会 kill 旧值，分支取并集，循环求有限符号集不动点。
5. 控制流节点、嵌套深度和 await 数继续有确定性上限，畸形或超限输入 fail closed。

## 冻结合同

### Semantic 合同

- schema 结构保持 `15`，semantic version 升级为 `1.16`；`15 / 1.15` 继续作为只读兼容输入。
- 在既有 `SemanticOperation` 树中增加编译器拥有的 async flow kind：
  - `async_block`
  - `async_local_declaration`
  - `async_if`
  - `async_while`
  - `async_do_while`
  - `async_for`
  - `async_break`
  - `async_continue`
  - `async_return`
- `async_for` children 固定为 initializer block、bool condition、increment block、body block。
- 每个受控 async 方法最多 256 个结构化节点，最大嵌套深度为 8。
- await 仍必须是方法体顶层表达式语句或单 local 初始化器；嵌套 await 明确拒绝。

### 状态帧合同

- 每个 await 的槽集合等于下一 segment 入口处真正活跃、且已声明的 local 集合。
- await 结果由 resume payload 定义，不从前一帧恢复。
- 简单 local 赋值会终止旧值活跃区间；compound assignment 与 increment/decrement 同时读写旧值。
- `if/else` 合流取可达分支活跃集并集；循环在有界 local 集合上求确定性不动点。
- break、continue 与 return 分别流向循环出口、循环继续点和方法退出，不把不可达尾语句错误加入帧。
- 槽排序、64 槽上限、4096 字节上限与类型能力沿用 C12。

### Guest 控制流合同

- Semantic flow node 直接 lowering 为 Guest basic block 和 `branch` / `branch_if` terminator。
- 分支合流不分配 heap state machine，不调用 Host，不生成按 local 的 import。
- 循环回边完全位于 WASM 内；await 边界仍由 compiler callback route 切分。
- return 路径不调度后续 producer；break/continue 只能出现在有效循环上下文中。
- 基本块 ID 由 method、segment 与单调 flow ordinal 确定，保证相同输入产生相同 Guest IR/WASM。

## 代表性脚本

```csharp
public static async void BeginPlay()
{
    int movementCount;
    if (UE.Self.IsActorTickEnabled())
    {
        movementCount = 2;
    }
    else
    {
        movementCount = 1;
    }

    await AvidContinuations.NextTickAsync();

    FVector step = new FVector(10.0f, 0.0f, 0.0f);
    for (int index = 0; index < movementCount; ++index)
    {
        UE.Self.AddActorWorldOffset(step);
    }
}
```

预期：`movementCount` 进入第一个 await 的帧；`index` 与 `step` 不跨 await，不进入该帧；循环在 Guest/WASM 内执行且不新增 Host 边界。
