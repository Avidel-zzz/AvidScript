# P57.12B 任意 UObject 事件订阅实施计划

状态：实施中

## 目标

在 P57.12A 的 descriptor 驱动事件合同之上，把动态多播事件源从宿主 `self` 扩展到同一
Runtime Session 内、由对象注册表授权的任意 `UObject` handle，并提供显式订阅令牌与取消
订阅闭环。新增事件继续只依赖 Profile 与 Reflection，不增加按事件手写的 C++/VM wrapper。

## 冻结的 C# 接口

现有 handler 合同保持兼容：

```csharp
[AvidEvent(AvidEvents.OnPickedUp)]
public static void OnPickedUp(AActor instigator, int itemId, float value)
{
}
```

生成 facade 新增强类型订阅入口：

```csharp
[AvidTransient]
private static AvidSubscription _pickedUp;

public static void BeginPlay()
{
    _pickedUp = AvidSubscriptions.OnPickedUp(UE.Self);
}

public static void StopListening()
{
    _pickedUp.Cancel();
    _pickedUp = default;
}
```

- `AvidSubscriptions.<事件名>` 的 source 参数类型来自 descriptor 的 owner class；
- `AvidSubscription` 是只读不透明令牌，只公开 `IsValid` 与 `Cancel()`；
- 保存 token 的静态字段必须标记 `[AvidTransient]`，成功热重载由新 `BeginPlay` 重建；
- 业务逻辑可提前调用 `Cancel()`；进入 `EndPlay`/Unload 时 session owner 会统一解绑，无需依赖
  Guest teardown 再取消；
- `AvidEvents.<事件名>` 继续是编译期常量，避免破坏 attribute 与现有脚本；
- facade 只生成强类型薄入口，所有事件共享同一对 Runtime ABI。

## 冻结的 Host ABI

| 模块 | Import | 签名 | 语义 |
| --- | --- | --- | --- |
| `env` | `event_subscribe` | `(iii)I` | `(slot, generation, event_ordinal) -> i64 token` |
| `env` | `event_unsubscribe` | `(I)i` | `i64 token -> 1/0` |

`event_ordinal` 只用于加载时已准备好的 candidate/active event catalog；广播热路径使用 prepared
event plan 与 prepared WASM export，不做字符串、UFunction 或属性名称查找。

## 安全与生命周期合同

- source handle 必须能在当前 `FAvidScriptObjectRegistry` 中解析，且对象必须满足事件的
  `ExpectedSourceClass`；
- 非宿主 source 还必须属于当前 session 的 owned/borrowed capability 域，不能仅凭共享
  registry 中碰巧相同的 slot/generation 越权订阅；
- source 必须属于当前 HostContext world。存在 session world 时，world 为空或不同的对象均
  拒绝订阅，避免跨 World/PIE 实例访问；
- 订阅与解绑只允许在 game thread，由 `FAvidScriptRuntimeSession` 的 subscription owner 管理；
- 候选 Runtime 的 `BeginPlay` 中产生的订阅先进入 prepared 集合，候选失败会整体丢弃，不触碰
  旧 Runtime；候选成功后一次提交；
- 成功热重载会使旧显式令牌失效，候选脚本应在 `BeginPlay` 重建订阅；失败热重载保留旧订阅与
  旧令牌；
- HostContext 变更、`EndPlay`、Unload 与 session teardown 都会解绑并使令牌失效；重复取消、
  伪造令牌和过期令牌返回失败，不影响 Runtime；
- 同步 delegate 回调重入继续沿用 P57.12A 的非致命 `reentrant_operation` 丢弃语义。

## 非目标

- 不实现 C# `event +=`、lambda、closure 或单播 delegate 替换；
- 不实现 latent continuation、RPC/interface dispatch；
- 不为具体 UE 事件手写 API；
- 不在小任务之间重复执行 Editor 构建或全量 Automation；
- 不 clean Editor target。
