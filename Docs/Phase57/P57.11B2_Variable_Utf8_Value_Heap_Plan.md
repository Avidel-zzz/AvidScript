# P57.11B2 变长 UTF-8 Value Heap 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 `FName/FString` 自动进入 descriptor、生成 C# facade 和 prepared dynamic executor，覆盖 value/const-ref/ref/out/return 与 property get/set，并建立后续变长值 codec 可复用的 session-owned heap。

**Architecture:** guest `string` 仍是一个 `i32` value reference：正值引用现有 linear UTF-8 data segment，负值引用 runtime session 的代际 value heap。Bindings 在调用前预留输出 token，在调用后事务化 intern 与写回；Editor 只投影通用类型合同，VM backend 不认识 UE 字符串。

**Tech Stack:** Unreal Engine 5.8 C++ reflection、Core Wasm i32 ABI、C# Roslyn frontend/Guest IR、prepared dynamic target、PowerShell architecture/performance contracts。

## Global Constraints

- 源码版 UE 5.8 固定为 `C:\UnrealEngine`，禁止 clean Editor target。
- token 固定为 `1-bit tag + 15-bit generation + 16-bit slot`，单 session 最多 `65535` 个 unique value。
- 单个 canonical UTF-8 payload 最大 `1 MiB`；所有长度与地址计算 fail closed。
- 不新增逐 UFUNCTION/API wrapper，不在 VM/WAMR/Wasmtime 中加入 `FName/FString` 分支。
- `struct_wire` 不接受字符串 child，schema 2-9 继续兼容。
- 构建、Automation、性能回归和集中审查仅在功能组完成后统一执行。
- 面向人阅读的文档使用中文；只暂存本批次拥有的文件。
