# P57.12C15 Switch 内 Await CFG 方案

## 状态

- 阶段组：`P57.12C15`
- 状态：接口冻结，正在实现
- 目标：允许受控 C# async 导出在 integral/enum `switch` section 中直接 await
- 性能债：`P57-D06-ControlledLeadership` 继续保持 `Fixing`

## 选择 Switch 而不是提前实现 Foreach

C14 已具备 branch/goto/await/return CFG、循环回边和精确活跃性，因此 `switch` 可以完全在
Semantic 与 Guest 编译期展开，不改变 Runtime ABI。`foreach` 的循环体若包含 await，则集合或
enumerator 通常必须跨暂停边界持久化；当前 bounded state frame 尚未定义数组、字符串或任意
enumerator 的动态布局所有权。C15 不用隐藏 Host 状态或逐元素 wrapper 伪装这一缺口，`foreach`
留给动态状态帧合同完成后的独立阶段。

## 冻结语义

1. Semantic schema/version 保持 `15 / 1.17`；C15 只使用 C14 已冻结的 CFG segment 与 transfer。
2. governing expression 首批只接受 local/parameter 读取及其无副作用转换，并且类型必须是 C#
   integral 或 enum；脚本可先把任意同步计算结果保存为 local 再进入 switch。
3. case 只接受编译期常量，支持多个 case label 共享 section 和一个可选 default；pattern、`when`
   guard、string switch、`goto case` 与 `goto default` 保持失败关闭。
4. dispatch 按源码 case 顺序展开为确定性 equality branch 链。governing local 的重复读取之间没有
   调用或副作用，因此等价于一次 C# switch dispatch，同时不需要 compiler-hidden spill local。
5. section 中的 `break` 跳到 switch successor；switch 位于循环中时，`continue` 仍跳到外层循环
   continue target。嵌套 loop/switch 各自覆盖最近的 break target。
6. section 中的直接 await、单 local initializer await、`return` 和既有结构化控制流沿用 C14 合同。
7. 64 segment、16 await、深度 8 和模块 64 await 的预算不变；case 展开导致超限时必须诊断拒绝。

## Guest/WASM 与性能边界

- switch dispatch 继续 lower 为普通 Guest `binary equals` + `branch_if`，不新增 Guest opcode。
- 初始导出和 resume function 仍只物化各入口同步可达的 CFG；await 成功调度后返回 Host。
- governing value 不跨 await 保存，除非 section 后续业务代码本身仍使用该 local；状态帧完全由
  CFG liveness 决定。
- 不新增 Host import、Runtime switch dispatcher、AST interpreter、Guest heap state machine 或
  按 enum/API 名称分支。
- C15 不新增竞品 benchmark；P57-D06 继续引用冻结性能证据并保持 `Fixing`。

## 代表性脚本

```csharp
public static async void BeginPlay()
{
    int mode = SelectMode();
    switch (mode)
    {
        case 0:
            return;
        case 1:
            await AvidContinuations.NextTickAsync();
            break;
        case 2:
        case 3:
            await AvidContinuations.DelayAsync(0.01f);
            break;
        default:
            UE.Self.SetActorTickEnabled(false);
            break;
    }
    Consume(mode);
}
```
