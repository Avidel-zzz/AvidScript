# P57.12C3 受控 C# async/await 实施计划

状态：完成

## 目标

在 C2 已验证的 `continuation_delay`、`continuation_load_object` 与
`avid_on_continuation_v2` ABI 上实现第一版原生 C# `async/await`。编译器把异步方法切成确定性的
同步 segment，并由 continuation callback 直接进入下一 segment；不引入 CLR `Task` Runtime、GC
状态机对象或每次 await 的堆分配。

```csharp
[UnmanagedCallersOnly(EntryPoint = "avid_on_begin_play")]
public static async void BeginPlay()
{
    UE.Self.SetActorScale3D(new FVector(1.0f, 1.0f, 1.0f));
    await AvidContinuations.NextTickAsync();

    AvidLoadedObject loaded = await AvidAssets.LoadObjectAsync(
        "/Engine/EngineMeshes/Cube.Cube");
    UObject mesh = UObject.TryCast(loaded);
    UE.Self.AddActorWorldOffset(new FVector(0.0f, 0.0f, 10.0f));
}
```

## 冻结语法子集

- async owner 必须是零参数、非泛型、block-bodied 的 `public static async void` 导出；
- 支持多个按源码顺序执行的直接 await：`DelayAsync(float)`、`NextTickAsync()`、
  `LoadObjectAsync(const string)`；
- await 只能是顶层独立语句，或单变量 local declaration 的 initializer；
- 普通 segment 支持表达式语句和带 initializer 的单变量 local declaration；
- 对象 await 结果可在紧随其后的 segment 中作为 `AvidLoadedObject` 使用；失败返回无效句柄，不伪造异常；
- 普通 local、参数和对象结果不得跨越下一 await；静态字段可作为显式跨暂停状态；
- 每方法最多 16 个 await、每模块最多 64 个 await；编译器 callback id 使用
  `[0x40000000, 0x7fffffff]`，用户 `[AvidContinuation]` id 限定在 `[1, 0x3fffffff]`；
- loop/if/switch/try/using/lock 内 await、assignment RHS await、async helper 调用链、重入 frame、
  lambda/closure、`Task`、`ValueTask`、异常传播和泛型 async 返回继续 fail-closed。

## Semantic 12 合同

Semantic 升级为 `12 / 1.12`，新增：

```text
SemanticAsyncMethod
  method_symbol_id
  export_name
  lowering = reentrant_zero_heap_cps
  segments[]

SemanticAsyncSegment
  ordinal
  statements[]
  await_site?

SemanticAsyncAwaitSite
  callback_id
  producer_kind = delay | next_tick | object_load
  payload_kind = none | object
  arguments[]
  result_symbol_id?
```

每个普通 statement 保存已验证的 `SemanticOperation` 与可选 local target。Async 方法不发布普通同步
CFG；其余方法继续使用现有 CFG。`ASCS3002` 只对不属于冻结子集的 async 形态保留。

## Guest lowering

- segment 0 继续使用原 callable function id，因此现有导出 ABI 不变；
- segment 1..N 生成内部 resume function；compiler callback id 由
  `avid_on_continuation_v2` router 直接路由到对应 resume function；
- delay/next-tick resume 无参数；object resume 接收现有
  `(AvidContinuationStatus, AvidLoadedObject)` payload，并把对象参数绑定到结果 local；
- segment 末直接调用已有 Host import，忽略不透明 token，由 Session owner 负责 cancel、prepared/active、
  teardown 与热重载；
- producer 返回零 token 表示 Session 拒绝调度，Guest 在当前源码 segment 立即 trap，避免异步流程无诊断地永久停住；
- 不生成 async frame global，不进入 state migration schema，不增加 Runtime/VM Host ABI；
- compiler callback id 标识 await site，Session token 标识具体 invocation；无 spill 子集允许同一 async 导出并发重入，
  是因为 resume function 不持有共享 frame，而不是因为 callback id 对每次调用都唯一。
