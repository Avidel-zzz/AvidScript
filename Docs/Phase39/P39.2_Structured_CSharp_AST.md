# P39.2 结构化 C# AST

状态：完成
日期：2026-07-13

## 本组实现

正式前端从根语法摘要扩展为面向后续语义分析与 Guest IR 的结构化 AST。模型没有序列化 Roslyn 内部对象，而是定义 AvidScript 自有契约：

- `FrontendDeclaration`：namespace、class/struct/enum、field、method、constructor、property、operator、delegate 等声明。
- `FrontendParameter`：参数名、类型、修饰符、默认值与 Span。
- `FrontendAttribute`：attribute 名称、参数节点与 Span。
- `FrontendAstNode`：受控的 statement/expression kind、名称、类型、修饰符、运算符、值、Span 与子节点。
- `FrontendSyntax.preamble`：保留编译单元的 using、extern alias 与 assembly attribute。
- 声明额外保留继承类型、泛型参数/约束和显式接口限定。

声明映射、语句/表达式映射和 Span 计算分别位于独立文件，避免把前端继续堆进单个分析器。

## 已覆盖语法

- 声明：namespace、常见 type、field/event field、method、constructor、property/event/indexer、operator/conversion、delegate 和 global statement。
- 语句：block、expression、local declaration、return、if/else、while/do/for/foreach、break/continue、throw 和 empty statement。
- 表达式：assignment、binary、invocation、argument、member access、object creation、literal、identifier、generic name、parenthesized、unary、conditional、cast、element access、declaration/out、await、conditional access、initializer 和 accessor。

不在支持集合内的 Roslyn 节点不会丢失或被猜测解析，而是保留原始 kind、源码文本和准确 Span，并设置 `is_supported=false`。Phase 40 可以据此产生明确的语义诊断。

## 文件

- `Model/FrontendAstModels.cs`：稳定声明与 AST 契约。
- `Roslyn/FrontendDeclarationMapper.cs`：声明映射。
- `Roslyn/FrontendAstNodeMapper.cs`：语句和表达式映射。
- `Roslyn/FrontendSpanFactory.cs`：统一 UTF-16/0-based Span。
- `AvidScript.CSharpFrontend.Tests/AstContractTests.cs`：真实示例与 unsupported 行为测试。

## 剩余风险

- AST 仍是 syntax model，不提供类型解析、符号绑定、重载选择或控制流合法性；这些属于 Phase 40。
- `is_supported=false` 当前只保留节点本身，不递归展开其内部结构，避免消费者误把未知语法当成部分支持。
- P39.3 前，旧 Source Adapter 还没有从正式 AST 读取字段和方法体。
