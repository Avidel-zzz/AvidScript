# P39.1 确定性 Roslyn 语法前端

状态：完成
日期：2026-07-13

## 本组实现

新增独立 .NET 8 工具 `AvidScript.CSharpFrontend`，直接引用 SDK 自带 Roslyn 程序集，不下载 NuGet 包。工具把 C# 源码转换成 `avidscript.csharp.frontend` schema v1 JSON，并提供真实 CLI：

```text
AvidScript.CSharpFrontend --source <path> --source-id <id> --output <path>
```

产物已经包含：

- 规范化 source id、UTF-8 SHA-256 和 UTF-16 长度。
- Token、ValueText、Trivia 与稳定 kind 名称。
- UTF-16 offset、0-based 起止行列的完整 span。
- Roslyn 语法 diagnostic、severity、code 和 invariant message。
- 根语法节点摘要、成功状态和前端版本。
- 固定属性顺序、snake_case、UTF-8 无 BOM、LF 结尾。

CLI 对合法源码返回 0；语法错误返回 1，但仍原子写入诊断 JSON；参数、文件和 IO 错误返回 2。

## 架构价值

PowerShell 不再需要承担 C# Token、Trivia 或诊断解析。Phase 40/41 可以只依赖版本化 JSON，不引用 Roslyn；UE Runtime/VM/Bindings 也没有新增 .NET 依赖。
