# P3.1 Runtime Microbenchmark

日期: 2026-07-02
状态: Done

## 范围

P3.1 为 AvidScript runtime 建立第一条微基准线, 目标是把 WAMR embedded smoke module 的核心生命周期拆成可重复统计项:

- runtime init
- module load
- module instantiate
- exec env create
- begin play call
- tick call
- unload

本阶段不做 packaging, 不做 Android 实机, 不引入新的 guest toolchain。基准只覆盖当前 Win64 Editor + WAMR embedded smoke path。

## 实现

新增公开 benchmark helper:

- `Source/AvidScriptRuntime/Public/AvidScriptRuntimeBenchmark.h`
- `Source/AvidScriptRuntime/Private/AvidScriptRuntimeBenchmark.cpp`

新增 automation:

- `Source/AvidScriptRuntime/Private/Tests/AvidScriptRuntimeBenchmarkTests.cpp`
- 测试路径: `AvidScript.Performance.RuntimeMicrobenchmarkSmoke`

核心结构:

- `FAvidScriptBenchmarkStats`: `Count/MinMs/MaxMs/AvgMs/P50Ms/P95Ms`
- `FAvidScriptRuntimeBenchmarkOptions`: `WarmupCount/SampleCount/TickDeltaSeconds`
- `FAvidScriptRuntimeBenchmarkResult`: 成功状态、错误信息、summary、各阶段统计

当前实现复用 `FAvidScriptWasmRuntimeInstance` 与已有 embedded smoke wasm。每轮执行 load -> begin -> tick -> unload, warmup 轮次不计入样本, 正式样本用于统计。

## 风险

- 当前基准使用 Editor/NullRHI, 不是 packaged 或 shipping 数据。
- 样本数为 smoke 级别, 足够防回归和建立口径, 不代表最终性能报告。
- embedded smoke module 非真实 C# guest workload, P3.2/P3.3 需要补 host binding/import 成本。
