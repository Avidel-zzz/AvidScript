# P47.1 对象属性 C# 游戏逻辑闭环成果

## 已完成

EngineGameplay 授权 profile 现包含 115 个函数与两个 AActor 只读属性：

- CustomTimeDilation，标量 float；
- RootComponent，对象句柄 USceneComponent。

完整授权 descriptor 保持 schema v4，总计 117 个 binding。生成门面提供普通强类型属性：

    USceneComponent root = UE.Self.RootComponent;
    FVector rootLocation = root.GetWorldLocation();

真实生命周期样例在 BeginPlay 组合了两类属性和组件实例调用：

    SetScale(
        UE.Self.CustomTimeDilation * 2.0f + rootLocation.X,
        3.0f,
        4.0f);

测试 Actor 的 CustomTimeDilation 为 1.25，RootComponent 世界 X 坐标为 0.5。真实 C# 经 Roslyn、Guest IR、WASM backend 和 WAMR 执行后，Actor X scale 为 3.0；随后 Tick 增加 0.5，结果为 3.5。

## 最小运行时切片

117 项授权上限被 reachability 自动裁剪为 5 个实际 import：

- AActor.CustomTimeDilation 属性 getter；
- AActor.RootComponent 属性 getter；
- USceneComponent.GetWorldLocation()；
- AActor.SetActorScale3D()；
- AActor.GetActorScale3D()。

没有为对象属性增加手写 ABI，也没有把完整 EngineGameplay 包带入运行时。

## 已验证流程

- Profile 选择与 descriptor 确定性；
- C# 强类型对象属性门面；
- 冷构建与热 semantic cache；
- WAMR BeginPlay 和 Tick；
- 对象句柄跨 binding 继续调用；
- 候选 reload host-effect transaction 提交；
- write-then-trap 候选回滚；
- 回滚后旧 C# 运行时继续 Tick；
- tampered binding package hash 拒绝。

## 后续

P47.2 已确认动态 WAMR thunk 会把失效 receiver 的 host 调度失败统一转成 trap，不会让脚本带默认值继续执行。后续应提供可恢复的脚本侧空值分支、覆盖 UObject 子类协变并进入属性 setter policy；setter 不能绕过 UE replication、BlueprintSetter 与候选 reload transaction。
