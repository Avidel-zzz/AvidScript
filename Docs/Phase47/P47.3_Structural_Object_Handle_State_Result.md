# P47.3 对象句柄结构状态成果

## 目标

可选组件是正常游戏逻辑，不应强迫脚本通过一次失败 host call 判断是否存在。P47.3 为每个生成 UObject 值包装器增加两个纯 C# 属性：

    public bool IsNull => Slot == 0 && Generation == 0;
    public bool HasHandle => Slot > 0 && Generation > 0;

它们只读取包装器内的两个整数，不产生 WASM host crossing，也不访问 UObject registry。

## 语义

- IsNull：只表示 host 明确返回空对象句柄 (0, 0)。
- HasHandle：只表示 slot 与 generation 都是正数。
- IsValid：为兼容已有 facade 暂时保留，语义仍等同于结构性 HasHandle。
- UObject 是否仍存活、generation 是否仍匹配，只能由 Runtime registry 在真实 binding 调用时判定。

脚本可以对正常的可选对象分支使用 IsNull：

    USceneComponent root = UE.Self.RootComponent;
    if (root.IsNull)
    {
        return;
    }

脚本不能用 HasHandle 或 IsValid 跳过 stale handle 校验；持有非零旧 generation 的包装器仍会在下一次 host 调用时以 host_import_failed 停止。

## 生成与兼容

- IsNull、HasHandle 和 IsValid 都是生成器保留成员名，反射方法不能与其碰撞。
- Emitter version 升级为 47.3.0。
- source hash 和 manifest hash 会变化，内容寻址发布目录不会复用旧 facade。
- descriptor schema 和 stable binding identity 不变，因为本阶段没有改变 UE ABI。

## 后续

后续可在真实 C# 游戏样例中加入可选组件分支，并评估把容易误解的 IsValid 标记为过时 API。任何迁移都必须保持旧项目可诊断，不能把结构状态扩展成未经 Runtime 验证的 liveness 承诺。
