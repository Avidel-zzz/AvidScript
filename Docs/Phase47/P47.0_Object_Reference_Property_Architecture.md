# P47 对象引用属性架构

## 目标

P47 把 P46 的只读反射属性从标量扩展到 UObject 引用。脚本应能像普通 C# 一样读取 AActor.RootComponent，取得强类型 USceneComponent，并继续调用自动生成的组件 API。

本阶段仍不新增逐属性 native 函数，也不允许把 UE 裸指针暴露给 WASM。

## 端到端数据流

1. EngineGameplay profile 显式授权 AActor.RootComponent。
2. Editor 属性策略把 FObjectPropertyBase 投影为 object_handle，并保留 /Script/Engine.SceneComponent 类型身份。
3. descriptor schema v4 生成属性 getter 的稳定 import 和返回布局。
4. Runtime 在加载 binding package 时缓存真实 FProperty*。
5. getter dispatch 从 Actor 读取 UObject 引用，经 FAvidScriptObjectRegistry 注册后向 guest memory 写入 (slot, generation)。
6. C# renderer 把两个整数还原为 USceneComponent 值包装器。
7. 后续组件实例调用再次通过 registry 解析句柄，并进入既有反射函数调用路径。

## 所有权边界

- WASM 只持有代际句柄，不持有 UObject*。
- 对象为空时返回空句柄；native 后续调用由通用对象校验拒绝。
- 对象销毁或 generation 失效后，native 后续调用必须被拒绝，不能复用旧 slot 指向的新对象。
- Profile、类型策略、marshaller 和 renderer 都是共享机制，禁止为 RootComponent 编写专用 switch。
- 生成门面不在 C# 中分支检查 native 返回值；动态 WAMR thunk 在 host 调度失败时统一设置 exception，VM 将其投影为 host_import_failed，并保留 import 与失败细节。
- 统一 trap 保证失败调用不会带着默认 storage 继续执行，也不需要在每个生成方法中复制检查代码。

## 性能约束

- descriptor JSON 与反射成员解析只发生在 package load。
- 热路径直接使用缓存的 FProperty*。
- registry 对象去重保证重复读取同一引用不会持续创建新身份。
- Roslyn reachability 只把脚本实际访问的属性和函数写入运行时 binding slice。

## 当前范围

P47.1 完成非空只读 UObject 引用属性和跨对象调用，P47.2 锁定空引用 receiver 的统一 trap 与诊断。属性 setter、容器属性、弱引用、软引用、接口引用和可恢复的脚本侧空值分支仍属于后续阶段。
