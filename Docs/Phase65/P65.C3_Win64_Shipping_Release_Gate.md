## 配置隔离

BuildCookRun 不再依赖仓库中最后一次生成的 `Content/AvidScriptGenerated/current.json` 配置。每次构建会在
`Saved/AvidScript` 下发布独立的 Generated Type Cook overlay，并通过
`AVIDSCRIPT_GENERATED_TYPE_COOK_ROOT` 仅传给当前 UAT/UBT 子进程。`ModuleRules` 把 overlay 的 source 映射到
固定 package target，receipt 校验器读取同一个 overlay，因此 Development 与 Shipping 不会互相改写源码指针，
并可安全使用不同的内容寻址 Runtime package。

不完整的 Puerts 对照插件同样只通过本次 Release、UBT 与 Cooker 命令行隔离；`.uproject` 没有被修改。

## 问题记录与防复发

1. Gate 两层脚本曾使用 PowerShell 自动变量名 `$Input` 保存 JSON，进入函数和 `switch` 后值被覆盖。
   已统一改为 `$StepInput`，合约明确禁止重新声明该自动变量。
2. 空可选路径曾被强制 splat 给子脚本，同时无 JSON 子进程的 stderr 被丢失。现仅转发非空可选参数，
   stderr-only 失败必须保留真实诊断。
3. `DisablePlugins` 曾只到达 UAT，没有覆盖前置 Release commandlet。现 Release、UBT、Cooker 三段共享同一选择，
   且标识符、重复项、启用/禁用冲突均在副作用前拒绝。
4. 源码 UE 更新后项目 Editor BuildId 漂移，已有 DLL 被拒绝加载。只执行非 clean 增量 metadata/模块构建，
   禁止用清理 Editor target 作为默认恢复手段。
5. 单一 Generated Type `current.json` 曾把 Development package 带入 Shipping receipt。现使用每次构建独立 overlay，
   禁止通过临时改写或提交某一种配置的全局指针来修复另一种配置。
