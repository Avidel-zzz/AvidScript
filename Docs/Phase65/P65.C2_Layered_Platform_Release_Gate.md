# P65.C2 分层平台 Release Gate

## 目标

P65.C2 把插件发布身份、项目生成产物、Win64 Shipping、Android toolchain/arm64/package/device 与人工体验边界收敛到一个版本化报告。Gate 复用现有 release、BuildCookRun、receipt、Android preflight 和 scenario runner，不在新入口复制构建规则。

## 稳定入口

```powershell
pwsh -NoProfile -File Build/InvokeAvidScriptPlatformReleaseGate.ps1 `
  -PackageRoot "C:\Path\To\AvidScript-Release" `
  -Mode Inspect `
  -ProjectRoot "C:\Path\To\Project" `
  -EngineRoot "C:\UnrealEngine"
```

`Inspect` 是默认只读模式，不启动 UBT、UAT、安装或设备任务。`Execute` 需要额外提供符合
`AvidScriptPlatformReleaseGatePlan.schema.json` 的计划文件；所有输入路径必须是项目相对路径，构建输出固定在
`Saved/AvidScript/ReleaseGate` 下，并为每次 run 创建唯一目录。

`disable_plugins` 只把经过标识符校验的插件名传给当前 UBT/Cooker 子进程，不修改 `.uproject`。同一插件不能在
`enable_plugins` 与 `disable_plugins` 中同时出现。

计划文件示例：

```json
{
  "schema_version": 1,
  "win64": {
    "enabled": true,
    "configuration": "Shipping",
    "source_path": "Plugins/AvidScript/Samples/CSharp/UiSaveDemo/UiSaveDemoScript.cs",
    "csharp_project_path": "Plugins/AvidScript/Samples/CSharp/UiSaveDemo/AvidScript.UiSaveDemo.csproj",
    "module_id": "avidscript.ui_save_demo",
    "artifact_stem": "ui_save_demo",
    "output_root": "Saved/AvidScript/ReleaseGate/Win64/Build",
    "archive_root": "Saved/AvidScript/ReleaseGate/Win64/Packages",
    "packaged_oracle_mode": "None",
    "cook_maps": ["/AvidScript/Demos/UiSave/L_UiSave"],
    "enable_plugins": [],
    "disable_plugins": []
  },
  "android": {
    "enabled": false,
    "device": { "enabled": false }
  }
}
```

## 八层证据

1. `release-package`：release manifest、inventory、dependency lock 和产物生产器身份。
2. `project-artifacts`：Generated Type 描述符/type/runtime 哈希、完整模块 catalog/package 与 runtime package 交叉身份。
3. `win64-shipping`：当前 run 的 Win64 BuildCookRun 与 package receipt。
4. `android-toolchain`：固定 Android 34、Build Tools 35.0.1、CMake 3.22.1、NDK 27.2.12479018、JDK 与 ADB。
5. `android-arm64`：Android arm64 BuildCookRun/UBT 与 target receipt。
6. `android-package`：APK 内唯一 `arm64-v8a/libUnreal.so`、ELF64/AArch64 与 archive SHA-256。
7. `android-device`：同 run APK 的安装、启动、BeginPlay/Tick/Event 与 package identity。
8. `shipping-manual`：UI 视觉、物理输入、手柄和设备体验，自动流程始终保持 `not_run`。

每层独立使用 `passed / failed / blocked / not_run`。任一失败使总结果为 `failed`；存在 blocked 或未执行层时为
`partial`。报告不写绝对路径，完整 JSON 以原子方式写到项目 `Saved/AvidScript/ReleaseGate`。
