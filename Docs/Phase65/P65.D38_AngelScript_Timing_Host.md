# P65.D38：AngelScript 校准与计时宿主

## 范围

新增 `As38LeadershipTiming` Commandlet、进程宿主、逐样本验证器和汇总器。复用 D37 的脚本、缓存 UASFunction 的桥接层及原生 oracle，不修改生产运行库。当前测量 Native 与 AngelScript Editor VM；Puerts/AvidScript 同一引擎的完整计时矩阵和 packaged generated native code 仍待完成。

计时宿主已编译成功，首轮两套工作负载各完成一次独立校准和一次测量进程：**327 个校准、120 个预热、720 个计时样本**均验证通过。验证器合同 **34/34** 通过。该轮是单进程诊断，不用于宣称性能领先；5 进程结果另行记录。

## 口径

- micro 的 10 个 workload 顺序、gameplay 的 2 个 workload 顺序、seed `1397313` 和按样本派生 seed 的 23 位掩码与既有 Phase56 profile 一致。
- 每个 lane/workload 从 profile 最小迭代数开始倍增。候选样本达到 5 ms 后，再收集 3 个确认样本，只有其中位数达到 5 ms 才冻结迭代数。超过既有最大迭代数仍不能确认则失败，保留尝试数据。
- 测量进程复用校准结果，每个 workload/lane 执行 5 次预热、30 次计时。Native/AngelScript 按进程、workload 和样本索引交替先后顺序。宿主支持每套 1 或 5 个测量进程。
- 原生 oracle、准备、结果读取、对象/调用计数校验、JSON 分配均在计时外；AngelScript 仅测 `ExecutePrepared`，计时区间使用 `FPlatformTime::Cycles64`。
- 每个样本核对校验和、最终 ScalarValue、13 类 native 调用次数，并独立复算调用调度。外部验证器还核对 seed、执行顺序、迭代冻结和 cycle/time 换算。
- 记录 `bStaticJITTranspiledCodeLoaded` 并拒绝把已加载 static JIT 代码的环境标记成 Editor VM。本入口不支持 packaged mode。
- 进程工作集差值只作为诊断字段，**不是分配次数**。CPU、亲和掩码、进程优先级、构建和输入身份保存在外置证据中。

## 验证与统计

所有校准、预热和计时记录均保留。日志与进程退出必须同时成功；每个进程前后验证输入哈希。汇总器复验 request/result/log 哈希和全部样本，要求完整的进程集合、唯一请求身份、相同校准数据。

分位数使用 nearest rank；跨进程 P50 使用各进程 P50 的中位数，P95 保留最差进程值，AS/Native 的 P95 比值采用最差配对进程比值，不删除高值样本。低于校准阈值的实际计时样本保留并计数，不通过筛选把结果变好。Native 是绝对成本参照，不能代替与其他脚本框架的比较。

34 项合同包含真实校准/测量报告接受、缺失/重复样本、执行顺序变化、seed/迭代错误、计时单位不一致、两侧同时少做 native 调用、漏掉校准确认、错误执行模式及失败/重复日志的拒绝。

## 执行

从 [适配器目录](../../Benchmarks/PuertsComparison/Leadership/AngelScript/README.md) 使用显式的隔离工程和成功构建证据：

```powershell
./Scripts/Invoke-AngelScriptTiming.ps1 `
    -ProjectFile $ProjectFile -Executable $EditorCommandlet `
    -BuildEvidence $BuildEvidence -OutputRoot $EvidenceRoot -ProcessRuns 5

./Scripts/Test-AngelScriptTimingContracts.ps1 -RunDirectory $RunDirectory
./Scripts/Summarize-AngelScriptTiming.ps1 `
    -RunDirectory $RunDirectory -OutputPath (Join-Path $RunDirectory 'summary.json')
```

校准和正式样本来自不同进程。每次运行新建证据目录，失败保留原始数据，不覆盖旧结果。`Invoke-AngelScriptValidation -PrepareOnly` 只进行 D37 既有输入/安装身份预检并返回快照，不启动 Editor 或创建运行目录，供计时宿主复用。

正式 protocol 的 AngelScript 仍为 `not_frozen`，生产性能门禁仍为 **16/18**。本小节不关闭 P65.D 或人工发布验收；Android/Mac 按用户要求暂缓。
