# P65.D8 正式性能复测

## 候选与口径

P65.D4-D6 完成后，从 clean commit `e25beed1b5bbc27ca61a0aecb8bf083600b24136`、tree
`a35f0ee1ffda24e46501342ae8bd2521dd8b3117` 装配候选 `49373cca83c660855875`。
Micro、gameplay、12 kernel identical-WASM 和 physical cost 全部使用冻结正式 profile：1 个校准进程、
5 个计时进程、每进程 5 次预热、每单元 30 个计时样本。统一结果有效、候选身份一致且未使用 fallback。

原始结果保存在仓库外受控证据目录；仓库只保留来源哈希与可审查摘要。候选 manifest SHA-256 为
`7b6b3f41a31b9a6dccc8e5dd5c6c75fdfe10c39b9fc6d8bd366bb977e97ae990`，统一 Gate 结果
SHA-256 为 `8ada12d8275784c22f7147f66c05611f23348faaaa41f23ce02436252739ec0e`。

## 正式结果

统一性能 Gate 共 18 项，12 项通过、6 项失败。

| 维度 | 正式值 | 门槛 | 结果 |
| --- | ---: | ---: | --- |
| Wasmtime/V8 identical-WASM P50 几何均值 | `1.126x` | `<= 0.95x` | 失败 |
| Wasmtime/V8 identical-WASM P95 几何均值 | `1.168x` | `<= 0.95x` | 失败 |
| P50/P95 kernel 胜率 | `58.3% / 25.0%` | `>= 60%` | 失败 |
| generated S1 scalar | `28.29 ns` | `<= 25 ns` | 失败 |
| generated S1 property | `51.40 ns` | `<= 50 ns` | 失败 |
| callback_empty | `494.31 ns` | `<= 150 ns` | 失败 |
| callback/Puerts | `1.912x` | `<= 0.85x` | 失败 |
| Semantic/Puerts reflection | `0.715x` | `<= 0.80x` | 通过 |
| small gameplay/best Puerts | `0.258x` | `<= 0.70x` | 通过 |
| dense gameplay/best Puerts | `0.352x` | `<= 0.70x` | 通过 |

相对 P65.D3，callback 从 `831.86 ns` 降至 `494.31 ns`，下降约 `40.6%`；P95 identical-WASM
几何均值从 `1.189x` 改善为 `1.168x`，P95 kernel 胜率从 `0%` 提升到 `25%`。这证明 event thunk、
低竞争 watchdog 和惰性观测方向有效，但还不足以关闭执行层与完整 callback 门禁。

controlled aggregate SHA-256 为

## 下一步

低层 prepared export 仅 `34.84 ns`，typed Host bridge 净成本仅 `7.855 ns`，而完整 callback 仍为
`494.31 ns`。剩余主要成本位于每次 guest entry 的 fuel/epoch 重置、watchdog 唤醒与 Session/Runtime
包络，不在 Host reflection bridge。

下一批建立显式的双层 containment：不可信或开发目录产物继续使用逐入口 fuel + epoch；经过 cooked
package 身份验证的项目产物允许使用无 fuel instrumentation 的 Cranelift profile，同时保留 epoch
wall-time、Host-call 和线性内存边界。该策略必须由产物 trust domain 驱动并 fail closed，不能由
benchmark 开关绕过。AngelScript 同语义矩阵仍是独立未完成项。
