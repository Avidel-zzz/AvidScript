# P65.A 可重复发布与原子安装

状态：实现冻结，等待基于已提交 Git tree 的生产发布与外置项目安装验证

## 实现范围

P65.A 建立了 Developer Preview 的第一条分发闭环：发布器只从调用方指定的 Git commit 读取
受控文件集合，生成内容寻址的 thin source package；安装器只接受完整验证后的 package，并以项目级锁、
同卷 staging、readback 和 rollback 完成 `Install`、`Upgrade`、`Repair`、`NoOp` 与 `Verify`。

核心文件：

- `Build/ReleaseEngineering/AvidScriptPluginReleasePackage.ps1`：严格 UTF-8/JSON、Schema、路径、
  inventory、release identity、package readback 与同根发布仲裁。
- `Build/ReleaseEngineering/AvidScriptPluginInstaller.ps1`：安装 receipt、计划、漂移检测、事务提交、
  回滚与提交后清理告警。
- `Build/PublishAvidScriptPluginRelease.ps1`：从选定 commit 的 allowlist 执行 `git archive`，生成公开
  README，验证依赖 lock，并执行文本和二进制隐私扫描。
- `Build/InstallAvidScriptPluginRelease.ps1`：稳定的 `Plan`、`Apply`、`Verify` CLI 与原子 JSON 报告。
- `Build/ReleaseEngineering/*.schema.json`：发布 manifest、安装 receipt 与 source-profile 三份机器合同。

## 安全与确定性

- package 根只允许 `release.json` 与 `payload/`；manifest 和 inventory 使用 canonical JSON 与 SHA-256。
- 拒绝绝对路径、路径逃逸、大小写碰撞、Windows 保留名、reparse point、ADS、未知文件、大小超限、
  非法 Schema、重复 JSON 属性和依赖身份漂移。
- 发布输入来自同一 commit 的 allowlist 与 dependency lock，不读取 dirty 文件或 ignored dependency binary。
- `source-developer` 是 thin profile，不包含当前本机编译的 Wasmtime 二进制；离线 binary profile 在中性
  构建根完成 path remap 和隐私 Gate 前保持禁用。
- 相同 release identity 在同一输出根重复发布时复用已验证赢家；不同内容发生路径碰撞时拒绝覆盖。
- 同一 release 的受管文件损坏可执行 `Repair`；出现 receipt 之外的未知文件时拒绝接管，避免覆盖用户内容。
- 提交前失败恢复旧插件；提交后的 backup 清理失败只返回告警并保留恢复材料。
