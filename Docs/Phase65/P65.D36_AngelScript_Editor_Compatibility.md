# P65.D36：AngelScript 隔离 Editor 兼容性验证

固定 AngelScript 源码已在隔离的 UE5.8.0 环境完成 Editor 编译，并实际通过两项脚本测试。
这证明了后续同语义对比所需的最小编译与运行入口；完整 workload、packaged native code
和正式性能矩阵尚未验证，protocol 中的 AngelScript 仍为 `not_frozen`。

## 来源与隔离范围

AngelScript 固定提交为 `f347f57f05e992976b6c2be6612303b7e8099502`，其上游对应 UE5.8.2。
本地将 107 个引擎 hook 文件移植到独立复制的 UE5.8.0 源码，并构建独立
`As36BenchmarkEditor Win64 Development` 目标；不能把这套本地移植称为上游 UE5.8.2
引擎的原始构建身份。

403 个插件源码文件在构建后再次与固定提交的物化文件逐一核对。最小工程只启用核心
`Angelscript`；已复制的 GAS、EnhancedInput 插件没有纳入本次验收。
编译产物写入隔离引擎或工程；两项测试运行前后均检查共享引擎的 107 个原始 hook 文件、
原 Editor 可执行文件，以及实际执行的隔离二进制、模块清单、工程与脚本哈希。

## 本轮修复与保留的失败证据

首次高并行构建因内存压力终止了 RTTI PCH 的生成进程，留下约 13.5 MB 的部分文件。
后续四进程构建在 SparseVolumeTexture 报 C1852。保留损坏文件后，重新执行导出的
同一条 PCH 编译命令，得到约 2.58 GB 的完整 PCH；随后仅执行剩余 4 个构建动作，
52.29 秒完成增量构建。没有用清理缓存或重建整个目标来掩盖失败。

首次脚本启动因跨模块全局函数没有 namespace 而编译失败；按该分支的实际可见性规则
修正测试脚本后，在新进程中完整重跑并通过两项测试。失败日志与最终通过日志均保留。

## 仍需完成

后续需要在同一隔离引擎配置中接入原始 AvidScript/Puerts harness，实际编译和验证
同语义适配器。原始 fixture 依赖 FJsObject 等 Puerts 类型，不能删去这些成员或使用替身
后声称 fixture 一致。现有适配器、264 组正确性用例和 17 项拒绝检查仅为外置草稿，
尚未编译、运行或计时。

Editor VM 与 packaged generated native code 必须分别证明执行模式，再与同引擎重建的
其他框架比较。现有生产 Wasmtime patchset.3、Windows 468/468、Shipping 和正式
16/18 性能 Gate 保持既有证据范围；没有新增性能领先声明。人工 Release 验收仍未完成，
Android/Mac 按用户安排暂缓。
