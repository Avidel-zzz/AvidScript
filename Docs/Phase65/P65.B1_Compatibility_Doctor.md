# P65.B1 Compatibility Doctor

状态：已完成

## 能力

`Build/InvokeAvidScriptCompatibilityDoctor.ps1` 提供单一只读诊断入口，输出
`avidscript.compatibility.report` schema v1。每项诊断使用稳定 `id`、`code`、`area`、`status`、
`severity`、`expected`、`actual`、`message` 与 `remediation`；总状态只可能是 `ready`、`degraded` 或
`blocked`。

当前 22 项顶层探针覆盖；Android 可用时再展开现有 preflight 的 19 项子检查：

- Host：Windows、PowerShell 7.4+、UE5.8 source tree、固定 .NET 8.0.416 与 VS2022/MSBuild。
- Plugin：descriptor/module 集合、`global.json`、受管安装 receipt 与完整文件树、WAMR、Wasmtime
  performance toolchain、Generated Type source/cooked package 身份。
- Project：普通目录边界、唯一 `.uproject`、插件安装位置、Game/Editor Target 和已验证 Binding package。
- Platform：复用现有 Android toolchain preflight，保留真实 `passed/total`，PC-first 下缺失工具链为
  warning，不冒充 Android ready。

外部进程探针可用 `-SkipExternalTools` 显式标为 `not_run`，不会静默跳过；CI 可用 `-FailOnBlocked`
把 blocked 报告映射为退出码 2。`-ReportPath` 使用临时文件、Schema 验证和原子替换。

## 验证

- PowerShell AST：3/3 入口无解析错误。
- Contract：`TestAvidScriptCompatibilityDoctorContracts.ps1` 为 `5/5 passed`。
- 当前 UE5.8 工程真实运行：`23 passed / 18 warning / 0 blocked / 0 not_run`，共 41 项；
  其中包含 22 项顶层检查和 19 项 Android 子检查。
- 通过身份：UE `5.8.0`、.NET `8.0.416`、VS `17.14.36616.10`、Wasmtime
  `cranelift-speed-x86_64-v3-contained-v3`、Binding 与 Generated Type package。
- warning 构成：源码 checkout 无 install receipt 1 项、Android 汇总 1 项、Android 未满足子项 16 项；
  Android 已具备的 3 个子项保持 passed。结果与当前已知边界一致。

本小节没有启动 UBT、Automation、打包或 benchmark。P65.B2 将在此稳定报告之上实现脱敏 support bundle。
