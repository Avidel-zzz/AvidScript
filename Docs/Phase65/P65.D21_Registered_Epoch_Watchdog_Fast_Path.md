# P65.D21 已注册 Epoch Watchdog 快路径

## 本节目标

继续压缩 verified packaged callback 的固定 Guest entry 成本，同时保留 epoch 超时中断、shutdown、重入调用、
延迟卸载与失败诊断合同。本节只优化所有 prepared export 共用的 watchdog 路径，不按 export 名、binding 类型或
benchmark workload 添加特判。

## 已实现

- Wasmtime backend 在成功注册共享 epoch watchdog 后，同时保存负责生命周期的线程安全共享所有权、watchdog
  稳定地址与 entry 非拥有快指针。
- `ArmRegistered` / `DisarmRegistered` 直接操作已注册 entry，不再为每次顶层 Guest call 重复执行共享指针、
  Signal、Event 和单例查询。`bStopping`、deadline 原子发布、earlier-wake 竞争和 epoch increment 全部保留。
- 卸载仍只在 `ActiveCallDepth == 0` 时执行；先撤销热路径快指针，再从 watchdog 注销共享 entry，最后释放
  function、instance、store 和 engine。旧 prepared handle 与 reentrant unload 继续失败关闭。
- runtime 性能候选固定在实现提交 `9335ae665715d8b95cf2987b1c116285dc04b87c`。后续 host producer
  `74eda44307d8bd0b41d3a3e78726f40923e71e2f` 只修复证据生产：使用 `-nodebuginfo`，拒绝 UAT
  复制失败文本，并要求每个 `.utoc` 都有同名、非空 `.ucas`；它不属于被测 runtime 二进制。

## 正式结果

| Workload / lane | D20 P50 | D21 P50 | D21 P95 | D21 / Puerts static P50 | D21 / Puerts static P95 |
| --- | ---: | ---: | ---: | ---: | ---: |
| callback_empty / generated S1 | `108.38 ns` | **`108.08 ns`** | `112.10 ns` | `1.032x` | `1.040x` |
| callback_tick / generated S1 | `131.54 ns` | **`111.04 ns`** | `117.27 ns` | **`0.948x`** | **`0.959x`** |
| callback_empty / adaptive semantic | `111.23 ns` | **`108.87 ns`** | `112.77 ns` | `1.039x` | `1.047x` |
| callback_tick / adaptive semantic | `132.06 ns` | **`108.93 ns`** | `115.50 ns` | **`0.930x`** | **`0.945x`** |

D21 同轮 Puerts static 的 callback_empty/tick P50 为 `104.77 ns / 117.07 ns`。generated callback_tick
P50/P95 已领先 `5.2% / 4.1%`；callback_empty 仍慢 `3.2% / 4.0%`，因此 callback leadership gate
尚未完全关闭。

跨候选绝对耗时同时受到本机运行状态和二进制布局影响：本节不把 Puerts 同步变化后的全部绝对降幅归因给
watchdog。可直接归因的实现变化是移除已注册 entry 的重复校验；是否领先以同进程、同轮 Puerts 比值为主。

十项 UE micro 的 generated S1 P50/P95 几何均值为 `0.669x / 0.667x`，P50/P95 各有 `7/10`
胜项；data-oriented 为 `0.670x / 0.668x`，同样各有 `7/10` 胜项。相对 D20 的 `0.712x / 0.723x`
继续改善，但 pure integer、callback_empty 与 object roundtrip 仍未全部领先。

## 证据生产故障与修复

首个 D21 archive 在磁盘空间不足时未复制 `AvidTPSTemplate-Windows.ucas`，AutomationTool 却仍返回
`ExitCode=0` 并输出 `BUILD SUCCESSFUL`。旧 producer 因此发布了不可启动 host，calibration 在 Pak 挂载前
断言，未产生任何可采信样本。无效临时产物已删除，修复后的 producer 排除约 2.5 GB 的 PDB，并在发布
manifest 前验证 UAT 文本和 IoStore 闭包；正式证据来自重新生成的完整 host。

## 当前结论

D21 证明已注册 watchdog 的稳定所有权可以转化为低风险热路径不变量。generated callback_tick 已在正式
矩阵中领先 Puerts static，callback_empty 的差距收敛到约 `3% - 4%`，但 P65-D03 仍保持未关闭。
同口径 AngelScript 矩阵、identical-WASM pure execution 与剩余 static/object 场景也不能由本节替代。
