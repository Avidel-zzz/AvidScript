## 候选与口径

本轮在 clean commit `5191cdc8eff90de14410e7adfc28f119b8598c23`、tree
`a4f9cfc031e1fd6f79686cea986f4f551d8a3e0c` 上冻结候选 `eba78aa5f226348c6799`。
Phase56 micro、gameplay、12 kernel identical-WASM 和 physical cost 均使用正式 profile：每项
1 个校准进程、5 个计时进程、5 次进程内 warmup 和 30 个计时样本。所有 correctness 检查通过，
没有 fallback。

候选 manifest SHA-256 为
`c5fe38fbb47c3f47fb822d838b76e45582b3e8823a840c5ce5c9229be2ae9e0c`；统一 Gate 结果

仓库只保留可审查摘要和来源哈希，原始多进程样本继续由受控 benchmark 工作区保存，不写入个人路径。

## 正式结果

统一性能 Gate 共 18 项，14 项通过、4 项失败。

| 维度 | 正式值 | 门槛 | 结果 |
| --- | ---: | ---: | --- |
| Wasmtime/V8 identical-WASM P50 几何均值 | 1.128x | <= 0.95x | 失败 |
| Wasmtime/V8 identical-WASM P95 几何均值 | 1.189x | <= 0.95x | 失败 |
| P95 kernel 胜率 | 0% | >= 60% | 失败 |
| typed callback | 831.86 ns | <= 150 ns | 失败 |
| callback/Puerts | 5.67x | <= 0.85x | 失败 |
| Semantic/Puerts reflection | 0.60x | <= 0.80x | 通过 |
| small gameplay/best Puerts | 0.38x | <= 0.70x | 通过 |
| dense gameplay/best Puerts | 0.52x | <= 0.70x | 通过 |
| S1 scalar | 19.65 ns | <= 25 ns | 通过 |
| S1 property | 38.81 ns | <= 50 ns | 通过 |
| prepared export/generic P50 | 0.91x | <= 0.95x | 通过 |
| typed empty net P50 | 5.67 ns | <= 12 ns | 通过 |

12 个相同 WASM kernel 中，P50 有 6 个领先，P95 无 kernel 达到领先阈值。主要尾部差距集中在
`scalar_float`、`simd128`、`mixed_gameplay` 和 `data_branch`；整数、顺序内存、内部调用等 kernel
已接近或局部领先 V8。controlled aggregate SHA-256 为
`a8dbae1de33ab7cdf06f3b3806cb27a00d20427e40e88ae5b24d2904334678e3`。

physical cost 证明 Host typed bridge 本身不是 callback 的主要瓶颈：typed empty 净成本仅
5.67 ns，而完整 callback 为 831.86 ns。physical aggregate SHA-256 为
`91ce58c4e647ce4aaeb246f0e21e102d85ce81e6d68ec30027f5a2b0334cf853`。

## 结论与下一步

当前可以确认 AvidScript 在已冻结的 UE 交互 workload 上领先 Puerts 对照；不能据此宣称完整性能
领导力。下一批优化优先处理每次 guest entry 的 watchdog/budget 重置、callback 成功路径观测成本，
并分析 fuel instrumentation 对浮点、SIMD 与混合 kernel 的影响。优化必须保留 fail-closed 执行边界，
禁止以 benchmark 专用关闭安全机制换取成绩。

AngelScript 同语义正式矩阵仍缺失，因此即使上述四项门禁关闭，也不能直接扩展为对全部成熟框架的
完整行业领先声明。
