# P65.D17 惰性内联 Profiler Scope

## 本节目标

降低 profiler 未启用时的 Guest/Host 调用固定成本，同时保留 runtime buffer 与 UE Trace 的动态启停。
优化面向通用 profiler scope，不按 export、绑定类型或 benchmark workload 特判。

## 已实现

- `FAvidScriptProfilerScope` 构造与析构改为 `FORCEINLINE`，消除每个 scope 的两次 out-of-line 调用。
- `Buffer == nullptr` 作为唯一未采集状态；capture 关闭时只写一个指针，不初始化 epoch、probe、
  correlation、operation 等约 64 字节的冷字段。
- `SetSucceeded` 在未采集时不写冷状态；capture 开启时仍保存完整元数据、读取起止 cycles 并调用
  原有 `Record`。
- `IsCaptureEnabled` 仍逐次检查 runtime buffer 与 UE Trace channel，因此动态开启诊断无需重建 Session。

## 正式结果

| Workload / lane | D16 P50 | D17 P50 | D17 P95 | D17 / Puerts static P50 |
| --- | ---: | ---: | ---: | ---: |
| callback_empty / generated S1 | `128.82 ns` | **`121.52 ns`** | `151.81 ns` | `1.125x` |
| callback_tick / generated S1 | `140.19 ns` | `146.70 ns` | `155.86 ns` | `1.128x` |
| callback_empty / adaptive semantic | `129.95 ns` | **`121.15 ns`** | `150.92 ns` | `1.121x` |
| callback_tick / adaptive semantic | `138.68 ns` | `147.63 ns` | `154.30 ns` | `1.135x` |

本轮 Puerts static 的 callback_empty/tick P50 为 `108.04 ns / 130.05 ns`。Generated S1 的 P50
比率为 `1.125x / 1.128x`；Tick 没有复现 D16 的 `1.101x`，所以 D17 不构成新的 callback 领先证据。
十项 UE micro 的 generated S1 P50/P95 几何均值为 `0.735x / 0.755x`，仍有 `6/10` 胜项。

跨候选绝对值受机器频率影响明显：相对异常偏快的 D16，未修改语义的 pure integer P50 漂移
`+57.1%`，而 vector value 又下降 `2.5%`。因此本节不以跨轮最大回退判定 scope 本身的收益；主要证据
是同轮 AvidScript/Puerts 比率、5 进程分布与完整正确性。后续应增加相邻候选交错执行，降低这种漂移。

## 当前结论

惰性 scope 简化了禁用态并通过完整运行时回归，但现有 formal 数据只能证明“无功能回归且保持整体领先”，
不能证明 callback 已领先，也不能把进程间波动归因于单一代码改动。P65-D03 继续保持未验证。

## 下一步

下一批把 `IsCaptureEnabled` 的 channel predicate 移入调用点可内联路径，消除禁用态剩余的一次 DLL 调用；
同时以同轮 Puerts 比率和相邻候选交错测量作为主要判据。若 P50/P95 没有稳定改善，则停止继续压缩
profiler，并转向 Wasmtime prepared export wrapper 与 runtime entry state。
