# P65.B2 脱敏 Support Bundle

状态：已完成

## 能力

`Build/ExportAvidScriptSupportBundle.ps1` 在一次调用中执行 Compatibility Doctor，并把结果发布为
`avidscript.support.bundle` schema v1。输出采用 `support.json + files/` 固定布局，manifest 记录
bundle ID、生成时间、Doctor 结果、固定限制、文件 inventory、总字节和 SHA-256；发布经过 staging、
隐私扫描、readback、输出锁和原子目录提交。

Compatibility report 不是原样复制，而是按字段 allowlist 重建。三个上下文路径固定映射为
`<PLUGIN>`、`<PROJECT>`、`<ENGINE>`；检查项只保留稳定诊断字段与经脱敏的文本。当前不会导出用户 C#、
WASM、PDB、debug map、Guest IR、生成源码、profile、环境变量、命令行、crash dump 或原始日志。

## 日志边界

- 默认日志数为 0，只有调用方显式提供的 `.log` 或 `.txt` 才会处理，最多 8 份。
- 每份日志从文件尾部读取，输入字节窗口最多 64 KiB，输出最多 200 行和 64 KiB。
- UTF-8 尾部会跨过可能被截断的多字节前缀；非法 UTF-8、reparse point 与 ADS 均拒绝。
- 输出文件使用 `log-01.txt` 等中性名称，不保存原始路径或文件名。
- 用户/工程/引擎路径、UNC/WSL 根、URL 凭据、Bearer/JWT、GitHub/AWS token、密码字段、邮件与私钥
  在 staging 内脱敏；发布前再对全部输出执行独立隐私扫描。
