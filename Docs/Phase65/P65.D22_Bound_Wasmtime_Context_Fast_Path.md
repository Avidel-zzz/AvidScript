# P65.D22 绑定 Wasmtime Context 快路径

## 本节目标

继续压缩 verified packaged callback 的固定 Guest entry 成本。本节将 export 解析期已经确定的 Wasmtime
context 保存到内部 function 句柄，使两个高频 prepared call 不再通过 store 二次取址；通用反射调用、
trap、reload lifetime、epoch watchdog 与 Host failure 合同保持不变。

## 已实现

- `AvidScriptWasmtimeFunction` 在 shim 内部保存其解析来源的 `wasmtime_context_t*`，该字段不穿透 opaque
  C API，也不进入 VM 公共合同。
- `i32,i32 -> i32` 与 `i32,f32 -> void` 两个 specialized prepared wrapper 直接消费 function 绑定的
  context，不再接收 store 参数。
- function 仍在 store 之前销毁；reentrant unload 仍由 `ActiveCallDepth` 延迟，旧句柄不会越过 owner
  生命周期。
- 未增加 export 名、binding 类型或 benchmark workload 特判；generic prepared/reflection 路径没有改动。

## 正式结果

| Workload / lane | D21 P50 | D22 P50 | D22 P95 | D22 / Puerts static P50 | D22 / Puerts static P95 |
| --- | ---: | ---: | ---: | ---: | ---: |
| callback_empty / generated S1 | `108.08 ns` | **`103.67 ns`** | `108.40 ns` | `1.001x` | `1.009x` |
| callback_tick / generated S1 | `111.04 ns` | **`108.31 ns`** | `114.75 ns` | **`0.947x`** | **`0.960x`** |
| callback_empty / adaptive semantic | `108.87 ns` | **`104.17 ns`** | `109.11 ns` | `1.006x` | `1.016x` |
| callback_tick / adaptive semantic | `108.93 ns` | **`106.02 ns`** | `118.12 ns` | **`0.927x`** | **`0.988x`** |

D22 同轮 Puerts static 的 callback_empty/tick P50 为 `103.56 ns / 114.35 ns`。generated callback_empty
P50 已接近持平，仅慢约 `0.11%`，P95 慢约 `0.92%`；callback_tick P50/P95 领先约 `5.28% / 4.01%`。
data-oriented callback_empty 已以 `0.9997x / 0.9948x` 同时通过 P50/P95。

相对 D21 绝对值，generated callback_empty P50/P95 下降 `4.08% / 3.29%`，同进程 Puerts static
比值收敛约 `3.05 / 3.11` 个百分点。由于同轮 Puerts 的绝对耗时也有变化，本节仍以候选内比值为主要
归因证据，不把全部跨候选降幅归因于一次指针取址优化。

十项 UE micro 的 generated S1 P50/P95 几何均值为 `0.665x / 0.655x`，P50/P95 各有 `7/10`
胜项；data-oriented 为 `0.664x / 0.655x`，胜项为 `8/10 / 7/10`。pure integer、generated
callback_empty P95 与 object roundtrip 仍未全部领先。

## 当前结论

D22 证明 export 解析期冻结的 context 可以安全转化为 prepared call 不变量，且 callback_empty 已从明确
落后收敛到约 `1%` 内。由于 generated S1 的 callback_empty P50/P95 仍略高于 Puerts static，
P65-D03 继续保持未关闭；本节不替代 identical-WASM 和 AngelScript 同语义矩阵。
