# P65.D32 Win64 公开二进制路径脱敏

状态：实现方案；尚未通过中性重建、二进制扫描或公开离线包 Gate。Android 与 Mac 实机验收按用户要求暂缓。

## 问题与范围

现有 Wasmtime managed receipt 能证明文件内容一致，却不能证明 DLL 没有内嵌个人目录。
P65-D04 因此继续保持 Open；当前 `source-developer` 发布合同与外部依赖方式不变。
本小节先补齐受控中性构建和可验证的隐私证据，真实结果通过后再单独扩展离线发布 profile。

修改 owner 为 Wasmtime 工具链构建入口及 `Build/ReleaseEngineering` 的文件扫描工具；不修改 VM
执行策略、Guest ABI、编译优化、安全预算和正在采样的冻结候选。公开包不能依赖手动修改 DLL 字节。

## 构建合同

1. 使用锁定的 upstream commit、归档 SHA-256、patch、Rust 版本、Cargo features 和 CMake profile。
   中性构建在独立根中进行，不覆盖主工程或性能候选的 installed runtime。
2. 源码、Cargo cache/target、生成代码和临时目录必须有完整前缀映射。Windows 正斜杠与反斜杠
   分别处理；宽泛映射在前，具体映射在后。实际构建目录不得处于用户 home 中。
3. 使用 `CARGO_ENCODED_RUSTFLAGS` 传递独立参数，避免含空格路径被拆开；受控模式拒绝未经记录的
   外部编译参数。保留 `SOURCE_DATE_EPOCH`、现有优化 profile 和全部安全能力。
4. 环境修改限制在构建子进程或可恢复的作用域；路径映射和隐私检查失败时不发布 managed install。
   receipt 只保存稳定虚拟映射身份和内容哈希，不能把真实用户名或私有路径重新写入可分发证据。

Rust 官方说明明确指出路径映射是文本替换，且不覆盖链接器自行生成的路径；因此配置成功不能代替
最终字节扫描。见 [Rust 路径映射](https://doc.rust-lang.org/rustc/remap-source-paths.html) 和
[Cargo 环境变量](https://doc.rust-lang.org/cargo/reference/environment-variables.html)。实际参数必须由
仓库固定的 Rust 1.93 工具链验证，不依赖最新文档才有的选项。

## 隐私证据合同

- 对将要分发的完整文件集合扫描，不只检查 DLL 的可打印字符串；至少覆盖 UTF-8、UTF-16LE/BE、
  两种 Windows 分隔符、大小写变化和跨读取块的匹配。
- 必查当前用户名、home、源码/Cargo/build/temp 根，以及常见个人目录模式。相对文件名同样检查。
  未知编码或工具引入的路径不由“已配置 remap”自动豁免。
- 只读扫描拒绝空集合、路径逃逸、reparse point、ADS、读取失败及扫描期间发生的文件变化；
  验证与报告必须绑定同一组文件内容。
- 报告包含相对路径、长度、SHA-256、规则标识和命中数量，不复制命中的私有字符串。
  扫描失败保留本地诊断并以非零状态阻止发布；receipt/inventory 不得把失败重新解释为成功。
- 许可证、锁定来源、导出符号、managed receipt 与扫描结果分别验证。隐私通过不表示许可、功能、
  确定性或 UE 安装运行已经通过。

## 集中验证与后续边界

行为合同使用合成文件覆盖多种编码、路径变体、边界匹配、命中拒绝和证据内容身份；构建参数合同
覆盖带空格路径、嵌套映射及环境恢复。真实 Gate 使用新的中性目录重建锁定工具链，扫描全部交付
文件，复核许可证、导出与 receipt，再执行隔离 Win64 集成验证。已有性能样本仍属于原 runtime
身份；换用新 DLL 后不能沿用旧身份宣称性能通过。

本节完成之前不启用公开离线二进制 profile。启用该 profile 需要另一个完整写集，包含发布 schema、
包内依赖 provenance、安装器验证、篡改拒绝及全新 UE 工程安装构建；不能只放宽扩展名 allowlist。
