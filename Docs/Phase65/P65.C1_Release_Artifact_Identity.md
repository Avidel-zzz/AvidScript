# P65.C1 发布产物身份合同

## 目标

P65.C1 让同一个插件 `release.json` 同时约束 Win64/Android 依赖，以及 Generated Type 和内容寻址模块包的生成合同。这样后续平台 Gate 可以把实际项目产物绑定到唯一 `release_id`，而不把某个项目的 `package_id` 错写进通用插件包。

## 实现

- source profile 新增 `artifact_contracts`，固定以下两个公开生产器：
  - `generated-type-package` -> `Build/AvidScriptGeneratedTypeCookPackage.ps1`
  - `module-release-package` -> `Build/AvidScriptModuleReleasePackage.ps1`
- 发布器只从选定 Git commit 的归档输入读取生产器，计算 SHA-256 后写入 manifest。
- `artifact_contracts` 参与规范化 `release_id` 计算，因此生产器、依赖 lock、源码 tree 或 payload 任一变化都会形成新的发布身份。
- package readback 同时校验生产器路径、哈希和 payload inventory；缺失、重复、路径漂移或哈希不符均 fail-closed。
- 插件发布 manifest 只绑定可复用的产物合同。项目实际的 Generated Type `package_id`、模块 `catalog.json` 和平台 receipt 将由 P65.C2 Gate 与 `release_id` 共同写入证据报告。

## 验证

`Build/Contracts/TestAvidScriptPluginReleaseContracts.ps1` 当前为 **24/24**：

- 保留原有确定性发布、Schema、篡改、路径、安装、升级、修复、锁和回滚合同；
- 新增两类生产器身份存在性与稳定排序验证；
- 新增生产器哈希漂移拒绝验证。

本小节没有执行 UBT、Automation 或平台打包。它只改变发布工程合同，平台级构建与设备状态在 P65.C2/C3 集中执行。
