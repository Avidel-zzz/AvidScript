# P65.D24 对象往返内联候选诊断归档

## 结论

P65.D24 尝试缩短生成绑定的通用对象往返路径，但诊断矩阵显示性能回退，因此候选已撤销，正式基准未运行。当前有效性能基线仍为 P65.D22。

## 候选设计

- 将返回第三个对象时才需要的世界检查、所有权借用和句柄注册抽到独立慢路径。
- 强制内联常见的接收者解析、输入对象解析、原对象/接收者别名复用和状态记录。
- 移除 owner 接收者每次重复的 `IsA`；首次 prepared-effect 解析仍执行类型校验，非 owner 路径仍由 `ResolveStableBorrow` 校验。
- 不改变 packed object ABI、句柄代际、GC/热重载失效、世界隔离或 fail-closed 行为，也不针对某个手写 UFUNCTION。
