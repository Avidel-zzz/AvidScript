## 实现和验证

固定 AngelScript 来源 `f347f57f05e992976b6c2be6612303b7e8099502`，继续使用 D36 的 UE5.8.0 移植环境。完整 harness 与 Puerts 采用物理副本；原始 fixture 保持冻结的 `8c032e9f` 字节，没有移除 `FJsObject` 或伪造 Puerts 类型。所有构建输出位于隔离环境，主引擎输入未被用于写入输出。

首次运行暴露了 AngelScript 方言差异：无符号常量须使用 `uint(value)`，隐式 UObject 引用通过 `==` 比较，值参数不能在函数体内修改。修正后发现 `RunWorkload` 的 `ParmsSize=12`，返回字段位于 offset 12；该引擎分支将输入参数大小与完整结构大小区分。桥接层依据实际 `FStructOnScope` 分配大小和 `ReturnValueOffset` 检查返回值，之后完整测试通过。失败尝试的日志与报告均保留。
