# P65.D7 Clean Candidate 性能诊断

## 目标与边界

在 P65.D4-D6 完成 prepared event call、低竞争 epoch watchdog 与 callback 成功路径惰性观测后，
从 clean commit 装配隔离候选并运行冻结的 diagnostic profile，先验证优化方向和正确性，再决定是否
进入正式多进程 Gate。

本记录是 **diagnostic 证据，不替代 P65.D3 的正式基线，也不关闭性能领导力 Gate**。两组诊断均为
1 个校准进程、1 个计时进程、1 次预热和 5 个计时样本；原始结果保存在仓库外证据目录。
