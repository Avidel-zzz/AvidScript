## 已修复的阻断

校准请求原先使用旧版 `Get-SidecarWasmtimeCompilerIdentity`，缺少 compiler profile、target、
最大 WASM 栈、fuel 与 epoch interruption，并使用旧字段名 `dll_sha256`。运行时 C++ backend
返回的是完整新身份，二者因此在计时前正确地 fail closed。

修复后，PowerShell runner 按 lock 验证所有安全和性能开关，并生成与
`BuildAvidScriptWasmtimeCompilerIdentity` 字节一致的身份字符串。契约测试固定完整字符串，后续
改变编译配置时必须同步更新两侧，禁止通过模糊比较或删除字段绕过来源校验。
