# P11.0 Editor Usable Entry Scope

日期: 2026-07-05
状态: Done

## 1. 目标

Phase 11 从 service-first 的 P10 进入 UE Editor 可用入口层。目标是让 `.avid` source 可以通过 Editor 入口触发 compile/reload, 同时保持核心逻辑可自动化测试、可复用。

| P11.1 | Planned | Editor command launcher。 |
| P11.2 | Planned | ToolMenus registrar。 |
| P11.3 | Planned | Module-owned sample command。 |
| P11.4 | Planned | 完整回归和文档收口。 |

## 3. 方案

采用 launcher + thin menu 的结构:

```text
ToolMenus / future UI
-> FAvidScriptEditorCommandLauncher
-> FAvidScriptEditorCommandService
-> FAvidScriptEditorReloadService
-> FAvidScriptWasmReloadSession
```

`FAvidScriptEditorCommandLauncher` 负责路径默认值、reload session 生命周期和 summary。ToolMenus 只负责把用户操作转成 launcher 调用。
