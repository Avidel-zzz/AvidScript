# P11.3 Module Sample Command

日期: 2026-07-05
状态: Done

## 范围

P11.3 将 P11.1 的 editor command launcher 和 P11.2 的 ToolMenus registrar 接入 `AvidScriptEditor` module 生命周期, 提供一个第一版可用的 Tools 菜单 sample command。

本组仍不做文件选择器、设置页、watcher 或 Slate 面板; sample command 固定指向 `Samples/AvidScript/ActorSetLocation/actor_set_location.avid`。

## 变更

- `FAvidScriptEditorModule` startup 创建 module-owned `FAvidScriptEditorCommandLauncher`。
- module startup 注册 `UToolMenus::RegisterStartupCallback`, shutdown 反注册 startup callback 和 owner。
- 新增 sample command helper:
  - `GetSampleCommandSourcePath`
  - `MakeSampleCommandConfig`
  - `MakeSampleMenuEntryConfig`
  - `ExecuteSampleCommand`
- sample menu entry 挂到 `LevelEditor.MainMenu.Tools` 的 `AvidScript` section, entry 为 `AvidScript.RunSampleCommand`。
- 菜单执行动作调用 launcher 的 `CompileSourceAndApply`, 并把成功/失败 summary 写入 `LogAvidScriptEditor`。
- 新增 `AvidScript.Editor.Module.SampleCommandConfigSmoke`, 验证 sample source、默认 command config 和 menu entry config。

## 当前可用能力

Editor module 加载后, ToolMenus startup callback 会注册 `Tools > AvidScript > Run Sample Script`。点击后会尝试编译并应用 `actor_set_location.avid`, 结果写入 `LogAvidScriptEditor`。

当前 sample command 依赖 P8/P9/P10/P11.1 的 frontend wrapper、report reader、compile gate、reload apply service 和 launcher。若当前 Editor 进程未能通过 PATH/环境变量找到 LDC, command 会 fail closed 并在 summary 中报告 toolchain/command failure。

## 剩余风险

- 尚未做人工 Editor UI 点击 smoke; P11.4 可在完整回归后补一条手动验证记录。
- 还没有文件选择器或最近脚本列表, 只能运行固定 sample。
- Toolchain 配置仍依赖 wrapper 参数、PATH 或环境变量; 后续应增加项目级设置或 Editor preferences。
- 菜单 entry 使用基础文本 label, 未接入自定义 icon 或 command binding system。
