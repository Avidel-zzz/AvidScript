# P11.2 ToolMenus Registrar

日期: 2026-07-05
状态: Done

## 范围

P11.2 新增一个薄的 `FAvidScriptEditorMenuRegistrar` 包装层, 用于把后续 module-owned command 接入 UE ToolMenus, 同时避免菜单注册代码承载 compile/reload 业务逻辑。

本组只完成可测试注册层, 不接入真实 LevelEditor 菜单项; P11.3 再把 sample command 挂到 module startup/shutdown 生命周期。

## 变更

- `AvidScriptEditor.Build.cs` 增加 `ToolMenus`, `Slate`, `SlateCore`, `LevelEditor` 私有依赖。
- 新增 `FAvidScriptEditorMenuEntryConfig`, 表达 owner/menu/section/entry/label/tooltip/execute action。
- 新增 `FAvidScriptEditorMenuRegistrationResult`, 记录注册结果和 fail-closed error category/message。
- 新增 `FAvidScriptEditorMenuRegistrar::RegisterMenuEntry`, 负责校验配置、创建或查找菜单、创建 section, 并注册 menu entry。
- 新增 `AvidScript.Editor.MenuRegistrar.RegistersMenuEntrySmoke`, 使用唯一测试菜单名验证 section、entry 和 delegate 行为。
