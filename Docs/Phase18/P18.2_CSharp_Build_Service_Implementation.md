# P18.2 C# Build Service 实现

## 实现内容

本阶段新增 `FAvidScriptEditorCSharpBuildService`，将 C# ActorLifecycle 的命令行构建封装成 Editor module 可调用服务。

核心路径:

- build script: `Plugins/AvidScript/Build/BuildCSharpActorLifecycle.ps1`
- output root: `Saved/AvidScriptCSharpGuest/ActorLifecycle`
- report: `Saved/AvidScriptCSharpGuest/ActorLifecycle/actor_lifecycle.csharp.report.json`

服务会规范化路径、创建输出目录、调用 PowerShell wrapper，并记录 stdout、stderr、exit code、report path 和错误分类。

## Module 集成

`FAvidScriptEditorModule` 新增:

- `GetCSharpActorLifecycleBuildAndBindEntryName()`
- `GetCSharpActorLifecycleBuildScriptPath()`
- `MakeCSharpActorLifecycleBuildAndBindMenuEntryConfig(...)`
- `ExecuteCSharpActorLifecycleBuildAndBinding(...)`

Editor 菜单新增:

```text
Tools > AvidScript > Build And Bind C# ActorLifecycle Script
```

执行流程:

1. 调用 `FAvidScriptEditorCSharpBuildService::BuildActorLifecycle(...)`。
2. 构建成功后调用既有 `ExecuteCSharpActorLifecycleBinding(...)`。
3. 绑定服务读取 C# report 中的 `artifacts.manifest_file`。
4. 为当前选中 Actor 创建或复用 `UAvidScriptComponent`，并写入 manifest 路径。

## 失败路径

- `build_script_missing`: build wrapper 不存在。
- `output_directory_failed`: 输出目录无法创建。
- `process_failed`: PowerShell 进程无法启动。
- `build_failed`: 构建进程返回非零 exit code。
- `report_missing`: 构建成功但 report 文件缺失。
- `platform_unsupported`: 当前实现只支持 Windows Editor host。

失败时不会修改 Actor 组件状态。
