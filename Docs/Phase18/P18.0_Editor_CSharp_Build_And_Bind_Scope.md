# P18.0 Editor C# Build And Bind 范围

## 目标

Phase 18 的目标是把 C# ActorLifecycle 样例的构建步骤纳入 UE Editor 工作流，让 PC Editor 内可以从固定 C# 样例源码一键完成构建、生成 report、并绑定到当前选中 Actor。

本阶段继续服务用户当前优先级: 先用 C# 开发 gameplay，不要求 `.avid` 作为必经入口。

## 交付内容

- 新增 Editor 侧 C# build service，负责调用 `BuildCSharpActorLifecycle.ps1`。
- 新增 `Tools > AvidScript > Build And Bind C# ActorLifecycle Script` 菜单入口。
- 构建成功后复用 Phase 17 的组件绑定入口，将最新 report 绑定到选中 Actor。
- 构建失败、report 缺失、绑定失败都要 fail closed，并在 Editor log 输出结构化原因。
- 新增自动化测试覆盖菜单配置、构建执行、report 生成和选中 Actor 绑定。

## 本阶段边界

- 只支持固定样例 `Samples/CSharp/ActorLifecycle/ActorLifecycleScript.cs`。
- 不做任意 C# 文件选择器，不做 Slate 面板，不做批量 Actor 绑定。
- 先支持 Windows/PC Editor；移动端与 packaging 继续作为后续验证目标。
- 不扩大 C# source adapter 语言子集。

## 验收标准

- `AvidScriptEditor` module build 成功。
- `AvidScript.Editor.Module.CSharpBuildAndBindSelectedActorSmoke` 通过。
- `AvidScript.Editor` 回归通过。
- 完整 `AvidScript` 回归通过。
- 文档记录 RED/GREEN 证据、实现范围、剩余风险和下一阶段建议。
