# P18.1 C# Build And Bind RED 测试

## 测试意图

Phase 18 先用自动化测试描述目标行为: Editor module 必须暴露 C# ActorLifecycle build-and-bind 入口，并且该入口能在测试世界中对选中 Actor 完成 C# 构建和组件绑定。

## 新增断言

- `FAvidScriptEditorModule::GetCSharpActorLifecycleBuildScriptPath()` 返回 `Plugins/AvidScript/Build/BuildCSharpActorLifecycle.ps1`。
- `FAvidScriptEditorModule::MakeCSharpActorLifecycleBuildAndBindMenuEntryConfig(...)` 返回可注册菜单配置。
- 新菜单 entry 名称为 `AvidScript.BuildAndBindCSharpActorLifecycle`。
- `ExecuteCSharpActorLifecycleBuildAndBinding(...)` 能运行构建脚本，生成 report，并把 report 绑定到当前选中 Actor。
- 绑定完成后 Actor 拥有 `UAvidScriptComponent`，组件指向生成的 C# manifest。

## RED 结果

执行 `AvidScriptEditor` module build 时，测试首先失败在编译阶段:

```text
fatal error C1083: cannot open include file: 'AvidScriptEditorCSharpBuildService.h': No such file or directory
```

这证明测试已经要求一个尚不存在的 C# build service，符合 TDD RED 阶段预期。

## 后续实现要求

- 新增 `FAvidScriptEditorCSharpBuildService`。
- 通过 `FPlatformProcess::ExecProcess` 调用 PowerShell build wrapper。
- 只在 build exit code 为 0 且 report 文件存在时返回成功。
- 将 build 成功结果交给已有组件绑定服务，避免重复解析 report/manifest。
