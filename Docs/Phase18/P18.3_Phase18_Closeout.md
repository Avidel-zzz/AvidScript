## 当前可用能力

到 Phase 18 结束，PC Editor 内已经具备一键 C# gameplay 验证闭环:

1. 在 UE Editor 中选中目标 Actor。
2. 点击 `Tools > AvidScript > Build And Bind C# ActorLifecycle Script`。
3. 插件调用 C# build wrapper，生成 direct ABI WASM、manifest 和 report。
4. 插件将生成的 manifest 绑定到选中 Actor 的 `UAvidScriptComponent`。
5. 进入 BeginPlay/Tick 后，组件加载 C# WASM 并执行 ActorLifecycle 逻辑。

这意味着用户已经可以用当前受限 C# 子集写 `BeginPlay()` 和 `Tick(float deltaSeconds)`，并通过 Editor 菜单完成构建与绑定验证。

## 剩余风险

- 当前 C# source adapter 仍是受限子集，不是完整 C# 编译器。
- 入口仍固定为 ActorLifecycle 样例，尚未支持任意 C# 文件或 profile 选择。
- 当前只支持 Windows/PC Editor host 调用 PowerShell build wrapper。
- 批量绑定、资产化配置、Message Log/notification UI 和 packaging/mobile 验证仍待后续阶段。
