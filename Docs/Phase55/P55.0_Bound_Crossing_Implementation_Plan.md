# Phase 55 预绑定调用边界实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 消除 Generated S1 scalar/property 与 Wasmtime callback 的重复运行时固定成本，在不削弱 UE 语义和热重载安全的前提下争取正式领先 Puerts Static。

**架构：** Bindings 在加载期生成 immutable prepared snapshot，Runtime 将其组装为地址稳定的 call cell，VM 仅持有 opaque context 与 shape-specific target。Property getter/setter 使用独立标量 ABI，Wasmtime export 在加载期验证后使用 unchecked call。

**技术栈：** Unreal Engine 5.8 源码版、C++20、Wasmtime 45.0.0 C API、C# to WASM frontend、PowerShell benchmark harness、Git phase workflow。

## 全局约束

- 引擎固定为 `C:\UnrealEngine` 的源码版 UE5.8。
- 只执行 no-clean target build，禁止清理 Editor Target。
- 人读文档使用中文。
- 不按 benchmark fixture、函数名或单个 UE API 写特例。
- semantic reflection fallback、write policy、reload journal、object generation、world 和 class 检查不得关闭。
- 小组内只运行静态/轻量 blocker；UBT、Automation 和正式矩阵在 P55.4 集中执行。
- 不修改主工作区已有受保护脏文件。
