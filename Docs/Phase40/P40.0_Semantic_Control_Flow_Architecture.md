# P40.0 语义分析与控制流架构

状态：完成
日期：2026-07-13

Phase 40 采用 Roslyn 语义分析能力作为 C# 规则真相，再输出 AvidScript 自有、版本化、确定性的 semantic JSON。这样既避免手写 C# binder，也不会让 Guest IR 依赖 Roslyn SDK 内部对象。

核心流水线：

~~~text
frontend JSON + C# source
  -> source hash gate
  -> Roslyn Compilation / SemanticModel
  -> IOperation / ControlFlowGraph
  -> AvidScript symbols / types / operations / CFG
  -> semantic JSON
  -> Phase 41 Guest IR
~~~

## 设计边界

- PowerShell 不新增任何语义解析职责。
- 公开契约不包含 Roslyn 数字 enum 或进程内 symbol key。
- 类型和符号使用 AvidScript 稳定 ID。
- 失败也写诊断工件，但阻断 Guest IR 与 WASM。
- UE facade reference assembly 由 Phase 42 生成，本阶段允许同 compilation 内的临时类型声明。
- 实例字段和方法在本阶段完成绑定，内存布局留给 Phase 41。

## 小组拆分

1. P40.1：Compilation、引用解析、semantic diagnostic 与稳定 symbol/type table。
2. P40.2：IOperation typed tree、常量、调用与 conversion。
3. P40.3：ControlFlowGraph、分支、循环、break/continue/return。
4. P40.4：实例字段、this、普通方法和不支持语义 gate。
5. P40.5：构建链 semantic artifact、Editor report 与完整收尾。

P40 不扩张手写 UE API，不负责最终 WASM lowering。
