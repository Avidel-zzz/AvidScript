# P40.2 类型化操作树与转换

状态：完成
日期：2026-07-13

## 本组目标

P40.2 把 Roslyn `IOperation` 投影为 AvidScript 自有的 semantic schema v2（semantic version 1.1）typed operation tree。后续 ControlFlowGraph 和 Guest IR 只消费这份版本化语义产物，不需要重新根据 C# 文本猜测字段、调用、重载或类型转换。

本组仍属于离线编译工具层，不改变 UE Runtime ABI，也不负责生成 WASM。

## 产物结构

`SemanticDocument.methods` 按完整方法 symbol ID 排序。每个方法包含一棵 operation tree：

- `kind`：AvidScript 稳定操作类别，如 `invocation`、`binary`、`conversion`。
- `operator_kind` 与 flags：区分 add/subtract、negate、increment/decrement，并保留 checked、lifted、postfix 语义。
- `is_supported`：当前语义配置是否支持该操作。
- `type_id`：Roslyn 已解析的结果类型，不由文本推断。
- `symbol_id`：字段、属性、局部变量、参数、构造器、运算符或调用目标的完整稳定 ID。
- `type_argument_ids`：泛型 invocation/method reference 的具体类型实参，与 OriginalDefinition ID 共同确定调用。
- `constant`：常量类别和 invariant-culture 文本。
- `conversion`：显式或隐式 conversion operation 的 identity、numeric、reference、nullable、user-defined 等属性，并由 operation flags 区分 checked cast 与 `as` try-cast。
- `input_conversion` / `output_conversion`：复合赋值和 argument 自身携带的 Roslyn 进入/写回转换，避免 Guest IR 重建语言规则。
- `span`：UTF-16 offset 与 0-based 行列。
- `children`：保持 Roslyn operation 子节点顺序的递归结构。

未知或不支持的操作不会被静默丢弃。产物保留其 kind、span、type 和子树，同时写入 `ASCS2001` error，使 `succeeded=false`，阻止后续 Guest IR 消费残缺语义。

## 符号绑定增强

本组没有实现手写重载解析。所有引用直接读取 Roslyn 绑定完成的 symbol：

- `new FVector(...)` 绑定完整构造器 ID。
- `FVector + FVector` 绑定 `op_Addition` ID。
- `UE.Self` 绑定完整 property ID。
- `AActor.SetActorLocation(FVector)` 绑定完整 method ID。
- local、field 和 parameter reference 均携带稳定 symbol/type ID。
- argument 绑定 Roslyn 选中的 parameter ID；实参值 conversion 继续保留在子 operation 中。

方法签名现在保留 `ref`、`out`、`in` 参数类别和泛型 arity，并把构造后的泛型 symbol 归一到 `OriginalDefinition`。indexer ID 包含参数签名；显式 accessor、表达式体 property/indexer getter 都会进入符号表和方法操作表，因此 `UE.Self`、`FVector.Zero` 这类实际 facade 代码不会遗漏。

局部变量 ID 由 containing method、源码声明位置、名称和 canonical type 构成；它不依赖进程内 Roslyn key 或对象地址。

## TDD 记录

首个 RED 在 .NET 8.0.416 下准确失败于缺少 `SemanticOperation` 和 `SemanticMethodBody`。基础 GREEN 覆盖：

- local、field、parameter reference；
- assignment 与 compound assignment；
- object creation、property、invocation 与 return；
- binary、unary、constant 与 numeric conversion；
- 真实 ActorLifecycle 的 FVector、UE.Self、AActor 完整绑定；
- unsupported lock 的保留与 fail-closed 诊断。

实现审阅阶段继续加入 accessor、表达式体 property、ref overload、operation-owned conversion、operator kind、indexer overload、generic arity/type arguments、checked/try cast 和 schema version RED，修复了 getter 漏投影、签名碰撞与 lowering 语义不完整问题。

P40.2 不提前宣称控制流完成：statement conditional（if）、loop、branch 和尚未投影 value conversion 的 coalesce 保留在 operation tree 中，但当前标记为 unsupported 并 fail closed；ternary conditional expression 仍按表达式支持。P40.3 接入稳定 CFG 后再有意识地升级这条支持边界。
