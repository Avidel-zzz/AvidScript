# P40.3 稳定控制流图

状态：完成
日期：2026-07-13

## 本组目标

P40.3 将 Roslyn `ControlFlowGraph` 投影为 AvidScript 自有的 semantic schema v3（semantic version 1.2）。它覆盖 `if/else`、`while`、`for`、`break`、`continue`、`return` 与短路布尔求值，为 Phase 41 Guest IR 提供可版本化、可确定性序列化的基本块和控制流边。

控制流只读取 Roslyn CFG，不根据 C# 文本、syntax 节点或 PowerShell 正则重新推导分支和循环。

## 结构设计

`SemanticDocument.control_flow_graphs` 按完整 method symbol ID 排序。每张图包含：

- `method_symbol_id`：与 `methods` 中 executable body 一一对应。
- `entry_block_ordinal` / `exit_block_ordinal`：唯一入口和出口。
- `blocks`：按 Roslyn ordinal 排序的 entry、block、exit。
- `operations`：基本块内按执行顺序排列的类型化 operation。
- `branch_value`：条件分支使用的类型化值。
- `condition_kind`：稳定映射为 `none`、`when_true` 或 `when_false`。
- `predecessors` / `successors`：同时保留 source、destination、edge kind 与 branch semantics。

边的 `semantics` 显式区分 `regular`、`return`、`program_termination` 等类别。公开 JSON 不写 Roslyn 数字枚举、对象 identity、程序集路径或 SDK 路径。

## 可执行体统一发现

新增 `SemanticExecutableBodyResolver`，让 operation tree 与 CFG 共用同一套方法、构造器、访问器、表达式体 property/indexer 发现逻辑。表达式体成员从表达式 operation 沿 `Parent` 上溯到 Roslyn 隐式 method/block root，因此 getter 的 return、typed operation 与 CFG 不会形成两套不一致视图。

真实 ActorLifecycle 中 38 个 executable method body 均有对应 CFG，包含 `FVector.Zero`、`FRotator.Zero`、`AActor.IsValid`、`USceneComponent.IsValid` 和 `UE.Self` 等表达式体 getter。

## Flow Capture

Roslyn 用 `IFlowCaptureOperation` 与 `IFlowCaptureReferenceOperation` 表达 `&&` 等短路求值的合流结果。schema v3 增加 `capture_id`：

- ID 由每张 CFG 独立的 `SemanticCaptureRegistry` 分配。
- 分配顺序来自稳定的 block/operation 遍历，格式为 `capture:0`、`capture:1`。
- capture 与 reference 使用 Roslyn `CaptureId` 的值相等关系绑定，但不会序列化其内部值或 `ToString()` 结果。
- ID 作用域限定在所属 method CFG，不与其他方法混用。

这避免把 SDK 内部类型名误当作稳定 ID，也避免 Guest IR 根据表达式文本重建短路求值。

## Fail-Closed 策略

P40.3 不输出半张图。任一 executable body 命中以下条件时，整份 `control_flow_graphs` 为空且 `succeeded=false`：

| 诊断 | 条件 |
| --- | --- |
| `ASCS3001` | exception region、throw/rethrow 或结构化异常边 |
| `ASCS3002` | async method |
| `ASCS3003` | iterator/yield method |
| `ASCS3004` | C# compilation error、Roslyn 无法创建 CFG 或未知 lowering operation |

statement conditional、loop 与 branch operation 在稳定 CFG 存在后升级为 supported。`coalesce` 仍保持 P40.2 的 unsupported gate，后续必须先投影 value conversion 才能开放。

## TDD 记录

首个 RED 因缺少 `SemanticControlFlowEdge` 等模型而编译失败。基础实现完成后，测试覆盖：

- `if/else`、`while`、`for`、`break`、`continue` 和 `return`；
- ordinal 连续、entry/exit 唯一、边端点有效、循环存在回边；
- predecessor 与 successor 描述同一组边；
- return 显式连接 exit；
- exception（含无目标 throw/rethrow 边）、async、yield 和非法 `break` 均 fail closed；
- 同输入 JSON 字节完全一致。

真实样例回归进一步暴露了表达式体 getter root 与 flow capture identity 两个问题。永久测试现在断言 ActorLifecycle 的 method/CFG 一一对应，并要求 capture ID 为 AvidScript 自有的数值格式，reference 只能指向已声明 capture。

仓库根 `global.json` 以 `rollForward=disable` 精确固定 .NET SDK 8.0.416，避免任何 SDK patch 改变 Roslyn CFG lowering、ordinal 或 capture 遍历。所有验证仍将 `DOTNET_CLI_HOME`、`APPDATA`、`LOCALAPPDATA` 和 `NUGET_PACKAGES` 隔离到插件 `Saved` 目录。
