# P41.0 Guest IR 与 WASM Backend 架构

## 本组结论

Phase 41 采用三模块编译架构：

- `AvidScript.GuestIr`：语言无关的 IR model、layout、serializer 和 validator；
- `AvidScript.CSharpGuest`：从 Phase 40 semantic artifact lowering；
- `AvidScript.WasmBackend`：从已验证 IR 生成 WASM 1.0。

`BuildCSharpActorLifecycle.ps1` 只保留工具发现、隔离环境、CLI 编排、artifact 清理和 report/manifest 组装。源码表达式解析、符号绑定、CFG、内存布局和 WASM opcode 不再属于 PowerShell。

## 为什么现在必须拆分

现有构建脚本约 2150 行，过渡 adapter 将 Roslyn span 提取、正则表达式识别、临时 statement model、host import 表和 WASM 字节编码放在同一文件。继续扩写会让字符串、数组、枚举和控制流各自形成第二套语义系统，也无法给未来 `.avid` 或其他 guest language 复用 backend。

Phase 40 已经提供稳定 type/symbol/operation/CFG；Phase 41 的唯一合理输入是 semantic artifact，不再读取源码文本猜测含义。

## Guest IR 形态

IR 使用 typed register CFG：

- module 维护 type、state/global、import、function、export 和 data segment；
- function 维护 parameter/local/basic block；
- block 维护有序 instruction 和唯一 terminator；
- value、block、function、type 都使用 AvidScript 自有稳定 ID；
- source span 只用于诊断和未来 source map，不参与执行身份。

该模型比 WASM operand stack 更适合作为多语言边界，也比在 Phase 41 立即引入 SSA/phi 更容易从 Roslyn CFG 正确 lowering。后端初版使用通用 block-dispatch loop；优化和 AOT 在 Phase 53 处理。

## 内存与容器

- scalar：`i32/i64/f32/f64`；
- enum：底层整数；
- struct：按字段 alignment 确定性布局；
- string：UTF-8 immutable data，header 保存 byte length；
- array：header 保存 element count，payload 按 element stride 排列；
- runtime allocation：模块私有 bump allocator；
- UObject：继续使用 slot/generation handle，不暴露指针。

每次 array 访问必须 bounds check。所有尺寸、offset 和 address 运算使用 checked arithmetic；失败写稳定 IR diagnostic 或 trap。

## Binding 边界

Guest compiler 不知道 `AActor` 或 `FVector`。外部调用只能来自：

1. C# semantic callable 上的稳定 import ABI；
2. Phase 42 Reflection Binding Generator 生成的 binding descriptor。

默认 ActorLifecycle 中现存的 `DllImport` 只用于把新 backend 接回已有 host ABI；不得借此继续手写 API。自定义 profile 的 reference facade 在 Phase 42 生成 descriptor 前保留明确兼容边界，不允许按方法名猜测。

## P41 分组

- P41.1：semantic callable 与 type-shape；
- P41.2：Guest IR core、serializer、validator；
- P41.3：状态和容器 data layout；
- P41.4：C# semantic lowering；
- P41.5：WASM backend；
- P41.6：构建链接入、UE 回归与收尾。

## 验收

Phase 41 收尾时，默认 ActorLifecycle 必须从 semantic artifact 经过 Guest IR 生成 direct ABI WASM，并通过 UE BeginPlay/Tick/EndPlay；PowerShell 不再作为默认语义 emitter。所有新增人读文档使用中文，完整实现不新增逐 UE API 的硬编码表。
