# P41.4 C# Semantic 到 Guest IR Lowering

## 完成内容

P41.4 新增独立的 `AvidScript.CSharpGuest` 编译阶段，将 Phase 40 的 C# semantic schema v4 / semantic 1.4 artifact 降级为语言无关的 Guest IR v1。该阶段不读取 C# 源码文本，不解析 `SemanticSymbol.Signature`，也不维护 UE API 手写映射；类型、调用、import/export、属性访问器和用户自定义运算符均来自 Roslyn 已绑定的 semantic contract。

产物发布顺序固定为：

1. 校验 semantic object graph、版本、成功状态和 provenance hash；
2. 投影 canonical Guest type、global state、callable ABI 与 stable ID；
3. 按 Roslyn CFG 降级 basic block、operation 和 terminator；
4. 通过 P41.3 共享 layout 放置 state 与 constant data；
5. 运行独立 `GuestModuleValidator`；
6. 仅在验证成功后原子写入 `.guestir.json`。

## 模块边界

- `CSharpTypeLowerer`：primitive、struct、enum、string、array 与 address type；
- `CSharpControlFlowLowerer`：block、branch、conditional、loop back-edge 与 return；
- `CSharpOperationLowerer`：标量表达式、显式存储、conversion 与 flow capture；
- `CSharpAggregateOperationLowerer`：struct allocation、field load/store 与 instance；
- `CSharpCallOperationLowerer`：static/instance call、constructor、property getter 和 ref/out/in 参数；
- `CSharpGuestDataPool`：按 canonical payload SHA-256 去重 UTF-8 string 与常量 array；
- `CSharpSemanticInputValidator`：损坏、null 或重复 semantic object graph 失败关闭；
- `GuestIr` validator 扩展：独立验证 storage、aggregate、pointer 与 data instruction。

这些职责不依赖 UE、WAMR 或 PowerShell。PowerShell 仍只负责未来 P41.6 的 CLI 编排。

## 已支持语义

当前 lowering 已覆盖：

- static script state、mutable local、普通 parameter 与 ref/out/in parameter；
- int/float/bool 常量、enum underlying integer、UTF-8 string、常量 array；
- assignment、compound assignment、numeric conversion、算术与比较；
- if/else、loop、break/continue 所形成的普通 CFG edge 与回边；
- flow capture 与跨 block capture reference；
- static/instance call、host import、Guest function、constructor 与 property getter；
- struct local、`this`、field load/store、显式 local address 和 indirect load/store；
- Roslyn 已绑定的用户自定义 binary operator；
- void/non-void return、semantic export 到 Guest function 的稳定关联。

新增 Guest IR instruction 为：

- 存储：`local_load`、`local_store`、`global_load`、`global_store`；
- 聚合：`stack_alloc`、`field_load`、`field_store`；
- 地址：`address_of`、`indirect_load`、`indirect_store`；
- 数据：`data_address`。

每个 opcode 都有独立 validator 规则。未知 opcode、错误 field、错误 pointee type、错误 callable signature 或未绑定 external call 均失败关闭。

## 测试与失败关闭

- CSharpGuest：14/14；
- GuestIr：29/29；
- production 与 tests 项目分别通过 `dotnet format`；
- synthetic tests 覆盖 state/local/parameter、if/loop、struct、out/ref、conversion、return、string/enum/array、flow capture、用户 operator 与 unsupported external call；
- CLI 测试覆盖两次字节确定性以及失败时删除 stale output；
- null/重复 semantic object graph 返回 `ASCG1001`，不泄漏 `NullReferenceException`；
- 重复且被指令引用的 Guest ID 返回 validator 诊断，不泄漏 LINQ sequence exception。

## 当前边界

P41.4 产出的是已验证 Guest IR，还不是可由 WAMR 执行的 WASM。开始在 UE 中运行这套新编译链还需要：

1. P41.5 将 Guest IR 编译为确定性 WASM 1.0，并验证 WAMR load/execute；
2. P41.6 将默认 ActorLifecycle 构建入口切到新 compiler，并完成 manifest/report provenance 与 UE automation；
3. P42 用 Reflection Binding Generator 批量生成真实 UE API descriptor/proxy/host dispatch。

当前 array creation 只接受可静态编码的常量 initializer。动态 heap array、完整 bounds-checked element access 和更广泛容器语义属于后续 backend/container 阶段，不在 P41.4 中伪装完成。
