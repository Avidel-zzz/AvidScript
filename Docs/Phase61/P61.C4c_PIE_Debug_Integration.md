# P61.C4c PIE 调试集成

## 目标

证明 P61.C 的调试协议不是 fake-only 模型：真实 Debug C# 必须编译为 WASM，由 PIE
`UAvidScriptComponent` 加载，并经生产 Editor Controller 完成暂停、变量、单步、继续和生命周期回收。

## 已实现

- 新增 `AvidScript.Editor.Debugging.PIEIntegration`；
- 在 `EWorldType::PIE` World 中创建真实 Actor 与 `UAvidScriptComponent`；
- 使用 Debug instrumentation 的 ActorLifecycle WASM 和 Debug Map v2；
- 生产 `TObjectIterator` 发现器识别 Component Session，并按真实 UObject path 选择目标；
- 从 Runtime 断点目录选择 Tick 源码位置，Editor Model 解析并绑定 probe；
- attach 后 pause-next 使真实 C# Tick 协作式暂停，变量视图读取 `deltaSeconds`；
- step-into 进入下一源码点，continue 完成原 Tick；
- 同清单 reload 推进 Runtime epoch，保留 debugger attached 状态并重新绑定断点；
- EndPlay 卸载 Runtime 后，Controller 自动移除目标、失效绑定并保留用户断点。

## 可重复入口

```powershell
pwsh Build/RunAvidScriptEditorDebuggerPIEIntegration.ps1
```

Runner 自动生成隔离的 `Saved/AvidScriptCSharpGuest/DebuggerPIE` fixture，启动 UE5.8 NullRHI
Automation，并要求发现数 `1`、Success `1`、Fail `0`、测试退出码 `0` 与正常 RequestExit 同时成立。

## 边界与教训

- Automation 证明 Runtime、World、Component、Controller 和 Session Model 的真实跨层闭环，不能代替用户
  在可见 Editor 中点击面板、检查布局和外部 IDE 打开体验；这些保留为 `P61.E` 人工验收；
- 本批次再次出现 Windows `rg` 直接路径通配与 `--` 后放置 `-g` 的错误，已更新 Harness lesson：
  先索引字面路径，所有 glob 选项必须位于终止符之前。
