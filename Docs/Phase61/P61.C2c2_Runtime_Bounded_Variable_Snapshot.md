# P61.C2c2 Runtime 有界变量 Snapshot

## 本节完成

- Runtime 的 Debug Map v2 读取器解析并严格验证 probe、frame 和变量布局；
- 每个 frame 最大 4 KiB、每个函数最多 256 个元数据变量，重复 probe、重叠槽、越界字段和未知存储均拒绝加载；
- Session 新增 `GetDebugVariables`，只允许在 `Paused` 状态读取当前 suspension frame；
- snapshot 携带 epoch、pause sequence、active probe、项目相对源码、函数与行列，避免 Editor 混用旧暂停结果；
- 参数在方法作用域可见，局部变量仅在声明完成且当前 probe 仍位于词法 scope 时出现；
- 首版格式化标量、enum、ObjectHandle、能力/容器 token，并为内存值类型提供有界摘要；
- 单次查询最多返回 128 个变量和 16 KiB 展示文本，超限以 `bTruncated` 明确标记；
- 对外结构不包含 frame 字节或原始 WASM memory，continue、reload 和 teardown 仍由 Session 生命周期清理。

## 架构边界

Debug Map 负责把稳定 probe 映射到 C# source symbol 和 frame slot；Session 负责暂停代际与 frame
所有权；VM 仍只实现 probe/suspend/frame-read ABI。变量树展开、容器元素读取和 UObject 友好名称
属于后续 Editor 调试服务，不进入 VM 或 C# 编译器热路径。
