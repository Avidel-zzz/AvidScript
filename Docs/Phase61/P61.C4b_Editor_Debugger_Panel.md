# P61.C4b Editor Debugger 面板

## 目标

把已经完成的 Runtime 调试协议、Editor Session Model 与 PIE Target Controller 组合为可操作的
UE Editor 工具，同时保持 UI、目标发现和 Runtime 生命周期解耦。

## 已实现

- 在 `Tools > AvidScript` 注册 `Open AvidScript Debugger`，按需打开隐藏 Nomad Tab；
- 面板可选择当前 PIE AvidScript Component 目标，并显示 World、module 与调试状态；
- 提供 attach、detach、pause、continue、step-into 和手动刷新；
- 支持按源码路径与行号新增断点，以及断点启停、删除和源码跳转；
- 暂停后展示与当前 epoch、pause sequence、active probe 一致的有界变量 snapshot；
- active source、断点源码跳转复用现有安全导航器，继续验证项目边界与 source SHA-256；
- 面板只调用 Controller command wrapper，不持有 Runtime Session 裸指针；
- 模块 ticker 仅在 PIE 活跃时低频刷新目标，面板 active timer 只刷新展示模型；
- 模块卸载时依次移除 ticker、PIE delegate、Controller 绑定与 Tab spawner。

## 架构边界

- Slate 面板属于私有展示层，公开契约仍是 `FAvidScriptEditorDebugTargetController` 与
  `FAvidScriptEditorDebugSessionModel`；
- 源码断点可在无 PIE 时维护，Runtime 控制命令必须先确认 live target；
- 当前不宣称完整 call-stack 面板、断点条件表达式或 async/non-void 暂停；这些能力按后续批次扩展，
  不在 UI 内另建调试协议。

## 验证

- UE5.8 no-clean `AvidScriptEditor` 模块构建成功；
- `AvidScript.Editor.Debugging`：发现 `3` 项，`3/3` Success，退出码 `0`；
- `AvidScript.Editor.Module`：发现 `8` 项，`8/8` Success，退出码 `0`；
- Automation 覆盖 Controller command wrapper、离线断点、目标替换、面板构造、菜单配置与 Tab 注册；
- 真实 PIE 点击、暂停变量目视检查和外部 IDE 打开体验由 `P61.C4c` 验收。
