# P61.C4a PIE 调试目标与生命周期

## 目标

把 Editor 调试模型接到真实 PIE `UAvidScriptComponent` Session，同时保持 Runtime 所有权和 teardown 安全。

## 已实现

- `UAvidScriptComponent` 在 Editor 构建中提供正式导出的调试 Session accessor；
- Controller 只发现 `PIE`/`GamePreview` World 中已加载 live Runtime 的 Component；
- 目标包含稳定 id、显示名、World、module id 和 Runtime identity，并按 id 确定排序；
- 首个目标可自动选择，也可按 id 切换；切换仍要求 Runtime 接受正常 detach；
- Session identity 变化时重建 adapter，用户源码断点由 Model 自动解析到新 probe；
- 目标消失或 PIE 结束时使用 `NotifyRuntimeDestroyed`，不调用可能已经失效的 Session；
- target discovery 可注入，Automation 不需要伪造 UObject 私有生命周期。

## 错误与防复发

初版跨模块 accessor 写成了 `dllimport` 类内 inline。UBT 链接成功，但真实 Editor 加载
`AvidScriptEditor.dll` 时以 `GetLastError=127` 拒绝。现已改为 Runtime `.cpp` 导出定义，并新增 Harness lesson：
跨模块 API 必须同时通过链接与真实模块加载验证。

## 验证

- UE5.8 完整 no-clean `AvidTPSTemplateEditor`：`15/15` actions，Runtime 与 Editor DLL 均重新链接；
- `AvidScript.Editor.Debugging`：发现 `2` 项，`2/2` Success，退出码 `0`；
- Controller Automation 覆盖 PIE 自动选择、目标替换、probe 重绑定、无旧 Session detach 和 EndPIE 清理；
- Slate 面板与真实 PIE 人工点击验收由 `P61.C4b-C4c` 完成。
