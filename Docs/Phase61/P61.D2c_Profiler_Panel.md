# P61.D2c Profiler 面板

## 目标

把已验证的 Profiler Model 接入现有 AvidScript Debugger Tab，形成可以在 PIE 中选择 Session、采样、定位热点
和导出证据的完整 Editor 工作流，同时避免再建立一套 target 或生命周期系统。

## 已实现

- Debugger Tab 增加 `Debugger / Profiler` 页签，共用目标选择与 PIE target 生命周期；
- Profiler UI 独立为 `SAvidScriptEditorProfilerPanel`，自行管理采样、过滤、刷新、导出和状态展示，
  父面板只保留目标工具栏与页面切换；
- capture checkbox 表达二元采集状态，reset、export 和源码跳转使用 Editor 图标按钮与 tooltip；
- 事件类型按 Guest、UE、Async、Runtime、Build 多选过滤；
- 支持最小时长、文本和仅失败事件过滤；
- Hotspots 按总耗时排序，显示 kind/operation、调用次数、总耗时、平均耗时与函数；
- Events 以最新优先显示 kind/operation、耗时、结果与源码函数；
- 有 source probe 的热点和事件可以直接跳转 C# 文件；
- export 原子写入 `Saved/AvidScript/Profiler/AvidScriptProfiler.json`，状态区显示结果路径；
- UI 默认只创建最新 `250` 个事件行和前 `50` 个热点行；snapshot revision 与过滤签名未变化时不重建 Slate。

- `AvidScript.Editor.Debugging`：发现 `4` 项，Success `4`、Fail `0`、正常退出；
- `AvidScript.Editor.Profiling`：发现 `1` 项，Success `1`、Fail `0`、正常退出；
- Debugging 日志 SHA-256：`cd6f0b749589f3b927179107ad4238c0f32e49e86c6774dea4b4d9cd91a4e042`；
- Profiling 日志 SHA-256：`44fdf07cedce0f1ad0523ba4a670934ab54f9baeee6e851271529bf77048c928`；
- panel construction、fake target lifecycle、真实 Debug C# WASM PIE 和 Profiler Model 均在本轮覆盖。

## 边界

- Automation 验证控件构造、模型和真实 PIE 数据链路，但不能替代人工点击、滚动、可读性与源码跳转体验；
- 人工 Editor 验收清单保留到 `P61.E`，不在本小节伪造通过结论；
- 当前为表格/热点视图，不绘制时间轴 flame graph；UE Insights 可通过 `AvidScriptProfiler` Trace channel
  消费完整事件，独立时间轴可在后续成熟度阶段按实际需求增加。
