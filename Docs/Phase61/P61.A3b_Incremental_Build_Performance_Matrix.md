# P61.A3b 增量构建性能矩阵

## 已实现

- 新增独立的增量构建矩阵工具，使用隔离工作目录和真实 C# 四阶段编译链；
- 覆盖无修改、方法体变更、Binding package 变更与工具链变更四类场景；
- 每轮同时记录 semantic/compilation cache、Frontend/Semantic/Guest IR/WASM 调用次数、
  persistent Worker 使用状态和端到端耗时；
- 正确性断言 fail-closed：缓存命中或阶段调用次数不符合依赖图时，矩阵立即失败；
- JSON 报告仅保留提交、平台、统计值与脱敏测量数据，不写入本机绝对路径和个人信息；
- Architecture Gate 固定场景、断言和预算入口，防止后续优化绕过正式矩阵。

## 当前边界

- 数据衡量 AvidScript C# 增量构建链，不等同于 Runtime UE/WASM 调用性能；
- 工具链变更场景刻意更换 Guest compiler fingerprint，只重建受影响的 Guest IR/WASM 节点；
