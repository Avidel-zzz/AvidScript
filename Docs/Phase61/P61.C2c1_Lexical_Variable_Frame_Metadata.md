# P61.C2c1 词法变量帧元数据

## 本节完成

- Debug Map v2 为可恢复同步函数附带可选 `frame` 布局，不影响无调试帧函数和旧读取器；
- 变量槽直接取自实际 suspension frame，不建立与恢复协议分离的第二套布局；
- 首批覆盖 C# 源参数与局部变量，记录稳定 symbol、名称、类型、值类别、WASM 存储、偏移和大小；
- 参数使用方法级作用域，局部变量从语义操作树定位到最近的 block、loop 或 switch case；
- 同时记录声明 span 与词法 scope，后续 Runtime 可按当前 probe 排除尚未声明或已经离开作用域的变量；
- 编译器 temporary、地址重建值和合成调试寄存器不进入面向用户的变量列表；
- frame、字段、类型或 source symbol 无法严格对应时，以 `ASDEBUG1006` 在产物生成阶段拒绝。

## 架构边界

元数据仍由 C# 工具链生成，Runtime 只消费版本化 Debug Map；VM 不理解 C# symbol，也不暴露原始
WASM memory。变量值读取必须基于 Session 已拥有的暂停 frame，并保持深度、元素数与字节预算。

本节尚未把 frame 字节转换为可展示值，也没有宣称 Editor 已能查看变量。该闭环由 `P61.C2c2`
和后续 Editor view-model 小节完成。
