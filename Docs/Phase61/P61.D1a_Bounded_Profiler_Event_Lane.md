# P61.D1a 有界 Profiler 事件通道

## 目标

建立不依赖 Editor、可由每个 Runtime Session 独立拥有的 Profiler 采集底座，避免在 Guest/UE crossing
热路径写字符串、申请内存或争用锁。

## 已实现

- `FAvidScriptProfilerEventBuffer` 构造时一次性分配固定容量，默认 `4096`、上限 `16384`；
- 单写者契约下 Record 不使用锁，快照只在 GameThread 冷路径生成；
- 容量耗尽时覆盖最旧事件，保留确定顺序并累计 `DroppedEventCount`；
- 非 owner thread 的 buffer 写入 fail-closed，并累计 `RejectedThreadEventCount`；
- 事件只携带 kind、operation id、cycles、epoch、probe、correlation id、数值 payload 与 outcome；
- RAII scope 只在 buffer 或 Trace channel 启用时读取 cycle counter；
- 自定义 `AvidScriptProfiler` UE Trace channel 输出与 buffer 相同的结构化字段；
- snapshot 提供稳定 sequence、revision、cycle 换算比例和完整丢弃统计。

## 架构边界

- D1a 只负责无锁存储、scope 与 Trace 输出，不负责 Runtime 业务埋点；
- Session 采集控制和 Guest/host/continuation/reload 事件由 `P61.D1b` 接入；
- Editor 过滤、聚合、导出和源码定位由 `P61.D2` 消费 snapshot，不反向依赖 Runtime 私有实现。

## 验证

- UE5.8 no-clean `AvidScriptRuntime`：新增源进入真实 action graph，最终链接成功；
- `AvidScript.Runtime.Profiling`：发现 `2` 项，`2/2` Success，退出码 `0`；
- Automation 覆盖 disabled fast path、固定容量覆盖、sequence 顺序、丢弃统计、metadata/outcome、
  reset 和 scope 采集。
