# P61.C1c 调试构建 Profile 与缓存身份

## 本节完成

- `BuildCSharpActorLifecycle.ps1` 新增 `DebugInstrumentation=auto|enabled|disabled`。
- `auto` 在 Debug 配置启用，在 Release 配置关闭；Editor 调试会话可显式选择 `enabled`。
- 正式 Guest compiler、persistent compiler worker 和 worker 协议均透传最终插桩模式。
- 编译缓存身份纳入最终插桩模式，Release 与 Debug artifact 不会错误复用。
- 构建报告与 runtime manifest 记录最终模式；编译器注入的 probe import 仅在模式启用且 ABI
  完全匹配时通过 binding authorization。
- 增量测量与测试用的 compiler wrapper 已同步新参数，Release 默认行为保持兼容。

## 当前边界

工具链现在可以正式生成并缓存带 probe 的 WASM，但 VM 尚未注册 probe host import，因此该产物
还不能进入 Runtime Session。P61.C1d 将补齐 VM capability 与双后端 import；P61.C2 再实现
Session pause continuation。
