# P61.A3a 结构化诊断与源码定位

## 已实现

- C# Build report 新增 `diagnostic_schema_version: 1`，并将 Frontend、Semantic 与构建链错误
  统一为稳定的 `code`、`severity`、`stage`、`message`；
- 带源码位置的诊断统一携带项目相对 `source_id`、源码 SHA-256、模块 id、UTF-16
  `start/length` 与 1-based `line/column/end_line/end_column`；
- Editor report reader 兼容旧的 0-based 诊断，同时显式解析新 schema、stage、hash、module
  与 line base；C# BuildService 结果直接保留结构化诊断数组；
- 新增 Editor 源码导航服务：只接受项目相对路径，拒绝目录穿越、文件缺失和源码 hash
  漂移，通过校验后交给 UE `FSourceCodeNavigation`；
- 源码 hash 使用 UE 随引擎提供的 OpenSSL SHA-256，避免依赖没有平台实现的
  `FPlatformMisc::GetSHA256Signature` 桩函数。
