# P61.D4b 离线源码索引

## 目标

为 Debugger、Profiler 与后续 IDE 工具提供不依赖活跃 Session 的源码目录，同时避免泄露本机绝对路径。

## 已实现

- 新增独立 `FAvidScriptEditorCSharpSourceIndexService`，Workspace Service 只在产物就绪后调用发布；
- 原子生成 `Intermediate/AvidScript/CSharpWorkspace/AvidScript.SourceIndex.json`；
- schema v1 记录 workspace、solution、project，以及用户脚本和 generated facade 的项目相对路径、角色和 SHA-256；
- source entry 按路径排序，输入不变时 JSON 和索引哈希确定；用户源码变化后索引哈希同步变化；
- Reader 严格验证 schema、相对路径、路径穿越、角色和 64 位十六进制哈希；
- Workspace Result 返回索引路径、内容哈希与刷新状态，Editor 结果详情可直接显示索引位置。

## 验证

- UE5.8 Editor 增量构建：新增服务轮 `6/6` action 通过；
- `AvidScript.Editor.CSharpWorkspaceService`：发现 `2` 项，Success `2`、Fail `0`、正常退出；
- 自动化覆盖离线读取、schema、两类 source、项目相对路径、哈希一致性和源码变化；
- 日志 SHA-256：`7d6a234ed2ec5d76523faa816d98bc5478ea7d3b1d914defe8bd5d77176b8b9e`。

## 边界

- 索引不替代 build report/debug map；它提供稳定的源码身份与入口，行列映射仍由现有调试映射负责；
- 外部 IDE 启动与命令注册属于 `P61.D4c`；实际 IDE 跳转体验保留到 `P61.E` 人工验收。
