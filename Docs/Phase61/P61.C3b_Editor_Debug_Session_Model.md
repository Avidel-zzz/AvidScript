# P61.C3b Editor 调试会话模型

## 目标

在 Slate 面板和 PIE 生命周期接线之前，先建立可测试、非阻塞且不拥有 Runtime 生命周期的 Editor 调试模型。

## 已实现

- `IAvidScriptEditorDebugRuntime` 将 Editor 与具体 Runtime Session 隔离；
- `FAvidScriptEditorRuntimeDebugAdapter` 只转发公开 Runtime 调试协议，不解析 artifact；
- 用户源码断点可在 PIE Session 之外保存，绑定后按项目相对路径和精确行解析稳定 probe；
- 同一行多个候选按列和 probe ID 确定选择，未命中保持 `Unresolved`；
- attach/detach、pause-next、continue 和 step-into 都是单次 GameThread 调用，不轮询或等待 Guest；
- 暂停变量必须同时匹配 epoch、pause sequence 和 active probe，不一致时清空旧视图；
- reload epoch 变化时重新读取 validated catalog，并把新的 probe 集合同步到已附加 Session；
- Session 解绑会清除 catalog、运行状态和变量，但保留用户断点请求。

## 所有权

- Runtime Session 仍由 Component 或 WorldSubsystem 拥有；
- Adapter 和 Model 均不延长 Session 生命周期；
- C4 的 PIE controller 必须在 Runtime teardown 前解绑 Model；
- Model 不直接依赖 Slate，因此命令、面板和测试可共享同一状态机。

## 验证

- UE5.8 `AvidScriptEditor` no-clean UBT：`12/12` actions，成功；
- `AvidScript.Editor.Debugging.SessionModel`：`1/1` Success；
- Automation 覆盖离线断点、绑定、启停同步、pause、变量一致性、continue、reload 重绑定和解绑；
- 真实 PIE 点击断点、变量展示和源码跳转保留到 `P61.C4` 人工验收。
