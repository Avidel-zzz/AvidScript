# P61.D1c Profiler Disabled 性能门禁

## 目标

确保 profiler 默认关闭时不会把观测成本带进游戏热路径，并提供可重复执行、会在预算超限时直接失败的
Automation Gate。

## 测量设计

- 复用 `FAvidScriptRuntimeBenchmark`，同进程测量 control loop、disabled scope 和 enabled capture；
- 固定 `3` 轮预热、`21` 个样本、每样本 `250,000` 次，轮间反转执行顺序降低热机偏差；
- 每次操作携带可观测 checksum，避免编译器消除循环；
- disabled 状态要求事件数为零，enabled 状态要求 ring 内事件数与 dropped 数之和等于操作总数；
- 若 `AvidScriptProfiler` UE Trace channel 已开启，门禁 fail-closed，避免把 Trace 成本误算成 disabled 路径；
- 固定预算：disabled 中位数 `<= 10 ns/op`，且 `<= enabled 中位数的 25%`。

## 最终结果

| 指标 | 中位数 |
| --- | ---: |
| Control loop | `1.538 ns/op` |
| Profiler disabled | `1.989 ns/op` |
| Disabled 增量 | `0.451 ns/op` |
| Profiler enabled | `33.318 ns/op` |
| Disabled / enabled | `5.97%` |

disabled 捕获 `0` 个事件；enabled ring 保留 `256` 个事件并记录 `5,999,744` 次覆盖，合计对应
`6,000,000` 次操作。预算通过。

## 执行入口

```powershell
pwsh Build/RunAvidScriptProfilerPerformanceGate.ps1
```

Runner 使用唯一 `-abslog`，严格校验测试发现数、Success、正常退出、`budget=pass` 摘要并输出日志哈希。
最终证据日志 SHA-256：`b77211e7afe4967ff0d3a2723ab769230ddc74d3cd5311531885b56416b8d403`。

## 边界

该结果是当前 Windows/UE5.8 开发机上的微基准，用于回归门禁，不等同于移动端或 Shipping 构建结论。
跨平台预算将在对应后端与目标平台可执行后分别校准，不能直接沿用本机绝对值。
