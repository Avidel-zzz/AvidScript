# P61.D4c2 Editor IDE 命令

## 目标

把现代 C# 工作区和 IDE 启动服务接成用户可直接操作的 Editor 工作流，并沿用现有菜单注册与结果展示体系。

## 已实现

- Tools > AvidScript 注册默认 IDE、Visual Studio、Rider、VS Code 四个工作区打开命令；
- 每个命令有稳定且互不冲突的 entry name、明确 label 和 tooltip；
- 执行时先调用 Workspace Service 安全刷新六个用户文件、typed facade 与 Source Index；
- 启动参数统一交给 `FAvidScriptEditorIdeLaunchService`，菜单 handler 不拼接进程命令；
- 成功和失败结果通过现有 AvidScript Diagnostic Log 发布，包含 IDE、target、executable、工作目录和下一步；
- Workspace 失败会原样映射为结构化 launch failure，不尝试启动外部应用。

- Visual Studio、Rider、VS Code 的安装发现和实际编辑体验保留到 `P61.E` 人工验收。
