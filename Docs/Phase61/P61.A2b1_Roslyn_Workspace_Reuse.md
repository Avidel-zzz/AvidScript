# P61.A2b1 Roslyn Workspace 复用

## 已实现

- 新增显式 `SemanticCompilerWorkspace`，由 persistent Worker 的 stage executor 持有；
- 每个 Worker 实例只创建一次 trusted platform assembly metadata reference set；
- primary source 与 generated reference source 使用内容哈希加 source id 的有界 LRU 语法树缓存，
  默认上限 64，避免无限增长；
- 普通 Semantic CLI 仍创建一次性 workspace，现有命令行和公共分析 API 保持兼容；
- Worker 响应公开 metadata build、syntax hit/miss 与当前 entry 数，供 Build report 和性能矩阵使用。

## 验证

`CompilerWorkerProtocolTests.ps1` 在同一 Worker 实例连续执行两次 Semantic：第一次
metadata build 为 1 且产生 syntax miss，第二次 metadata build 仍为 1，并出现新增 syntax hit。
Worker 项目使用固定 SDK `8.0.416` 编译为 `0 warning / 0 error`；Semantic 自执行测试
`97/97` 通过，并覆盖容量 1 时的命中、淘汰与 metadata 单次构建。

## 边界

- 当前复用的是 Roslyn 不可变 metadata 与 syntax tree；每次请求仍创建独立 Compilation 和
  SemanticModel，避免旧源码语义泄漏到新请求；
- Build 脚本接入、transport timeout/crash fallback 和实例指标写入 build report 属于
  `P61.A2b2`。
