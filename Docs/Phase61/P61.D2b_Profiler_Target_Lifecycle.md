# P61.D2b Profiler Target 生命周期

## 目标

让 Editor Profiler 与 Debugger 选择同一个真实 PIE `UAvidScriptComponent` Session，同时保持接口、状态模型和
命令面解耦，并在 target replacement 或 World teardown 时不访问旧 Runtime。

## 已实现

- target descriptor 增加独立 `CreateProfilerRuntime` factory；
- 生产发现器使用 `TWeakObjectPtr<UAvidScriptComponent>` 与 Session identity 双重校验后创建 profiler adapter；
- Controller 共享 target 选择和 identity 检测，但分别拥有 debug runtime、profiler runtime 和两个 model；
- Tick 分别刷新 Debug Session 与 Profiler Snapshot，不让 profiler 警告改变调试状态机；
- capture、reset 与 JSON export 通过 Controller 命令路由到 Profiler Model；
- target 切换先解绑两个模型，再创建新 adapter；创建中途失败会使已绑定模型 fail-closed；
- Session replacement、target 消失和 PIE EndPlay 直接使两个模型失效，不对旧 Runtime 调用 detach/reset。

## 验证

- UE5.8 `AvidScriptEditor` 增量构建：`3/3` action 通过；
- `AvidScript.Editor.Debugging.TargetController`：`1/1` 通过，覆盖 capture、target replacement 与 EndPIE；
- `AvidScript.Editor.Debugging.PIEIntegration`：`1/1` 通过，真实 C# WASM target 由 Controller 启用采集，
  并在 EndPlay 后同时失去 debug/profiler binding；
- PIE Runner 日志 SHA-256：`fd8fe63c60222d982f6e18d045dbb5d45c29eacc3984c8224e256907ba6fe564`。

## 边界

- target 生命周期已完成，但本小节不增加 Slate 控件；
- 用户可见的 capture、filter、hotspot、event 与 export 控件由 `P61.D2c` 接入现有 Debugger Tab；
- profiler capture 状态属于每个 Session，切换 target 不会把上一个 target 的 enabled 状态复制到新 Session。
