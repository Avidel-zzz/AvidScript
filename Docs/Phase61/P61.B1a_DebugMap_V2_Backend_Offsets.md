# P61.B1a DebugMap v2 与 Backend 偏移回填

## 已实现

- DebugMap 升级为 schema v2，并在函数映射下增加有序 sequence point；
- sequence point 携带稳定 Guest instruction identity、semantic operation identity、kind、hidden
  标记与 C# UTF-16 span；
- 同步 C# CFG lowering 在语义操作产生首条 Guest instruction 时附加瞬态 debug location；该字段
  使用 `JsonIgnore`，不会改变 Guest IR schema 或缓存身份；
- WASM backend 在真实编码时记录每条 Guest instruction 的 function-relative offset，Guest 层不
  估算 LEB128、局部变量表或指令长度；
- backend 生成带 Guest IR/WASM SHA-256 的临时 offset artifact，C# Guest 校验 module、函数索引
  空间与 provenance 后原子回填 DebugMap；临时 artifact 不进入发布包；
- one-shot compiler 与 persistent Worker 使用相同的 finalize 链路，失败时拒绝发布未回填的 v2 map；
- Build 合同同时接受 v1 与 v2，v2 必须额外验证 WASM hash、sequence point 身份、顺序、kind
  与 span；v1 留作已有 artifact 的函数级兼容输入。

## 数据流

```text
Semantic operation
  -> transient Guest debug location
  -> DebugMap v2 draft (offset = -1)
  -> WASM backend real byte emission
  -> bounded offset artifact (Guest IR hash + WASM hash)
  -> atomic DebugMap finalize
```

DebugMap v2 最终 provenance 同时绑定 Frontend、Semantic、Guest IR 与 WASM，避免 source map
与实际执行模块发生跨构建混用。

## 当前边界

- 当前精确 sequence point 首先覆盖同步 CFG 语义操作；async resume、await transfer 与 host
  crossing frame 合并将在 `P61.B1b/B2` 完成；
- Runtime 仍按 v1 函数 span 映射，本小节尚不宣称 Editor 已具备语句级调用栈；
- backend offset 与 Wasmtime/WAMR trap offset 的端到端校准属于下一小节 Runtime 集成。
