# P61.C1d VM 调试 Probe 能力

## 本节完成

- 在 VM 公共契约中加入 `DebugProbe` capability，以及 `Continue/Pause/Abort` 动作协议。
- 冻结静态导入 `avidscript.avid_debug_probe(i64) -> i32`，probe id 全程按 64 位传递。
- Wasmtime 与 WAMR 均声明该能力；WAMR 原生 wrapper 和共用静态调用路径已完成注册。
- Runtime 在尚未开启调试会话时返回 `Continue`，因此带插桩的 WASM 已可被双后端加载并正常执行。
- 导入只存在于 `avidscript` 模块，不进入旧 `env` 兼容面。

## 当前边界

本节打通的是编译产物、VM 后端与 Runtime 之间的 probe 执行闭环。Runtime 当前尚未建立活动
debug lane，probe 默认继续执行；因此还不能宣称断点暂停、继续、单步或变量查看可用。
`P61.C2` 将实现 Session-owned 调试状态机和非阻塞 pause continuation。
