# P61.A2b2 Build 链路接入

## 已实现

- `BuildCSharpActorLifecycle.ps1` 新增 `auto|required|disabled` 三种 Worker 模式，默认 `auto`；
- Worker 按编译器源码、项目文件、客户端脚本、固定 .NET host 的内容指纹隔离，使用 named
  mutex 串行 provision，并通过 `CurrentUserOnly` named pipe 通信；
- 只有 cache miss 需要编译时才构建或连接 Worker；完整双层 cache hit 保持四阶段零调用，
  也不会为了 ping 而启动进程；
- Frontend、Semantic 与默认 Guest IR/WASM 路径在同一 Worker 内执行；自定义 Guest compiler
  仍由原 PowerShell 路径调用，避免插件扩展点被静默绕过；
- transport timeout、断连或协议身份错误在 `auto` 模式记录 `ASCW3009` 并回退 one-shot，
  `required` 模式直接失败；编译器正常诊断不会被错误地重跑；
- build report 新增 `compiler_worker`：模式、状态、fingerprint、instance/PID、启动/构建、
  fallback、阶段次数/耗时与 Roslyn workspace 指标。
