# P61.C2a Session 调试通道

## 本节完成

- 新增 Session-owned debug lane，所有状态只在 GameThread 访问，不引入等待线程或阻塞循环。
- 支持 attach/detach、有界断点集合、pause-next、continue 与 step-into 决策。
- 命中时记录稳定 probe id、pause sequence 与 runtime epoch；continue/step 会抑制恢复点一次，
  避免立即重复命中。
- reload/unload 可推进 epoch、清除旧暂停与单步状态，同时保留当前 Session 的断点集合。
- Runtime 的 `avid_debug_probe` 已路由到该通道；没有调试器时仍保持零状态的 `Continue`。
- candidate BeginPlay 验证阶段禁用暂停，只有事务提交后的 live Runtime 才接入调试通道。

## 当前边界

当前完成的是断点命中决策和 Session 生命周期，并未宣称 Guest 已经在命中位置挂起。现有插桩仍需
把 `Pause` 动作接入编译器生成的可恢复控制流，保存同步调用链与局部状态后返回 GameThread；这属于
`P61.C2b`。在该步骤完成前，Editor 不会展示“已暂停”。
