# P61.B1c Async Sequence Point 映射

## 已实现

- `reentrant_zero_heap_cps` 与 `continuation_cfg` 两条 async lowering 路径统一标记
  statement、condition、await 和 return；
- 初始 async 函数与每个 resume 函数都从最终 Guest IR 投影 sequence point，包含无指令
  `return` terminator，不再只停留在函数声明 span；
- WASM backend 沿用 v2 instruction/terminator identity 回填真实函数内偏移，async 不新增旁路格式；
- DataLane Fusion 将被批处理替换的调用调试位置迁移到对应 command 记录，优化开关不改变
  可定位的 C# 语义点集合；
- 调试位置继续使用 `[JsonIgnore]` 瞬态附着，不改变 Guest IR schema、序列化哈希或缓存身份。

## 边界

- Runtime 已能把 VM frame 映射到 async resume 内的最近可见源码点；
- host crossing 的逻辑帧合并与 Editor 结构化调用栈属于 `P61.B2`；
- 本小节不引入断点协议、变量求值或 Profiler 数据面。
