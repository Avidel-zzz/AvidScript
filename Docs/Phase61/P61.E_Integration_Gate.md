## 人工验收清单

以下项目必须在真实 Editor/PIE 中由人操作确认，当前不宣称已通过：

- 从 Tools 菜单分别打开系统默认 IDE、Visual Studio、Rider 与 VS Code；
- 在 PIE Component Session attach，设置源码断点，检查暂停变量并执行 continue/step；
- reload 后确认 target、epoch 与断点安全重绑，EndPlay 后确认目标失效；
- 从 Debugger 调用栈与 Profiler 事件跳转到正确 C# 源码；
- Profiler 执行 capture/reset、组合过滤、热点查看和 JSON 导出，并检查可读性。
