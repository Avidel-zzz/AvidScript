# P61.C1b 后端无关调试插桩

## 本节完成

- C# Guest CLI 新增 `--debug-instrumentation enabled|disabled`，默认 `disabled`。
- 启用后，在每个非 hidden sequence point 前插入 `avidscript.avid_debug_probe` 调用。
- ABI v1 固定为 `avid_debug_probe(i64 probe_id) -> i32 action`，action 预留 Continue、Pause、Abort。
- 插桩器显式补齐 ABI 所需的 `int64/int32` 规范类型，不依赖用户脚本恰好使用这些类型。
- Probe call 继承原 sequence point 的源码位置；原指令清除重复位置，因此 WASM backend 仍是
  function-relative offset 的唯一权威。
- Guest IR 新增受校验的 `debug` dispatch class，普通 Release 路径不新增 import 或调用。

## 当前边界

当前产物已经具备后端无关的调试调用点，但 Runtime 尚未注册该 import，构建入口也尚未开放
Debug profile。因此默认构建行为完全不变，不能将本节宣称为可暂停断点。

后续 P61.C1c 将完成构建 profile、cache/worker 身份和 VM capability 接线；P61.C2 再实现
Session pause continuation 与 continue/step 状态机。

## 验证

- `AvidScript.CSharpGuest.Tests`：`120/120` 通过。
- 新增测试覆盖默认零插桩、ABI 签名、probe/Debug Map 一一对应、Guest IR 校验及真实 WASM 编译。
