# P61.D4c1 IDE 启动服务

## 目标

把外部 IDE 打开行为从 Editor 命令中解耦，形成可验证、可替换且不会在 Automation 中真实启动应用的服务边界。

## 已实现

- 新增 `FAvidScriptEditorIdeLaunchService` 与可注入 `IAvidScriptEditorIdeLaunchHost`；
- 支持系统默认 `.slnx` 关联、Visual Studio、Rider 和 Visual Studio Code；
- Visual Studio/Rider 打开 solution，Rider 可在 solution 缺失时回退 csproj，VS Code 打开 workspace root；
- 显式 IDE 支持 executable override；生产 host 可发现常见 Visual Studio、JetBrains Toolbox/Rider 和 VS Code 安装；
- 启动前验证 workspace 位于项目内、solution/project 位于 workspace 内，并拒绝缺失 target；
- 返回结构化 executable、arguments、working directory、错误类别和下一步，不把进程逻辑散落到菜单 handler。

## 验证

- UE5.8 Editor 普通增量构建发现新增源文件并通过：`6/6` action；
- `AvidScript.Editor.CSharpWorkspace.IdeLaunchService`：发现 `1` 项，Success `1`、Fail `0`、正常退出；
- fake host 覆盖四种 IDE、工作目录、项目边界和缺失 solution，全程不启动真实外部应用；
- 日志 SHA-256：`38f5b5801740834c02af608eba443f638f6922f9c55a453b15796abb63ecea13`。

## 边界

- 本小节只提供服务，不注册 Editor 菜单；用户可见命令属于 `P61.D4c2`；
- 真实 IDE 安装发现与打开体验保留到 `P61.E` 人工验收，不由 fake host 自动化代替。
