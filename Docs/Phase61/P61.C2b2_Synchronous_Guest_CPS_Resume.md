# P61.C2b2 同步 Guest CPS 恢复

## 本节完成

- Debug 构建将可恢复的同步顶层 `void` export 拆成原 ABI wrapper 与内部 machine；
- 每个可见 sequence point 拥有确定性 route，暂停时保存原参数、locals 与 route；
- 聚合值通过 frame field 深拷贝，frame 上限为 4 KiB，超限在 WASM codegen 前失败；
- 新增 `avid_on_debug_resume(i64 token, i32 route) -> void`，读取一次性 frame 后恢复任意分支和循环 CFG；
- Runtime 缓存恢复导出，Session 负责 continue、step-into、旧 token 失效和再次暂停；
- 暂停期间拒绝 Tick、Event 与 Delegate 重入，Tick 不继续派发 Timer、continuation 或 deferred event；
- 未执行的到期 Timer 会重新入队，不会因断点被静默丢弃。

## 保守边界

当前只对没有 Guest 调用者的同步顶层 `void` export 生成可暂停点。non-void、async、普通 helper、
Guest call target 与 `avid_on_end_play` 保持非暂停路径，避免在尚无跨 Guest 调用栈 continuation
或 EndPlay host epilogue 保存协议时产生错误恢复。变量查看和 Editor 断点管理属于后续小节。
