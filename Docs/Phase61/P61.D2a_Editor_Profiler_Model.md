# P61.D2a Editor Profiler 数据模型

## 目标

让 Editor 在不了解 Runtime 私有实现的前提下消费 Session profiler snapshot，并形成可由 Slate、命令行或后续
工具复用的过滤、聚合和导出模型。

## 已实现

- `IAvidScriptEditorProfilerRuntime` 只暴露 capture、reset、snapshot 与 source catalog；
- Runtime adapter 包装 `FAvidScriptRuntimeSession`，不复制 Session 生命周期或保存 UObject；
- 支持 kind mask、最小时长、文本、仅失败事件和最大显示行数的组合过滤；
- 事件表保留最新的有界行，热点统计覆盖全部匹配事件，并按总耗时稳定排序；
- 使用 probe ID 关联 C# 文件、函数和行号；没有 Debug Map 时仍保留 profiler 数据并显示相关警告；
- dropped 与跨线程拒绝计数进入 view 和导出结果；
- JSON schema 固定为版本 `1`，uint64 标识按字符串输出，避免 JSON number 精度损失；
- 导出先写同目录临时文件，再原子替换目标文件，不留下半成品。

## 验证

- UE5.8 `AvidScriptEditor` 增量构建：`3/3` action 通过；
- `AvidScript.Editor.Profiling.Model`：发现 `1` 项、Success `1`、Fail `0`、正常退出；
- 用例覆盖 capture 状态、组合过滤、source probe 关联、热点聚合、原子 JSON 导出、reset 与 Runtime 销毁失效。

## 边界

- 本小节交付无 Slate 依赖的数据模型；PIE target 的自动绑定由 `P61.D2b` 接入；
- 面板过滤控件、热点表、事件表和导出命令由 `P61.D2c` 接入现有 Debugger Tab；
- source catalog 不可用不会阻断采样，但导出的 source 字段为空并保留警告。

## 复发预防

新增 `.cpp` 会改变 UE Unity Build 分组。匿名命名空间并不能隔离同一个 unity 聚合文件中的通用 helper 名称，
因此模块内 helper 使用唯一命名；调用基础类型哈希时使用显式全局限定，避免被本地 ADL 重载遮蔽。
