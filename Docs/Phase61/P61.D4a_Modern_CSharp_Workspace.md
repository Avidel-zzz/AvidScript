# P61.D4a 现代 C# 工作区

## 目标

让项目脚本工作区可以直接作为现代 IDE 工程打开，同时延续现有的确定性生成和用户文件保护语义。

## 已实现

- 工作区新增 `AvidScript.Gameplay.slnx`，采用 UE5.8 已使用的 XML Solution 结构并引用 WASI C# 项目；
- 新增 `.editorconfig`，固定 UTF-8、CRLF、四空格缩进和基础 C# 风格；
- Workspace Result 显式返回 solution/editorconfig 路径与首次创建状态；
- 首次创建现在生成六个用户文件，后续刷新默认逐字节保留，只有 `bOverwriteUserFiles=true` 才更新；
- Reflection facade 继续发布到 `Intermediate` 并在每次刷新时原子替换，不进入用户工作区所有权；
- Editor 结果详情展示 solution 与 editorconfig 路径，下一步指向打开 `.slnx`。

## 验证

- UE5.8 Editor 增量构建：实现轮 `6/6`、最终代码轮 `4/4` action 通过；
- `AvidScript.Editor.CSharpWorkspaceService`：发现 `2` 项，Success `2`、Fail `0`、正常退出；
- 自动化覆盖首次创建、刷新保留、显式覆盖、路径越界、模板缺失和目录冲突；
- 日志 SHA-256：`f7f2c9c16b9489df3bf4247d42c7dcd8f4a2beb29e8aa0f5f2207647508410e6`。

## 边界

- 本小节只生成 IDE 工作区，不主动拉起外部进程；Visual Studio、Rider 与 VS Code 的发现和启动属于 `P61.D4c`；
- 离线源码索引属于 `P61.D4b`；IDE 实际打开和编辑体验保留到 `P61.E` 人工验收。
