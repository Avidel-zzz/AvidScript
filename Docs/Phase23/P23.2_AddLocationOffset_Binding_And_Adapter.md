## 范围

P23.2 实现 Phase23 的核心纵切: `Actor.AddLocationOffset(float x, float y, float z)`。

## 已实现内容

- `FAvidScriptActorBinding::AddActorLocationOffset(...)`: 读取当前 Actor location, 计算 `Current + Offset`, 并复用 `SetActorLocation(...)` 的写策略与失败诊断。
- `FAvidScriptWasmRuntimeInstance::HandleActorAddLocationOffsetImport(...)`: 新增 direct handler, 缺少 registry、非法 handle、写策略拒绝或移动失败时 fail closed。
- WAMR native symbol: 新增 `actor_add_location_offset` 到 `avidscript` 与 `env` 两个 import module 别名。
- C# source adapter: `actor_lifecycle_v2` 支持 `Actor.SetLocation(...)` 与 `Actor.AddLocationOffset(...)`, 生成两个 host imports。
- 默认 C# 样例: `BeginPlay` 设置初始位置, `Tick` 使用 `Actor.AddLocationOffset(120.0f * deltaSeconds, 0.0f, 0.0f)`。
- 中文 authoring 文档: 更新当前可写 C# gameplay 子集与使用方式。
