# P5.0 D Guest Toolchain Spike

日期: 2026-07-04
状态: In Progress

## 1. Scope

本小组验证 D-first guest language 路线是否能进入 AvidScript MVP 主线。验证路径:

```text
D source -> .wasm -> FAvidScriptWasmModuleLoader -> FAvidScriptWasmRuntimeInstance -> actor_set_location -> UE Actor
```

## 2. In Scope

- 本机 D/WASM 工具链探测。
- 最小 D guest ABI sample。
- 可诊断 build script。
- PC Editor automation 加载外部 D artifact。
- 记录 D 路线继续推进或切换 C# fallback 的依据。

## 3. Out Of Scope

- 完整 D runtime / Phobos / GC 集成。
- C# guest 工具链实现。
- Android/iOS device smoke。
- Packaging/cook/stage/pak。
- Editor UI、watcher、热重载界面。
- UE API 面扩展。

## 8. Decision

P5.0 结论: Done, blocked-on-local-toolchain for real D artifact.

当前证据:

```text
Toolchain probe: ldc2/dub/wasm-ld/clang missing from PATH
Build script: result=missing_toolchain missing=ldc2,wasm-ld
D guest artifact: not generated
AvidScript.Guest.D automation: 1 test Success, warning path because artifact is absent and blocker is documented
Full AvidScript regression: 30 tests performed, Success
```

D 路线判断:

- 不切 C# fallback。
- D-first 方向保留, 但还没有完成真实 D -> WASM artifact 证据。
- 下一步需要安装或暴露 `ldc2` 与 `wasm-ld` 到 PATH, 然后重跑 `BuildDGuestActorSetLocation.ps1` 和 `AvidScript.Guest.D`。
- 如果生成 artifact 后出现 WASM import module mismatch, 优先解决 D/LDC 的 import module 映射, 再考虑 Host alias 或 C# fallback。

C# fallback 状态:

- 未触发。
- 触发条件仍是: D 无法稳定生成 freestanding WASM、产物依赖过重、或移动端/工作流风险明显高于收益。
## 9. P5.1 Follow-up

P5.0 的 missing-toolchain 结论是当时 PATH 环境下的历史结果。P5.1 已在用户授权后使用官方 LDC 1.42.0 Windows x64 便携包完成真实验证:

```text
Saved/AvidScriptDGuest/actor_set_location_guest.wasm = built, 492 bytes
AvidScript.Guest.D.ExternalActorSetLocationSmoke = Success
Full AvidScript automation = 30 tests performed, Success
```

关键发现:

- LDC 1.42.0 可以通过内置 LLD 产出 wasm, 不需要独立 `wasm-ld.exe` 作为硬依赖。
- LDC freestanding `extern(C)` undefined import 默认模块是 `env`, 因此 runtime 增加了 `env` 兼容别名。
- canonical Host ABI 仍是 `avidscript`; `env` 只是 D/LDC 当前工具链兼容入口。

详细记录见 `Plugins/AvidScript/Docs/Phase5/P5.1_D_Guest_LDC_Artifact_Registration.md`。
