## 3. 当前能力

P5.2 完成后, PC Editor 侧已经具备:

- 通过明确 LDC 路径或工具链根目录生成真实 D WASM artifact。
- 同步生成可被 UE runtime 读取的 `.avidscript.json` manifest。
- UE runtime 校验 manifest schema、ABI、language、wasm 文件、sha256、required imports/exports。
- reload session 可携带 `FAvidScriptWasmHostContext`, staging candidate 可在 `BeginPlay` 调用 `env.actor_set_location`。
- 失败 artifact 或坏 manifest 不会替换当前 live runtime。

## 4. Phase 6 入口

Phase 6 可以正式从“脚本语言/绑定生成器最小纵切”开始, 推荐第一条链路:

```text
AvidScript DSL or D-friendly binding declaration
-> generated D import declarations
-> LDC wasm build
-> generated manifest
-> UE manifest loader
-> reload staging
-> UE Actor Host ABI smoke
```

Phase 6 不需要再先解决工具链定位、manifest 识别、hash 校验或 reload host context 接线。

## 5. 剩余风险

- D reload artifacts 仍生成在 `Saved/AvidScriptDGuest/Reload/...`, 不进入 Git; 自动化在缺少 artifact 时只能走 documented warning path。
- 当前 D import module 仍依赖 `env` 兼容别名; canonical ABI 仍是 `avidscript.*`。
- 还没有 Editor watcher、UI、资产导入或 IDE 集成。
- 移动端 runtime 仍停留在预适配设计, Android/iOS device smoke 未做。
- packaging/cook/stage/pak 继续 deferred。
