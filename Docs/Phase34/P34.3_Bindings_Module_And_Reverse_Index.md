# P34.3 Bindings 模块与对象反向索引

状态：Done

## 实现

- 新增 `AvidScriptBindings` Runtime 模块。
- 使用 Git rename 迁移 ObjectRegistry、ActorBinding 和 SceneComponentBinding，保持公开文件名与类型名兼容。
- API 导出宏改为 `AVIDSCRIPTBINDINGS_API`。
- Runtime 显式依赖 Core 和 Bindings；Editor 对测试直接使用的 Bindings 增加直接依赖。
- `FAvidScriptObjectRegistry` 新增 `TMap<TObjectKey<UObject>, int32>` 反向索引与 live handle 计数。

重复注册同一个 UObject 现在直接通过反向索引定位 slot，均摊复杂度从 O(n) 降至 O(1)。Release 和 Reset 同步清理索引，slot 复用仍推进 generation，保持 stale handle 防护。
