# P34.2 Core 与生命周期状态机

状态：Done

## 实现

- 新增 `AvidScriptCore` Runtime 模块，仅依赖 UE `Core`。
- 新增 `EAvidScriptLifecycleState` 与 `FAvidScriptLifecycleStateMachine`。
- 状态覆盖 Empty、Loaded、Starting、Running、Stopping、Stopped、Faulted。
- 将状态机接入现有 `FAvidScriptWasmRuntimeInstance` 的 Load、Begin、Tick、Event、End 和 Unload。
- guest callback trap 会进入 Faulted；Unload 重置为空状态。

旧结果结构依赖的布尔字段暂时保留兼容，不再作为唯一转换依据。Phase 36 的 Session 重构会清理重复状态。
