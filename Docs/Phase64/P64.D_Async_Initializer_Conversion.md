# P64.D 异步初始化的隐式类型转换

状态：编译器修复已验证；UI 重载运行时验收另行记录。

## 问题与修复

真实 UiSaveDemo 改为异步 BeginPlay 后，Semantic 成功但 Guest IR 返回 `ASCG1001`。
根因是 async 局部声明只投影 initializer 的表达式语法，丢掉了 Roslyn 的上下文隐式转换。
例如 `UUserWidget userWidget = widget` 的目标是基类 facade，投影却仍带派生类类型，
因此 `ValidateAsyncMethods/IsMethodLocal` 正确拒绝了不一致的输入。

修复统一读取 `IVariableInitializerOperation.Value`，保留完整 conversion operation，覆盖
线性 CPS、结构化分支及含 await 的 CFG/for 声明。不修改 validator、不引入 UI 类型特判，
也不更改 Semantic Schema、Guest IR 或 WASM ABI。

## 验证

- Semantic console runner：98/98；覆盖 int 到 double 的线性、嵌套分支和 for initializer。
- Guest console runner：135/135；组合 async BeginPlay、两级 facade 上转、四个订阅、Ready 字段赋值和 OnClicked，实际编译 WASM。
- 负向输入：移除 conversion 或篡改目标类型仍返回 `ASCG1001`，不会接受不一致的 Semantic。
- 真实样例 `async-facade-8697f292bbb75-fixed`：`direct_abi_built`，新 compiler Worker 生效、无 fallback。
- 后续 UI 重载三份源码快照也全部 `direct_abi_built`，存于项目
  `Saved/AvidScript/UiSaveReload/bc74e938bae7424c82255f0e7f758224`。它们仅证明编译，不证明运行时重载成功。

本小节不需要 UE 构建；UI 集成与资源快照在所属重载小节集中构建和验证。
既有 async 逻辑运算的短路语义是独立缺口，本次没有修复，不能用这组转换测试宣称已覆盖。

## 预防

上下文转换应从 Roslyn 的完整 initializer operation 取得，不能只对表达式语法调用 GetOperation。
涉及赋值、返回值或参数传递的投影时，同时验证源表达式类型与目标上下文类型，不能通过放松下游校验掩盖丢失的转换。
