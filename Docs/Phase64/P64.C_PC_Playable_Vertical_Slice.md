# P64.C PC 可玩纵向切片

## 已实现

- `PickupRushScript.cs` 以 C# 实现 BeginPlay、Tick、Overlap、Timer、Gameplay Event、计时、收集、胜负与重开。
- `AAvidScriptPrimitiveHost` 仅提供通用 StaticMesh 与碰撞，不包含样例游戏规则。
- `pickup_rush` scenario 在 TopDown/TwinStick 世界中自动生成宿主并挂载内容寻址模块。
- `InvokeAvidScriptPickupRush.ps1` 统一发布当前 Reflection 绑定、同配置 Generated Type、编译模块、启动 Editor/Package 与校验报告。
- `InvokeAvidScriptStartupScenarioProbe.ps1` 为任意 packaged scenario 提供可复用的机器验收入口。
- UE 同步碰撞委托在 Guest 正忙时进入 64 项有界 FIFO，回调返回后派发；溢出仍 fail-closed 并计数。
