# P64.D 调用生命周期修复

状态：架构 v14 的调用帧与 backend 重载所有权修复、50 轮分配栈对照和一小时复验已完成；
D07 当时仍为 Fixing，现已由架构 v15 包内一小时证据验证，原始平台及人工验收范围不变。

## 依据

[分配追踪](P64.D_Native_Allocation_Tracing.md)发现反射 FString 参数每轮净保留 7 项/208 字节，
并发现 backend 长期重用时 ExportEntries 与历史身份集合持续增长。本批直接修复所有权，
不增加新的通用诊断框架，不通过清缓存、强制 Purge 或缩短实验规避问题。

## 冻结合同

- Binding 冷路径缓存调用帧中需要析构的属性；构造和释放必须覆盖同一帧，包括入参、ref/out、
  返回值和内部字段。成功、解码失败、调用拒绝及输出失败均由统一 scope guard 清理一次。
  不以 UFunction 的 DestructorLink 完整性作为前提，不在热路径重新进行反射发现。
- Wasmtime 身份拆分为 backend 稳定 owner 与加载代际；外国 owner 仍报 foreign_export，
  过期代际仍报 stale_export。代际耗尽时拒绝继续加载，不回绕复用旧句柄。
- VM 公共 prepared call 增加可选不透明 TargetLifetime，共享所有权只在准备/复制/释放时变化，
  调用时不复制 shared pointer。Wasmtime 导出表与实际持有旧调用的调用者共同拥有条目；
  卸载先使条目失效并释放函数包装，再清空导出表。旧条目不保留名称和引擎资源。
- prepared target 失效检查先于 backend 解引用；不因回收历史条目引入 use-after-free。
  WAMR 可保留空 TargetLifetime，既有调用接口不改，Guest IR/WASM ABI/schema 不变。
- 不修改 Runtime/Bindings 对具体 backend 的依赖方向；不扩大此次修复到引擎引脚队列或第三方 JIT。

## 分工与验证

两个独立写集并行：Binding worker 负责 Invocation 下的帧生命周期及 Bindings 测试；主线负责
VM backend/public prepared call、VM 测试、架构/状态和中文文档。都不触碰三个 protected dirty 文件。

集中验证一次受影响 no-clean Editor 构建与相关 Automation：覆盖含非平凡属性的原生调用帧
成功/失败清理，反复加载/卸载、旧句柄/旧 prepared call 拒绝、条目最终释放及外来句柄拒绝。
然后复用 50 轮 TraceMemory 工作负载，比较同一 SetUtf8Value 分配栈的窗口净保留；本批不重复
未修改的 188 例 PowerShell 合同。必要修复完成后再跑原始一小时长稳，不以短测关闭 D07。

## 结果

### Binding 调用帧

`FInvocationCodecProgram` 在 descriptor 冷准备阶段缓存完整 `PropertyLink` 中需要析构的属性。
每次调用仍由 `InitializeStruct` 初始化完整帧，统一 scope guard 按缓存表逐项析构；成功、ref 输入
解码失败和返回值输出失败共用同一路径，不在热路径搜索反射信息。新增真实非平凡测试结构，
持有 FString 容器资源并记录构造/析构所有权。

`AvidScript.Bindings.PreparedDynamic.InvocationFrameLifetime` **1/1 通过**：四个帧值分别构造、
析构一次，三条成功/失败路径均释放资源。首次 fixture 错把 bool=2 当作非法输入；codec 会将
非零值规范化为 true，因此改用无效 ObjectHandle 验证真实晚期解码拒绝，未修改产品语义。

### Wasmtime 重载所有权

backend identity 现在代表稳定 owner；每个存在可见导出的加载周期使用不回绕 generation。
`ExportEntries` 改为共享条目，prepared call 只在准备/复制/释放时持有 TargetLifetime，调用热路径
不复制引用。Unload 先删除 function 并置空，再清空 backend 导出表；旧调用只在实际持有者存在时
保留无名称、无引擎资源的失效条目。删除了永久增长的历史 identity 集合，空 Unload 不消耗代际，
owner 或 generation 耗尽时 fail-closed。

`AvidScript.VM.Wasmtime` **14/14 通过**。新增 ReloadLifetime 覆盖 32 次加载/卸载、每轮两个调用
形状、512 次额外空卸载、slot 复用、generation 隔离、旧/foreign handle、prepared copy 释放、
backend 销毁后拒绝和 shared lifetime 最终释放。D08 已具备关闭证据。
