# P64.D 通用委托来源上下文

状态：本小节实现与集中验证通过；不代表 P64 UI/存档完整闭环已验收。

## 能力

同一无参数委托可由多个对象触发，C# 通过生成的 `AvidSubscriptions.IsCurrentSource(source)` 判断当前来源。
查询通过 `env.event_is_current_source(i32 slot, i32 generation) -> i32`，静态 binding ordinal 仅追加。
Wasmtime 与 WAMR 共用合同，原有 callback 参数和导出 ABI 不变。

Profile 明确指定 Actor Self 后，可以选择独立 UObject 的普通单播/多播委托并显式订阅，
例如 Actor 脚本订阅多个 UButton 的 OnClicked。没有显式 Self 时保留旧推断规则。
RPC/RepNotify inbound 仍检查其 owner 与 Self 的继承关系，不因此扩大网络权限。

## 生命周期与边界

- Session 在同步派发期间用 RAII 保存/恢复弱引用来源，不延长 UObject 生命周期。
- Runtime 查询校验 Game Thread、registry、generation、capability 和 World；回调外或无效来源返回 false。
- 回调取消自身订阅不破坏正在执行的来源身份；teardown 立即使其失效。
- 被拒绝的重入恢复外层来源，不让嵌套来源残留。
- emitter 从 49.3.0 升至 49.4.0，使生成源码和缓存身份同步变化。
