# P64.D 事件型 Guest 与导出签名

状态：本小节实现与原生专项验证通过；P64 和 UI/存档验收仍未完成。

## 已实现

- Guest 可省略 `avid_on_tick`；保留 Session 心跳，不阻断 Timer、continuation 和 deferred inbound 调度。只有真实 Guest Tick 才增加调用计数和耗时。
- 加载时只解析一次 Tick；存在时必须是 `(F32) -> void`，manifest 显式要求但未提供时仍拒绝。unload/reload 清除旧入口。
- `IAvidScriptVmBackend::ValidateExportSignature` 校验实际函数参数与结果类型，不用相同 cell 数代替类型校验。Wasmtime/WAMR 各自读取后端类型信息，不执行 Guest，也不引入 UE 入口名。
- Binding manifest 按独占能力判断启用的能力组，共享 `avid_value_release` 不再误触发完整数组组要求。FText、legacy/current array 和 composite container 可合法组合；缺项、重复或错误签名仍失败关闭。
- 委托订阅的成功 token 和拒绝原因提供按需 Verbose 日志，默认不输出。

实现位于 Runtime 的 `AvidScriptWasmRuntime`、`AvidScriptWasmReload` 与 VM backend adapter；没有新增按钮/存档专用 Host API。
