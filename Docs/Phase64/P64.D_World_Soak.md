# P64.D World 重建与持续运行

状态：真实 World 重建与两次一小时连续存取通过；已知调用帧/backend 保留已修复，剩余内存归因和
其他场景待验，P64 尚未关闭。

## 范围

复用 UiSaveDemo 的正常 C# 发布包与真实地图，通过 UE OpenLevel 在同一进程内销毁并重建 World。
不新增玩法 Host API，不手动 EndPlay 冒充地图销毁，不持有旧 World、Actor、Widget 的强引用。
第一次从 0 分收集并保存；之后每个新 World 的 C# 状态先为 0，再 Load 前一轮存档、Collect、Save。
最后一次 travel 后也必须恢复最终存档，才能完成报告。

前三轮为内存预热，每轮强制 GC 后记录进程 physical/virtual 字节、UObject 数与有效脚本 Session 数。
内存增长记录为观测，不将进程工作集波动或单一端点当作无泄漏证明。World 旧对象必须真正可回收，
订阅和 ownership 数量必须满足固定边界。后续压力模式仍需涵盖热重载、网络和包内运行。

## 入口与冻结参数

`Build/InvokeAvidScriptUiSaveDemo.ps1 -Mode VerifyWorld`，沿用 ExpectedPackageId、VerifyUserRoot 和
TimeoutSeconds。新增 WorldCycles（2..1000，默认 10）、SoakSeconds（0..21600，默认 0）。
WorldCycles 表示至少完成的 travel 次数；持续模式直到轮数与时长同时达标，最多 10000 轮。
原生参数为 AvidScriptUiSaveProbe=world、AvidScriptUiSaveWorldCycles、AvidScriptUiSaveSoakSeconds。
超时预算为 `SoakSeconds + max(120, WorldCycles * 20)` 秒；外层进程额外保留 30 秒退出窗口。
`long_run_verified` 仅在成功且实际 elapsed >= 3600、completed_cycles >= 10 时为 true。
每轮至少停留 3 秒，不通过密集空转制造时长。

## 回执合同

继续使用根 probe schema_version=1、mode=world、真实 module/package 身份与独立 UserDir。
根 result/succeeded/failure_category、process_mode、process_id、input_kind、map、started_utc、finished_utc、
elapsed_seconds、timeout_seconds、save_path/save_file_exists/save_file_bytes/save_file_sha256、score_text、
status_text、runtime、startup 仍有真实值。physical_click_verified/visual_verified 始终 false。
root actions 为空，详细动作按 world_lifecycle.cycles 分组；gc_performed 成功时为 true。

新增 world_lifecycle 对象：

- requested_cycles、requested_soak_seconds、completed_cycles、activated_worlds、travel_count、cleanup_count。
- elapsed_seconds、warmup_cycles=3、world_lifecycle_verified、long_run_verified、memory_measured。
- final_recovered_score（整数，等于 completed_cycles）、final_save_sha256、cycles、final_actions（ready/load 两项）。
- memory_summary：baseline_available、baseline_physical_bytes、final_physical_bytes、peak_physical_bytes、
  baseline_virtual_bytes、final_virtual_bytes、peak_virtual_bytes；这里只汇总观测，不声明 memory_stable。
- 每个 cycle：cycle、saved_score、save_sha256_before、save_sha256、save_file_bytes、events_before_travel、
  actions、resources、cleanup、gc、passed。
- actions 项：action、expected_score、observed_score、expected_status、observed_status、dispatch_frame、
  check_frame、save_sha256_before、save_sha256_after、passed；第 1 轮为 ready/collect/save/gc，后续轮为 ready/load/collect/save/gc。
- resources：active_subscriptions=4、bound_buttons=4、owned_entries=0、borrowed_entries（7..8）、
  pending_timers/pending_continuations/prepared_continuations/prepared_subscriptions=0、backend。
- cleanup：observed、component_end_play、guest_end_play、session_released、owner_released、buttons_unbound、
  widget_removed、saved_reference_cleared，均必须为 true；events_before/events_after 相等。
- gc：world_collected、host_collected、component_collected、widget_collected、saved_object_collected、
  new_world_identity、new_host_identity、new_component_identity，均必须为 true；
  physical_bytes、virtual_bytes、uobject_count、active_sessions（应为 1）均为非负整数。

每轮 saved_score=cycle；第 1 轮进入时无存档，之后每次 Load 都恢复 cycle-1。
每个 travel 后的新 World 必须回到 0/Ready；最后恢复 completed_cycles/Loaded。
文件只由 Save 动作改变；GC、travel 与 Load 不改变哈希。原生记录逐动作哈希校验结果，
外层再次验证最终真实文件大小和 SHA-256、计数、动作顺序、数值类型与时长。
