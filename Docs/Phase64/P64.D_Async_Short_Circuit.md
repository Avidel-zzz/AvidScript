# P64.D C# 异步短路语义

状态：编译器修复与集中 managed 验证通过。对应债务 `P64-D06-AsyncShortCircuit`；不替代真实 WASM/UE 的完整语言验收。

## 问题与设计

异步值表达式此前将 `&&`/`||` 的两个操作数连续 Lower，再生成 boolean binary。这会先执行
右侧的调用、赋值或异常路径，即使左侧已经决定结果。`&`/`|` 的主动双侧求值不能替代条件逻辑。

修复分为两步，继续使用已有 Guest IR：

- `CSharpOperationLowerer` 只为内建、非 lifted 的 bool 条件运算记录 RHS 指令范围及结果槽。
- `CSharpShortCircuitLowerer` 在函数完成前，将范围转换为已有 `branch_if`、RHS block、join block
  和 `local_store/local_load`。左值只求一次，右值只在需要时执行，后续指令沿 join 继续。
- 嵌套范围按外层先展开，保留左右顺序；结构不合法、范围交错或缺失时返回 `ASCG1004`，不发布模块。
- 同步 CFG、线性 async 和可恢复 async CFG 共用此转换；没有 UI、Host API 或 VM 后端特判。

没有新增 Semantic Schema、Guest IR 指令、WASM ABI 或运行时分配。编译期增加范围分析与少量分支块，
运行时避免本不应发生的 RHS 求值；本轮未执行性能 benchmark，不声明性能提升比例。

## 验证

2026-09-04，固定 SDK 8.0.416：

```powershell
& "$env:USERPROFILE/.dotnet/dotnet.exe" run `
  --project Tools/AvidScript.CSharpGuest.Tests/AvidScript.CSharpGuest.Tests.csproj --configuration Release
& "$env:USERPROFILE/.dotnet/dotnet.exe" run `
  --project Tools/AvidScript.CSharpSemantic.Tests/AvidScript.CSharpSemantic.Tests.csproj --configuration Release
```

| 范围 | 结果 |
| --- | --- |
| Guest console runner | 140/140，exit 0 |
| Semantic console runner | 98/98，exit 0 |
| 新增短路回归 | 5/5 组，13 个实际标量 Guest IR 执行场景与 3 个负向 Semantic 输入 |
| 覆盖 | 左右短路、嵌套、赋值、initializer、参数顺序、普通函数返回、while/do/for、跨 await 恢复、保留 `&`/`|` 双侧求值、跳过除零路径 |
| WASM 生成 | 每个执行场景同时通过 Guest IR validator 与真实 WASM 编译 |

执行器只提供 trace/continuation imports，解释实际生成的 Guest CFG 与普通 Guest callees，未知指令失败。
该证据是 **Guest IR 执行与 WASM 编译**，不是 Wasmtime、V8 或 UE 执行；不能和
[UI 重载](P64.D_UI_Reload.md)使用较早编译器生成的制品拼成这一修复的 WASM 执行证明。

仓库外日志位于 `P64-D06-AsyncShortCircuit/1788476250647/guest-attempt2.log` 与 `semantic.log`。
首轮测试执行器遗漏合法 `zero` 常量，失败日志 `guest-attempt1.log` 保留；修复后重新执行全部 Guest
runner。后续新增执行型夹具必须覆盖真实常量编码并拒绝未知指令，不能将解释器缺口误判为编译器错误。

本小节不重复 UE 构建，也不累加到候选 `9e08cdc` 的历史全量数。任意 awaiter、lambda/closure、
重载运算符和其他未支持的 C# 语法仍沿既有 capability 边界处理。
