# P64.D 存取穿插重载与对象生命周期

状态：20 轮存取与正文重载组合流程通过；P64 原始目标仍在实施中。

## 问题与边界

UiSaveDemo 原有 `OwnedSave` 是 transient，正文重载后不再可见，但 Session ownership 跨成功重载保留。
每次重载后再保存会新建对象，旧对象直到 Session 停止才释放。该问题应修复样例对显式 ownership 的使用，
不能在重载时清空所有 owned 对象，破坏其他脚本保留 ActorComponent 等对象的合同。

另外，`BorrowedObjects` 不强持有 UObject，但已 GC 的对象对应登记与 registry lease 仍可能积累。
清理应由 Runtime 的 GC 生命周期入口统一处理，不增加 SaveGame 特判或逐 API 手写包装。

## 生命周期实现

RuntimeLifecycleCoordinator 订阅 UE5.8 `GarbageCollectComplete`，在 purge 完成后通知 Session。
Ownership 线性扫描 borrowed journal，稳定压缩仍存活的条目，逐项释放失效对象对应的 registry lease。
不触碰 owned 对象，也不释放其他 Session 的 lease；旧代际不能释放已经复用的 slot。

若 GC 发生于 Guest 调用或候选准备期间，Session 只置 pending 标志，下一安全入口再清理，避免移动
候选的 `RetainedCount` 回滚边界。停止、World 退出、宿主切换和 coordinator 关闭清除 pending 工作。
平时入口仅检查 pending 标志，不在每次 Borrow/Host crossing 或无 GC 的 Tick 中扫描对象。

样例已移除 transient `OwnedSave`：Save 复用宿主 `SavedObject`，仅首次创建时取得短期 ownership，
赋予宿主强引用并完成保存后释放它，成功/失败共用清理路径。Load 仍在类型与数值校验全部通过后
才替换宿主引用；EndPlay 清空宿主引用。三种重载制品由当前 C# 源码正常编译，不改写 WASM。
