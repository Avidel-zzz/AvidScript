# Phase 64 实施计划

## P64.A Startup Scenario 合同

- 定义严格、版本化的 scenario schema、解析器与诊断。
- 支持显式 scenario 选择、world 白名单、ModuleId 和三种宿主模式。
- 加入路径、数量、重复键、未知字段和歧义匹配的 fail-closed 合同。
- README 只新增已经通过合同验证的 composition 能力。

完成标准：schema/loader 合同通过，Core/Bindings/VM 依赖方向不变，提交并推送。

## P64.B Runtime 挂载与事件闭环

- 从 `UAvidScriptWorldSubsystem` 抽出 startup coordinator，移除默认 embedded smoke 工作负载。
- 幂等挂载/生成宿主，复用 `UAvidScriptComponent` 与模块 catalog。
- 验证 BeginPlay、Tick、Overlap、Timer、Actor 销毁、World teardown 和故障隔离。
- 记录 composition 与 Session 分层指标。

完成标准：真实 UWorld 集成测试通过，既有生命周期合同无回归，提交并推送。

## P64.C PC 可玩纵向切片

- 交付一个以 C# 编写全部游戏行为的可视化交互样例和严格 scenario。
- 提供单入口构建/发布/启动脚本，不要求手改关卡或 Runtime C++。
- 对同一源验证 Editor、Development package 与 Shipping AOT package。
- 输出机器可读 gameplay report，并保留 PIE/键鼠或手柄体验为人工验收项。

完成标准：用户可直接阅读 C# 游戏脚本；PC 打包进程观察到完整事件与状态变化，提交并推送。

## P64.D Android 构建与设备就绪

- 实现无副作用 toolchain preflight，固定 UE5.8 SDK/NDK/JDK 版本。
- 完成 Android arm64 UBT 与 package receipt/内容身份检查。
- 提供 ADB install/run/report runner；只有连接设备并得到运行报告时才标记 device passed。
- 将设备缺失、图形/输入和后台恢复等结果结构化，不以跳过冒充成功。

完成标准：当前可用环境中的最高真实 Gate 层通过；未运行的人类/设备项显式保留，提交并推送。

## 集中 Gate

实现批次期间只运行阻塞性编译探针和必要定点测试。P64.A-P64.D 完成后统一执行架构检查、固定
.NET 套件、PowerShell 合同、UE5.8 no-clean UBT 与完整 `AvidScript.*` Automation，并生成不可变
Gate 报告、attestation 和中文收尾记录。
