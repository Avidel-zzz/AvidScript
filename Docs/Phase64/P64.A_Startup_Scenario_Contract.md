# P64.A Startup Scenario 合同

## 已实现

P64.A 建立了版本化、显式激活的 Startup Scenario 数据合同。它只描述模块应该挂载到哪些 UE
对象，不包含游戏专用 Host API，也不绕过现有 `UAvidScriptComponent`、catalog 和 Session 边界。

- `schema_version` 当前固定为 `1`，未知字段、重复 JSON key 和未知版本均失败关闭。
- scenario 必须显式声明 `activation: "explicit"`，并通过完整 world package 白名单限定生效范围。
- binding 通过规范化 `module_id` 引用发布 catalog 中的模块。
- `world_host` 为 world 创建通用宿主；`existing_actor` 按类、可选 tag 和上限选择已有 Actor；
  `spawn_actor` 按严格的 transform 列表生成 Actor。
- 数组数量、路径长度、标识符、有限浮点数、非零 scale、重复 scenario/world/binding 均有界校验。
- 解析器只产生不可执行的配置模型；实际对象解析、挂载、回收和事件闭环由 P64.B coordinator 负责。

## 验证

- UE5.8 `AvidTPSTemplateEditor Win64 Development` no-clean UBT：通过。
- `AvidScript.Runtime.StartupScenario.Schema`：`1/1` 通过。
- 覆盖合法三种目标模式，以及重复 key、未知字段、空 scenario、隐式激活、非法 world、未知
  target、无效实例上限和零 scale 的失败关闭路径。

测试日志保存在阶段外证据目录
`C:\tmp\AvidScript\P64A\startup-schema-rerun.log`，不提交机器本地日志。

## 边界

本小节只宣告 schema 和 loader 可用，不宣告 Runtime 自动挂载或可玩 Demo 已完成。这两项分别由
P64.B 与 P64.C 验收。
