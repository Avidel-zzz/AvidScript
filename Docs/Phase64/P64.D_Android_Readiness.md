# P64.D Android 构建与设备就绪

## 边界与入口

本批次沿用 Android arm64 交叉 AOT，不把 Win64 JIT 产物当作移动端 Runtime。
工具链检测、UE 打包、回执校验和设备运行各自返回机器可读结果；缺环境返回 `not_run`，不计为通过。

- `TestAvidScriptAndroidToolchain.ps1`：只读检查源码版 UE5.8 与 SDK/NDK/JDK。
- `BuildCSharpScriptTypes.ps1 -TargetPlatform Android -HeadlessRelease`：把目标平台贯穿 Generated Type、Runtime Release 与 Cook 发布，校验 arm64/target triple 身份。
- `InvokeAvidScriptAndroidBuildCookRun.ps1`：默认只预检；显式 BuildCookRun 使用 arm64/ASTC、no-clean、skipbuildeditor，工具链环境只传给子进程。
- `TestAvidScriptPackageReceipt.ps1 -TargetPlatform Android`：选择当前配置的唯一 arm64 variant，校验预编译策略、内容哈希、Generated Type 与静态 Wasmtime 身份；Android 不携带 Windows DLL。
- `InvokeAvidScriptAndroidScenario.ps1`：默认检查设备；Run 先核对 APK 包名、版本和原生库 ELF/AArch64 头，再安装 APK/可选 OBB、启动指定 Activity，并接收唯一运行 ID 对应的 UE 报告。
- 通用场景探针接受 `AvidScriptScenarioProbeRunId`，自行在 Saved 下生成报告路径，输出单行 JSON，避免设备端依赖 Windows 绝对路径。

设备入口不清空 logcat，不卸载应用，不自动选择多个可用设备中的一个，也不接收旧运行报告。
Android Development 可使用 UE 的 `cmdline` Intent；源码版 UE5.8 Shipping 不接受该开发入口，当前
Shipping 设备探针明确返回 `shipping_requires_embedded_commandline_and_report_transport`。

## 使用

先发布目标为 Android 的 C# 模块及 Generated Type，再执行：

```powershell
pwsh -NoProfile -File Build/InvokeAvidScriptAndroidBuildCookRun.ps1 -Mode Preflight
pwsh -NoProfile -File Build/InvokeAvidScriptAndroidBuildCookRun.ps1 -Mode BuildCookRun -Configuration Development
pwsh -NoProfile -File Build/InvokeAvidScriptAndroidScenario.ps1 -Mode Inspect -AdbPath <adb.exe>
pwsh -NoProfile -File Build/InvokeAvidScriptAndroidScenario.ps1 -Mode Run `
  -AdbPath <adb.exe> -ApkPath <已归档的arm64.apk> -DeviceId <设备序列号>
```

外置数据包通过 `-ObbPaths` 传入；文件名必须与从 APK 读取的包名、versionCode 一致。
打包入口返回 APK/OBB 路径和 SHA-256；设备报告只记录对应应用的匹配结果，不保存其他设备日志。

- 真实 5 个 Generated UE 类型交叉 AOT 通过，package `8d269fcf4db2a25ebf2bcfcc6f2b2e0885087404b47cb8714fd22135775823e4`；产物为 ELF/AArch64（machine 183），策略 `require_precompiled`。

当前缺失 `android-34`、Build Tools `35.0.1`、CMake `3.22.1`、NDK `27.2.12479018/r27c`、

不能据此宣称已完成移动端支持。

## 回执修正

原 Win64 回执脚本仍引用 patchset.1 安装目录，导致报告中的期望运行库 hash 过时，但实际归档使用
patchset.2。现在从锁文件读取安装位置，消除重复版本常量；同时 `module_count` 只统计选中的模块，
不再包含被正确跳过的其他平台模块。该修正不改变 P64.C 已观察到的包内玩法结果。
