# P1.2b WAMR Source Snapshot And Win64 Static Build

版本: 0.1
日期: 2026-06-30
状态: Done

## 1. 目标

P1.2b 的目标是把 P1.2 中定义的 WAMR ThirdParty 方案推进到可链接状态:

1. 获取 WAMR 上游源码快照。
2. 记录 tag、commit 和 license。
3. 构建 Win64 静态库。
4. 让 `AvidScriptRuntime` 在 UE5.8 Editor target 中走 `AVIDSCRIPT_WITH_WAMR=1` 编译路径。

## 3. 构建脚本

新增脚本:

```text
Build/BuildWAMRWin64.cmd
```

脚本行为:

1. 调用 Visual Studio 2022 `vcvars64.bat`。
2. 使用 CMake + Ninja 配置 WAMR Windows platform。
3. 构建 CMake target `vmlib`。
4. 将生成的静态库复制到 `Source/ThirdParty/WAMR/lib/Win64/Release`。

## 4. 构建配置

```text
WAMR_BUILD_INTERP=1
WAMR_BUILD_FAST_INTERP=1
WAMR_BUILD_AOT=0
WAMR_BUILD_JIT=0
WAMR_BUILD_FAST_JIT=0
WAMR_BUILD_LIBC_BUILTIN=1
WAMR_BUILD_LIBC_WASI=0
WAMR_BUILD_MULTI_MODULE=0
WAMR_BUILD_SIMD=0
WAMR_BUILD_MINI_LOADER=0
```
