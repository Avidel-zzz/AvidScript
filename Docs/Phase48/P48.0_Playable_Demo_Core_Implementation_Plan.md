# Phase 48 可玩 Demo 核心闭环 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在源码版 UE5.8 Win64 Editor 中，让项目 C# gameplay 脚本通过自然事件入口、真实控制流、扩展的反射类表面和安全的 `FName` 输入 ABI 实现可重复收集物玩法。

**Architecture:** 普通 UE API 继续由 Editor 反射选择、descriptor、生成 C# facade、Roslyn reachability、最小 binding slice 和 Runtime 缓存 `ProcessEvent` 路径贯通。自然 gameplay 事件复用稳定的 `avid_on_gameplay_event` 导出；`FName` 使用独立 descriptor identity，C# 值包装器内部持有现有 Guest IR UTF-8 data address，Runtime 从经过范围验证的长度前缀字节构造 UE `FName`。

**Tech Stack:** Unreal Engine 5.8 source build、C++20、Roslyn/.NET 8、AvidScript Semantic/Guest IR/WASM Backend、WAMR、PowerShell、UE Automation Framework。

## Global Constraints

- Engine root 固定为 `C:\UnrealEngine`，项目为 `<ProjectRoot>\AvidTPSTemplate.uproject`。
- 插件仓库根目录为 `<PluginRoot>`，当前工作直接在已授权的 `main` 分支推进。
- 不执行完整 Editor target clean；新增 `.cpp` 后验证 unity source list，优先使用 scoped module build。
- 不修改、还原或提交 Phase 48 开始前已经存在的工作区文档改动。
- 人读文档使用中文；代码标识符、命令、路径和日志原文保留原语言。
- 普通 UE 函数不得新增逐函数 VM enum、WAMR wrapper 或 Runtime switch。
- UObject 只通过 slot/generation 句柄跨越 WASM 边界。
- 构建失败不得发布新 manifest/WASM；reload 候选失败必须保留旧 runtime。
- `FName` 首版只接受 `value` 和 `const_ref` 输入；`return`、`out`、`ref` 必须由类型策略明确拒绝。
- `FName` UTF-8 数据采用现有 Guest IR 布局：地址处 4 字节 little-endian 长度，随后为 payload 和一个尾随零字节。
- `FName` Runtime 输入最多读取 `NAME_SIZE * 4` 个 UTF-8 字节，转换后的 TCHAR 长度必须小于 `NAME_SIZE`；负长度、越界、嵌入 NUL 或非法 UTF-8 必须失败关闭。
