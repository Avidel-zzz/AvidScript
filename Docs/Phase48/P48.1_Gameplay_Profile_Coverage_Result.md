# P48.1 Gameplay Profile 覆盖结果

## 状态

已完成。

P48.1 将 Engine Gameplay Profile 从 `AActor`、`USceneComponent` 两个门面扩展为六个门面，并保持“成员发布到真实声明类”的约束。生成包当前包含 279 个反射函数和 2 个只读属性，共 281 个 binding。

## 实现范围

- 新增 `UActorComponent`、`UPrimitiveComponent`、`APawn`、`AController` 四个自动发现规则。
- `AActor` 与 `USceneComponent` 保持原有规则和 stable id；没有把基类函数复制到派生门面。
- 直接 function/property selection 会比较反射声明 owner，继承成员伪装到派生门面时分别返回 `function_owner_mismatch` 和 `property_owner_mismatch`。
- 反射元数据存在但默认值为空时，不再发布无效的可选参数；函数仍保留，调用方需要显式传参。
- C# facade 回归验证六个门面均生成，`APawn` 包含 `AddMovementInput`，但不包含 `AActor.K2_GetActorLocation`。

## 剩余风险

- 目前仍不能表达 `FName`、`FHitResult`、容器和部分输入值类型，因此不是完整 UE API 覆盖。
- 派生门面不会自动获得基类方法；C# 侧的安全向上转换需要独立设计，不能通过伪造 descriptor owner 实现。
- 空反射默认值会退化为必传参数，保证绑定可用和契约确定性，但暂不还原对应 C++ 默认表达式。
