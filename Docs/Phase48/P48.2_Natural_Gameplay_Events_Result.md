# P48.2 自然 Gameplay 事件入口结果

## 状态

已完成。

P48.2 允许 C# 游戏脚本直接声明 `OnBeginOverlap`、`OnEndOverlap`、`OnHit` 和 `OnInput`。Semantic 层识别并校验这些入口，Guest 编译器按实际存在的回调自动合成唯一的 `avid_on_gameplay_event` WASM 导出；脚本作者不再需要手写八参数 ABI 路由。

## 作者体验

```csharp
public static void OnBeginOverlap(AActor otherActor, FVector location)
{
    // 编写游戏逻辑。
}

public static void OnInput(InputEvent input)
{
    // input.ActionId、input.TriggerEvent 与 input.Value 可直接使用。
}
```

四个保留入口必须是 `public static void`，并使用稳定参数布局。声明错误会在 Semantic 阶段给出 `ASCS5101` 至 `ASCS5106` 诊断；自然回调与手写 raw router 同时存在时，Guest 编译器以 `ASCG1007` 拒绝歧义输入。

## 编译链合同

- Semantic schema 升级到 `7`，版本升级到 `1.7`。
- `gameplay_event_callbacks` 保存事件类型、方法符号和精确源码 span。
- reachability 使用 `entrypoint_roots`，根集合严格等于普通导出与自然事件回调的并集。
- Guest IR 与 WASM backend schema 保持不变；事件适配完全由 C# Guest lowering 合成。
- 合成 router 只包含脚本实际声明的分支，不为缺失回调生成死调用。
- router 的稳定 ABI 为五个 `i32`、三个 `f32` 参数，Runtime ABI 没有变化。
- 调试映射保留合成函数占用的 WASM 索引，但不为没有 C# 声明的 router 伪造源码位置。
- 只有受信任的 `CSharpGuestIds.GameplayEventFunctionId` 可以无源码映射；其他未知函数继续以 `ASDEBUG1003` 关闭式拒绝。

## 生成门面与模板

- 生成的 `AvidScript` C# 门面新增只读 `InputEvent` 值类型，包含 `ActionId`、`TriggerEvent` 和 `FVector Value`。
- 项目 workspace 模板默认提供四个自然事件方法。
- `ActorLifecycle` 正式样例已删除手写 `OnGameplayEvent`，真实构建由编译器生成 router。
- 缺少某个自然回调时不会生成对应调用分支；没有自然回调时不会额外生成事件 router。

## 剩余边界

- 本切片完成的是编译器生成事件入口，不包含任意 Blueprint delegate 的自动订阅。
- `InputEvent` 当前保留稳定整数 action/trigger 标识；Enhanced Input 的资产级强类型 facade 属于后续输入工具链。
- 回调内部可表达的复杂控制流和状态仍受现有 C# Guest lowerer 能力限制，将在 P48.3 扩展。
- `FName` 仍未进入 descriptor 与 Runtime marshalling，将在 P48.4-P48.5 完成。
