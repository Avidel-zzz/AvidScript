# P48.6 可玩拾取物闭环结果

## 状态

已完成实现、真实 C# 到 WASM 验证和 UE5.8 端到端回归。

本阶段不再只验证单个 binding，而是把 P48.1-P48.5 的控制流、自然事件、FName、动态反射调用、计时器和事务热重载组合成一份可以直接阅读和修改的游戏脚本。

## 游戏逻辑

新增 `Samples/CSharp/PlayablePickup/PlayablePickupScript.cs`：

- `BeginPlay` 在迁移到已收集状态时重建复活计时器，初次加载沿用关卡 Actor 配置；
- `Tick` 在未拾取时按每秒 90 度旋转；
- `OnBeginOverlap` 接收自然 `AActor` 参数，通过 `ActorHasTag("Player")` 过滤玩家；
- 玩家拾取后调用 `SetActorHiddenInGame(true)` 和 `SetActorEnableCollision(false)`；
- `UE.SetTimer(3.0f, 7)` 创建一次性计时器；
- `OnTimer` 在 3 秒后恢复显示与碰撞；
- `Collected` 使用显式 `[AvidPersist]` 状态合同阻止重复收集；成功热重载会保留已收集状态并在候选 runtime 中重建 timer。

脚本使用具名常量保存计时器 id、旋转速度和复活时间。自然 gameplay callback 与低层 `avid_on_gameplay_event` 模式互斥，本样例只声明 `OnBeginOverlap`，统一 WASM export 由编译器生成。

## 公共计时器 facade

正式 C# binding renderer 现在为含 `AActor` 代理的 package 统一生成：

```csharp
public static int SetTimer(float delaySeconds, int callbackId);
public static bool CancelTimer(int timerHandle);
```

其底层分别映射到现有的 `env.timer_set_once` 与 `env.timer_cancel`。这两个接口属于生命周期运行时原语，不是某个 UE API 的手写 binding；反射 API 仍由 descriptor、renderer 和动态 invocation 自动覆盖。

Emitter version 已升级为 `48.6.0`。共享 FName fixture 与实时 renderer 保持逐字节一致，architecture gate 同步锁定当前 public surface。

## 自动裁剪结果

样例以 EngineGameplay 的 342 项授权 package 构建，最终 runtime package 只保留 5 个实际可达的反射 binding：

1. `AActor.GetActorRotation`
2. `AActor.SetActorRotation`
3. `AActor.ActorHasTag`
4. `AActor.SetActorHiddenInGame`
5. `AActor.SetActorEnableCollision`

WASM 另外只保留实际使用的 `timer_set_once` 运行时导入；未调用的 `CancelTimer` 不进入最终 guest module。这证明公共 facade 的扩展不会把完整授权面带入每个脚本。

## UE 端到端验证

新增 `AvidScript.Editor.BindingRuntime.PlayablePickup`，通过正式 BuildProfile、WAMR 和 `UAvidScriptComponent` 验证：

1. 构建并加载生成的 manifest、WASM 与最小 runtime binding package；
2. `BeginPlay` 初始化拾取物；
3. `Tick(0.5)` 将 Yaw 从 10 度推进到 55 度；
4. 无 `Player` Tag 的 Actor 重叠不会触发拾取；
5. 带 `Player` Tag 的 Actor 触发自然 BeginOverlap，拾取物隐藏且碰撞关闭；
6. scheduler 推进 3.1 秒后触发 callback id 7，拾取物重新显示并恢复碰撞；
7. 已收集状态下以相同 `ModuleId` 成功热重载，`Collected` 迁移后仍保持隐藏和无碰撞，并由新 runtime 的 timer 恢复；
8. 语法错误的 C# 候选构建失败，不发布可加载产物；
9. 模拟 watcher 收到 malformed manifest 时，reload transaction 拒绝候选、恢复已提交 manifest 与 module；
10. 旧 WASM 随后继续 Tick，Yaw 正常增加 22.5 度。

## 剩余边界

- 本阶段验证的是预放置或运行时绑定 Actor 的逻辑闭环，还没有提供专用 Pickup Actor 模板、Editor 向导或内容资产。
- 热重载已经覆盖成功状态迁移与失败保活；当前重建的是一次性复活 timer，更复杂的 timer 剩余时长迁移仍需独立设计。
- EngineGameplay 当前授权面仍是人工维护的 profile 选择规则，不等同于任意 UE 模块的全自动按需发现。后续重点应转向项目级 API profile 生成、容器/委托/异步对象引用和调试体验，而不是逐函数增加胶水。
