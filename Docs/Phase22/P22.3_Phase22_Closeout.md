## 用户现在可以做什么

1. 在 Editor 中执行 `Tools > AvidScript > Create Default C# Profile`。
2. 编辑 `Saved/AvidScriptCSharpProfiles/default.csharp-profile.json`, 或保持默认 ActorLifecycle 示例。
3. 选中关卡中的 Actor。
4. 执行 `Tools > AvidScript > Build And Bind C# Profile Script`。
5. 进入 PIE 验证 `BeginPlay()` 和 `Tick(float deltaSeconds)` 驱动 Actor 位置变化。
6. 如果失败, 从 log/presentation details 中查看 `Next action`。
