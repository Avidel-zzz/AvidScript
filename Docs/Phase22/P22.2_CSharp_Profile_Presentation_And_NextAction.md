# P22.2 C# Profile Presentation 与 NextAction 实现

## 完成内容

P22.2 已完成 C# profile 工作流的可读诊断层:

## Presentation 规则

| 场景 | Severity | Title |
| --- | --- | --- |
| C# profile 模板生成失败 | Error | `AvidScript C# profile template failed` |
| C# profile 模板已创建或已存在 | Info | `AvidScript C# profile ready` |
| C# profile build 失败 | Error | `AvidScript C# profile build failed` |
| C# profile build 成功但绑定失败 | Warning | `AvidScript C# profile binding failed` |
| C# profile build 并绑定成功 | Info | `AvidScript C# profile bound` |

`Details` 会按存在情况输出 `Next action`, `Profile`, `Source`, `Module`, `Report`, `Manifest`, `Actor`, `Stdout`, `Stderr` 等字段。
