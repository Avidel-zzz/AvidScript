# P22.0 C# Gameplay Authoring Diagnostics 范围

## 目标

Phase21 已经能生成默认 C# profile 并从 Editor 执行 profile build-and-bind。Phase22 目标是提升 C# 编写游戏逻辑时的可理解性: 用户知道当前 C# 能写哪些 `BeginPlay`/`Tick` 逻辑, 失败时能从 Editor 输出里看到清晰的 title、body、details 和下一步建议。

本阶段不扩大 C# source adapter 语法子集, 先把诊断与示例打牢。

## 交付内容

- 扩展 `FAvidScriptEditorCSharpBuildResult`, 增加 `NextAction`。
- 扩展 `FAvidScriptEditorResultPresenter`, 支持 C# profile template 和 profile build-and-bind 的 presentation。
- `HandleCreateDefaultCSharpProfileTemplate()` 与 `HandleBuildAndBindCSharpProfile()` 改用 presentation 输出统一日志。
- 自动化覆盖 template created/failure、profile build success/build failure/binding failure 的 presentation。
- 自动化覆盖 C# build/source missing 与 profile missing 时保留 next action。
- 新增中文 `Docs/CSharpGameplayAuthoring.md`, 写明当前可用 C# 写法、profile workflow 和常见错误。

## 本阶段边界

- 不做 Slate UI、toast notification 或 Message Log tab。
- 不改变 runtime lifecycle、WASM ABI 或组件加载逻辑。
- 不扩大 C# parser/source adapter 支持范围。
- 不做 packaging/mobile 验证。
- 不重命名既有菜单入口。

## 验收标准

- 新增 C# presentation 自动化先 RED 后 GREEN。
- C# build/profile 失败结果包含可读 `NextAction`。
- C# profile/template 菜单 handler 输出统一 presentation。
- 中文 C# authoring 文档可直接指导用户写 `BeginPlay()` / `Tick(float deltaSeconds)` 样例。
- `AvidScriptEditor` module build、相关 focused automation、完整 `AvidScript.Editor` 和完整 `AvidScript` 通过。
