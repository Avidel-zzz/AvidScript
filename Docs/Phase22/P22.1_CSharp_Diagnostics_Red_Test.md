# P22.1 C# 诊断 RED 测试

## 目标

本小组先用自动化测试描述 Phase22 需要的新行为: C# profile/template/build/bind 的结果必须能转换成统一 presentation, 且失败结果必须保留下一步建议。

## 新增测试

- `AvidScript.Editor.Presentation.CSharpProfileTemplateCreatedSmoke`
- `AvidScript.Editor.Presentation.CSharpProfileTemplateFailureSmoke`
- `AvidScript.Editor.Presentation.CSharpProfileBuildAndBindSuccessSmoke`
- `AvidScript.Editor.Presentation.CSharpProfileBuildFailureSmoke`
- `AvidScript.Editor.Presentation.CSharpProfileBindingFailureSmoke`
- `AvidScript.Editor.CSharpBuildService.SourceMissingNextActionSmoke`
- `AvidScript.Editor.Module.CSharpProfileMissingNextActionSmoke`

## RED 结果

执行 `AvidScriptEditor` module build 后按预期失败。失败点集中在:

- `FAvidScriptEditorCSharpBuildResult` 尚无 `NextAction` 字段。
- `FAvidScriptEditorResultPresenter` 尚无 C# profile template presentation API。
- `FAvidScriptEditorResultPresenter` 尚无 C# profile build-and-bind presentation API。

这证明测试确实覆盖了 Phase22 要实现的新接口, 不是误用既有行为通过。
