# P16.0 Editor 组件绑定范围

## 目标

Phase 16 的目标是把 Phase 14/15 的 C# 构建产物接到 Editor 使用流：Editor 侧可以读取 C# build report 中的 manifest 路径，并把该 manifest 应用到目标 Actor 的 `UAvidScriptComponent`。

完成后，PC Editor 路径不再只依赖手工复制 manifest 路径。工具层可以直接从 `actor_lifecycle.csharp.report.json` 解析 `artifacts.manifest_file`，然后为选中 Actor 创建或复用 `UAvidScriptComponent`。

## 本阶段范围

- 新增 Editor 侧组件绑定服务。
- 支持显式 Actor + manifest 路径。
- 支持当前 Editor 选中 Actor + manifest 路径。
- 支持显式 Actor + C# build report。
- 支持当前 Editor 选中 Actor + C# build report。
- 自动化验证 C# report 到选中 Actor 的绑定路径。

## 非目标

- 不做完整 Slate 面板。
- 不做文件选择器或资产化脚本管理。
- 不改 C# source adapter 支持子集。
- 不做 PC packaged 或移动端验证。
- 不把 Editor-only 逻辑放进 Runtime module。

## 验收标准

- `AvidScript.Editor.ComponentBinding.ApplyManifestToActorSmoke` 通过。
- `AvidScript.Editor.ComponentBinding.ApplyCSharpReportToSelectedActorSmoke` 通过。
- 完整 `AvidScript.Editor` 回归通过。
- 完整 `AvidScript` 回归通过。
