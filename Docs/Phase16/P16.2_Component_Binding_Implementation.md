# P16.2 组件绑定实现

## 新增服务

新增 `FAvidScriptEditorComponentBindingService`：

- `ApplyManifestToActor`
- `ApplyManifestToSelectedActor`
- `ApplyCSharpReportToActor`
- `ApplyCSharpReportToSelectedActor`

服务位于 `AvidScriptEditor` module，依赖 Runtime 的 `UAvidScriptComponent`，但不执行 WASM，也不改变 Runtime module 边界。

## 行为

- manifest 路径为空时 fail closed，返回 `manifest_path_missing`。
- manifest 文件不存在时 fail closed，返回 `manifest_missing`。
- C# report 不存在或不是 direct ABI 成功报告时 fail closed。
- 当前 Editor 没有选中 Actor 时 fail closed。
- Actor 没有 `UAvidScriptComponent` 时默认创建组件。
- 组件创建后调用 `SetScriptManifestPath` 写入规范化后的 manifest 路径。

## C# report 解析

服务读取 C# build report 的以下字段：

- `language == "csharp"`
- `result == "direct_abi_built"`
- `direct_abi_supported == true`
- `artifacts.manifest_file`

`artifacts.manifest_file` 支持 project-relative 路径，例如：

```text
Saved/AvidScriptCSharpGuest/ActorLifecycle/actor_lifecycle.avidscript.json
```

Editor 服务会将其解析为完整路径，再写入组件。

## 自动化覆盖

- `ApplyManifestToActorSmoke` 验证显式 Actor + manifest 路径。
- `ApplyCSharpReportToSelectedActorSmoke` 验证 C# report + Editor selection + 自动创建组件。
