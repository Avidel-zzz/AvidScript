# P33.1 Gameplay Event RED 测试

状态：Done

## 测试目标

- Runtime 必须能把 `eventId + float value` 调用到 guest `avid_on_event`。
- 事件只能在 BeginPlay 与 EndPlay 之间派发。
- 非法 eventId/NaN 必须拒绝，但不能卸载健康 runtime。
- 缺少 export 或 guest trap 必须返回结构化错误。
- 组件入口必须可由 Blueprint 调用，并保留事件统计。
- C# source adapter 必须生成 v11 event export，同时兼容未声明 `OnEvent` 的旧脚本。

## RED 证据

测试先引用尚不存在的 `DispatchEvent`、`DispatchScriptEvent`、event result 字段和 v11 manifest 契约，因此 Runtime、Component 与 C# 工具链均产生目标失败。实现后保留三项专用 Runtime 自动化，覆盖参数校验、生命周期、成功调用、缺失 export 与 trap。
