状态：Done

## Runtime 与组件

- `FAvidScriptWasmRuntimeInstance::DispatchEvent(int32, float, ...)` 调用 guest `avid_on_event(i32, f32)`。
- `UAvidScriptComponent::DispatchScriptEvent(...)` 暴露为 `BlueprintCallable`，可由 Blueprint、Enhanced Input 或碰撞事件主动转发。
- 事件统计记录调用次数、最近 eventId、最近 value 与调用耗时。
- host 参数错误只拒绝当前事件；guest 缺失 export 或 trap 会停止并卸载该脚本实例。
- Reload session 可派发事件；成功 Reload 后新实例统计归零，失败 Reload 保留旧实例。

## C# v11

```csharp
[UnmanagedCallersOnly(EntryPoint = "avid_on_event")]
public static void OnEvent(int eventId, float value)
{
    UE.Self.AddActorWorldOffset(new FVector(0.0f, value, 0.0f));
}
```

Adapter v11 生成 `avid_on_event`；脚本未声明 `OnEvent` 时生成 no-op export，保持旧 profile 兼容。`value` 只允许出现在 `OnEvent`，当前支持字面量、静态 float 字段、乘法和加法。
