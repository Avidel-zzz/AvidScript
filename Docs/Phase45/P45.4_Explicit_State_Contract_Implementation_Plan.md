# P45.4 C# 显式状态契约实施计划

> 执行方式：按 P45.4A-D 分组推进；每组先增加能证明行为缺失的聚焦回归，再实现最小生产变更并执行该组完整回归。禁止清理 UE Editor target。

**目标：** 为 C# + WASM 热重载增加渐进兼容的持久化属性、严格模式、字段别名、版本化 State Schema v2 与事务 alias 迁移。

**架构：** Roslyn Semantic 负责把 AvidScript Attribute 投影为结构化状态契约；CSharpGuest 负责选择安全 Guest 槽位并生成 v2 schema；UE manifest loader 和独立 StateMigration 服务负责 v1/v2 校验与 exact/alias 匹配。`RuntimeSession` 不拥有契约解析或迁移算法。

**技术基线：** .NET 8、Roslyn、AvidScript Guest IR、WAMR、UE5.8 source build、PowerShell 构建编排。

## 全局约束

- 默认策略为 `compatible`，现有未标注安全字段继续迁移。
- 只有类型显式声明 `AvidStateMode.Explicit` 时才要求字段标有 `[AvidPersist]`。
- alias 只允许 exact type fingerprint 和 size 复制，不做隐式数值转换。
- schema v1 继续可读，新编译器只发布 schema v2。
- 候选失败必须保留旧 runtime、scheduler、manifest 与 Tick 能力。
- 人读文档使用中文；四份用户维护中的受保护文档不得暂存或提交。
