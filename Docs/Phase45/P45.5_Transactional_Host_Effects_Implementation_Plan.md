# P45.5 候选热重载宿主副作用事务实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为候选 C# + WASM `BeginPlay` 增加生成式 effect policy、可逆 transform journal 和失败回滚，使候选失败后旧 runtime 与已覆盖的 UE transform 状态都保持有效。

**Architecture:** Binding Descriptor v3 声明 `reload_effect`，旧 v2 package 按 const/non-const 安全归一化。`AvidScriptBindings` 在静态和动态写入前调用可选 journal，`AvidScriptRuntime` 的独立 transaction service 保存 Actor/SceneComponent transform，`RuntimeSession` 只在候选 `BeginPlay` 期间拥有并注入 transaction。

**Tech Stack:** UE5.8 source build、C++20/UE Core、UE Reflection/ProcessEvent、WAMR、C# direct ABI、PowerShell、Unreal Automation Framework。

## 全局约束

- 只使用源码版 UE5.8，Engine Root 为 `C:\UnrealEngine`。
- 禁止 clean Editor target；UBT 使用普通增量构建、`-MaxParallelActions=1 -NoUBA`。
- live runtime 的 Tick/Event/Input 写入语义不得改变；transaction 只存在于候选 reload `BeginPlay`。
- 未声明或未实现 adapter 的非 const binding 在候选阶段必须在 `ProcessEvent` 前 fail closed。
- 不通过逐个新增 host import 扩大 API；新增函数只增加声明式 effect policy，ABI lowering 和动态 dispatcher 继续复用生成链。
- 用户维护中的 `Docs/CSharpGameplayAuthoring.md`、Phase42/Phase44 架构文档和 `Docs/AvidScript_Technical_Status.md` 不得暂存或提交。
- 给人读的阶段文档使用中文；每组完成后更新 checkbox、实现记录和 `AGENTS.md`。

{
public:
