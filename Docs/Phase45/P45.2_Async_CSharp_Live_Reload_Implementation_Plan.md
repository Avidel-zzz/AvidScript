# P45.2 异步 C# Live Reload 实施计划

> **供 agentic worker 执行：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans` 按任务推进。每一步使用 checkbox 追踪；本项目已获得连续执行授权，采用当前任务内 inline execution。

**目标：** 将 Project C# Auto Live Reload 的外部构建改为可取消、可观测且不阻塞 Editor 主线程的异步双阶段流水线，同时保持旧 runtime 的事务保活语义。

**架构：** 同步与异步入口共享 invocation prepare/finalize 和 build pipeline phase contract。`FMonitoredProcess` delegate 只写线程安全状态；Editor ticker 驱动 bootstrap、binding slice、final build 与最终 Actor binding 的主线程状态机。

**技术栈：** UE5.8 Core `FMonitoredProcess`、`FTSTicker`、`TQueue<EQueueMode::Mpsc>`、C++20/UE Core types、现有 PowerShell + .NET 8 C# frontend、WAMR runtime。

## 全局约束

- Engine 固定为 `C:\UnrealEngine` 源码版 UE5.8。
- 目标固定为 `AvidTPSTemplateEditor Win64 Development`，只执行增量 UBT；禁止 Clean Editor target。
- 人类阅读文档全部使用中文。
- 不修改或暂存用户拥有的 `Docs/CSharpGameplayAuthoring.md`、`Docs/Phase42/P42.0_Reflection_Binding_Generator_Architecture.md`、`Docs/Phase44/P44.0_Project_CSharp_Workspace_and_Live_Reload_Architecture.md`。
- 不新增第二套命令行转义、report 解析、binding slice 或 Actor reload 实现。
- 不把 UE reflection、`UObject` 或 binding publication 放入 `FMonitoredProcess` callback。
- 测试覆盖真实风险边界，不为私有 getter 或无行为分支堆叠测试。
- 每个任务独立提交；新增 cpp 若未进入 action graph，只删除已验证的目标 `Makefile.bin` 后普通增量构建。

**接口：**

- Job 不接收或持有 Actor；它只加载 profile、驱动 build phase 并交付 final report。

- [ ] **Step 1：增加状态转换回归**

使用 fake process factory 覆盖：

- 显式 binding package：`Preparing -> FinalRunning -> ReadyToBind`；
- 自动 slice：`Preparing -> BootstrapRunning -> PublishingBindingSlice -> FinalRunning -> ReadyToBind`；
- bootstrap failure 不启动 final；
- final failure 保留结构化 cause；
- 任意运行阶段 Cancel 只产生 Canceled；
- output/progress 随 Poll 更新。

- [ ] **Step 2：运行 RED**

- [ ] **Step 4：实现 async job**

`Start` 在主线程加载 profile并调用 pipeline `Prepare`；`Tick` 轮询 process completion，根据状态进入 bootstrap finalize、slice publication 或 final finalize；`Cancel` 转发 kill-tree 并禁止后续 phase；`ConsumeResult` 只允许终态调用一次。
