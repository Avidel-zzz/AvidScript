# P45.6 C# Runtime 诊断与函数级调用栈实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让正式 C# + WASM 构建在 WAMR trap 后返回经过 provenance 验证的项目相对源码、方法签名与函数声明 span，同时保持健康生命周期热路径零额外调用栈成本。

**Architecture:** `AvidScript.CSharpGuest` 从 Semantic callable 与 Guest function index space 生成确定性 debug map；构建 manifest 用 SHA-256 绑定该 artifact 与 Guest IR。`AvidScriptVM` 只采集通用 WAMR function index/offset frame，`AvidScriptRuntime` 验证 debug map 并映射成 C# 诊断，Editor 仅负责呈现。

**Tech Stack:** C# 12 / .NET SDK 8.0.416、Roslyn Semantic artifact、Guest IR、WASM 1.0、WAMR fast interpreter、UE5.8 C++、PowerShell 7、Automation Tests。

## 全局约束

- 引擎固定使用源码版 UE5.8：`C:\UnrealEngine`。
- .NET 命令固定使用 `$env:USERPROFILE\.dotnet\dotnet.exe`，SDK 必须包含 `8.0.416`。
- VM public contract 不得出现 C#、源码路径、`UObject` 或 WAMR 类型。
- WAMR 文本解析只允许存在于 `AvidScriptVM/Private`。
- debug map 只保存项目相对 source identity，禁止绝对路径、盘符、UNC 和 `..` 逃逸。
- 调用栈只在 trap/host import failure 路径采集；健康 BeginPlay/Tick/Event/Timer 不新增 host import 或 frame allocation。
- v1 只映射函数声明 span；WAMR offset 保留为 raw evidence，不宣称精确表达式行号。
- 继续兼容没有 debug map 的旧 manifest；声明 debug map 的 manifest 必须 hash/provenance fail closed。
- 不修改或暂存用户现有改动：`Docs/CSharpGameplayAuthoring.md`、`Docs/Phase42/P42.0_Reflection_Binding_Generator_Architecture.md`、`Docs/Phase44/P44.0_Project_CSharp_Workspace_and_Live_Reload_Architecture.md`、`Docs/AvidScript_Technical_Status.md`。
- 禁止 clean Editor target；跨模块 ABI 变化使用项目 target 加受影响的 `-Module=`，最后执行普通 no-clean 项目 target build。
- 每次新增 plugin `.cpp` 在首次 UBT 前必须进入 Git index，并确认 unity/module source list 已包含它。

- [ ] **Step 3：实现模型、投影与 canonical serializer**

模型固定为：

```csharp
public sealed record CSharpGuestDebugMap(
    int SchemaVersion,
    string DebugVersion,
    string ModuleId,
    CSharpGuestDebugSource Source,
    CSharpGuestDebugProvenance Provenance,
    IReadOnlyList<CSharpGuestDebugFunction> Functions);

public sealed record CSharpGuestDebugFunction(
    int WasmFunctionIndex,
    string GuestFunctionId,
    string MethodSymbolId,
    string DisplayName,
    SemanticSpan Span);
```

Projector 通过 `function.Id == "function:" + callable.MethodSymbolId` 精确关联；缺失、重复、负 index、非 canonical SHA 或无 symbol span 时抛出 `InvalidDataException`。serializer 使用 snake_case、固定属性顺序、UTF-8 无 BOM 和 LF 结尾。

- [ ] **Step 4：接入 CLI 三产物失败清理**

`GuestCommandLine` 解析 4/6/8 参数组合，删除旧 debug output，在 Guest IR canonical bytes 写入后计算 SHA-256，再投影并原子写 debug map。异常处理把 `debugMapPath` 一并传给 `DeletePublishedArtifacts`。
