# Phase 45.1 C# 自动 Live Reload 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 UE5.8 Editor 中监听项目 C# workspace，经过防抖与 single-flight 调度后复用正式构建和事务 reload，把结果稳定应用到启用时固定的 Actor。

**Architecture:** 纯 coordinator 管理时间与请求 generation；Editor watch host 包装 DirectoryWatcher；build executor 组合 Profile/Build/Binding service；live reload service 管理弱目标、队列、ticker 和诊断；Editor module 只管理显式 Start/Stop 命令与生命周期。

**Tech Stack:** UE5.8 C++、DirectoryWatcher、Core ticker、TQueue MPSC、现有 Roslyn/Guest IR/WASM pipeline、WAMR、UE Automation。

## Global Constraints

- 只使用源码版 UE5.8：`C:\UnrealEngine`。
- 只增量构建 `AvidTPSTemplateEditor Win64 Development`，`-MaxParallelActions=1 -NoUBA`，禁止清理 Editor target。
- P45.1 的自动构建复用同步 `FAvidScriptEditorCSharpBuildService`；不得把 UE reflection/UObject 路径放入线程池。
- 自动模式必须显式启用；模块启动不自动编译用户脚本。
- 目标 Actor 在启用成功时固定为弱引用；后续 selection 变化不得改变 target。
- build 或 reload 失败不得释放旧 runtime、关闭 Tick、覆盖 active manifest path 或新增失败导致的 dirty。
- watcher callback 不访问 UObject、不执行构建；只把 change batch 放入 MPSC queue。
- 人读文档使用中文；代码、稳定 category 与 public symbol 使用英文 ASCII。
- 保护现有用户未暂存文件，不暂存、不覆盖、不回退。
