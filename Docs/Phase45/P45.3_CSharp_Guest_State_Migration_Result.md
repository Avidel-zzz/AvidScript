# P45.3 C# Guest 状态迁移阶段成果

## 阶段结论

P45.3 已完成。AvidScript 现在能够在 Win64 Editor 中进行 C# -> WASM 自动热重载时，把旧实例中兼容的基础值状态迁移到候选实例，并在迁移成功后才执行候选 `BeginPlay` 和原子切换。

这解决了此前“改一行 C# 代码后运行时字段全部归零”的核心开发体验问题。迁移失败、候选 `BeginPlay` 失败或后续验证失败时，候选实例会被卸载，旧 runtime、scheduler、manifest 和 Tick 能力保持不变。

## 已实现能力

### 工具链

- Roslyn Semantic + Guest IR 自动生成确定性状态 schema，不需要为每个字段手写 UE API。
- 导出的生命周期函数用于定位唯一脚本 owner，只投影该 owner 的安全静态 Guest global。
- 每个槽位包含由 owner + 字段名组成的类型无关稳定 ID，以及递归类型指纹、offset、size 和 alignment。
- CLI 原子发布 Guest IR、状态 schema 和 WASM；失败时清理陈旧产物。
- 正式 build report 和 runtime manifest 均携带状态迁移摘要。

### Runtime 与 VM

- `IAvidScriptVmBackend` 提供可选、语言无关的 Guest memory capability。
- WAMR backend 对读写范围执行地址校验；宿主越界校验不会污染后续 WASM 调用。
- 独立 `Private/StateMigration` 服务负责匹配、快照和候选写入，`RuntimeSession` 只编排生命周期。
- 只有新旧 manifest 双边启用 `host_snapshot`、`module_id` 相同且 owner type 相同时才尝试迁移。
- 同稳定 ID 的类型指纹和尺寸必须完全一致；offset 可以变化。
- 新增和删除字段被跳过；同 ID 类型不兼容时 fail-closed，并保留旧实例。

## C# 使用方式

当前可迁移状态以脚本类型的安全静态字段表达。例如：

```csharp
public sealed class GameplayScript
{
    public static float TotalRotationDegrees;

    public static void Tick(float deltaSeconds)
    {
        TotalRotationDegrees += 90.0f * deltaSeconds;
    }
}
```

修改并保存 C# 后，自动重载会生成新 schema。只要字段身份和类型保持兼容，`TotalRotationDegrees` 会进入新 WASM 实例，新版本代码从旧值继续运行。

## 安全边界

当前支持标量、枚举和只包含安全值成员的结构。以下状态默认不迁移：

- 字符串、数组、容器和引用类型。
- UObject/Actor 句柄和任意宿主对象引用。
- Guest 堆地址、计时器、协程、调用栈和 VM 栈。
- 未出现在 manifest 中的任意线性内存。

宿主限制为最多 1024 个槽位、单槽最多 64 KiB、单次总计最多 1 MiB。日志只记录槽位数、字节数、跳过数和失败 stable ID，不记录字段值。
