# Phase 60 实施计划

## 总目标

在不引入逐 API wrapper 的前提下，把 Interface、Delegate、脚本 UFunction 默认参数、Blueprint 新声明
函数和通用异步动作接入同一 descriptor、prepared route 与 Session 生命周期，形成可用于小型游戏 Demo
的现代 UE 互操作表面。

## P60.A Interface 与默认参数

进度：`P60.A1 Interface`、`P60.A2 脚本 UFUNCTION 默认参数` 已完成。

- 建立统一 receiver compatibility helper，覆盖 class 与 interface；
- 为 `FInterfaceProperty` 增加 ObjectHandle codec，保持 ABI 为 `(slot, generation)`；
- 扩展 object type checked cast，使 interface 使用 `ImplementsInterface`；
- 为 interface UFunction 增加 concrete-class PIC 与 reinstance 失效；
- C# facade 生成可检查、转换和调用的 interface proxy；
- Semantic 冻结脚本 UFunction 可选参数常量；
- Generator 把默认参数写入 UHT metadata、manifest 和 native structure fingerprint；
- 用 native + Blueprint interface implementation 和真实 UFunction metadata 验证。

完成条件：interface cast/call 与脚本默认参数都通过真实 UE Reflection/Runtime 闭环，且没有新增项目 API
名称分支。

## P60.B 完整 Delegate

- 抽取 shared prepared delegate signature plan；
- 支持 `FDelegateProperty` 选择、descriptor、facade 与 Session-owned bind lease；
- singlecast unbind 只在仍拥有 property 时恢复旧 delegate；
- 多播沿用 add/remove，统一 token、reload 和 teardown；
- callback 支持 singlecast return/ref/out，复用输出事务；
- 为 singlecast execute 与 multicast broadcast 生成 ordinal 驱动 typed import；
- 加入 ownership、重复 bind、外部改写、trap rollback 与 stale token 验证；
- 加入 callback/invoke 分层 benchmark。

完成条件：C# 能绑定和调用单播/多播 delegate，生命周期与 ref/out 事务在失败路径仍正确。

## P60.C Blueprint 函数与通用异步

进度：`P60.C1a Blueprint 自声明出站 callable` 与 `P60.C1b Blueprint 自声明入站 event` 已完成；
通用 async action 待完成。

- Profile 精确选择 Blueprint class 自声明 callable/event；
- descriptor 冻结 Blueprint asset/function fingerprint；
- 出站调用走 cached ProcessEvent + concrete-class PIC；
- 入站 event 复用 `replace/before/after`、重入 FIFO 和原 thunk 所有权；
- 生成阶段拒绝隐式自递归的 invoke/replace 组合；
- 识别 `UBlueprintAsyncActionBase` 工厂 + `BlueprintAssignable` delegate 结构；
- 生成 typed awaitable/outcome，Session 统一管理 action lease、subscription 和 continuation；
- 验证完成、取消、reload、teardown 和 Blueprint reinstance。

完成条件：一个真实 Blueprint 自声明函数可双向交互，一个非手写名称的 async action pattern 可从 C#
await 到完成。

## P60.D 集成与 Gate

- 更新示例脚本，展示 interface、default、delegate、Blueprint callable 和 async action；
- 更新简洁 README 的“已实现”与当前性能数据，不堆积阶段日志；
- 集中执行固定 .NET console suites 与 PowerShell 合同；
- 运行 UE5.8 no-clean Editor UBT；
- 运行 focused Automation 后再运行完整 AvidScript Automation；
- 运行 clean detached architecture gate；
- 输出 interface/delegate/Blueprint/async 分层性能矩阵；
- 记录人工 PIE、Blueprint pin 与交互验收边界；
- attestation、close、推送并核对远端 SHA。

## 提交与验证节奏

- 每个可审阅能力小节完成后使用精确 whitelist 提交并立即推送；
- 普通小节只运行静态/局部 console/focused 证据，不碎片化运行完整 UBT 与全量 Automation；
- 一个大批次完成后集中做一次影响审查；阶段末统一做 UBT、完整 Automation、architecture 和 benchmark；
- 阻塞性高风险立即修复，其余债务登记后在批次末集中处理；
- 不修改或暂存三项受保护 dirty 文件。

## 预算

- UBT：实现批次最多 3 次，阶段 Gate 1 次 no-clean；
- Automation：focused 最多 2 轮，完整 Gate 最多 2 轮；
- 每个 benchmark 固定 workload、warmup、sample 和 percentile，失败不能用重跑择优掩盖。
