# P60.C1b Blueprint 自声明事件入站闭环

## 目标

让 Profile 精确选择 Blueprint class 自声明的字节码函数，并把它作为 C# 入站事件接入现有
`before/after/replace` 函数 Hook、Session 生命周期和 WASM callback，不增加第二套事件系统，也不为资产或
函数名编写宿主 wrapper。

## 已实现

- descriptor 升级到 schema `22`，为 Blueprint function handler 冻结 owner asset path 与 function
  fingerprint；selection/package hash 同步覆盖 provenance；
- 无网络标记、非 RepNotify、由 Blueprint 生成类直接声明的字节码函数自动归类为
  `blueprint_event`；当前要求返回 `void`，参数仅允许 value/const-ref；
- Runtime load 核对生成类、资产路径、非原生字节码和函数指纹，变化时以
  `binding_reflection_provenance_mismatch` 失败关闭；
- 入站执行复用已有 Function Hook Registry、prepared codec、重入 FIFO、原函数所有权和 Session teardown；
- `before` 与 `after` 保留 Blueprint 原函数，`replace` 由 C# handler 取代原函数；解绑后恢复原 thunk；
- 同一 Blueprint 函数若同时生成出站 callable 与 `replace` handler，会以
  `blueprint_event_replace_invocation_conflict` 在生成阶段拒绝，避免隐式自递归；
- C# package resolver 与 Runtime reload manifest 已完整放行 descriptor schema `20-22`，实际 WASM artifact
  可以消费新事件描述符；
- singlecast callback 在 Runtime callback 分类中继续走 delegate subscription，不会误落到 function handler。

## C# 使用方式

Profile 将 Blueprint 函数加入 `include_handlers`、`before_handlers` 或 `after_handlers` 后，生成 facade 会发布
对应的 `AvidEvents` 常量。脚本继续使用统一事件属性：

```csharp
[AvidEvent(AvidEvents.ScriptOnlyEvent)]
public static void OnScriptOnlyEvent()
{
    AAvidScriptGameplayActor self = UE.Self;
    self.AddActorWorldOffset(new FVector(0.0f, 0.0f, 25.0f));
}
```

`include_handlers` 对应 `replace`；若 C# handler 还需要调用同一 Blueprint 原函数，应改用
`before_handlers` 或 `after_handlers`，不要绕过生成阶段的递归门禁。
