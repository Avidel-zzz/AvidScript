# P60.A2 脚本 UFUNCTION 默认参数

## 结果

C# 脚本声明的可选参数现在会进入真实 UE Reflection，而不只在 C# 调用点生效：

```csharp
[UFunction(BlueprintCallable = true, Category = "Projectile")]
public void ConfigureLaunch(float speed = 1200.0f, bool homing = false, int burstCount = 1)
{
    PrecisionScale = speed;
    IsActive = homing;
    ActivationCount += burstCount;
}
```

生成的 UHT 壳包含：

```cpp
UFUNCTION(BlueprintCallable, Category="Projectile",
    meta=(CPP_Default_speed="1200", CPP_Default_homing="false", CPP_Default_burstCount="1"))
virtual void ConfigureLaunch(float speed, bool homing, int32 burstCount);
```

因此 Blueprint 和 UE 反射调用读取的是同一份 `CPP_Default_*` 合同。C# 内部省略参数仍由 Roslyn
绑定为常量，不增加 Runtime ABI 分支或额外 crossing。

## 实现

- Semantic schema 提升到 `20`、version `1.22`，每个默认值冻结
  `{ordinal, name, type_id, kind, canonical_value}`；
- 允许 bool、整数、有限浮点、string，以及来自受控 UE facade 的命名 enum 常量；
- 非命名 enum 值、decimal、null、ref/out、非尾部区间和 override 重声明均 fail-closed；
- Generator manifest 提升到 schema `6`、version `1.8`，默认值进入 generation key 与 native
  structure fingerprint；只改默认值也会触发 `native_rebuild_required`；
- UHT renderer 统一生成 metadata，并自动生成 `UFunction::GetMetaData` 反射断言；没有项目 API
  名称分支，也没有第二套默认参数系统。
