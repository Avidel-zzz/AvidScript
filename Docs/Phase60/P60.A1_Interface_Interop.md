# P60.A1 Interface 互操作实现记录

状态：已完成

## 实现结果

- Reflection 现在把 `FInterfaceProperty` 投影为稳定的 `object_handle`，继续使用 `(slot, generation)` ABI；
- C# facade 为 UE Interface 生成 `I` 前缀的强类型 handle，可作为函数参数、返回值和属性使用；
- Runtime 统一使用 `ImplementsInterface` 校验接口对象，普通 UObject class 仍使用 `IsA`；
- `FScriptInterface` 编解码同时支持原生接口实现和 Blueprint-only 实现，不向 Guest 暴露原生接口指针；
- 接口 UFUNCTION 在接收者具体类上解析签名兼容的实现，并按具体 `UClass` 缓存一个 hot-path 命中；
- object type checked cast、prepared invocation 和 delegate 参数编码复用同一兼容判定。

没有增加按接口名或项目 API 名称分支，也没有增加新的 Host ABI。Profile 仍然决定哪些接口和函数可以
进入 descriptor。

## C# 使用表面

生成的接口 handle 与普通对象 handle 一样可判空和传递，接口函数来自 UE Reflection：

```csharp
IAvidGameplayTarget target = receiver.GameplayTarget;
if (target.HasHandle)
{
    int applied = target.ApplyGameplayValue(4);
    receiver.GameplayTarget = receiver.RoundtripTarget(target);
}
```

其中 `IAvidGameplayTarget`、`GameplayTarget`、`ApplyGameplayValue` 和 `RoundtripTarget` 都由项目 Profile 与
Reflection 生成，不需要手写 C++ wrapper。
