# P60.C2c4 Blueprint AsyncAction 生命周期

## 目标

关闭 pending Blueprint AsyncAction 在 Blueprint reinstance、对象失效、显式取消和 teardown 下的
生命周期缺口。所有权仍由 Session continuation 统一管理，不为单个异步 API 增加手写 wrapper。

## 已实现

- 仅存在 pending action 的 Session 才监听 UE `OnObjectsReinstanced`，归零后立即退订；replacement map
  只取消实际受影响的 action；
- reinstance 会先解绑 delegate、撤销 bridge route、释放 action lease，再以 `Cancelled` 恢复仍存活的
  C# awaiter；
- drain 前扫描 pending action；对象失效或 class 带 `CLASS_NewerVersionExists` 时自动走同一取消路径；
- 显式取消和对象失效均产生一次 consume-once `Cancelled` completion；
- Session unload、World teardown 或 owner context 失效不再向无效 Guest 派发 completion，只回收 action、
  delegate、route 与 continuation；
- 所有 teardown 后的迟到广播都会被 deactivated bridge 和 generation/activation fence 抑制。

## Reinstance 策略

框架不尝试迁移任意异步原生操作的内部状态。Blueprint structural compile 可能替换实例，也可能保留
generated class 地址，因此正确证据是 replacement 回调后的 delegate 解绑、`Cancelled` 状态和 token
回收，而不是比较 `UClass*` 地址。

旧 binding package 若仍持有旧 Blueprint 反射对象，后续调用会失败关闭；重新生成并事务式加载 package
后才允许创建新 action。这样不会把不可证明兼容的旧 `FProperty/UFunction` 指针带入新实例。

## 验证

- UE5.8 `AvidTPSTemplateEditor Win64 Development` no-clean UBT：通过；
- `AvidScript.Runtime.Continuation.BlueprintAsyncAction`：1/1 通过；
- `AvidScript.Editor.BindingRuntime.BlueprintAsyncActionPayloadCSharp`：1/1 通过；
- Editor 用例通过 production C# profile 构建 WASM，创建 Blueprint-generated action，执行 structural
  compile，并验证 C# `await` 收到 `Cancelled`、无 payload、无残留 continuation；
- Runtime 矩阵覆盖正常完成、同步完成、显式取消、对象失效、Session teardown、World teardown 和晚到
  广播抑制。
