# P60.C1a Blueprint 自声明函数出站调用

## 目标

让 Profile 精确选择 Blueprint class 自声明的函数，通过现有 descriptor、ObjectHandle 和 prepared
`ProcessEvent` 路径调用真实 Blueprint bytecode，不为具体资产或函数名编写宿主 wrapper。

## 已实现

- descriptor schema 升级到 `21`，每个函数显式记录 `reflected_owner_kind`；
- Blueprint 自声明函数额外冻结 owner asset path 与 function fingerprint；
- fingerprint 由 canonical signature identity 与 Blueprint bytecode SHA-256 组成；
- selection/package hash 覆盖 provenance，防止描述符字段被替换后仍沿用旧身份；
- Runtime load 阶段核对生成类、owner asset、非原生函数、bytecode 与 fingerprint；
- 调用继续复用 ordinal、ObjectHandle、prepared codec 和 cached `ProcessEvent`；
- 零参数/零返回函数不再初始化空参数帧，合法调用 `ProcessEvent(Function, nullptr)`；
- Blueprint 重编译改变 bytecode 后，旧描述符以
  `binding_reflection_provenance_mismatch` 失败关闭。

## 架构边界

Blueprint provenance 只扩展 descriptor 事实与装载校验，不进入 VM enum，也不增加项目 API 名称分支。
调用仍由 `AvidScriptBindings` 所有，C# facade 和 WASM ABI 继续消费通用生成结果。

当前小节只完成出站 callable。Blueprint 入站 event 的 `before/after/replace`、递归策略和 Session hook
归入 `P60.C1b`；`UBlueprintAsyncActionBase` 结构化 awaitable 归入 `P60.C2`。
