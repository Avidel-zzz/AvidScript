# P60.C2c3 Blueprint AsyncAction C# 端到端

## 目标

把 P60.C2c2 的参数捕获能力接入真实 C# `await`，并验证 AsyncAction 在事务式 Guest reload 前后
都由 Session 正确管理。该批次只闭环运行时语义，不把 Blueprint class reinstance 或完整取消矩阵
提前计为完成。

## 已实现

- 通过 production C# profile 选择测试 AsyncAction 工厂与 `AActor.SetActorScale3D`；
- C# 脚本直接等待生成的强类型 awaitable，并读取 outcome、scalar 与 UObject payload；
- binding slice 会保留 continuation 间接引用的 payload/result 类型，避免裁剪后 descriptor 失效；
- composite payload 可以进入有界 result slot，并继续复用既有 result codec；
- Guest reload 会解绑旧 action、创建并绑定候选 action，提交后仅允许新 action 恢复脚本；
- 旧 action 的迟到广播被抑制，不会重复恢复或污染新 Session 状态；
- Wasm backend 补齐 C# 条件表达式需要的整数 `&&` / `||` lowering。

## 关键不变量

- action outcome 仍遵循首广播获胜；
- result slot 分配只接受字段数、偏移、宽度与总大小均受限的 composite payload；
- payload 中的 UObject 继续使用 capability handle，不向 Guest 暴露原生指针；
- reload 候选失败时不得破坏旧 Session，提交后旧 lease 不得再次生效；
- 参数捕获失败必须 fail closed，并在异常冷路径留下可诊断日志。
