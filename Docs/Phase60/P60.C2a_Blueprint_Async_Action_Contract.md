# P60.C2a Blueprint Async Action 生成契约

## 目标

本小节建立 `UBlueprintAsyncActionBase` 的生成式契约，让 C# facade 能按 UE 反射结构生成强类型
awaitable，而不是为每个异步 API 手写 wrapper。Runtime action lease、delegate 完成桥和 teardown 归入紧接着
的 `P60.C2b`。

## 已实现

- schema 23 新增 `blueprint_async_action` dispatch 与 `async_action` 冻结模型；
- 只按结构识别：static `BlueprintCallable` factory 返回 `UBlueprintAsyncActionBase` 子类；
- 自动收集、排序并冻结全部 `BlueprintAssignable` dynamic multicast outcome；
- outcome ordinal、delegate member、stable id、payload type 和 completion policy 全部进入 selection/package hash；
- 生成独立 outcome enum 与 `AvidOutcomeAwaitable<TOutcome>` C# facade；
- producer import 固定为“factory 参数 + callback id -> continuation token”；
- schema 23 已进入 descriptor parser、canonical serializer、package script 和 reload manifest 兼容范围。

## 当前边界

本批次交付时只接受无参、无返回值的 outcome delegate。后续 `P60.C2c1` 已在保持 schema 23 的前提下
增加统一 typed result layout；`ref/out`、返回值和未支持的复杂 payload 仍失败关闭。

本批次还没有绑定 action delegate、调用 `Activate()` 或恢复 continuation，因此 README 只标记“结构识别与
awaitable 生成”，不声明 Runtime 闭环完成。

## 验证

- UE5.8 `AvidTPSTemplateEditor Win64 Development` no-clean UBT：通过；
- `AvidScript.Editor.BindingDescriptor.BlueprintAsyncActionSchema23`：`1/1 Success`；
- schema 测试覆盖结构识别、确定性 outcome、typed C# facade 与 ordinal 漂移拒绝。
