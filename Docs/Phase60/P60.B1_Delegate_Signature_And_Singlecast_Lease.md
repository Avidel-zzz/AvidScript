# P60.B1 Delegate 共享签名与单播租约

状态：已实现，待随 Phase 60 集中 Gate 复验

## 目标

在不新增逐 API wrapper 的前提下，让 `FDelegateProperty` 与
`FMulticastDelegateProperty` 复用一套 prepared signature、参数 codec 和输出事务，并把单播绑定
生命周期收归 Session 管理。

## 已实现

- descriptor schema 20 发布 Delegate 返回值，旧 schema 11-19 继续按原合同加载；
- prepared event 由扁平字段收拢为 `FAvidScriptPreparedDelegateSignaturePlan`，以 storage kind 区分
  singlecast、multicast 与 function handler；
- Editor Reflection 可选择 `FDelegateProperty`，生成 `BindX(source)` C# facade；多播继续生成
  `SubscribeX(source)` 并保留兼容别名；
- C# `[AvidEvent]` 回调支持固定布局返回值及 `ref/out`，所有输出共用一次事务，顺序为参数输出后返回值；
- singlecast 显式绑定会保存旧 Delegate，只在属性仍由 AvidScript bridge 持有时恢复；外部覆盖不会被取消或
  Session teardown 反向覆盖；
- 同一 source 与 event ordinal 同时只允许一个 singlecast lease，stale token 与重复绑定失败关闭；
- 修复 schema 20 selection/package hash 的身份域隔离，并保留旧 descriptor 的 `void` 兼容行为。

## 生命周期语义

1. `Prepare` 只发布 singlecast catalog，不自动占用属性；
2. C# 调用生成的 `BindX(source)` 后，Session 创建 bridge、保存旧值并取得租约；
3. `AvidSubscription.Cancel()`、reload 或 teardown 释放租约；
4. 若属性仍指向 bridge，恢复旧 Delegate；若已被外部覆盖，保留外部值；
5. Guest trap 或不完整输出事务不会提交部分 `return/ref/out` 值。
