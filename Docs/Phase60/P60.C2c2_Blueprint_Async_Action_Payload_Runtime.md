# P60.C2c2 Blueprint Async Action Payload Runtime

## 目标

把 C2c1 生成的 typed result 接入真实 Delegate 广播参数帧和 continuation result slot，同时保持
Reflection 生成、Session 生命周期与 ObjectHandle 安全边界，不为具体 AsyncAction 手写 wrapper。

## 已实现

- Bindings 在 package load 时为每个 outcome 构建不可变 payload encoder；
- encoder 复用 prepared value codec，校验 delegate 参数与 `<Outcome>_<Parameter>` 字段的类型和 offset；
- Session 在首个 Delegate 广播期间捕获临时参数帧，随后立即解除全部 outcome 订阅；
- scalar、enum、`FVector/FRotator/FTransform` 和固定 `USTRUCT` 保存为 fixed wire；
- 顶层 UObject/interface 参数由强引用保留到 Guest 消费结果，再借用为 generational ObjectHandle；
- composite result codec 按 descriptor field offset 写入线性内存，未命中的 outcome 字段保持零值；
- encoder 构建、参数捕获、字段类型或对象类型任一失配都会失败关闭，不暴露原始 `UObject*`；
- 无参 outcome 继续使用原有 enum ABI，保持 schema 23 兼容。

## 生命周期

prepared package 持有只读 encoder，Session entry 持有 action、delegate bridge 和对应 encoder。首广播完成
参数捕获后，Session 先释放 action producer，再把 payload 留在 continuation result slot。取消、teardown、
过期 lane 和晚到广播均不会再次捕获或恢复 Guest。

## 当前边界

- 本小节验证的是 Reflection encoder、Session 捕获和统一 result codec 基础设施；
- C# Guest 对 typed result 的真实 `await/GetResult` 端到端、reload 与 Blueprint reinstance 压力路径归入
  C2c3；
- `FString/FName/FText`、容器和嵌套 UObject 字段仍失败关闭，不在本次支持范围内。

## 验证

- UE5.8 `AvidTPSTemplateEditor Win64 Development` no-clean UBT：通过；
- `AvidScript.Runtime.Continuation.BlueprintAsyncAction`：`1/1 Success`，覆盖广播帧参数捕获；
- `AvidScript.Editor.BindingRuntime.BlueprintAsyncAction*`：`2/2 Success`，覆盖无参回归和真实生成的
  `int32 + UObject` payload encoder；
- 测试同时检查 discriminator、标量字节、对象强引用、首广播获胜和结果槽消费。

## 过程修正

- 首次 Automation 错误启用了当前未构建的可选 `AvidScriptPerfHarness`，测试未发现即退出，该轮不计入
  证据；功能聚焦模板不再无条件启用性能插件。
- 首版对象夹具误实例化 UE5.8 的抽象 `UObject`，触发 ensure；已改用插件内具体 `UCLASS`，并将规则
  写入 Harness lessons，防止复发。
