# P60.C2c1 Blueprint Async Action Payload 生成契约

## 目标

让带参数的 `BlueprintAssignable` outcome 继续走生成式 Reflection，而不是为每种 AsyncAction 编写
专用结果类型或 Runtime wrapper。本小节冻结 descriptor 与 C# facade，实际 Runtime 捕获归入 C2c2。

## 已实现

- outcome delegate 可携带 `value/const_ref` 参数；
- 多个 outcome 合成为一个确定性 `struct_wire` result，首字段固定为 `Outcome` discriminator；
- 参数字段按 `<Outcome>_<Parameter>` 命名，解决不同 outcome 同名参数冲突；
- wire offset、alignment、size、child type id 全部进入既有 type graph 与 package hash；
- 当前接受 scalar、enum、`FVector/FRotator/FTransform`、固定 `USTRUCT` 和顶层 UObject handle；
- 不支持的 payload 类型以 `async_action_outcome_payload_type_unsupported` 失败关闭；
- C# facade 自动生成 `AvidOutcomeAwaitable<TResult>`，`TResult` 是显式布局的只读结构；
- type-graph 诊断现在会报告具体 stable type、field、实际/期望 offset，避免只返回笼统
  `types.fields`。

## 设计说明

结果结构采用带 discriminator 的平坦聚合，而不是隐式 union。未命中的 outcome 字段保持零值；调用方先检查
`Outcome`，再读取对应前缀字段。该布局简单、确定、可被 WASM 线性内存直接消费，也为后续生成更友好的
discriminated-result 语法糖保留空间。

现有 schema 23 已能表达 enum、`struct_wire` 和 child type graph，因此没有为了这一能力制造 schema 24；
package hash 会完整覆盖新布局，旧无参 outcome 仍保持原 enum payload。

## 验证

- UE5.8 `AvidTPSTemplateEditor Win64 Development` no-clean UBT：通过；
- `AvidScript.Editor.BindingDescriptor.BlueprintAsyncActionPayloadSchema23`：`1/1 Success`；
- fixture 覆盖两个 outcome、`int32`、UObject handle、确定性 field namespace、严格递增 wire offset、
  discriminator enum 与生成式 C# awaitable。

## 下一步

C2c2 在 Bindings 构建 immutable payload encoder，由 Session 在首个 delegate 广播时捕获参数并写入统一
continuation result slot；之后再补 C# 实际 await、reload 与 Blueprint reinstance 压力验收。
