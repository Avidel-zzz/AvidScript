# P60.B1G Architecture Gate 基线刷新

状态：已完成

## 背景

P60.B1 在 clean detached worktree 首次运行 `Build/TestPhase50Architecture.ps1 -Mode Gate` 时报告
20 类差异。使用完全相同的 checker 对上一远端基线 `b280553` 复验，也得到相同的 20 类差异；因此这些
差异不是 singlecast 实现新增，而是 P57-P60 已审阅能力长期未同步到 Phase 50 strict allowlist。

## 刷新内容

- static host catalog 从旧 20 项更新为当前 48 项精确 multiset，并继续验证 enum 稠密顺序；
- C# renderer DllImport 从宽泛 `EntryPoint` token 计数改为只统计 `DllImport` literal，登记当前 40 项
  精确 multiset；
- 登记 continuation、value container、subscription 等生成 wrapper 与 `avid_value_*` 基础 ABI；
- `avid_on_delegate_` 作为 stable-id 派生的 Guest export 前缀登记，不把它误判为逐 API host import；
- 把 `AvidScriptBindingObjectCompatibility.h` 加入注册输入，Interface-aware UObject 类型兼容 helper 的
  `CLASS_Interface / ImplementsInterface / IsA` 三分支进入闭包与调用 allowlist；
- 根据 `-Mode Hashes` 输出更新 renderer、默认值 formatter 与 ObjectRegistry 的 canonical token hash。

## 不变量

- 未删除 bespoke import、wrapper、path lookup、helper call 与 parser completeness 检查；
- allowlist 仍按大小写精确匹配并校验 multiset 数量；
- frozen hash 仍覆盖 renderer 全源、关键函数、默认值 formatter、ObjectRegistry 和诊断叶；
- Gate 仍要求 registered input、checker 与被验证 commit 构成 clean committed tree。

## 验证计划

1. `-Mode Fixtures` 验证 checker 自身的正负夹具；
2. 工作树 `-Mode Gate` 只允许剩余 clean-tree 拒绝；
3. 提交后在 detached worktree 运行 `-Mode Gate`，记录 commit、tree、checker SHA 与 registered input 数；
4. 安全移除临时 worktree，推送并核对远端 SHA。
