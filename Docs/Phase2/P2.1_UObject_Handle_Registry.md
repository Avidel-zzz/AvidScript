# P2.1 UObject Handle Registry

日期: 2026-07-01
状态: Done
范围: UObject handle ABI / generation-counted registry / weak UObject invalidation

## 1. 目标

P2.1 的目标是为 AvidScript 建立第一层 UE binding 安全边界: guest 只能看到 host-owned handle, 不能看到 raw `UObject*` 或 pointer-sized 地址。

本小组只实现纯 C++/UE registry, 暂不接入 WASM import 或 Actor host API。P2.2 会复用本 registry 继续实现 Actor location read/write binding。

## 2. 实现内容

新增 `FAvidScriptObjectHandle`:

```c++
struct FAvidScriptObjectHandle
{
    uint32 Slot;
    uint32 Generation;
};
```

规则:

- `Slot == 0` 或 `Generation == 0` 是 invalid handle。
- `ToUInt64()` 只编码 slot/generation, 不暴露 raw `UObject*`。
- handle 由 host registry 分配, guest 不拥有 UObject lifetime。

新增 `FAvidScriptObjectHandleResult`:

| 字段 | 含义 |
| --- | --- |
| `bSucceeded` | 本次注册、解析或释放是否成功。 |
| `Handle` | 对应 handle。 |
| `ObjectPath` | 成功或失败路径中可用于日志的 UObject path。 |
| `ErrorCategory` | 结构化失败分类。 |
| `NextAction` | host/guest 后续处理建议。 |
| `ErrorMessage` | 可直接写 UE log 的完整错误信息。 |

新增 `FAvidScriptObjectRegistry`:

| API | 行为 |
| --- | --- |
| `RegisterObject(UObject*, Result)` | 注册 live UObject, 返回 slot/generation handle。 |
| `ResolveObject(Handle, Result)` | 校验 handle、slot、generation、occupied 状态和 weak object 有效性。 |
| `ResolveObject<T>(Handle, Result)` | 在基础解析成功后执行 UE `Cast<T>` 类型校验。 |
| `ReleaseHandle(Handle, Result)` | 释放 slot、清理 weak pointer、递增 generation、加入 freelist。 |
| `Reset()` | 清空 registry 并推进 generation domain, 阻止旧 handle 跨 reset 生效。 |

失败分类:

| 分类 | 触发条件 |
| --- | --- |
| `invalid_object` | 注册空/无效 UObject, 或 weak object 已被 GC/销毁。 |
| `invalid_handle` | slot/generation 为 0, 或 slot 不在 active registry 中。 |
| `generation_mismatch` | 旧 generation 访问已复用 slot 或 reset 后 registry。 |
| `stale_handle` | 访问已经 release 但尚未复用的 slot。 |
| `type_mismatch` | `ResolveObject<T>` 请求类型与注册对象类型不匹配。 |

## 3. 测试覆盖

新增 automation suite:

```text
AvidScript.Binding.ObjectRegistry
```

测试用例:

| 测试 | 覆盖点 |
| --- | --- |
| `HandleSmoke` | live UObject 注册成功; handle 有效; handle 编码不是 raw pointer; lookup 返回原对象。 |
| `GenerationSmoke` | release 后 slot 复用; generation 改变; old handle 返回 `generation_mismatch`; new handle 可解析。 |
| `InvalidationSmoke` | UObject 被 GC 后 weak handle fail closed, 返回 `invalid_object`。 |
| `ResetAndTypeSmoke` | reset 推进 generation domain; reset 前 handle 失效; wrong typed lookup 返回 `type_mismatch`。 |

测试文件中新增 `UAvidScriptObjectRegistryTestObject`, 避免直接实例化 UE 抽象基类 `UObject`。

## 6. 当前结论

P2.1 已完成 AvidScript UObject handle ABI 的第一层 host-side 安全模型:

1. guest-facing handle 不暴露 raw pointer。
2. slot/generation 可以识别 release 后复用和 reset 后旧 handle。
3. UObject lifetime 由 `TWeakObjectPtr` 观察, GC 后 fail closed。
4. 所有失败路径都有结构化错误分类与 next action。
5. Phase 1 runtime smoke 回归通过。

## 7. 未覆盖项与下一步

P2.1 不覆盖以下内容:

- WASM import ABI 中的 handle 参数编码。
- Actor/Component binding API。
- 多 world registry ownership。
- 跨 reload 的 handle 迁移策略。
- 网络 authority / replication policy。

下一步进入 P2.2: 最小 Actor host binding API, 复用 `FAvidScriptObjectRegistry` 实现 Actor location read/write smoke。
