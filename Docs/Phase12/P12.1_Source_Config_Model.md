# P12.1 Source Config Model

日期: 2026-07-05
状态: Done

## 范围

P12.1 新增可测试的 source selection/config model, 让 Editor 侧可以对任意 `.avid` source 构建 launch config, 不再只能依赖 Phase 11 的固定 sample path。

本组仍不做文件选择 UI、Project Settings、Message Log 或 watcher; 只提供后续 UI/菜单/命令可复用的 service API。

## 变更

- 新增 `FAvidScriptEditorSourceConfigRequest`:
  - `SourcePath`
  - `BindingsPath`
  - `OutputRoot`
  - `ReportPath`
- 新增 `FAvidScriptEditorSourceConfigResult`:
  - success/error category/message/next action
  - normalized source path
  - source id
  - `FAvidScriptEditorCommandLaunchConfig`
- 新增 `FAvidScriptEditorSourceConfigService::BuildLaunchConfig`。
- 支持 fail-closed validation:
  - empty source -> `source_empty`
  - non-`.avid` source -> `source_not_avid`
  - missing source -> `source_missing`
  - plugin base dir missing -> `plugin_missing`
- 支持默认路径:
  - bindings: `Bindings/ActorHostBindings.avidscript.json`
  - output: `Saved/AvidScriptGenerated/<source_id>`
  - report: `Saved/AvidScriptReports/<source_id>.frontend.report.json`
- 支持 custom bindings/output/report override 并归一化路径。

## 工作流防错

P12.1 再次确认 `AvidScriptEditor` 新增 `.cpp` 时需要留意 UBT source-list cache:

- 新增测试 `.cpp` 后, 普通 module build 可能显示 `Target is up to date`。
- 用 `-NoUBTMakefiles -Module=AvidScriptEditor` 可触发 source rescan 并看到 expected RED。
- 若测试 `.cpp` 和实现 `.cpp` 分两步加入, GREEN 前也要确认 generated unity file 同时包含两者。
- 这不是执行 `Build.bat -Clean` 的理由。
