## 范围

## 已完成能力

- 任意 `.avid` source 可通过 `FAvidScriptEditorSourceConfigService` 构建 launch config。
- Toolchain/output/report roots 可通过 `FAvidScriptEditorSettingsService` 应用到 launch config。
- `FAvidScriptEditorModule::MakeCommandConfigForSource` 已让 sample command 复用 generic source+settings helper。
- `FAvidScriptEditorResultPresenter` 已把 command result 映射为 `severity/title/body/details/source/manifest` 展示模型。
- Editor sample command 已改为使用 presentation model 写日志。
