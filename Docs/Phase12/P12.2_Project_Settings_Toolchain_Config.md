# P12.2 Project Settings Toolchain Config

日期: 2026-07-05
状态: Done

## 范围

P12.2 新增 toolchain/settings 配置模型, 将 LDC/toolchain/output/report root override 应用到 P12.1 生成的 launch config。当前仍不做真实 Project Settings UI 或配置文件持久化, 先提供可测试的 service API 和 module generic helper。

## 变更

- 新增 `FAvidScriptEditorToolchainSettings`:
  - `Ldc2Path`
  - `ToolchainRoot`
  - `OutputRoot`
  - `ReportRoot`
- 新增 `FAvidScriptEditorSettingsService::ApplySettings`:
  - 空 settings 不改变 launch config。
  - 非空 `Ldc2Path` / `ToolchainRoot` 会归一化后写入 launch config。
  - 非空 `OutputRoot` 会生成 `<OutputRoot>/<source_id>`。
  - 非空 `ReportRoot` 会生成 `<ReportRoot>/<source_id>.frontend.report.json`。
- `FAvidScriptEditorModule` 新增 `MakeCommandConfigForSource(SourcePath, Settings, OutConfig, OutErrorMessage)`。
- `MakeSampleCommandConfig` 改为复用 generic source+settings helper, sample command 行为保持兼容。
