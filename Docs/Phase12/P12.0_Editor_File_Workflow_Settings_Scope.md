# P12.0 Editor File Workflow And Settings Scope

日期: 2026-07-05
状态: Done

## 1. 阶段目标

Phase 12 目标是把 Phase 11 的固定 sample command 推进为可复用的 Editor 文件工作流基础设施。第一版仍保持 service-first, 重点是 source selection/config model、toolchain settings 读取层和 result presentation adapter, 不做完整 Slate 面板。

## 2. 小组拆分

| 小组 | 目标 | 状态 |
| --- | --- | --- |
| P12.0 | scope、spec、plan、tracker/log | Done |
| P12.1 | source selection config model | Planned |
| P12.2 | project settings/toolchain config | Planned |
| P12.3 | result presentation adapter | Planned |
| P12.4 | closeout | Planned |

## 3. 范围

- 允许 Editor command 对任意 `.avid` source 构建 launch config, 而不是只能运行 `actor_set_location.avid` sample。
- 将 source validation、默认 bindings/output/report 路径生成封装为可测试服务。
- 增加 toolchain/settings 配置模型, 让 LDC/toolchain 路径、output/report root 可由配置层传入 launcher。
- 增加 result presentation adapter, 把 command result 转为 UI/日志可消费的 severity/title/body/details。
- 继续复用 P9-P11 的 frontend invoker、report reader、compile gate、reload service 和 command launcher。

## 4. 非目标

- 不做完整 Slate/UMG 面板。
- 不做 Content Browser asset 类型或 `.avid` uasset 封装。
- 不做 file watcher 或 IDE 插件。
- 不恢复 packaging 验证。
- 不做 Android/iOS 设备验证。
- 不改 runtime ABI、manifest schema 或 `.avid` 语法。

## 5. 验收标准

- `AvidScriptEditor` module build 通过。
- 新增 P12.1/P12.2/P12.3 automation 覆盖正向和 fail-closed 路径。
- 完整 `AvidScript.Editor` automation 通过。
- P12.4 完整 `AvidScript` automation 通过。
- 文档同步 root tracker/log 和 plugin Phase12 docs。
