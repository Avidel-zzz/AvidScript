# P12.3 Result Presentation Adapter

日期: 2026-07-05
状态: Done

## 范围

P12.3 新增 Editor command result presentation adapter, 将 `FAvidScriptEditorCommandLaunchResult` 统一映射为 Editor UI/日志可消费的展示模型。当前仍不做 Message Log、notification 或 Slate panel, 只提供后续 UI 可复用的 severity/title/body/details 数据层。

## 变更

- 新增 `EAvidScriptEditorPresentationSeverity`:
  - `Info`
  - `Warning`
  - `Error`
- 新增 `FAvidScriptEditorCommandPresentation`:
  - `Severity`
  - `Title`
  - `Body`
  - `Details`
  - `SourcePath`
  - `ManifestPath`
- 新增 `FAvidScriptEditorResultPresenter::MakePresentation`。
- 展示规则:
  - command failure -> `Error`, title/body/details 包含 error category、message 和 next action。
  - generated-only -> `Warning`, body 明确说明没有 live reload。
  - reload-applied -> `Info`, body 包含 module/source 信息。
- `FAvidScriptEditorModule::HandleRunSampleCommand` 改为使用 presentation model 写日志, 不再直接只输出 raw summary。
