# P27.0 Typed Read 与 FVector 表达式范围

状态: Done

## 目标

Phase27 将 Phase26 的类型化 Actor 写入扩展为位置读改写闭环：

```csharp
FVector currentLocation = UE.Self.GetActorLocation();
UE.Self.SetActorLocation(
    currentLocation + new FVector(120.0f * deltaSeconds, 0.0f, 0.0f));
```

## 本阶段范围

- 为 `AActor` 增加返回 `FVector` 的 `GetActorLocation()`。
- 复用 `env.actor_get_location(slot, generation, out_ptr) -> i32`。
- source adapter 支持局部 `FVector`、向量加法和 typed Actor 调用。
- 使用 WASM 线性内存传递三个连续 `f32`，不向 guest 暴露宿主指针。
- 保持 `BeginPlay`、`Tick`、`EndPlay`、旧 `Actor.*` facade 和非 slot 1 owner 行为兼容。

## 非目标

- 完整 C# 编译器语义、任意局部变量、分支、循环和集合。
- `FRotator`、`FTransform`、组件、Spawn、输入、Timer、碰撞事件和反射调用。
- 移动端打包验证。
