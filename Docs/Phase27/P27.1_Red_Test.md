## 先行契约

测试和默认 C# 样例先要求：

- `AActor.GetActorLocation()` 与 `Native.ActorGetLocation(...)`。
- `FVector currentLocation = UE.Self.GetActorLocation();`。
- `currentLocation + new FVector(...)`。
- manifest subset 升级为 `actor_lifecycle_v6`。
- required imports 包含 `env.actor_get_location`。

## RED 证据

旧 adapter 无法解析局部 `FVector`，转入 .NET/WASI fallback；fallback 编译同时因 `FVector` 尚无 `operator +` 报出 `CS0019`，最终结果为 `direct_abi_unsupported`。

这证明失败来自 Phase27 尚未实现的 typed read/vector expression 能力，而不是既有 runtime 或测试环境。
