# P27.2 Adapter v6 Typed Read 实现

状态: Done

## C# projection

- `FVector` 增加 `operator +`。
- `AActor.GetActorLocation()` 通过 handle-backed native import 返回 `FVector`。
- 默认 Tick 先读取当前位置，再加上基于 `deltaSeconds` 的位移。

## WASM ABI

adapter v6 在原四个 import 后追加：

```text
4 env.actor_get_location(i32 slot, i32 generation, i32 out_ptr) -> i32
```

生命周期函数索引移动到 5/6/7。module 声明一页线性内存，地址 16 作为 12 字节 `FVector` scratch 区；宿主完成边界验证后写入 X/Y/Z，guest 使用三个 `f32.load` 读入 WASM locals。

## 表达式映射

- 一个局部 `FVector` 映射为三个 `f32` locals。
- Tick 的 `deltaSeconds` 保持 local 0，向量 locals 从 local 1 开始。
- `local + new FVector(...)` 按分量生成 `f32.add`。
- typed Actor 读写继续使用 `owner_get_slot` / `owner_get_generation`，不硬编码 slot/generation。

## 安全边界

- guest 只接触自己的线性内存地址，不接触 `UObject*` 或宿主地址。
- owner handle 和 generation 仍由 object registry 验证。
- host import 失败继续以确定性错误终止当前 guest 调用。
