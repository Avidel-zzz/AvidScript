## 阶段结论

Phase27 已完成首个类型化 UE 值返回闭环：

```text
C# UE.Self.GetActorLocation()
  -> owner slot/generation
  -> WASM actor_get_location import
  -> UE AActor location
  -> guest linear memory
  -> local FVector + FVector expression
  -> SetActorLocation
```
