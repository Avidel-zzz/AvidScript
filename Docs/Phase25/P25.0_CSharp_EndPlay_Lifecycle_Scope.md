# P25.0 C# EndPlay 生命周期范围

## 目标

Phase25 将 C# 脚本生命周期从 BeginPlay/Tick 扩展到 BeginPlay/Tick/EndPlay。这个阶段的重点是 UE 事件流程闭环: Actor 绑定到 `UAvidScriptComponent` 后, 脚本不仅能在开始和帧更新时执行业务逻辑, 也能在 EndPlay 时执行清理或最终状态逻辑。

## 本阶段支持

- C# 样例导出 `avid_on_end_play`。
- C# source adapter 生成 `actor_lifecycle_v4` direct ABI WASM。
- manifest/report `required_exports` 包含 `avid_on_end_play`。
- runtime 可调用 guest EndPlay, 并记录 `EndPlayCallMs` / `bEndPlayCalled`。
- reload session 暴露 `EndPlayLive` 供自动化和后续工作流复用。
- `UAvidScriptComponent::EndPlay` 在卸载 WASM 前通知 guest EndPlay。
- 旧 WASM 缺少 `avid_on_end_play` 时, runtime EndPlay 兼容为成功 no-op。

## 本阶段不支持

- UE overlap/input/delegate 事件。
- 多对象实例化脚本模型。
- 移动端和打包验证。
- 完整 C# 编译器或任意 C# 语法。

## 验收方式

默认 C# 样例的 `EndPlay()` 会调用 `Actor.SetLocation(0.0f, 0.0f, 0.0f)`。自动化测试通过 reload session 和 `UAvidScriptComponent` 两条路径验证 EndPlay 后 Actor 位置归零, 从而证明 guest 代码确实接入了 UE 生命周期。
