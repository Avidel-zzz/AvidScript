# P31.2 反射 Schema 与契约校验

状态：Done

实现提交：`14c8588`

## 已实现

- Editor 阶段读取 UE5.8 `UClass`、`UFunction`、`FProperty` 元数据。
- 以固定 allowlist 生成稳定排序的 JSON Schema。
- 记录 UE owner、函数名、脚本名、Host import、WASM ABI、投影策略、返回类型和参数信息。
- 首批覆盖 Actor、SceneComponent、FVector、FRotator、FTransform、USceneComponent。
- 支持 UTF-8 临时文件加原子替换写入。
- 读取真实 C# guest manifest，并验证 12 个 `required_imports` 全部属于生成契约。

## Fail-closed 诊断

- `class_missing`
- `function_missing`
- `unsupported_property`
- `duplicate_import`
- `manifest_read_failed`
- `manifest_invalid`
- `binding_contract_mismatch`
- `serialize_failed` / `write_failed`

运行时仍使用静态 WAMR native imports。UE 反射只存在于 Editor 生成与校验阶段，不进入 BeginPlay/Tick 高频调用路径。
