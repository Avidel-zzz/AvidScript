# P31.0 反射绑定 Schema 范围

状态：Done

Phase 31 在 Editor 生成阶段读取 UE5.8 的 UClass、UFunction 和 FProperty 元数据，生成 AvidScript 静态 binding schema。

该 schema 记录当前 C# gameplay API 的 UE 来源、脚本名、Host import、WASM 签名与完整反射参数。运行时继续使用静态 native imports，不在 Tick 中查询反射。

本阶段只覆盖明确 allowlist，不开放任意 UFunction，也不自动生成全部 wrapper C++。
