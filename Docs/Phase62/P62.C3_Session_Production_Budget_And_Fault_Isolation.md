# P62.C3 Session 生产预算与故障隔离

## 结果

本小节把 P62.C2 的 VM 执行预算接入 Runtime Session，并补齐所有已知 live guest 入口的故障收敛路径。
预算仍由 Session 决策，Runtime 只转交后端，因此游戏层不依赖 Wasmtime 类型。

## 已实现

- Wasmtime Session 默认对每次最外层入口配置 5000 万 fuel、1 个 epoch deadline、64 MiB 线性内存和 10 万次 host call；
- WAMR Session 只启用已验证的 10 万次 host-call 上限，不伪装支持 fuel、epoch 或 Store limiter；
- Runtime 在 VM load 前冻结预算，直接创建的低层 Runtime 默认仍为无预算，兼容测试与工具调用；
- 旧 `Tick`、`TickLive/TickHot`、event、gameplay event、delegate、continuation、debug resume、`EndPlay` 与 Generated Type prepared export 的 VM 故障统一进入 Session quarantine；
- quarantine 只调用 `StopAndUnload` 做逆序清理，不会再次进入已 faulted Guest；
- Session snapshot 暴露根故障次数、失败 export、重复入口拒绝次数和被抑制诊断次数；
- VM 错误消息限制为 4096 字符，details 限制为 2048 字符，调用栈限制为 32 帧，单帧文本限制为 512 字符；
- 同一 fault latch 的后续入口返回 `session_faulted`，但不重复写根故障日志。

## 验证

- UE5.8 `AvidTPSTemplateEditor Win64 Development` no-clean UBT：成功，16 个增量 action；
- `AvidScript.Runtime.Diagnostics.ManifestRuntimeIntegration`：`1/1` Success，覆盖旧 Tick quarantine、根故障指标、重复诊断抑制和健康 peer Session；
- `AvidScript.Runtime.GeneratedTypes.SessionPreparedDispatch`：`1/1` Success，覆盖 Wasmtime prepared export trap、路由清理、Runtime 卸载和重复调用拒绝；
- 两轮 Automation 均为 Queue Empty、TestExit、状态 0。
