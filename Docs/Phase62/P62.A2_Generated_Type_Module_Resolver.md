# P62.A2 Generated Type 公共模块解析

## 已实现

- Generated Type Cook pointer 升级为 schema v2，只保存类型清单、逻辑 `module_id` 与期望 `package_id`；
- Runtime WASM、预编译 artifact 与 binding package 由通用 module release publisher 发布，不再复制第二套 bundle；
- Runtime Host 通过 `LoadPublishedModule` 校验 package drift 并加载，与普通 Component 共享 resolver 和 trust；
- v1 pointer 只保留为 Editor/旧内容兼容路径，非 Editor target 强制使用 v2；
- v2 Generated Type bundle 只包含 `type-manifest.json`，pointer 与类型清单使用 UFS staging。

## 验证

| 项目 | 结果 |
| --- | --- |
| PowerShell 合同 | 7/7 通过，覆盖确定性、v2、catalog、package drift、missing module、路径逃逸与 hash 篡改 |
| UE5.8 no-clean UBT | Runtime 与 Generated 集中构建通过 |
| Cooked package Automation | `AvidScript.GeneratedTypes.CookedPackageLoad` 1/1 通过 |

由此，Generated Type 与普通 C# gameplay module 已收敛到同一发布、解析和 artifact trust 链。
