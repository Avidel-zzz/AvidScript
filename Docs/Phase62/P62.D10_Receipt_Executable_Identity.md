# P62.D10 回执可执行文件身份

## 问题

旧的 stale receipt 复用规则按 TargetName 手工拼接 `TargetName.exe`。UE Shipping 的真实
输出名为 `TargetName-Win64-Shipping.exe`，即使 UAT 明确报告该输出，规则仍会错误拒绝。

## 实现

- 从已按 TargetName、Platform、Configuration、TargetType 精确选中的 `.target` 回执读取
  `BuildProducts`。
- 只接受唯一 `Type=Executable` 项，并要求使用 `$(ProjectDir)/` 宏。
- 展开后要求路径位于 ProjectRoot、扩展名为 `.exe` 且文件真实存在。
- UAT 日志必须包含该完整绝对路径的 `Output binary:` 证据，才允许复用旧时间戳回执。

该规则不再依赖 Development/Shipping 命名约定，同时继续拒绝缺失、歧义、越界或不存在
的可执行文件身份。
