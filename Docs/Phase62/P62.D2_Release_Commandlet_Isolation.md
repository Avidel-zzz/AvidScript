# P62.D2 Release Commandlet 隔离

## 问题

无头 C# Release 在生成新的 Generated Type manifest 后，会启动 UE5.8 Release Commandlet。
若工作区仍保留上一轮 Editor package 描述符，模块启动阶段可能先加载旧描述符，并因 hash 不匹配让已经成功的发布进程返回失败。

## 实现

- Release runner 固定传入 `-AvidScriptSuppressGeneratedTypeExecution`；
- Release Commandlet 的严格开关白名单显式接收该参数，其他未知参数仍然拒绝；
- 该标志只在 `WITH_EDITOR` 且 `IsRunningCommandlet()` 时生效；
- Generated Type 模块在该模式下不安装工作区旧包；
- Runtime Host 将生成类型实例的启停处理为空操作，避免 Commandlet 临时 World 激活脚本类型；
- Cook 与打包游戏不携带该标志，正式运行和 Shipping 路径保持 fail-closed。

## 验证

- Release contract 覆盖参数、平台边界和模块/实例双层隔离；
- P62.D 的真实 Development/Shipping BuildCookRun 将继续验证发布产物和打包执行路径。
