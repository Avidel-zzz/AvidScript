# P62.B3 包回执验证器

## 目标

在打包完成后，以 UBT 生成的 `.target` 回执为准，确认 AvidScript 的脚本包、Generated Type 清单和 Wasmtime 运行库已经按预期进入最终产物。验证器只接受精确集合，避免“构建成功但运行时缺文件”或意外携带旧资源。

## 已实现

- `Build/TestAvidScriptPackageReceipt.ps1` 读取指定的 Development 或 Shipping 回执。
- 从模块目录、内容寻址包描述、Generated Type v2 指针和 Wasmtime 性能托管标记重建期望依赖集合。
- 校验每个源文件存在且 SHA-256 与发布元数据一致。
- 要求脚本内容和 Generated Type 文件使用 `UFS`，Wasmtime DLL 与许可证使用 `NonUFS`。
- 对 AvidScript 相关依赖执行精确集合比较：缺失、额外、重复或类型错误都会失败。
- 成功和失败均输出单行 JSON，便于后续 BuildCookRun 与 CI 直接消费。

## 安全边界

- 模块和 Generated Type 路径必须是规范化相对路径，不能包含根路径、`.` 或 `..`。
- 插件根必须严格位于 `<ProjectRoot>/Plugins/AvidScript`。
- JSON 拒绝重复属性；发布标识和哈希采用大小写敏感的规范格式。
- 验证器只读取现有回执与发布文件，不修改打包产物。

## 验证

`Build/Contracts/TestAvidScriptPackageReceiptContracts.ps1` 覆盖正常回执、依赖缺失、额外依赖、UFS/NonUFS 类型错误、源文件缺失、源哈希漂移、Wasmtime 托管哈希漂移和配置不匹配，共 10 项契约，当前全部通过。
