# P62.C1 Session 故障隔离

## 已实现

- Guest trap 将 Runtime 标记为 `Faulted` 后，Session 立即执行 host-side quarantine；
- quarantine 不再进入已故障 Guest，也不会调用 Guest `EndPlay`；
- Session 解绑 delegate 与 inbound handler，撤销 continuation、timer/scheduler 和 ObjectHandle 所有权；
- fault 根类别与 module identity 被保留在 Session snapshot 中；
- 后续 Tick、event、gameplay event 与 delegate 入口统一拒绝，并返回稳定 `session_faulted`；
- 成功加载新候选模块或显式 unload 会清除 quarantine latch。

## 验证

| 项目 | 结果 |
| --- | --- |
| UE5.8 no-clean UBT | `AvidScriptRuntime` 编译与链接通过 |
| Runtime diagnostics Automation | `AvidScript.Runtime.Diagnostics.ManifestRuntimeIntegration` 1/1 通过 |
| 隔离断言 | faulted Session 无活动 Runtime、无 pending timer/continuation，重复入口被拒绝 |
| peer Session | 另一健康 Session 在故障后仍可 BeginPlay 与 Tick |

本小节处理故障生命周期与资源回收；fuel、epoch、linear-memory 和 host-call budget 属于后续 P62.C 批次。
