# P62.D9 Shipping Oracle 控制面

## 问题

UE Shipping 默认启用命令行 allow-list。未由游戏 Target 全局批准的参数会在 Core 初始化时
被删除，因此 `AvidScriptPackagedOracle` 的模块 ID 与报告路径在 Shipping 中不可见。
插件不应要求接入项目为了验收器修改全局 `Target.cs`。

## 实现

- runner 在子进程 `ProcessStartInfo.Environment` 中注入模块 ID 与报告路径。
- Runtime 优先兼容原命令行入口；参数不存在时读取两个进程级环境变量。
- 环境只作用于被启动的打包进程，不修改用户或系统环境。
- 报告路径仍经过项目 `Saved` 根目录约束，外部路径会被拒绝并改写到安全位置。
- 缺失报告错误现在包含打包进程退出码，减少 Shipping 日志裁剪后的盲区。

该控制面只负责启动验收器，不改变模块解析、脚本权限或 Shipping Runtime 策略。
