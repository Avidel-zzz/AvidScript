# P62.D4 发布清单数组保真

## 问题

模块发布器会对 JSON 对象做键名排序，以得到稳定的包哈希。旧实现通过 PowerShell
管道返回规范化数组，导致空数组被折叠为 `null`，单元素数组被折叠为标量。Cook
产物中的 `state_migration.slots` 因此无法通过 Runtime 清单校验，打包游戏无法启动脚本。

## 实现

- 规范化数组改用强类型列表逐项转换。
- 使用 `Write-Output -NoEnumerate` 保留数组边界，包括空数组和单元素数组。
- 不对 JSON 文本做字符串修补，数组形状在结构化对象层保持不变。

## 契约

`TestAvidScriptModuleReleasePackage.ps1` 直接使用 `System.Text.Json.JsonDocument`
检查发布产物，覆盖：

- `state_migration.slots` 空数组；
- `required_exports` 单元素数组；
- Runtime 与 Binding 清单中的 `required_imports` 空数组。

该契约针对 JSON Token 类型断言，不会把 `null`、标量与数组误判为等价值。
