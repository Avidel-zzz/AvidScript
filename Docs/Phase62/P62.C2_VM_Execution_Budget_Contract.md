# P62.C2 VM 执行预算合同

## 结果

本小节建立了后端无关的执行预算合同，并把 Wasmtime 的资源控制能力接入统一 VM 调用路径。
预算默认关闭，只有 Runtime 或测试显式提供数值时才成为实例策略。

## 已实现

- `FAvidScriptVmLoadConfig::FExecutionBudget` 统一承载每次入口 fuel、epoch deadline、线性内存和 host-call 上限；
- VM capability 明确声明 fuel、epoch、Store limiter 与 host-call budget，调用方不依赖具体后端类型；
- Wasmtime 受控编译 profile 启用 fuel/epoch instrumentation，固定 2 MiB Wasm native stack，并把设置写入 compiler identity；
- Wasmtime Store 在实例化前配置 limiter、fuel 与 epoch deadline，普通调用和 prepared fast path 在最外层入口统一重置预算；
- static、dynamic 与全部 typed ABI family 在执行 UE target 前统一消费 host-call budget；
- trap code 稳定区分 fuel、epoch、stack、guest memory 与普通 Guest trap；
- WAMR 只声明已实现的 host-call budget，对当前构建不支持的 fuel、epoch 与 linear-memory budget 在加载阶段失败关闭。

修改 compiler identity 后，旧 `.cwasm` 不再与新 profile 混用；发布流程必须重新生成预编译产物。

## 验证

- Wasmtime performance toolchain contract：`66/66`；
- UE5.8 `AvidTPSTemplateEditor Win64 Development` no-clean UBT：成功，28 个增量 action；
- `AvidScript.VM.Wasmtime`：`13/13` Success，其中 infinite loop 由 fuel 终止，下一入口成功获得新预算，64 KiB limiter 拒绝 memory growth，prepared typed 快路径在预算耗尽后不再进入 UE target；
- `AvidScript.Architecture.VM.WamrBackendSmoke`：`1/1` Success，验证 capability 与 unsupported budget fail-closed；
- 两轮 Automation 均出现 Queue Empty、TestExit、状态 0。
