# P62.B2 C# 发布 Commandlet

## 目标

提供一个可由本地开发流程和 CI 共同调用的发布入口，把 C# 游戏脚本编译为必须预编译的 Wasmtime 模块，再交给统一发布器生成内容寻址包。入口固定使用源码版 UE5.8，避免编辑器 UI、松散 JIT 配置或人工拷贝参与正式发布。

## 已实现

- `UAvidScriptReleaseCommandlet` 严格解析源码、C# 工程、模块标识、产物名称、输出目录、dotnet 和可选 Binding 包路径。
- 所有项目输入与输出必须位于项目根内；dotnet 允许使用项目外的绝对文件路径。
- 构建配置固定为 `Release`，VM 产物策略固定为 `RequirePrecompiled`。
- 发布前验证 Runtime manifest、`wasmtime_serialized_v1` 格式、`require_precompiled` 策略和对应 `.cwasm` 文件。
- `Build/InvokeAvidScriptRelease.ps1` 固定调用 `C:\UnrealEngine` 的 UE5.8 `UnrealEditor-Cmd.exe`，先验证性能托管 Wasmtime 工具链，再调用统一模块发布器。
- 每次运行生成唯一 `-abslog`，成功输出单行 JSON；Commandlet 和发布器失败均保留稳定 category。

## 验证

- PowerShell 发布契约：5/5 通过。
- UE5.8 `AvidTPSTemplateEditor Win64 Development` 无清理增量编译通过。
- 真实 `UnrealEditor-Cmd -run=AvidScriptRelease` 烟雾测试已确认 Commandlet 可注册、可执行，并对缺失参数返回稳定的 `argument_missing`。

完整 C# 编译、内容寻址发布、Cook 和打包回执的成功闭环由 Phase 62 端到端验收批次统一执行。
