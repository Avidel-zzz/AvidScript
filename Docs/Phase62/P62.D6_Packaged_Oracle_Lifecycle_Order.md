# P62.D6 打包 Oracle 生命周期顺序

## 问题

`UWorldSubsystem::OnWorldBeginPlay` 的调用早于世界内 Actor/Component 完成 `BeginPlay`
分发。旧 oracle 在创建动态 `UAvidScriptComponent` 后立即检查 Runtime 状态，会把
“组件尚未进入 BeginPlay”误判为 `runtime_start_failed`。

## 实现

- 创建健康与故障隔离组件后，不再同步断言 Runtime 已加载。
- oracle Tick 等待两个组件完成 Runtime 启动，再且仅再派发一次初始脚本事件。
- Runtime 返回明确错误时快速失败；正常生命周期尚未到达时继续等待。
- 统一保留 5 秒超时，防止无错误但永远不进入运行态的挂起。
- oracle 停止时清理 Runtime-ready 状态，避免跨 World 泄漏。

该调整只修正发布验收器对 UE 生命周期顺序的假设，不改变生产脚本组件的
`BeginPlay/Tick/EndPlay` 行为。
