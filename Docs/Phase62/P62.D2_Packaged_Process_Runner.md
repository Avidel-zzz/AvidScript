# P62.D2 打包程序启动 Runner

## 目标

让同一个 BuildCookRun 命令在 archive 和 receipt 通过后，继续启动真实 Game executable，并把进程退出与 Runtime Oracle 合并进单行机器回执。

## 实现

- `Build/InvokeAvidScriptPackagedOracle.ps1` 只接受规范化 target/module/configuration，按 archive 固定布局选择 bootstrap executable；
- 子进程通过 `ProcessStartInfo.ArgumentList` 启动，使用独立 log/report 路径和 10–600 秒有界超时；超时只终止本次启动的进程树；
- Oracle JSON 使用严格解析，拒绝重复字段，并核对配置、模块、package resolve、BeginPlay/Tick/Event/Timer/continuation/EndPlay、故障拒绝和 World 继续运行；
- `InvokeAvidScriptBuildCookRun.ps1` 的固定顺序变为 release、UAT、receipt、packaged oracle，任一步失败都返回稳定 step/category；
- 最终 BuildCookRun JSON 同时保留 release、receipt 和 packaged process/oracle 证据路径，不依赖 Shipping 日志是否启用。

真实 Development 与 Shipping 构建、启动耗时和报告内容在 P62.D 集中 Gate 中冻结。
