# P62.D3 Game Target 兼容

## 问题

Win64 Development Game target 首次编译暴露出 Editor 构建未覆盖的条件编译问题：运行时 Binding 使用了
`WITH_METADATA` API、Blueprint 的 Editor-only 生成来源，以及仅 Editor 提供的对象重实例化委托。

## 实现

- 普通函数以函数标志和参数结构执行运行时复核，Latent 函数同时识别 `FLatentActionInfo`；
- 有 metadata 时继续复核 `Latent`、`CustomThunk`、`LatentInfo`、`WorldContext` 和 `BlueprintSetter`；
- 无 metadata 的打包目标使用已发布 Binding 描述符，并继续校验属性、Setter 函数、参数与调度策略；
- Blueprint 来源在打包目标使用 `CLASS_CompiledFromBlueprint`、生成类路径和函数字节码指纹复核；
- 对象重实例化监听只在 Editor 注册；异步 Action 的正式运行路径保持不变；
- UeTypeGenerator 只在 `WITH_METADATA` 下生成默认参数 metadata 测试。
