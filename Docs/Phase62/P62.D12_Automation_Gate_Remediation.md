# P62.D12 Automation Gate 修复

## 问题

Phase 62 首轮完整 Automation 在 429 条测试中暴露 5 个失败：生命周期测试未同步 Timer
语义、组件编译测试复用了共享缓存、Wasmtime trap 分类仍按 WAMR 断言，以及 Development
发布包错误继承了 `require_precompiled` 策略。

## 修复

- 生命周期断言按真实调度顺序验证：`Tick` 后执行 Runtime Timer；Continuation 由 UE World
  帧推进，不在该 helper 中提前完成。
- ComponentGameplay 使用测试专属 Compilation Cache，调用次数不再受其他测试污染。
- Wasmtime 保留 `guest_trap`，WAMR 保留 `trap`，不降低诊断精度。
- 发布配置成为最终执行策略所有者：Development 发布为
  `prefer_precompiled + attestation_id + wasmtime_jit fallback`，Shipping 仍强制
  `require_precompiled` 并剥离进程证明与回退字段。

## 证据

- Module Release PowerShell contract：`15/15 passed`。
- UE5.8 `AvidTPSTemplateEditor Win64 Development` 无清理增量编译通过。
- 正式 Headless Development 发布生成 package
  `b5240c271ada4d219575c102773c23d4cddf2cd1e61b4094c0578547439e350d`，新 Editor
  进程可按 Development trust contract 加载。
- 完整 `AvidScript` Automation：原 5 项中 3 项转绿，结果 `427/429`；剩余两项修正后，
  `AvidScript.Editor.BindingRuntime.GeneratedCSharp` 聚焦复验 `2/2 Success`。

最终 429 条集中复验与 Phase Gate 仍在 P62.D 收尾中，本记录不提前宣称 Phase 62 关闭。
