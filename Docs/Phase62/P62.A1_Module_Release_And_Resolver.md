# P62.A1 模块发布与逻辑解析

## 目标

将脚本入口从开发期的松散文件路径升级为稳定的逻辑 `ModuleId`，并建立发布工具与 Runtime
共同遵守的内容寻址模块包合同。该批次只建立发布和解析基础，不把尚未完成的 Shipping 信任链
标记为可用。

## 已实现

- `Build/AvidScriptModuleReleasePackage.ps1` 原子发布模块包与有序 `catalog.json`；catalog 是单一 target configuration 的完整视图，切换 Development/Shipping 时剔除不兼容条目；
- package identity 由 ABI、平台、配置、Wasmtime 编译身份、CPU profile 和全部 artifact hash
  确定性计算；
- Shipping 发布强制 `require_precompiled`，并剥离 debug map、源码、Guest IR 与临时 attestation；
- Runtime resolver 严格校验 JSON shape、路径边界、文件集合、SHA-256、ABI、平台、最低运行时版本
  以及 runtime/binding manifest 的交叉一致性；
- `UAvidScriptComponent` 支持配置逻辑 `ModuleId`，开发环境继续保留松散 manifest 兼容路径；
- Shipping 配置拒绝松散 manifest 和隐式 smoke fallback，缺失模块时明确失败。
