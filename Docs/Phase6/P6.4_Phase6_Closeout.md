## 5. 剩余风险

- DSL parser 仍是 PowerShell prototype, 语法很窄。
- binding 表只有 `actor_set_location`。
- 还没有正式 type checker、诊断位置、source map 或 IDE 集成。
- Editor watcher/UI 未做。
- Android/iOS 和 packaging 继续 deferred。
- manifest 仍依赖当前 LDC 的 `env` import module 兼容别名。

## 6. 下一阶段建议

Phase 7 建议进入 typed binding generator and frontend diagnostics:

```text
binding declaration -> generated import stubs -> richer .avid calls -> diagnostics with source span -> reload workflow command
```

优先扩展方向:

- 将 host binding 白名单从脚本内硬编码移动到 manifest/binding declaration。
- 给 parser 增加行列号和稳定错误码。
- 支持变量声明和简单表达式, 但仍保持 fail closed。
- 建立 Editor command 或 watcher, 从 `.avid` 变更自动触发 build + reload。
