# P6.0 Language Frontend And Binding Generator Scope

日期: 2026-07-05
状态: Done

## 1. 目标

Phase 6 开始把 AvidScript 从“D guest 工具链验证”推进到“自有脚本语言入口”。本阶段的 MVP 链路是:

```text
.avid source -> generated D -> LDC wasm + manifest -> UE manifest loader -> reload session -> Actor Host ABI
```

P6 成功后, 项目可以说“已经有一个最小 AvidScript 源文件能编译成 WASM 并驱动 UE Actor”, 而不是只依赖手写 D guest。

## 2. 设计选择

采用 `.avid` DSL 生成 D 的路线。

理由:

- 复用 P5.2 已验证的 LDC、manifest、WAMR、reload 和 host context。
- 最快形成自有语言端到端证据。
- 保持 WASM-first 和 PC Editor first。
- 后续可以逐步把 parser/type checker/codegen 从 PowerShell prototype 迁移到正式 compiler。

## 3. 最小语言

首个支持语法:

```text
module actor_set_location

use actor_set_location

on begin_play {
    actor_set_location(1, 1, 123.0, 456.0, 789.0)
}

on tick(delta_seconds) {
}
```

约束:

- 只支持一个 module。
- 只支持 `use actor_set_location`。
- 只支持 `on begin_play` 中一次 `actor_set_location` 调用。
- 只支持空 `on tick(delta_seconds)`。
- 参数只支持 literal, 不支持变量、表达式、条件、循环或任意 UObject API。

## 5. 非目标

- 不实现完整 type checker。
- 不实现 Editor watcher/UI。
- 不生成 Blueprint/Reflection 绑定。
- 不扩大 Host API 到任意 UObject 方法。
- 不做 Android/iOS device smoke。
- 不恢复 packaging/cook/stage/pak。
