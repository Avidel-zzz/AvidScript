# P43.1 选择 Profile 与兼容性报告实施计划

> **执行要求：** 使用 `superpowers:executing-plans` 按任务推进。每个任务完成后更新复选框，并在源码版 UE5.8 上增量验证。

**目标：** 用声明式类边界批量发现可绑定 UFunction，输出确定性选择与兼容性报告，并复用现有 descriptor v2 生成链路。

**架构：** Selection Types 是无反射逻辑的数据契约；Function Policy 只判断 UFunction 资格；Selection Resolver 负责发现、过滤和类型策略验证；Descriptor Generator 只消费解析后的精确选择。

**技术栈：** UE5.8 C++、UClass/UFunction Reflection、Automation Tests、现有 descriptor v2 与 C# Binding Package。

## 全局约束

- 使用源码版 UE5.8，目录固定为 `C:\UnrealEngine`。
- 只运行现有 UBT DLL 的低并发增量构建，禁止清理 Editor Target。
- 不新增按 UE API 手写的运行时桥接。
- 兼容性报告必须确定性排序并使用稳定错误类别。
- 给人阅读的文档使用中文。
- 不修改或提交用户现有的 `Docs/CSharpGameplayAuthoring.md` 与 `Docs/Phase42/P42.0_Reflection_Binding_Generator_Architecture.md` 改动。
