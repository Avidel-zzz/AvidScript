# P43.5 内容寻址 Semantic Cache 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 建立项目级不可变 C# Semantic Cache，使相同语义输入的自动 custom 热构建达到 `Build=2 / Frontend=0 / Semantic=0`，并让 Editor 从结构化 report 读取真实工具调用次数。

**架构：** `AvidScriptCSharpSemanticCache.ps1` 只拥有 cache key、工具链指纹、不可变 entry 查找/发布和损坏隔离；`BuildCSharpActorLifecycle.ps1` 仍拥有构建编排与 package 策略；P43.4 prepared helper 继续作为命中条目的 provenance 与双文件发布 gate。Build report 成为调用次数和缓存状态的唯一事实来源，C++ Invoker 只读取并透传，不推断。

**技术栈：** Windows PowerShell 5.1、.NET 8.0.416、Roslyn Frontend/Semantic JSON、SHA-256、UE5.8 C++ Editor automation、WAMR。

## 全局约束

- 使用 `C:\UnrealEngine` 源码版 UE5.8，仅做增量构建，禁止清理 Editor Target。
- 缓存根默认为 `<Project>/Saved/AvidScript/CSharpSemanticCache/v1`，不得进入插件源码、Content、bootstrap Intermediate 或最终可加载 artifact 目录。
- Cache key 必须只由规范化语义输入决定，不得包含时间、机器名、绝对缓存根或 output root。
- 缓存 helper 禁止解析用户 C# 文本、启动 dotnet/powershell、解释 Roslyn 语义或决定 binding package 策略。
- Guest IR、WASM、authorization/runtime 子集校验和正式发布在命中后仍执行。
- 缓存失败不得消费未验证 artifact；损坏条目必须 rejected 后完整重编。
- 稳定诊断固定为 `ASBI4501` key/指纹无效、`ASBI4502` entry/provenance 无效、`ASBI4503` 路径逃逸、`ASBI4504` 发布/winner 冲突、`ASBI4505` 隔离/清理失败。
- 面向团队阅读的阶段文档与实现报告使用中文。
- 每个任务完成后只暂存该任务明确文件；保持用户自有 `Docs/CSharpGameplayAuthoring.md` 与 `Docs/Phase42/P42.0_Reflection_Binding_Generator_Architecture.md` 未暂存。

- [x] **Step 3：实现规范输入与指纹**

```powershell
function Get-AvidScriptCSharpSemanticCacheContext {
    param(
        [Parameter(Mandatory = $true)][string]$PluginRoot,
        [Parameter(Mandatory = $true)][string]$ProjectRoot,
        [Parameter(Mandatory = $true)][string]$CacheRoot,
        [Parameter(Mandatory = $true)][string]$Configuration,
        [Parameter(Mandatory = $true)][string]$SourcePath,
        [Parameter(Mandatory = $true)][string]$ProjectPath,
        [AllowNull()][object]$AuthorizationPackage
    )

    $ToolchainFingerprint = Get-AvidScriptCSharpToolchainFingerprint -PluginRoot $PluginRoot
    $CanonicalInput = [ordered]@{
        schema_version = 1
        configuration = $Configuration
        target_framework = "net8.0"
        dotnet_sdk_version = $ToolchainFingerprint.DotNetSdkVersion
        source = [ordered]@{ id = Convert-ToStableProjectPath $SourcePath; sha256 = Get-AvidScriptBindingSha256Hex $SourcePath }
        project_sha256 = Get-AvidScriptBindingSha256Hex $ProjectPath
        reference_sources = @(New-AvidScriptCacheReferenceSources $AuthorizationPackage)
        authorization = New-AvidScriptCacheAuthorizationIdentity $AuthorizationPackage
        toolchain_fingerprint = $ToolchainFingerprint.Sha256
    }
    $CacheKey = Get-AvidScriptUtf8JsonSha256 $CanonicalInput
    # EntryDirectory 固定为 <root>/<first-two>/<64-char-key>。
}
```

工具链闭包固定包含 `global.json`、两个 Invoke 脚本，以及 Frontend/Semantic 目录中按插件相对路径排序的 `.cs/.csproj`，排除 `bin/obj`。使用 `ConvertTo-Json -Compress -Depth 32` 和 UTF-8 无 BOM 字节计算哈希；通过已存在的 containment helper 拒绝 reparse point。
