# P43.4 Prepared Semantic 复用实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 自动自定义 C# 构建在保持 bootstrap/final 双包校验的前提下，只执行一次 Roslyn Frontend 与 Semantic。

**架构：** bootstrap report 作为一次 BuildService 调用内的 prepared semantic 索引。独立 PowerShell helper 严格验证源码、authorization package、路径包含关系和 artifact SHA-256，再把 Frontend/Semantic 原子复制到 final output；Guest IR、WASM Backend、runtime slice 子集校验和正式发布仍在 final 重跑。

**技术栈：** UE5.8 C++、PowerShell、Roslyn Frontend/Semantic、Guest IR、WASM Backend、UE Automation。

## 全局约束

- 固定源码引擎 `C:\UnrealEngine`；只做低并发增量编译，禁止清理 Editor Target。
- 人读文档使用中文。
- prepared helper 不启动 dotnet、不扫描 C# 文本、不决定 binding package 策略。
- final report/manifest 只引用 final output 产物，不引用即将删除的 bootstrap 文件。
- 复用验证失败必须返回独立 `prepared_semantic_invalid`，不得静默降级。
- 不复用 Guest IR 或 WASM，不实现跨 Editor 会话缓存。
- 两份用户自有文档不得修改、暂存或提交。
