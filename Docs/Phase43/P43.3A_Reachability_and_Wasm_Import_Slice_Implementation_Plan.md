# P43.3A 语义可达性与 WASM Import 裁剪实施计划

> **执行约束：** 按小组完成并逐项标记。使用源码版 UE5.8，保持增量编译，禁止清理 Editor Target。

## 目标

让正式 C# 脚本只把生命周期 export 可达的函数与 host import 降低到 Guest IR/WASM，同时保留完整 Gameplay package 作为授权上界，并在产物中记录实际使用的 UE binding stable ID。

## 架构

Roslyn Semantic 新增独立 `SemanticReachabilityProjector`，不把闭包逻辑混入 callable 或 CFG projector。Guest 只消费显式 reachability 契约。PowerShell 构建层只做 package manifest 与实际 import 的结构化集合校验和 provenance 映射，不解析 C# 文本。
