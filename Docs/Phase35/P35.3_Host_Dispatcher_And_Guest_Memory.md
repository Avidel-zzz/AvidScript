# P35.3 Host Dispatcher 与 Guest Memory

状态：Done

## 实现

- 16 个 WAMR native symbols 全部迁移到 `AvidScriptVM/Private`。
- VM wrapper 将参数转换为 `EAvidScriptHostBindingId + FAvidScriptHostCall` 固定 POD 帧。
- Runtime 实现 `IAvidScriptHostDispatcher`，再调用现有 Actor、SceneComponent、Owner 和 Timer typed handler。
- VM 负责 guest address validate、native address translation 和 FVector/FRotator/handle POD 写回。
- host import failure 与 guest trap 保持不同结构化类别。
- `avidscript` 为标准 import module，继续保留 `env` 兼容别名支持 LDC artifact。

## 边界结果

- VM 不认识 UObject、Actor、SceneComponent、FVector、FRotator 或 FTransform。
- Runtime 不包含 `wasm_export.h`、`wasm_runtime_*` 或 `AVIDSCRIPT_WITH_WAMR`。
- Bindings 不依赖 VM 或 WAMR。

## 回归修复

backend 使用多继承。首次实现把最派生对象地址作为 `void*` 存入 WAMR，取出后直接当第二基类接口，未进行基类偏移调整。修复为存入 `static_cast<IAvidScriptWamrHostBridge*>(this)`，并新增真实 imported-WASM 测试锁定该 ABI 规则。
