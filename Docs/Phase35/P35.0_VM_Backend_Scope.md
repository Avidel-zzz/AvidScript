# P35.0 VM Backend 范围

状态：Done

## 目标

建立独立 `AvidScriptVM` 模块，使 WAMR 与 UE gameplay binding 形成物理边界。VM 公共契约只使用 Core/POD 类型，Runtime 通过 backend、opaque export handle 和 HostCall dispatcher 组合能力。

## 边界

- VM 可以在 Private 实现中依赖 WAMR。
- VM Public 不得出现 WAMR、UObject、Actor、SceneComponent、FVector、FRotator 或 FTransform。
- Bindings 不得依赖 VM/WAMR。
- Runtime 显式依赖 Core、Bindings 与 VM。
- WAMR 全局 lease 最终只能由 VM 模块拥有，迁移期间不能同时存在两套 refcount。

## 阶段拆分

- P35.1：公共契约、export table、模块墙。
- P35.2：WAMR Backend PImpl 与独立 smoke。
- P35.3：16 个 native imports 转为 BindingId/POD dispatcher。
- P35.4：Runtime 切换并删除 WAMR 依赖。
- P35.5：完整回归、性能验证与收尾。
