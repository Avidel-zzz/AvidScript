# P35.4 Runtime Backend 迁移

状态：Done

## 实现

- `FAvidScriptWasmRuntimeInstance` 从三个 WAMR raw pointer 与全局 lease bool，改为唯一 `TUniquePtr<IAvidScriptVmBackend>` owner。
- Load、ValidateRequiredExports、BeginPlay、Tick、EndPlay、Timer、Event 和 Unload 全部通过 backend contract。
- Runtime Build.cs 删除 WAMR dependency。
- VM load metrics 映射回现有 Runtime metrics，保持组件日志和自动化兼容。
- 标准 callback 使用实例级 opaque handle cache；Unload 时统一失效。
- 现有 C# adapter v11、guest ABI v1、manifest schema v1 和组件公开接口未改变。

## 代码规模

Runtime 删除约 1,100 行 WAMR native glue。WAMR backend 与 host wrappers 进入 VM Private，模块墙通过脚本持续检查。

## 验证

- `AvidScriptVM`、`AvidScriptRuntime`、`AvidScriptEditor` 增量构建成功。
- Runtime WAMR API/source scan 结果为 0。
- VM native symbol 数量为 16。
- C# BeginPlay/Tick/EndPlay、typed Actor、SceneComponent、Timer、Event、Reload 和 Editor build-and-bind 均包含在完整回归中。
