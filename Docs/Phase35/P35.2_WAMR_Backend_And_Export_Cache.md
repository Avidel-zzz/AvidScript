# P35.2 WAMR Backend 与 Export Cache

状态：Done

## 实现

- 在 `AvidScriptVM` Private 中实现 WAMR backend。
- backend 独占 module bytecode、module、module instance、exec env、export table 与 load metrics。
- VM 全局 lease 使用临界区保护首个 init 与最后 destroy。
- Unload 顺序固定为 clear user data、destroy exec env、deinstantiate、unload module、release lease。
- export handle 使用 slot + generation；Unload 后旧 handle 返回 `stale_export`。
- Runtime、Bindings 与 VM Public 不暴露任何 WAMR 类型。

## 性能

backend 对同名 export 只执行一次 `wasm_runtime_lookup_function`。Runtime 进一步缓存 BeginPlay、Tick、EndPlay、Timer 和 Event 的 opaque handle，热路径不再构造 export 名称或访问 backend 名称表。

## 验证

- 无 import 最小 WASM 完成 load、resolve、call、unload。
- 同一 Tick export 解析两次时 WAMR lookup 总数仍为 1。
- Reset 后旧 handle 被 generation 拒绝。
