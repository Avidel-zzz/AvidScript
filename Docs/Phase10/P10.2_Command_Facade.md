# P10.2 Command Facade

日期: 2026-07-05
状态: Done

## 1. 目标

P10.2 在 `AvidScriptEditor` 模块中加入 Editor command facade, 将 P9 compile gate 和 P10.1 reload apply service 组合成一个可被后续 UI、菜单、watcher 或命令行入口复用的服务层。

命令门面负责输出统一 command result, 不直接拥有 runtime session, 不改变 `AvidScriptRuntime` 的 WASM ABI、reload session 或 manifest schema。

## 2. 新增 API

新增文件:

```text
Plugins/AvidScript/Source/AvidScriptEditor/Public/AvidScriptEditorCommandService.h
Plugins/AvidScript/Source/AvidScriptEditor/Private/AvidScriptEditorCommandService.cpp

```

核心类型:

```text
EAvidScriptEditorCommandStatus
FAvidScriptEditorCommandConfig
FAvidScriptEditorCommandResult

```

`FAvidScriptEditorCommandService` 暴露两条路径:

```text
ApplyEvaluatedCompileResult(CompileResult, ReloadSession, OutResult)
CompileAndApply(Config, OutResult)
```

## 3. 行为映射

| 输入/状态 | Command 结果 | Reload 行为 |
| --- | --- | --- |
| missing `ReloadSession` | `CompileFailed`, `reload_session_missing` | 不调用 compile wrapper, 不触碰 runtime session |
| compile diagnostics/invocation/manifest failure | `CompileFailed` | 不加载 runtime module |
| generated-only compile result | `GeneratedOnly`, success | 不执行 reload |
| reload apply initial load/reload | `ReloadApplied`, success | session 获得 live module |
| reload apply runtime failure | `ReloadFailed` | 保留 reload service/runtime failure 信息 |

## 5. 当前能力

P10.2 完成后, Editor 侧已经具备一个无 UI 的 command/reload execution facade。调用方可以把 frontend compile/report 的 evaluated result 交给命令门面, 由命令门面决定是 generated-only、compile failure、reload applied 还是 reload failed。

这意味着 Phase 11 的 UI/菜单/按钮可以先不用理解 runtime reload 细节, 只消费 `FAvidScriptEditorCommandResult`。P10.3 将继续补 command smoke, 尤其是 built artifact / diagnostic path 的端到端覆盖。
