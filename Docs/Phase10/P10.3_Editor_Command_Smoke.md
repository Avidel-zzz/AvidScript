# P10.3 Editor Command Smoke

日期: 2026-07-05
状态: Done

## 1. 目标

P10.3 补齐 Editor command facade 的 smoke 覆盖, 重点验证 P10.2 的命令门面不只支持 in-memory evaluated compile result, 也能承接真实 frontend wrapper 与已生成 built manifest 的工作流。

本小组是 coverage/documentation 小组, 没有新增 production API。P10.2 的 command facade 已满足本小组新增 smoke, P10.3 的价值是把这些关键路径固化为自动化回归。

## 2. 新增测试

修改文件:

```text
Plugins/AvidScript/Source/AvidScriptEditor/Private/Tests/AvidScriptEditorCommandServiceTests.cpp
```

新增 automation:

```text
AvidScript.Editor.CommandService.CompileAndApplyGeneratedOnlySmoke
AvidScript.Editor.CommandService.ExistingBuiltManifestCommandSmoke
```

覆盖内容:

| 测试 | 验证点 |
| --- | --- |
| `CompileAndApplyGeneratedOnlySmoke` | 走 `FAvidScriptEditorCommandService::CompileAndApply`, 调用 frontend wrapper 的 `-SkipCompile` 路径, 得到 `GeneratedOnly`, 不触碰 live runtime。 |
| `ExistingBuiltManifestCommandSmoke` | 若 `Saved/AvidScriptGenerated/actor_set_location/actor_set_location.avidscript.json` 存在, 将 built report 交给 compile gate, 再通过 command facade apply 到 caller-owned reload session, 并验证 Actor 被 WASM begin_play 移动。 |

## 3. 实现说明

`ExistingBuiltManifestCommandSmoke` 不跨模块引用 runtime private test type。测试创建临时 `UWorld`, spawn 一个普通 `AActor`, 挂载临时 `USceneComponent` root, 注册到 `FAvidScriptObjectRegistry`, 并为 reload session 设置 `FAvidScriptWasmHostContext`。

这样 built artifact 中的 `actor_set_location` host import 能在 begin_play 阶段真实执行, command facade 的结果也能验证到 UE Actor 状态变化。

如果 built manifest 缺失, 测试会以 warning-style skip 退出, 不把环境缺 artifact 当作代码失败。本次验证环境中 manifest 存在, 因此 smoke 执行了真实 built artifact command apply 路径。
