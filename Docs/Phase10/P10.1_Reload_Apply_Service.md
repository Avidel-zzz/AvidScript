# P10.1 Reload Apply Service

日期: 2026-07-05
状态: Done

## 1. 目标

P10.1 在 `AvidScriptEditor` module 中新增 reload apply service。它把 P9 的 `FAvidScriptEditorCompileResult` 应用到调用方提供的 `FAvidScriptWasmReloadSession`, 完成 initial load 或 live reload。

本阶段不做 UI, 也不持有全局 session。Editor UI、watcher 或 commandlet 后续都应显式传入自己的 runtime session。

## 3. Apply 状态

```text
SkippedGeneratedOnly
AppliedInitialLoad
AppliedReload
RejectedCompileResult
FailedRuntime
```

- `SkippedGeneratedOnly`: compile 成功但仅生成 D source, 不触发 reload。
- `AppliedInitialLoad`: session 当前无 live runtime, 已通过 `LoadInitialModule` 加载。
- `AppliedReload`: session 已有 live runtime, 已通过 `ReloadModule` 热更。
- `RejectedCompileResult`: compile/gate 失败、非 reloadable 或缺少 bytecode。
- `FailedRuntime`: runtime session 拒绝 initial load/reload, 保留 runtime error details。

## 4. 行为

- `SucceededGeneratedOnly` 返回 success, 但 `bApplied=false`。
- failed compile result fail closed, 不触碰 runtime session。
- reloadable result 如果缺 bytecode, 返回 `bytecode_missing`。
- reloadable result 且 session 未加载时调用 `FAvidScriptWasmReloadSession::LoadInitialModule`。
- reloadable result 且 session 已加载时调用 `FAvidScriptWasmReloadSession::ReloadModule`。
- runtime failure 会映射为 `FailedRuntime`, 并复制 `FAvidScriptWasmReloadResult`。

## 6. 已验证场景

- `GeneratedOnlySkipsReloadSmoke`: generated-only compile result 被成功处理, 但不加载 runtime。
- `InitialLoadAppliesSmoke`: reloadable compile result 在空 session 上执行 initial load。
- `LiveReloadAppliesSmoke`: 第二个 reloadable compile result 在 live session 上执行 reload, successful reload count 增加。
- `FailedCompileRejectedSmoke`: failed diagnostics compile result 被拒绝, session 保持 unloaded。

## 7. 剩余风险

- service 不持有 session, 后续 UI/command facade 必须明确 session 生命周期。
- P10.1 单元测试使用内存 WASM fixture, 不覆盖真实 wrapper/manifest 路径; P10.3 再补 command smoke。
- 还没有统一 command result model; P10.2 负责补这一层。
