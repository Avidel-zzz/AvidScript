# P10.0 Editor Command Reload Execution Scope

日期: 2026-07-05
状态: Done

## 1. 目标

Phase 10 把 Phase 9 的 Editor compile/reload gate 推进到真正的 runtime reload execution。阶段目标不是做 UI, 而是建立可以被 UI、菜单、watcher、CI 复用的 command/service surface。

目标链路:

```text
Editor command/service
-> FAvidScriptEditorCompileService
-> FAvidScriptEditorReloadService
-> FAvidScriptWasmReloadSession
-> live initial load / reload / rollback result
```

## 3. 方案

采用 service-first 的两层薄封装:

- `FAvidScriptEditorReloadService`: 输入 `FAvidScriptEditorCompileResult` 与调用方拥有的 `FAvidScriptWasmReloadSession`, 输出 reload apply result。
- `FAvidScriptEditorCommandService`: 组合 P9 compile service 和 P10 reload apply service, 输出统一 command result。

`AvidScriptRuntime` 继续拥有 WASM validation、manifest/hash/import/export 校验、reload session、rollback 和 live runtime。`AvidScriptEditor` 只负责 command-facing result model 和工作流编排。
