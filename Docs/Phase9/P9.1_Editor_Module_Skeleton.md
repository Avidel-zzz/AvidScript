# P9.1 Editor Module Skeleton

日期: 2026-07-05
状态: Done

## 1. 目标

P9.1 新增最小 `AvidScriptEditor` Editor module, 为后续 report reader、frontend invoker 和 reload gate service 提供 Editor-only 承载位置。

Runtime module 继续只负责 WAMR/runtime/reload; Editor workflow code 从本阶段开始进入 `AvidScriptEditor`。

## 2. 实现内容

- `AvidScript.uplugin` 增加 `AvidScriptEditor` module, Type 为 `Editor`, LoadingPhase 为 `Default`。
- 新增 `Source/AvidScriptEditor/AvidScriptEditor.Build.cs`。
- 新增 `FAvidScriptEditorModule` 和 `LogAvidScriptEditor`。
- module startup/shutdown 输出 display 日志。
- 新增 `AvidScript.Editor.ModuleLoadsSmoke` automation, 通过 `FModuleManager` 验证模块加载状态。

## 4. 说明

P9.1 不引入 UI、菜单或 watcher。它只建立 Editor module 边界和最小 automation, 为 P9.2 的 report reader 提供编译与测试位置。
