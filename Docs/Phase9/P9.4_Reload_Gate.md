# P9.4 Reload Gate Service

日期: 2026-07-05
状态: Done

## 1. 目标

P9.4 在 `AvidScriptEditor` module 中加入 compile/reload gate service。它负责消费 P9.3 invoker 的结果, 判断是否可以继续走 runtime manifest validation。

本阶段不做 Slate UI, 也不直接执行 runtime reload swap。真正的 manifest 读取、WASM hash 校验和后续 reload session 仍由 `AvidScriptRuntime` 拥有。

## 3. Gate 状态

```text
SucceededGeneratedOnly
SucceededReloadable
FailedDiagnostics
FailedInvocation
FailedManifest
```

- `SucceededGeneratedOnly`: frontend 成功, 但最后 build result 是 `generated`, 不进入 runtime reload。
- `SucceededReloadable`: frontend 成功, 最后 build result 是 `built`, manifest 和 wasm 已通过 runtime loader 校验。
- `FailedDiagnostics`: report 失败或包含 error diagnostic, 不读取 manifest。
- `FailedInvocation`: wrapper 调用失败、report 读取失败或 report 缺少 build event。
- `FailedManifest`: built artifact 的 manifest path 缺失或 runtime loader 校验失败。

## 4. 行为

- `Compile()` 调用 P9.3 `FAvidScriptFrontendInvoker`, 然后进入 gate 评估。
- `EvaluateInvocationResult()` 可直接消费已有 invocation result, 便于 UI、CI 和 automation 做纯 gate 测试。
- report 失败或包含 error diagnostic 时, 不调用 `FAvidScriptWasmReloadManifestLoader`。
- `generated` 成功路径会返回 success, 但 `bReloadable=false`。
- `built` 成功路径会从 manifest override、build event fields 或 raw output 中提取 manifest path。
- manifest validation 通过 `FAvidScriptWasmReloadManifestLoader::LoadFromFile` 完成, 不复制 runtime 校验逻辑。

## 6. 已验证场景

- `GeneratedOnlyGateSmoke`: `generated` result 成功但不可 reload, 且不尝试 manifest load。
- `DiagnosticGateSmoke`: diagnostic failure 直接 gate 掉, 不触碰 manifest loader。
- `MissingManifestGateSmoke`: `built` result 缺失 manifest 时返回 `FailedManifest` 和 `manifest_file_missing`。
- `ExistingBuiltManifestGateSmoke`: 现有 built manifest 存在时, 通过 runtime loader 校验并返回 reloadable。

## 7. 剩余风险

- 现阶段 service 只返回 reloadable bytecode/manifest, 不负责实际 reload session swap。
- built manifest smoke 依赖 `Saved/AvidScriptGenerated/actor_set_location/actor_set_location.avidscript.json`; 缺失时会以 warning-style skip 通过。
- UE 启动阶段仍可能出现与 AvidScript 无关的外部 HTTP 探测 warning。
