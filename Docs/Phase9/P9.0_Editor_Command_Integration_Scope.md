# P9.0 Editor Command Integration Scope

日期: 2026-07-05
状态: Done

## 1. 目标

Phase 9 把 Phase 8 的 CLI/report workflow 接到 UE Editor 侧。阶段目标不是做 UI, 而是建立一个可测试、可复用的 Editor module service, 后续菜单、按钮、watcher、IDE adapter 都可以调用它。

目标链路:

```text
Editor command/service
-> InvokeAvidScriptFrontend.ps1
-> JSON report
-> C++ report reader
-> reload gate
-> FAvidScriptWasmReloadManifestLoader
```

## 2. 小组拆分

| 小组 | 状态 | 目标 |

| P9.0 | Done | 范围、spec、plan、plugin scope 和根日志建立。 |

| P9.3 | Done | Editor frontend invoker。 |
| P9.4 | Planned | reload gate service。 |
| P9.5 | Planned | 完整回归和文档收口。 |

## 3. 方案

采用轻量 Editor module + service-first 路线。

`AvidScriptRuntime` 继续负责 runtime ABI、WAMR、manifest validation 和 reload session。`AvidScriptEditor` 负责开发者工作流: 参数整理、wrapper invocation、report 解析、diagnostic result 和 reload gate。
