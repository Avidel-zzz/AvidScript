# Phase 50 Typed Project API 架构设计

## 1. 阶段目标

Phase 50 解决 Phase 49 已经可以生成项目 `UFUNCTION`，但自定义 Actor 仍缺少自然 typed handle 的最后一段断点。

阶段完成后，项目可以在 C# profile 中声明脚本 owner 类型和可创建类，生成工具链自动完成：

- `UE.Self` 返回项目声明的自定义 Actor handle 类型；
- Blueprint 子类 class reference 保留其 native base result type；
- `UE.SpawnActor` 根据 class reference 静态类型返回对应 Actor handle；
- `UE.Self` 用一次 Host crossing 取得完整 owner handle；
- 自定义 handle 向 UE 基类 handle 的转换不进入 Host；
- UE 基类 handle 向自定义 handle 的转换执行一次安全类型检查；
- 自定义原生 C++ `UFUNCTION` 继续通过 descriptor 和 cached `ProcessEvent` plan 调用；
- 错误 owner、伪造 ordinal、过期 handle 和不兼容类型在 `BeginPlay` 前或调用点失败关闭。

本阶段不以增加预置 EngineGameplay API 数量为目标，也不为项目函数增加逐 API WAMR wrapper。

## 2. 已批准方案与备选方案

用户已选择方案 A：优先完成 typed 自定义项目 API 闭环。

未选择的两个方案分别是：

- 先做 UObject/Component factory、Attach/Detach 和 ownership policy；
- 先做 Win64 Cook/Shipping。

它们都依赖稳定的对象类型合同。若在 typed handle 之前实现，会迫使组件工厂或 packaged runtime 继续向脚本暴露弱类型 `AActor`/`UObject`，随后再进行破坏性 ABI 调整。因此 Phase 50 先建立类型图和转换语义。

## 3. 范围

### 3.1 必须完成

1. C# profile schema v3 增加可选 `self_class_path`。
2. descriptor schema v6 为 handle-capable UObject 类型发布不可变类型图。
3. package load 一次性解析并锚定 object type `UClass`。
4. 生成 typed `UE.Self`。
5. 生成 typed class reference 和 typed `SpawnActor` overload。
6. 为 handle wrapper 生成零 Host crossing 的安全 upcast。
7. 增加一个通用 checked downcast Host import。
8. 用自定义 native Actor `UFUNCTION` 和 Blueprint 子类实例完成真实 C#/WASM/WAMR/UE 闭环。
9. 保持 schema v2-v5 descriptor、profile v1-v2 和 `TSubclassOfAActor` 兼容。
10. 建立 typed cast、typed spawn 和自定义 UFUNCTION 性能/结构证据。

### 3.2 明确不做

- 任意 UObject 或 Component 构造；
- Outer、ownership、Attach/Detach 和组件查找；
- Blueprint 图中新声明函数的完整 authoring 闭环；
- C# managed class inheritance、运行时泛型和反射；
- `TArray`、`TMap`、`TSet`、任意 `UStruct`；
- Spawn/Destroy 候选副作用补偿；
- Cook、Staging、Shipping、Android 或 iOS；
- IDE debugger、断点和新的 source-map 功能。

Blueprint 子类可以作为 class reference 被 typed Spawn，并调用 native base 暴露的自定义 `UFUNCTION`。Blueprint 图中新声明的函数不作为 Phase 50 完成条件。

## 4. 用户侧合同

### 4.1 Profile schema v3

```json
{
  "schema_version": 3,
  "language": "csharp",
  "source_path": "Plugins/AvidScript/Samples/CSharp/TypedProjectApi/TypedProjectApiScript.cs",
  "binding_profile": {
    "package_name": "avidscript.project.typed_api",
    "self_class_path": "/Script/MyGame.MyScriptActor",
    "module_paths": [
      "/Script/MyGame"
    ],
    "class_references": [
      {
        "script_name": "Projectile",
        "class_path": "/Game/Blueprints/BP_MyProjectile.BP_MyProjectile_C",
        "base_class_path": "/Script/MyGame.MyProjectile",
        "load_policy": "EditorLoad"
      }
    ]
  }
}
```

规则：

- `self_class_path` 可省略；省略时继续生成 `AActor UE.Self`，descriptor v6 显式记录 `AActor` type id；
- 字段存在时必须解析为 `AActor` 派生 `UClass`；
- abstract native base 可以作为 self type，因为实际 owner 可以是 Blueprint concrete subclass；
- self type 必须进入 selection hash、descriptor package hash 和 semantic cache identity；
- profile v1/v2 字节语义保持不变；
- schema v1/v2 出现 `self_class_path` 时失败关闭，禁止静默忽略。

### 4.2 生成式 C# API

```csharp
AMyScriptActor self = UE.Self;
self.ApplyGameplayValue(4.0f);

AMyProjectile projectile = UE.SpawnActor(
    ProjectClasses.Projectile,
    FTransform.Identity);

AActor actor = projectile;
AMyProjectile checkedProjectile = AMyProjectile.TryCast(actor);
if (checkedProjectile.HasHandle)
{
    checkedProjectile.ActivateProjectile();
}
```

语义：

- `AMyProjectile -> AActor` 为 Guest 内两个 `i32` 的复制，Host import 数为 0；
- `AMyProjectile.TryCast(AActor)` 对有效 handle 执行一个通用 type-check import；
- 类型不匹配是正常分支，返回 `(0, 0)` invalid handle；
- stale、cross-world 或未注册 handle 是合同错误，返回稳定诊断；
- typed Spawn 与旧 untyped Spawn 使用同一 Host import，仍为一次 crossing；
- `DestroyActor` 和现有接受基类 handle 的 API 通过生成 upcast 继续工作。

## 5. Descriptor schema v6

### 5.1 Root 字段

schema v6 增加：

```json
{
  "self_type_id": "type-stable-id-or-empty"
}
```

包含 Actor 生命周期入口的 package 必须发布非空 `self_type_id`。profile 未指定
`self_class_path` 时，该字段指向闭包中的 `AActor`；只有不包含 Actor Self
语义的纯静态 package 才允许为空。

### 5.2 Object type 元数据

现有 `types` 数组继续是唯一类型表。`kind == "object_handle"` 的 handle-capable 类型增加：

```json
{
  "object_type_ordinal": 3,
  "class_path": "/Script/MyGame.MyProjectile",
  "base_type_id": "nearest-generated-base-type-stable-id"
}
```

规则：

- ordinal 在 object-handle 子空间内从 0 连续递增；
- 排序键为 canonical class path，不能依赖反射遍历顺序；
- `class_path` 必须与 `canonical_type` 的 UObject path 一致；
- `base_type_id` 指向类型闭包内的直接 UClass super；
- `UObject` 根类型的 `base_type_id` 为空；
- static-only owner 不获得 ordinal，也不进入 Runtime object type plan；
- schema v2-v5 的 type hash 与 package hash 算法保持原样；
- schema v6 package hash覆盖 self type、ordinal、class path 和 base edge。

### 5.3 类型闭包

object type closure 包含：

1. 所有 instance binding owner；
2. 所有 object-handle 参数和返回值；
3. profile `self_class_path`；
4. 每个 class reference 的 `base_class_path`；
5. 上述类型到 `UObject` 的 UClass super chain。

仅含静态函数的 `UBlueprintFunctionLibrary` 继续生成 C# static class，不制造无意义 handle。

### 5.4 Class reference result type

每个 class reference 增加：

```json
{
  "result_type_id": "base-class-object-type-stable-id"
}
```

`result_type_id` 必须指向其 `base_class_path` 对应 object type。Runtime 继续验证实际 class 是 base class 的子类。

## 6. 模块与职责

### 6.1 AvidScriptEditor

负责：

- profile schema v3 解析；
- self UClass 与 class reference base UClass 验证；
- object type closure 和确定性 ordinal；
- descriptor v6、C# handle、转换和 typed Spawn 生成；
- 将 v6 reference surface 交给现有 Roslyn/semantic/build pipeline。

Editor 只在生成阶段读取 `UClass` 继承关系。生成结果发布后，Runtime 不重新推导字符串类型图。

### 6.2 AvidScriptBindings

负责：

- descriptor v6 严格解析；
- package load 时把 object type graph 转换成 immutable `UClass*` plan；
- 强引用锚定已验证 class；
- expected self type 查询；
- checked object-type cast dispatch；
- 保持 reflected UFUNCTION cached `ProcessEvent` plan 不变。

`EAvidScriptBindingInvocationKind` 从 lifecycle 专用 header 移到共享 invocation-kind header。新增 object type capability family，避免把类型转换继续塞进生命周期文件。

### 6.3 AvidScriptVM

VM 继续只消费 language-neutral import spec：

```text
module = avidscript
name = avid_object_type_is_a
signature = (iii)i
```

三个参数依次为 slot、generation、object type ordinal。该 capability 面向通用
`UObject` handle；Actor 的同 World 约束属于 Actor effect policy，不得固化进类型
检查。VM 不包含 `UClass`、`UObject` 或 C# 类型。

typed `UE.Self` 增加兼容性 Host import：

```text
module = avidscript
name = avid_owner_get_handle
signature = ()I
```

返回值低 32 位为 slot，高 32 位为 generation。旧
`env.owner_get_slot`/`env.owner_get_generation` 保留用于旧 artifact，新生成的 v6
facade 使用 packed `i64` 一次取得完整 handle。

### 6.4 AvidScriptRuntime

负责：

- 在候选 Runtime `BeginPlay` 前验证 owner handle 满足 descriptor expected self type；
- initial load mismatch 直接失败；
- reload candidate mismatch 保留旧 Runtime；
- 给 checked cast 提供 registry、World 和 owner 上下文；
- 维持 generational handle 生命周期。

Runtime 不根据 C# 名称或 class path 执行反射查找。

### 6.5 C# Frontend、Semantic、Guest IR

- 支持多个生成式 nominal class-ref struct，而不是只识别 `TSubclassOfAActor`；
- class-ref 仍只有一个 private readonly `int Ordinal`；
- constructor 仍只接受生成代码中的非负整数字面量；
- 任意 class-ref 仍不能与 `int` 或 object handle 隐式互转；
- `SemanticConversion.IsUserDefined` 且带 `MethodSymbolId` 的转换必须新增 callable lowering，不能沿用当前普通 `convert` 重解释；
- checked downcast 只是一个生成方法和一个授权 import，不新增 CLR cast 语义；
- WASM 中 object handle 仍是两个 `i32`，class ref 仍是一个 `i32`。

## 7. Runtime 数据流

### 7.1 Build

```text
profile v3
  -> resolve self/class/function selection
  -> build object type closure
  -> descriptor v6
  -> generated typed C# facade
  -> Roslyn semantic artifact
  -> reachable Guest IR
  -> WASM
  -> authorization/runtime binding slice
```

### 7.2 Initial load

```text
manifest
  -> verify binding package provenance
  -> parse descriptor v6
  -> resolve object type UClass plans once
  -> register owner handle
  -> validate owner IsA(expected self)
  -> instantiate WAMR
  -> BeginPlay
```

### 7.3 Checked downcast

```text
typed wrapper TryCast(base handle)
  -> one dynamic import
  -> registry resolve slot/generation
  -> immutable object type ordinal lookup
  -> UObject::IsA(cached UClass)
  -> return 1 or 0
  -> Guest reuses or clears the original two-cell handle
```

不分配 UObject，不修改 registry，不构造 object path，不访问 Guest Memory，也不把
Actor-only World 假设施加到 Component 或普通 UObject。

## 8. 失败关闭合同

| 场景 | 结果 |
| --- | --- |
| profile self path 缺失 | `self_class_missing` |
| self 不是 Actor | `self_class_not_actor` |
| schema v6 type ordinal 不连续 | `object_type_ordinal_invalid` |
| class path 与 canonical type 不一致 | `object_type_class_path_mismatch` |
| base type 不存在或不是真实 super | `object_type_base_mismatch` |
| self type id 不存在 | `self_type_missing` |
| class reference result type 不匹配 base path | `class_reference_result_type_mismatch` |
| initial owner 类型不匹配 | `runtime_owner_type_mismatch` |
| reload candidate owner 类型不匹配 | 拒绝 candidate，旧 Runtime 保持运行 |
| cast ordinal 越界 | `object_type_ordinal_out_of_range` |
| stale handle | 复用 registry generation mismatch 诊断 |
| cast 类型不匹配 | 调用成功但返回 0，Guest 得到 invalid typed handle |

失败路径保留可操作诊断；成功热路径不构造 UObject path。

## 9. 热重载语义

- object type graph 和 self type 属于 package identity；
- self type、base edge 或 class reference result type 变化会改变 package hash；
- candidate 在执行 `BeginPlay` 前完成 owner type 验证；
- checked cast 是只读操作，可以在 candidate reload 中使用；
- typed Spawn 继续遵守 Phase 49 规则，在 candidate reload 中失败关闭；
- schema 不兼容、owner mismatch 或 type plan load 失败不会替换旧 Runtime。

## 10. 性能预算

| 操作 | 预算 |
| --- | --- |
| upcast | 0 Host import，两个 `i32` copy |
| typed Self | 1 Host import，packed `i64` 拆成两个 `i32` |
| typed Spawn | 1 Host import，与 Phase 49 相同 |
| checked downcast | 1 Host import |
| object type resolve | O(1) ordinal index |
| warm typed dispatch | 0 class load，0 reflected name lookup |
| 现有 typed binding | 相对 Phase 49 不超过 5% 回退 |

新增 benchmark 报告 Native `IsA`、Binding object-type check 和真实 WAMR checked cast。外部框架对比仍需同机同项目 harness，不在本阶段伪造排名。

## 12. 验收标准

Phase 50 只有同时满足以下条件才可关闭：

1. profile v3 自定义 Actor owner 生成 typed `UE.Self`；
2. Blueprint subclass class reference 生成 typed Spawn result；
3. 自定义 native Actor `UFUNCTION` 从真实 C# 经 WASM/WAMR 修改 UE 对象；
4. upcast 的 WASM 路径没有 Host import；
5. typed Self 只有一次 Host import；
6. checked downcast 的成功与 mismatch 路径各只有一次 Host import；
7. wrong owner 在 `BeginPlay` 前被拒绝；
8. reload candidate wrong owner 不替换旧 Runtime；
9. schema v2-v5 与 profile v1-v2 合同保持通过；
10. warm path class load 和 reflected name lookup 为 0；
11. 完整 AvidScript Automation 无非成功结果；
12. 未引入逐 UFUNCTION wrapper、Runtime 字符串反射查找或 WAMR 类型泄漏；
13. 所有人读文档使用中文。
