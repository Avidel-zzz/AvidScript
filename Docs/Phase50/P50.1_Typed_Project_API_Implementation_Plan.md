# Phase 50 Typed Project API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立自定义 C++ `UFUNCTION`、typed `UE.Self`、typed Blueprint class reference、typed Spawn、零 crossing upcast 和一次 crossing checked downcast 的真实 C#/WASM/UE 项目脚本闭环。

**Architecture:** Editor 从 profile v3 构建 descriptor v6 object type graph；Bindings 在 package load 时把类型图解析成不可变 `UClass` plan；生成式 C# facade 只发布稳定 value-type handle 和 nominal class reference。Runtime 热路径按 ordinal 查询缓存类型，普通项目 `UFUNCTION` 继续复用统一 dynamic ABI 与 cached `ProcessEvent`，不增加逐 API wrapper。

**Tech Stack:** Unreal Engine 5.8 源码版、C++20、UHT/UBT、Roslyn semantic artifact、.NET SDK 8.0.416、AvidScript Guest IR、WebAssembly、WAMR、PowerShell 7、Unreal Automation Framework。

## Global Constraints

- 引擎固定为 `C:\UnrealEngine` 的 UE5.8 源码版，当前阶段先支持 Win64 PC。
- 禁止执行 Editor Target clean；公开 ABI 变化后用一次 no-clean UBT 同时重链 producer 与全部直接 consumer。
- P50 的 UBT 预算为 3、Automation 预算为 2、Full Gate 预算为 2；非阻塞问题记录为 debt，在批次末集中处理。
- C# object handle 的 WASM ABI 始终是两个 `i32`；class reference 始终是一个 `i32`。
- schema v2-v5 descriptor、profile v1-v2 和旧 `env.owner_get_slot`/`env.owner_get_generation` artifact 必须兼容。
- 不为单个类或 `UFUNCTION` 手写 VM import、Runtime switch、WAMR wrapper 或 renderer 特判。
- Runtime 热路径禁止根据 C# 名称或 class path 执行字符串反射查找。
- 所有人读文档使用中文；代码标识符、诊断 category 和 ABI 名称使用 ASCII。
- 不修改或暂存用户现有的 `Docs/Phase42/P42.0_Reflection_Binding_Generator_Architecture.md` 与 `Docs/AvidScript_Technical_Status.md`。
- 修改未知 owner 前先用 `rg --files` 或 `rg -l -F` 定位，不推测重构后的文件路径。
