# P52 双向属性 Binding 实施计划

## 批次总览

| 批次 | 目标 | 主要出口 |
| --- | --- | --- |
| P52.1 | Profile access intent、write policy 与 descriptor v8 | canonical setter metadata 可生成、可解析、可拒绝 |
| P52.2 | immutable setter plan 与 property transaction | cached direct/Blueprint setter 可执行且 candidate 可回滚 |
| P52.3 | C# facade、slice、Guest IR/WASM provenance | 普通 C# `get/set` 到动态 import 闭环 |
| P52.4 | 真实 gameplay 与性能 | BeginPlay/Tick/reload 可观察行为和 P50/P95 |
| P52.5 | 独立复审、集中 Gate、文档与发布 | PhaseWorkflow attest/close 与安全推送 |

## P52.1 Profile 与 descriptor v8

1. 扩展 project binding profile 的 property access intent，旧 schema 默认 read-only。
2. 新增独立 write policy，集中处理 flags、BlueprintSetter、replication 与现有 marshaller 类型资格。
3. 扩展 selection result/compatibility report，区分 getter accepted、setter accepted 与稳定拒绝原因。
4. descriptor model 新增 `property_set`、`write_policy` 与 `cached_property_set/cached_blueprint_setter`。
5. 更新 canonical serializer/parser、identity、selection/package hash 与 v2-v7 兼容门禁。
6. 用真实反射属性覆盖 direct setter、BlueprintSetter、read-only、replicated、container 与 unsupported struct。

出口：同一属性的 getter/setter 是两个稳定 binding，descriptor v8 byte deterministic；旧 descriptor 行为不变。

## P52.2 Runtime plan 与回滚

1. load 阶段解析 owner class、FProperty、可选 BlueprintSetter UFunction 与 frame layout。
2. 将 getter/setter plan 分流但共享 type marshaller、object authority 与 scratch allocator。
3. direct setter 使用 `FProperty` copy semantics；BlueprintSetter 使用缓存 `ProcessEvent` frame。
4. 扩展 host-effect journal，以对象 handle + property stable id 捕获对齐且可析构的旧值。
5. commit 销毁快照；rollback 逆序恢复；重复写同一属性只捕获一次。
6. candidate 失败、stale receiver、wrong-type object value 和 snapshot failure 全部失败关闭。

出口：Bindings/Runtime producer-consumer no-clean build 通过，候选成功提交与失败恢复旧值均可证明。

## P52.3 C# 与最小 runtime slice

1. renderer 合并 getter/setter 为自然 C# 属性，并为 setter 生成 stable DllImport。
2. CSharp binding package/resolver 接受 descriptor v8，保持旧 schema identity。
3. semantic reachability 将 property setter accessor 解析为 callable import。
4. slice service 同步保留 setter binding、所需 type/object ordinal 与 write policy。
5. final Guest IR import 与 runtime package 执行严格 identity/provenance 比较。
6. 未授权、错 ordinal、getter/setter 混淆和 runtime slice 缺失均删除可加载制品并发布稳定报告。

出口：真实 C# setter 编译为 Guest IR/WASM，runtime package 只包含可达 getter/setter，不包含同 profile 中未使用成员。

## P52.4 Gameplay 与性能

1. 新增中文版 C# 样例，至少在 BeginPlay/Tick 中写 scalar 与 struct/object 支持类型。
2. 验证 active runtime 正常写入、candidate reload success commit、candidate trap rollback 和旧 runtime 延续。
3. benchmark 对比 native direct、binding direct 与 WAMR setter。
4. 记录 P50/P95、crossing、snapshot capture count、class load 与 reflected-name lookup。
5. 用同一完整 Automation 日志承载功能和性能最终证据，避免额外重复全量运行。

出口：可观察 UE 行为闭环，warm class/name lookup 为 0，每次 WAMR setter 一次 crossing。

## P52.5 集中收尾

1. 独立审查 architecture、policy、lifetime、rollback、ABI、performance 与 privacy。
2. batch 完成后一次性执行 PowerShell parser/architecture、五个 .NET host/format 与合同宿主。
3. 执行普通 no-clean UE5.8 Editor build，禁止 clean Editor Target 和全局 `-DisableUnity`。
4. 最终完整 `Automation RunTests AvidScript` 只运行一次，验证 found=completed=succeeded、Queue Empty、TestExit、RequestExit status 与进程退出码。
5. 生成不可变 Gate report、attestation commit、close evidence、中文收尾报告和机器摘要。
6. 安全审计后 fast-forward 推送，保留完整提交历史。

## 验证节奏

- 批次内只运行能阻塞当前实现方向的 parser、focused host 或 scoped no-clean module build。
- 非阻塞低风险问题登记到 P52.5 集中处理，不做每个小改动后的完整 UBT/Automation。
- 新增 `.cpp` 后首次 producer build 使用 `-NoUBTMakefiles` 刷新 action graph，但不清理 Target。
- 共享 .NET project graph 永远串行。
- PhaseWorkflow 状态机只在主插件运行；实现代码可在 Phase 52 worktree 开发。
