# P58 实施计划

## Group A：值图核心与非容器 UE 值

- descriptor schema v19：递归 `type_arguments`、`capability_kind`、stable identity；
- `FAvidScriptCompositeValueHeap`、reservation/commit/rollback、Session reset；
- `FText` 精确保真 pass/return、presentation UTF-8 bridge；
- soft/weak object pointer pass/return 与失效语义；
- C# wrapper、Semantic schema 与 Guest i32 capability lowering。

完成标记：`P58.A`。

## Group B：递归容器

- string element 与 nested `TArray`；
- `TSet<T>` 与 `TMap<K,V>` 的 canonical snapshot/mutation；
- 统一 count/child/read/write/release imports；
- 旧 flat-array bulk path 保持 benchmark 行为。

完成标记：`P58.B`。

## Group C：delegate ref/out 与真实脚本闭环

- multicast/single-cast 授权 handler 的 `ref/out` transaction；
- 生成 C# handler signature、Guest output slot 与 UE frame commit；
- 一个项目自定义 UFUNCTION/delegate fixture 覆盖所有新值类别；
- C# gameplay sample 展示 BeginPlay/Tick/event 中的实际读写方式。

完成标记：`P58.C`。

## Group D：集中验收

- 固定 .NET、PowerShell contracts/parser；
- UE5.8 no-clean Editor target；
- 完整 AvidScript Automation；
- clean architecture gate；
- 新值路径的 allocation/latency benchmark 与泄漏统计；
- 中文 README、阶段报告、state、Git 提交与远端证据同步。

完成标记：`P58.D`。

## 执行规则

- A/B/C 开发期间只做阻塞性编译/契约检查；完整构建与 Automation 集中到 D。
- 不为每个 UE API 写测试；fixture 按类型图、生命周期和事务风险覆盖。
- 非阻塞普通缺陷进入组末集中修复；安全、数据损坏、生命周期泄漏和 ABI 漂移立即修复。
- P59 性能后端债不反向污染 P58 的类型架构。
