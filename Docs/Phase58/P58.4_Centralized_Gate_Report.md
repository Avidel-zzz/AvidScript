# P58.D 集中验收报告

## 状态

P58.D 的产品实现、无清理增量构建、全量 Automation 与性能采样已在当前工作树完成。
本报告记录工作树级证据；严格 Phase 关闭仍需候选提交、同一 Git tree 的架构检查、
Gate attestation 与关闭提交，当前不提前宣称 Phase 58 已关闭。

## 集中修复

- 含泛型值类型的 binding descriptor 统一提升到 schema 19，避免递归容器与旧 schema 混用；
- 保留 `TArray<UObject*>` 的 ObjectHandle 支持，只对真正的复合容器强 UObject 叶子
  fail-closed；
- 复合强引用对象的拒绝用例改为 `TMap<FName, TObjectPtr<UObject>>`，与平面数组能力分离；
- 同步修正 schema、delegate 参数方向、生成 binding 数量及授权包总数的测试基线。
- Semantic 合同升级到 schema 17 / `1.19`，复合 wrapper、token field 与内部构造函数
  必须来自可执行 reference source；主源码伪造同形 `FAvid*` 类型会 fail-closed；
- C# Build Invoker 和递归 Semantic/GuestIR/WASM 子步骤统一使用 PowerShell 7，修复
  内容寻址 generated package/source 在长路径下被 Windows PowerShell 误判缺失的问题；
- 新增真实 generated facade 编译闭环：合法 `avid_on_begin_play` 从 `UE.Self` 转成生成
  对象 wrapper，读取 Array/Set/Map `UPROPERTY` facade 并编译容器 read/write/find/upsert/remove。

## 能力结果

- FText、soft/weak object、递归 `TArray`、`TSet`、`TMap` 进入统一复合值 capability；
- delegate ref/out 从 descriptor、C# Guest、VM import 到 Runtime transaction 形成闭环；
- 当前 gameplay profile 生成 371 个函数和 2 个属性，共 373 个 reflected bindings；
- 授权 import 包共 390 项，其中 373 项来自反射生成，17 项为共享基础 import；
- 平面 UObject 数组继续通过 ObjectHandle 交互；复合容器内强 UObject 引用在 GC anchoring
  完成前保持拒绝，避免悬空引用。
