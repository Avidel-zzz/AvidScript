# P58.0 通用 UE 值图架构

## 目标

Phase 58 扩展 AvidScript 的通用 UE 类型覆盖，使 C# 脚本可以通过同一套生成式
Reflection pipeline 使用 `FText`、包含字符串或容器的递归 `TArray`、`TSet`、`TMap`、
soft/weak object pointer，并为 delegate `ref/out` 建立一致的值生命周期。

本阶段禁止为具体 UFUNCTION、具体类或具体 API 名增加 wrapper/switch。新增类型必须进入
Reflection type policy、descriptor、C# facade、Semantic/Guest type graph、Runtime codec
program 和 Session capability 生命周期这一条通用链路。

## 核心决策

### 1. 统一复合值 capability

新增 Bindings-owned `FAvidScriptCompositeValueHeap`。每个 slot 保存：

- generation-safe 32-bit token；
- descriptor `type_id`、值种类和活动 Reflection identity；
- 由 `FProperty::InitializeValue/CopyCompleteValue/DestroyValue` 管理的对齐存储；
- 父子 capability 依赖与引用计数；
- Session/lane/reload ownership。

Guest 只持有 token，不持有 `FText`、`FString`、UE container 或 soft/weak pointer 的本机
布局。所有返回值先进入事务式 reservation，完整编码成功后统一 publish；失败、trap、
candidate reload、Session teardown 会回滚或释放整棵值图。

### 2. 快路径与通用路径并存

现有 `FAvidScriptUtf8ValueHeap`、固定元素 `FAvidScriptArrayValueHeap` 和 compiler-managed
array region 保持不变，继续服务高频 blittable 数据。新复合值堆是非平凡类型和递归容器的
通用 fallback，不取代已经通过 benchmark 的数据路径。

codec planner 在 descriptor activation 时一次性选择：

- scalar/object/固定 struct：现有 inline codec；
- `FName`/`FString`：现有 UTF-8 codec；
- 固定元素一维数组：现有 array capability；
- `FText`、soft/weak pointer、递归/非平凡 container：composite capability。

热路径不解析 JSON、不遍历 UFunction 名称，也不在每次调用重建 codec program。

### 3. 递归 descriptor 类型图

descriptor schema v19 为 type model 增加有序 `type_arguments` 与
`capability_kind`：

- `array<T>` / `set<T>` 有一个 type argument；
- `map<K,V>` 有两个 type arguments；
- `text`、`soft_object<T>`、`weak_object<T>` 使用稳定 canonical identity；
- v2-v18 的 `element_type_id` 保持只读兼容，v19 emitter 同时发布 canonical
  `type_arguments`。

stable id 必须包含 kind、全部递归 argument stable id、布局/Reflection identity；修改
任一子类型都必须改变 package identity。递归深度、节点数、单值字节数和容器元素数继续有
硬上限并 fail closed。

### 4. C# 值语义

生成 facade 使用 readonly capability wrapper：

- `FAvidText` 保留 UE `FText` history/namespace/key/source 的宿主副本；`ToString` 只是
  presentation snapshot，不能反向冒充原本地化 identity。
- `FAvidSoftObject<T>` 保存 soft path identity，可显式解析或交给受控 async loading。
- `FAvidWeakObject<T>` 不延长 UObject 生命周期；解析失败返回 null handle。
- recursive array/set/map 使用生成的具体 C# collection shape，但 Guest lowering 统一为
  i32 capability token。

`Release`、`Count`、child clone/read、set/map mutation 等能力通过少量按语义命名的通用
Host import 提供，不按 UE API 或具体元素类型生成 Host import。

### 5. 容器确定性

`TArray` 保留索引顺序。`TSet`/`TMap` 的 UE 内部 bucket 顺序不作为脚本合同；输出
snapshot 按 key/element 的 canonical wire bytes 排序。无法形成 canonical key 的类型不进入
P58 set/map key 白名单。重复 key、NaN key、失效 object key 和超限图均 fail closed。

### 6. delegate ref/out

delegate handler 继续使用 Session-owned invocation frame。`ref/out` 参数在进入 Guest 前
建立 composite/inline transaction，Guest 只写授权 output slot；handler 成功返回后再一次性
commit 到原 UE frame。trap、reentrancy overflow、取消或 reload 不产生半写入。

首批仍不支持 latent delegate、返回引用、指针参数和任意 CLR object graph。

## 模块边界

| 模块 | 责任 |
|---|---|
| `AvidScriptEditor` | Reflection 投影、schema v19 type graph、C# facade |
| `AvidScriptBindings` | composite heap、codec program、事务和通用 value imports |
| `AvidScriptRuntime` | Session/lane/reload 生命周期组合，不解释具体 UE 类型 |
| `AvidScriptVM` | 继续只处理标量 ABI、guest memory 与 import linking |
| C# Semantic/Guest | 识别生成类型图并把 capability wrapper lowering 为 i32 |

VM 不新增 gameplay type enum；Runtime 不新增按 API 名或 UClass 名分支。

## 性能约束

- activation 后 codec plan 全部缓存；调用期不做字符串类型分派；
- scalar/固定 struct/固定 array 不回退到 composite heap；
- composite output 使用单次递归 size/preflight 与单事务 publish；
- 容器 child token 使用 arena 批量 reservation，避免逐元素全局锁；
- P58 集中 benchmark 至少覆盖 FText pass-through、string array、nested array、set/map
  snapshot 与 mutation，不用微不足道的单函数测试代替架构性能判断。

## 失败边界

以下情况必须稳定失败且不泄漏 capability：schema/type graph 不一致、Reflection property
类型漂移、超深/超节点/超字节值图、Session 或 lane 不匹配、stale generation、重复释放、
无 canonical set/map key、delegate output transaction 未完成。

## 非目标

- 不实现完整 .NET Runtime 或 CLR GC；
- 不把所有值强制装箱到 composite heap；
- 不在 P58 处理 LLVM AOT，未解决的纯执行门禁属于 P59；
- 不宣称 Cook/Shipping/Android/iOS 已完成，平台验收属于后续 Phase。
