# P44 项目 C# Workspace 与事务式 Live Reload 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让项目作者一键获得可由 IDE 编辑、可正式构建绑定、可在 UE Actor 生命周期运行并可事务热重载的 C# 游戏脚本 workspace。

**Architecture:** WorkspaceService 只物化项目文件并刷新 generated IDE facade；ProfileService/BuildService/ComponentBindingService 继续拥有加载、构建和绑定。`UAvidScriptComponent` 复用 RuntimeSession 已有候选验证与 rollback 语义，新增 manifest-backed live reload，不把 Editor、profile 或文件生成职责放进 Runtime。

**Tech Stack:** UE5.8 C++ Editor/Runtime modules、C# net8.0、Roslyn Frontend/Semantic、generated reflection bindings、WAMR、Windows PowerShell 5.1。

## Global Constraints

- 使用 `C:\UnrealEngine` 源码版 UE5.8，只做增量构建，禁止清理 Editor Target。
- 用户 source/project/profile/global.json 位于项目 `Scripts/AvidScript`，默认不得覆盖。
- generated facade 位于项目 `Intermediate/AvidScript/CSharpWorkspace`，不得进入 Runtime manifest。
- WASM/report/manifest 位于项目 Saved，Semantic Cache 保持 P43.5 所有权和安全规则。
- WorkspaceService 禁止编译脚本、解析 reflection descriptor 或绑定 Actor。
- Runtime Component 禁止依赖 Editor、workspace、profile 或 generated source。
- Live reload 失败必须保留旧 runtime 和旧 manifest path；不得通过 unload 后重建伪装 rollback。
- 面向用户和团队的阶段文档使用中文。
- 只暂存本阶段明确文件；保留用户自有文档未暂存。

- [x] **Step 1: 写 component reload RED**

初始加载 v1 后把 manifest path 指向兼容 v2，调用 `ReloadConfiguredScript` 并断言 `SuccessfulReloadCount=1`、module 切换、Tick 继续。再指向坏 hash/BeginPlay trap candidate，断言 `RejectedReloadCount=1`、`bRollbackPreservedLiveRuntime=true`、旧 module 继续 Tick。

- [x] **Step 2: 实现 Component rich/simple API**

manifest loader 成功后，根据 RuntimeSession live state 调用 ReloadModule。成功更新 RuntimeStats；失败只记录诊断，保持 `bRuntimeLoaded`、Tick enabled、delegates 和旧 session，不调用 `ReleaseRuntime`。

- [x] **Step 3: 写 binding transaction RED**

live component 应用坏 manifest 时保存旧 path；reload 失败后 `GetScriptManifestPath()` 等于旧 path，result 为 `reload_rejected` 且旧 runtime 仍 live。成功时 path 与 active module 一起提交。

- [x] **Step 4: 实现 ApplyManifest transaction**

`FAvidScriptEditorComponentBindingResult` 新增 `bReloadAttempted/bReloadApplied` 和 RuntimeResult。非 live component 不尝试 reload；live component 失败恢复旧 path 并保持 component/package dirty 状态与结果一致。
