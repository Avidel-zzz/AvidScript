# P17.0 Editor C# 绑定入口范围

## 目标

Phase 17 的目标是把 Phase 16 已完成的 C# report/manifest 组件绑定服务，包装成用户可在 Editor 中直接触发的入口。

完成后，PC Editor 侧的 C# 最小使用链路应变成：

1. 编写或修改 `Samples/CSharp/ActorLifecycle/ActorLifecycleScript.cs`。
2. 运行 `BuildCSharpActorLifecycle.ps1` 生成 direct ABI WASM、manifest 和 C# build report。
3. 在 UE Editor 中选中目标 Actor。
4. 通过 `Tools > AvidScript > Bind C# ActorLifecycle Script` 把最新 C# report 绑定到该 Actor 的 `UAvidScriptComponent`。
5. PIE/BeginPlay 时组件加载 C# 产物，并执行 `BeginPlay` / `Tick` 游戏逻辑。

## 范围

- 在 `FAvidScriptEditorModule` 中新增 C# ActorLifecycle 绑定菜单配置。
- 复用 `FAvidScriptEditorMenuRegistrar` 注册到 `LevelEditor.MainMenu.Tools` 的 `AvidScript` section。
- 复用 `FAvidScriptEditorComponentBindingService` 读取最新 C# report 并绑定到当前选中 Actor。
- 添加 automation 覆盖菜单配置和选中 Actor 绑定行为。
- 用中文记录该入口的使用方式、验证结果和剩余风险。

## 非目标

- 不做完整 Slate 面板或资产浏览器。
- 不做任意 C# 源文件选择。
- 不做批量绑定多个选中 Actor。
- 不改 C# source adapter 的语言子集。
- 不推进 packaging/mobile 验证。

## 验收标准

- 新入口有稳定 entry name、label、tooltip 和 execute action。
- 命令调用后能读取 `Saved/AvidScriptCSharpGuest/ActorLifecycle/actor_lifecycle.csharp.report.json`。
- 命令能对当前选中 Actor 自动创建或复用 `UAvidScriptComponent`，并写入 manifest 路径。
- `AvidScript.Editor.Module`、`AvidScript.Editor` 和完整 `AvidScript` automation 通过。
