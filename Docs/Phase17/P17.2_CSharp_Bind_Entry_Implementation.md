# P17.2 Editor C# 绑定入口实现

## 实现内容

Phase 17 在 `AvidScriptEditor` module 上新增 C# 绑定入口：

- `FAvidScriptEditorModule::GetCSharpActorLifecycleBindEntryName`
- `FAvidScriptEditorModule::GetCSharpActorLifecycleReportPath`
- `FAvidScriptEditorModule::MakeCSharpActorLifecycleBindMenuEntryConfig`
- `FAvidScriptEditorModule::ExecuteCSharpActorLifecycleBinding`
- `FAvidScriptEditorModule::HandleBindCSharpActorLifecycleReport`

Editor 启动后，`RegisterMenus` 会注册两个 `Tools > AvidScript` 菜单项：

- 既有 `.avid` sample command。
- 新增 `Bind C# ActorLifecycle Script`。

## 运行路径

新菜单项的执行路径如下：

1. 用户在 Editor 中选中一个 Actor。
2. 点击 `Tools > AvidScript > Bind C# ActorLifecycle Script`。
3. module 读取固定 report 路径：
   `Saved/AvidScriptCSharpGuest/ActorLifecycle/actor_lifecycle.csharp.report.json`。
4. module 调用 `FAvidScriptEditorComponentBindingService::ApplyCSharpReportToSelectedActor`。
5. 绑定服务解析 report 中的 `artifacts.manifest_file`。
6. 服务为 Actor 创建或复用 `UAvidScriptComponent`，写入 manifest 路径。
7. 后续 BeginPlay/Tick 由 `UAvidScriptComponent` 加载 C# WASM 并驱动游戏逻辑。

## 失败处理

命令失败时不会崩溃 Editor，而是通过 `LogAvidScriptEditor` 输出结构化 warning：

- `category`
- `message`
- `next`
- `report`

常见失败包括没有选中 Actor、C# report 缺失、report 不是 `direct_abi_built`、manifest 缺失或 report 指向不合法 manifest。
