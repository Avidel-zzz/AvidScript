# 已提交路径的保护移交

Phase 启动时的 dirty 快照不能永久阻止后来获得用户授权的功能或文档交付。
但不能以刷新整个快照的方式掩盖无关用户文件漂移。

受控命令：

```powershell
pwsh -NoProfile -File Build/InvokePhaseWorkflow.ps1 adopt-protected-path `
  -Phase <当前阶段> -Scope <精确路径> -Evidence <已提交哈希> -Reason "明确授权及移交原因"
```

仅允许实现期、尚未集中审查时执行；路径必须原本受保护、当前无暂存或未提交改动，证据必须是
HEAD 的祖先，且该阶段至证据提交之间确有此路径的提交。只移交该路径，其余保护原样保留。
授权仍由任务上下文确认，不把命令存在视为任意处置用户改动的权限。
