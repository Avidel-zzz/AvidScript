# P59.C2c2 Session Prepared Export Dispatch

## 目标

把 P59.C2c1 的不可变 UClass/type/member 注册表接入真实 Runtime Session，让生成 UObject thunk 能够用
`typeOrdinal + memberOrdinal` 进入预解析的 WASM 函数，而不是在每次调用时查找 export 或反射成员。

## 已实现

- `FAvidScriptRuntimeSession` 实现 `IAvidScriptGeneratedTypeInstance`，一个 Session 显式拥有一个
  receiver、稳定 ObjectHandle、type ordinal、共享 registry snapshot 和 move-only router registration。
- 配置阶段校验 receiver 继承关系、ObjectHandle、Session owner 一致性和可选 ObjectRegistry 反查；CDO、
  销毁中对象、重复 route、错误类型和 owner 漂移全部 fail closed。
- `FAvidScriptWasmRuntimeInstance::PrepareNamedExportCall` 在加载冷路径解析 canonical export 并生成
  backend-neutral `FAvidScriptVmPreparedExportCall`。
- 候选 Runtime 在 BeginPlay 和 live swap 前必须预解析当前类型的所有函数 export。任一 export 缺失或
  未携带 packed ObjectHandle receiver 时，整个候选事务被拒绝，旧 Runtime 与旧 prepared calls 保持有效。
- reload 成功后才原子替换 prepared-call 数组；卸载时立即清空 calls，但保留 receiver route 供后续重载；
  Session 销毁或显式 clear 时释放 route。
- 调用热路径只检查 Session/receiver/handle/generation 和数组边界，然后直接调用 prepared function。
  `i64 this` 按低 32 位 slot、高 32 位 generation 展开为两个 VM cells，不做字符串查找、JSON 解析或
  UE 反射扫描。
- 首批固定 codec 支持：`(this)->void`、`(this)->int32`、`(this, float)->void`。它们覆盖无参函数、
  int32 查询、BeginPlay/EndPlay/Initialize/Deinitialize、Tick 和示例 `Activate(float)`；其他签名保留
  export 计划但在调用时 fail closed，等待后续 codec 扩展。

## 验证证据

- UE5.8 no-clean 增量 UBT：18 个动作，UHT、Runtime、Editor 全部成功，`Result: Succeeded`。
- focused Automation `AvidScript.Runtime.GeneratedTypes.SessionPreparedDispatch`：发现 1 条、执行 1 条、
  `Result={Success}`、Queue Empty、退出状态 0。
- GeneratedTypes 集中回归：Dispatcher、Registry、SessionPreparedDispatch 共 3 条，`3/3 Success`；
  结构解耦后再次运行结果不变。
- 测试使用真实 Wasmtime JIT 和最小 `(i64 this)->i32` WASM export，验证：
  - live Runtime 之前调用被封锁；
  - Dispatcher 经 Session prepared call 进入 WASM；
  - 返回值证明 ObjectHandle slot 已按 i64 ABI 传入；
  - reload 后新 prepared handle 生效，没有使用旧 backend generation；
  - unload 后调用立即失败，显式 route teardown 成功。

## 当前边界

本小节完成了普通生成 UFunction 的第一条执行闭环，但脚本定义类型的生命周期仍需专用 activation：
现有 Session activation 会调用全局 `avid_on_begin_play`，生成 shell 又会调用类型专属 canonical export；
下一小节必须把 generated-type Session 切换为 shell 驱动的 BeginPlay/Tick/EndPlay，避免双触发。

完整四类型样例中的 UPROPERTY getter/setter import 也尚未注册到 Runtime binding package，因此这里不把
手工验证过的函数执行链声明为完整样例可玩闭环。后续将继续实现 generated property imports、复杂参数/
返回值 codec 和 Blueprint 子类实例接线。
