# P59.B4 Headless C# Binding 发布入口

## 结果

Editor module 新增受控命令：

```text
AvidScript.PublishCSharpBindings [output-root] [exit]
```

它直接复用 `FAvidScriptEditorCSharpBindingEmitter::PublishEngineGameplay`，发布 descriptor、generated C#
reference source 和 package manifest，不复制 facade 或反射选择逻辑。

## 启动期安全

`-ExecCmds` 在 Editor 启动第 0 帧执行。第一次验证发现，直接进入 reflection publication 会等待仍需
Game Thread 推进的 AssetRegistry，导致命令和后续 `Quit` 都不再前进。

修复后的命令：

- AssetRegistry 已就绪时同步发布；
- Registry 仍在加载时注册 `OnFilesLoaded`，立即把控制权还给 Editor；
- module shutdown 会移除尚未触发的 delegate；
- 显式 `exit` 在发布完成后调用 `RequestExitWithStatus`，成功为 0、失败为 1；
- 交互式 Editor 调用不带 `exit`，不会意外关闭用户 Editor。

该事故已写入 `AgentHarness/lessons/rules.json`，规则 id 为
`editor-startup-commands-defer-reflection-discovery`。

## 验证

- 源码版 UE5.8 no-clean Editor build：成功，最终候选 12 actions；
- headless 命令在第 0 帧记录 queued；
- AssetRegistry ready 后发布成功并退出 0；
- package hash：`8d23e6867bb3c09a40910bee678ff8fc74e70315a784e7b7e7f9f8f5cd23005a`；
- reference source 与 manifest 位于项目 `Saved/AvidScriptGeneratedBindings/avidscript.engine.gameplay/`
  的内容寻址目录，不进入 Git。
