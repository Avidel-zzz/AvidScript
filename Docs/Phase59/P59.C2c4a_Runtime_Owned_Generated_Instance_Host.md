# P59.C2c4a Runtime-owned 生成实例 Host

## 目标

移除脚本定义 UObject 依赖外部代码手工拼装 `ObjectRegistry + ObjectHandle + RuntimeSession + router`
的要求，为生成 shell 提供单一的 Runtime 实例所有者。

## 已实现

- 新增进程内 `FAvidScriptGeneratedTypeRuntimeHost`，由 `AvidScriptRuntime` module 在 router 安装后启动、
  在 router 卸载前关闭。
- Host 安装一份不可变 generated type registry snapshot 和对应 Runtime artifact；已有活跃实例时禁止
  替换或清空 package，避免 registry、WASM 与 prepared call generation 漂移。
- `BeginInstance` 在 GameThread 上按 type ordinal 校验真实 UClass，集中创建并拥有：
  - anchored `ObjectHandle`；
  - 绑定 World、ObjectRegistry 和 owner handle 的 `FAvidScriptRuntimeSession`；
  - generated receiver route；
  - 已验证并完成 canonical export prepare 的 Runtime artifact。
- 任一步失败都会逆序释放 Session、route 和 ObjectHandle，不发布半初始化实例。
- `EndInstance` 先停止并卸载 Session，再注销 route，最后释放 ObjectHandle；module shutdown 复用同一
  teardown 顺序，不依赖 UObject 析构顺序。
- Host 不进入 generated dispatch 热路径；shell thunk 仍通过 router 直接到 Session prepared call。

## 当前边界

本小节建立 Runtime 所有权内核，但生成 shell 尚未调用 `BeginInstance/EndInstance`，正式 type manifest
和 `.avidscript.json` artifact 也尚未自动安装。它们分别由 C2c4b 与 C2c4c 接入。

## 验证范围

- UE5.8 source Editor no-clean UBT：首次旧 action graph 未收录新增 `.cpp`，使用 `-gather` 仅刷新
  makefile 后 4 个增量动作成功，未清理 Editor target；
- focused Automation `AvidScript.Runtime.GeneratedTypes.RuntimeHost`：`1/1 Success`；
- GeneratedTypes 集中回归：Dispatcher、Registry、RuntimeHost、SessionPreparedDispatch 共
  `4/4 Success`；
- Automation 使用真实 Wasmtime JIT 和最小 canonical export；
- 验证 package 安装、自动 handle、Session、route、prepared dispatch 与返回值；
- 验证 EndInstance 后 Session 数、router route 与 ObjectHandle 全部归零。
