# P59.A UE 类型声明合同实现

## 1. 本节结果

P59.A 已建立从 C# 语法到版本化 UE 类型声明合同的完整前端链路：

```text
[UClass]/[UProperty]/[UFunction]
  -> Roslyn canonical symbol
  -> SemanticUeTypeProjector
  -> semantic schema 18 / version 1.20
  -> ue_type_declarations
  -> Guest fail-closed validator
```

这不是字符串扫描或逐类配置。属性、类型、继承、成员和覆写都来自 Roslyn symbol，输出按稳定
symbol id 排序，后续 P59.B 的 UHT shell generator 只消费该合同。

## 2. 用户可写表面

generated C# facade 现在提供：

- `[UClass]`：`Name`、`Blueprintable`、`BlueprintType`、`Abstract`、`NotPlaceable`、`Transient`；
- `[UProperty]`：编辑/可见性、Blueprint 访问、Replication/RepNotify、SaveGame、Transient、Category；
- `[UFunction]`：Blueprint callable/pure/event、RPC direction/reliability、Category；
- `AvidActor`、`AvidActorComponent`、`AvidWorldSubsystem`、`AvidGameInstanceSubsystem` 标记基类；
- 标记基类中的生命周期虚方法，为后续 Session dispatch 保留规范覆写入口。

示例见 `Samples/CSharp/ScriptDefinedTypes/ScriptDefinedTypes.cs`。

## 3. Semantic 合同

新增 `SemanticUeTypeDeclaration`：

- `type_id` 与 `symbol_id`：绑定现有 semantic type/symbol registry；
- `engine_name`：不含 C++ `A`/`U` 前缀的 UE 反射逻辑名；
- `kind`：`actor`、`actor_component`、`world_subsystem`、`game_instance_subsystem`；
- `base_type_id`：保存直接标记基类或脚本基类身份；
- `flags`、`properties`、`functions`：仅保存生成 UE shell 需要的规范信息；
- 函数签名继续由 `SemanticCallable` 唯一拥有，避免产生第二套 ABI。

脚本继承会递归继承根类别，但保留直接基类 id。C# `override` 被规范化为 function flag，P59.C
将据此建立 prepared parent/override route。规范标记基类上的 `BeginPlay`、`Tick`、`EndPlay`、
`Initialize` 和 `Deinitialize` 被覆写时会自动进入 `lifecycle + override` 合同，不要求用户重复添加
`[UFunction]`。

## 4. Fail-closed 规则

当前会拒绝：

- 非顶层、static、泛型或非 `partial` 的 `[UClass]`；
- 未继承规范标记基类或脚本 UClass 的类型；
- 重复或非法 engine name；
- static/indexer/非法成员上的 `[UProperty]`；
- 相互冲突的编辑与 Blueprint property flags；
- 找不到合法无参 `void` 方法的 `ReplicatedUsing`；
- static/泛型 `[UFunction]`；
- 冲突的 Blueprint event、RPC direction 和 reliability flags；
- semantic artifact 中伪造的类型、成员、callable 或重复 class identity。

同名伪属性不会被接受，只有 `AvidScript.UClassAttribute` 等 canonical symbol 可以产生合同。

## 7. 当前边界

P59.A 只完成声明、序列化、缓存、发布和验证合同：

- 尚未生成 `.h/.cpp` native shell；
- Editor 中还不会出现由 C# 声明产生的真实 `UClass`；
- 还不能以该类型创建 Blueprint 子类；
- marker lifecycle 还未连接 Runtime Session；
- property/function flags 已验证但尚未交给 UHT。

这些能力属于 P59.B/P59.C/P59.D，不能把本节的 semantic 结果描述成 Runtime 已完成。
