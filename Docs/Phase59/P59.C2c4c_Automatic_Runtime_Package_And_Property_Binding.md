# P59.C2c4c 自动 Runtime Package 与属性绑定闭环

## 目标

让 `BuildCSharpScriptTypes.ps1` 的产物能够在 Editor 启动时自动安装，并让脚本定义类型的实例在
Wasmtime JIT 中执行 C# UFunction 时直接读写对应的 UE `UPROPERTY`。游戏代码不再手工拼装
registry、WASM artifact 或 Runtime Session。

## 构建与安装

- `BuildCSharpScriptTypes.ps1` 默认继续调用既有 C# Runtime 构建链，原子发布
  `AvidScriptGeneratedPackage.json`；描述符记录 generation key、类型 manifest、Runtime manifest、
  package id 和 `wasmtime_jit` 后端。
- 该描述符是本机构建产物，已加入 `.gitignore`，不会把项目绝对路径、用户信息或缓存文件提交到仓库。
- `AvidScriptGenerated` 模块启动时发现描述符后自动安装 package；没有描述符时保持静默可用，不影响
  未启用脚本定义类型的项目。
- Runtime Host 将描述符、类型 manifest 和 Runtime manifest 约束在项目目录内，逐文件校验 SHA-256，
  再校验 package id、module id、generation key 与 registry schema，任何不一致都 fail closed。
- 安装成功后，Actor、Component 和 Subsystem 的生成 shell 会按 C2c4b 的生命周期 hook 自动创建与
  释放 Session。

## UPROPERTY 热路径

- Registry 在构建时解析并缓存准确的 `UClass*` 与 `FFloatProperty*`。
- 每个实例 Session 根据 Runtime manifest 的实际 import 集合选择能力，不会为未引用属性扩大授权面。
- C# 对象引用沿用 Guest IR 的 64 位 packed ObjectHandle ABI：getter 为 `(i64)->f32`，setter 为
  `(i64,f32)->void`。
- Wasmtime typed host import 只接受 Runtime 创建的 supplemental authority；普通 binding package、
  脚本导入名称或伪造 ordinal 都不能获得该能力。
- 调用热路径仅解包并比较 slot/generation、校验弱引用与预期 UClass，然后通过缓存的
  `FFloatProperty*` 直接读写容器；没有名称查找、manifest 解析或动态分配。
- 同一模块包含多个脚本类型时，每个 Session 都定义完整实际 import 集合，但属性上下文只允许与当前
  receiver 类型兼容的调用。

## 测试隔离

正式 package 会在 Editor 启动时创建 `UEncounterSubsystem` 脚本实例，因此旧测试不能再假设全局
Router/Host 为空。Dispatcher 测试改为检查相对路由基线，RuntimeHost descriptor 测试使用独立 host，
避免测试替换或清理真实运行 package。

新增 `AvidScript.GeneratedTypes.CSharpPropertyInteraction`：生成 `AProjectile` 获得真实 Runtime Session，
以 UE 初值 `Damage=25` 调用示例 C# 的 `Damage *= 2.0f`，最终回读 UE 属性为 `50`。该用例覆盖
C# -> WASM export -> prepared property getter/setter -> UE `FProperty` 的完整交互链。

## 验证结果

- 真实 `ScriptDefinedTypes.cs`：`4` 个 UE 类型、`8` 个 exports、`2` 个属性 imports，WASM SHA-256 为
  `a7e4b55e4b9dde4c2c67e848004f814fa3a789137f7ec0cd7c4bc1b087b0a701`。
- 自动 package id：`8f797b0217e8e8939787495bf3a595bfecab271635bbe6dccdbf6ce507ae3a8d`。
- 源码版 UE5.8 增量 UBT：最终 `14` 个 action 成功；新增测试源仅使用 `-gather` 更新 action graph，
  未清理 Editor Target。
- `AvidScript.Runtime.GeneratedTypes`：`4/4 Success`。
- `AvidScript.GeneratedTypes.CSharpPropertyInteraction`：`1/1 Success`。
- 启动日志不再出现 generated package 安装失败、`EncounterSubsystem` activation 失败或属性 import
  类型不兼容。

## 当前边界

- 当前 prepared property codec 只实现生成器现有样例所需的 `float`；其他属性类型继续 fail closed，
  后续应由共享 codec 表批量扩展，而不是手写逐 API binding。
- C# 属性初始化器尚未接入 UE 对象构造/初始化流程；本小节验证的是已存在 UE 属性值上的读写交互。
- 使用普通 UE API 的生成模块仍保留其 binding package；只有所有实际 imports 都由生成属性 registry
  精确覆盖时，Runtime Host 才会移除无关的 package owner 限制。
