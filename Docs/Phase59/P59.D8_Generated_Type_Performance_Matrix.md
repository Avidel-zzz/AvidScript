# P59.D8 Generated Type 四轴性能矩阵

## 目标

为 P59 脚本定义 UE 类型建立可重复的真实 Runtime 性能基线。单个 Automation 用例分别报告：

- generated native shell 到 Runtime router 的完整调用；
- 跳过生成 shell、直接进入已准备 WASM export 的调用；
- 执行 C# `Activate` 并读写五个 UE 原生标量属性的调用；
- 同一生成 Actor 的 Session `EndInstance + BeginInstance` 生命周期交叉。

四条路径都使用真实 `AProjectile`、ObjectHandle、Session 和 Wasmtime JIT，不使用空 mock、按名称
反射查找或为单个 UE API 手写的快捷实现。

## 结果

测试环境为 UE5.8 源码版、Win64 Development Editor、Wasmtime 45。热路径每组 11 个样本、
每样本 2000 次；生命周期路径每组 7 个样本、每样本 32 次。

| 路径 | p50 | p95 | 语义范围 |
| --- | ---: | ---: | --- |
| native shell dispatch | 68.700 ns | 92.850 ns | 生成 C++ shell、dispatcher、router、prepared export |
| prepared WASM export | 61.200 ns | 66.200 ns | router、Session、prepared export 与返回值 |
| prepared property access | 196.300 ns | 289.050 ns | `Activate(1.0)` 内五个原生标量属性更新 |
| lifecycle crossing | 1.611 ms | 1.649 ms | Session End、资源回收、Session Begin 与重新准备 |

本矩阵的门禁是正确性、有限正值和灾难性上限；它不把单机微小抖动当成回归，也不把四种不同语义
工作量直接相除后宣称相对性能。后续优化应在相同硬件、相同 workload 和相同语义下维护历史基线。
