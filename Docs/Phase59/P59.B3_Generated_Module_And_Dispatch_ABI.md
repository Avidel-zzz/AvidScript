# P59.B3 生成模块与 Dispatcher ABI

## 结果

插件新增永久 Runtime module `AvidScriptGenerated`，项目脚本生成的 shell 具有稳定编译归属：

```text
AvidScriptGenerated
  -> private AvidScriptRuntime
  -> Core / CoreUObject / Engine
```

`AvidScriptRuntime` 不反向依赖 `AvidScriptGenerated`。项目特定的 generated header/source/manifest 已加入
`.gitignore`，模块骨架与 ABI 仍由插件 Git 管理。

## Dispatcher ABI

新增 `FAvidScriptGeneratedTypeDispatcher` 与 `IAvidScriptGeneratedTypeDispatchTarget`：

- shell 只传 `UObject`、dense type ordinal、member ordinal、参数地址视图与可选返回槽；
- 热路径没有 `FName`、`FindFunction`、`FindObject` 或 class path 查询；
- Runtime router 使用原子 owner 注册，重复安装同一 owner 幂等，竞争 owner fail-closed；
- `Uninstall` 先阻止新 owner 安装，再清空 target，并等待所有在途 dispatch 退出；
- 卸载不得从 target 自身回调内重入，P59.C teardown owner 必须在 dispatch 栈外执行。

这个 target 是全局入口，不等于单 Session。P59.C 的 Runtime router 将依据 Receiver 的 world/object identity
选择 Session-owned instance，生成 module 不持有 Session 或 VM。
