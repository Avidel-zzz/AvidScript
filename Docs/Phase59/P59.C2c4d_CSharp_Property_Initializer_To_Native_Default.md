# P59.C2c4d C# 属性初始化器与 UE 原生默认值

## 目标

让脚本定义 UE 类型中的确定性 C# 属性初始化器成为真实 UObject 默认状态。例如：

```csharp
[UProperty(EditAnywhere = true, BlueprintReadWrite = true)]
public float Damage { get; set; } = 25.0f;
```

生成的 `AProjectile` 必须在实例创建时拥有 `Damage=25`，随后 C# 游戏逻辑可通过既有
WASM prepared property codec 读写该原生 `UPROPERTY`。

## 状态所有权

- 原生 `UPROPERTY` 继续是唯一状态 owner；WASM 不保存一份镜像默认值。
- 初始化器由生成的 UE C++ 构造函数写入 CDO 和新实例，不在 `BeginPlay` 或 Session 激活时补写。
- 脚本 body reload 不会重新执行 UObject 构造，因此不会覆盖运行中的关卡状态。
- 脚本继承沿用 C++ 构造链：基类初始化器先执行，派生类型只写入自己声明的默认值。

该语义与 UE 的对象创建、编辑器默认值和后续 Blueprint 子类验证方向一致，也避免把冷路径默认值处理
塞进 WASM 调用热路径。

## 契约与生成链

Semantic UE Type Declaration Contract 升级为 schema `19` / version `1.21`，属性新增可空的
`initializer`：

```json
{
  "kind": "float32",
  "canonical_value": "25"
}
```

Roslyn projector 只接受能确定求值的 primitive 编译期常量。当前支持：

- `bool`；
- `byte/sbyte/short/ushort/int/uint/long/ulong`；
- `float/double`；
- `string`。

非确定表达式、对象构造和值类型构造当前使用 `ASUE1105` fail closed，禁止静默忽略。数值使用 invariant
canonical value，生成器再按目标 C++ 类型添加显式 cast 或 suffix。

UeTypeGenerator manifest 升级为 schema `5` / generator `1.4`。具有初始化器的类型会生成显式默认
构造函数；真实样例产生：

```cpp
AProjectile::AProjectile()
{
    Damage = 25.0f;
}

UHealthComponent::UHealthComponent()
{
    CurrentHealth = 100.0f;
}
```

Runtime Registry 同步冻结为 manifest `5/1.4`。旧清单仍会被拒绝，不通过兼容分支绕过版本验证。

## 完整交互证明

`AvidScript.GeneratedTypes.CSharpPropertyInteraction` 不再在测试中手工设置 `Damage=25`：

1. UE 生成并 Spawn `AProjectile`；
2. 在 BeginPlay 前确认原生实例默认值为 `25`；
3. Runtime Host 为实例建立 Session 与 packed ObjectHandle；
4. 调用 C# `Activate(2.0f)`；
5. WASM 通过 prepared getter 读取 `25`，执行 `Damage *= damageScale`；
6. prepared setter 写回原生 `UPROPERTY`，UE 回读为 `50`。

## 当前边界

- 初始化器支持面已覆盖 primitive 常量，但 prepared UPROPERTY codec 目前仍只覆盖 `float`；其余类型需
  通过共享 codec 表批量扩展。
- `FVector` 等 UE 值类型初始化、对象引用、容器默认值尚未进入确定性 initializer contract。
- Blueprint 子类继承/覆写脚本默认值、CDO 保存重载与 Cook 验证属于 P59.D 集中集成门禁。
