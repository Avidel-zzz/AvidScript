# P59.B1 共享生成合同校验

## 结果

P59.B1 把 UE 类型生成所需的严格读取与合同校验提升到 `AvidScript.CSharpSemantic` 公共所有者：

```text
semantic artifact
  -> SemanticSerializer.Deserialize
  -> SemanticUeTypeContractValidator
  -> Guest lowerer / UHT shell generator
```

Guest 和后续生成器不再各自复制 JSON 读取选项、类型类别、flag 白名单和交叉引用校验。

## Fail-closed 边界

共享校验器当前会拒绝：

- 缺失、重复或未稳定排序的类型、symbol、callable 与 UE declaration identity；
- 非法 engine/property/function 标识符；
- 不存在或所有权不匹配的 type、symbol、callable 交叉引用；
- 不受支持、冲突或伪造的 class/property/function flags；
- 同一 UClass 中冲突的 property/function 反射名；
- 不落到规范 Actor、Component、WorldSubsystem、GameInstanceSubsystem 根的继承；
- 继承环或跨 kind 的脚本继承；
- schema 18 之前伪造的 `ue_type_declarations`。

错误返回稳定的英文机器诊断，面向项目开发者的说明继续由中文 Phase 文档承载。
