# P59 集中 Gate 报告

## 结论边界

P59.A-D 已形成从 C# 声明、UHT shell、真实 `UClass`、Blueprint 子类到 Wasmtime 游戏逻辑的
产品闭环。阶段只有在冻结候选通过统一 Gate、attestation 和 close 后才标记完成；精确候选身份、
日志哈希与计数由 `P59_Gate_Summary.json` 记录，本报告不复制易漂移的运行身份。

## 能力验收映射

| 验收能力 | 自动证据 |
| --- | --- |
| C# Actor 的 BeginPlay、Tick、EndPlay | GeneratedTypes lifecycle 与真实 WASM Session |
| C# Component、WorldSubsystem、GameInstanceSubsystem | 四类 owner 创建、Tick、销毁与 teardown |
| UPROPERTY、RepNotify、默认值 owner | 原生 FProperty flags、CDO/实例默认值、WASM property codec |
| UFUNCTION、继承、override、parent call | 真实 generated shell、最派生 route 与 C# base call |
| Blueprint 子类 | 创建、编译、保存、卸载、重载、Spawn 和 Parent Call Automation |
| body-only reload 与结构变化 | transaction commit/rollback 与 NativeRebuildRequired 分类 |
| 网络闭环 | dedicated server + 2 clients、listen server + remote client 独立进程 |
| Cook 发布布局 | 内容寻址 bundle、哈希复核、当前文件 NonUFS staging 与 isolated load |

## 统一 Gate

冻结候选只运行一次集中矩阵：

- 固定 .NET SDK 的 Semantic、Guest、Frontend、Guest IR、WASM Backend、UE Type Generator；
- PowerShell parser、发布/缓存/构建合同、reload/Cook/Harness 合同；
- UE5.8 源码版 `AvidTPSTemplateEditor Win64 Development` no-clean UBT；
- 完整 `AvidScript` Automation，核对 Found、Completed、Success、Fail、Queue Empty 和退出状态；
- 干净 detached worktree 架构检查；
- `AvidScript.Performance.GeneratedTypeMatrix` 四轴性能矩阵。

任何产品源码变化都会使候选失效并重新冻结。普通低风险问题集中记录，不在 Gate 中扩展产品范围。

## 性能基线

本机 Generated Type p50/p95：native shell `68.700/92.850 ns`、prepared export
`61.200/66.200 ns`、五属性脚本体 `196.300/289.050 ns`、Session lifecycle pair
`1.611/1.649 ms`。完整方法见 `P59.D8_Generated_Type_Performance_Matrix.md`。
