# P59.C2c4e 表驱动标量 UPROPERTY Codec

## 目标

把脚本定义 UE 类型的 prepared property 交互从单一 `float` 扩展到常用游戏标量，同时保持：

- 不为每个属性或 UE API 手写 wrapper；
- UObject 与原生 `UPROPERTY` 是唯一状态 owner；
- packed ObjectHandle 继续是 WASM `this` 身份；
- 热路径不做名称查找、反射发现或分配；
- package-backed 与 supplemental runtime authority 不互相越权。

## ABI 分层

VM typed-host contract 新增 packed property shape，按 WASM cell 家族而不是 C# 属性名组织：

| 家族 | getter | setter | 当前 UE 属性 |
| --- | --- | --- | --- |
| `i32` | `(I)i` | `(Ii)` | `bool`、`int32` |
| `i64` | `(I)I` | `(II)` | `int64` |
| `f32` | `(I)f` | `(If)` | `float` |
| `f64` | `(I)d` | `(Id)` | `double` |

`I` 表示 packed `ObjectHandle`。Wasmtime C bridge 为四个家族提供固定 functype 与 unchecked
trampoline；C++ backend 只把匹配 shape 的 prepared target 交给 linker。

## Runtime Codec 表

Session 配置阶段遍历不可变 generated type registry，通过 `FGeneratedPropertyCodecDescriptor` 表选择
属性 adapter，并把已经验证的 `FProperty*`、receiver UClass、ObjectHandle 和读写函数指针保存到
instance-owned context。

调用阶段只执行：

1. 解包并比较 ObjectHandle slot/generation；
2. 校验 GameThread、弱引用、实际 UClass 与销毁 flags；
3. 调用缓存的标量读写函数；
4. 返回 typed-host status。

`CastField` 只存在于 Session 配置冷路径。架构 Gate 对 `GetGeneratedScalarProperty` /
`SetGeneratedScalarProperty` 热路径切片禁止 `CastField`、`FindFProperty`、`FindFunction`、`GetName` 和
`MakeUnique`。

## Authority 修复

集中 VM 回归发现 Wasmtime Load 曾把完整 typed import 集合传入 supplemental policy。生成属性全部是
supplemental authority，因此此前闭环没有暴露问题；package-backed TypedHost 则会被错误拒绝。

现在 Load 冷路径先按 `bSupplementalRuntimeAuthority` 分类：

- import policy 只接收 supplemental 子集；
- typed linker validator 仍接收完整集合；
- package-backed imports 继续精确验证 stable id、ordinal 和 signature；
- supplemental imports 必须具有与 shape 完全匹配的 prepared target。

## 真实 C# 闭环

`Projectile.Activate` 同时执行：

```csharp
Damage *= damageScale;
ActivationCount += 1;
AccumulatedDamage += 25L;
PrecisionScale *= 2.0;
IsActive = true;
```

测试从生成构造默认值开始，最终在 UE 原生对象回读：

- `Damage`: `25 -> 50`；
- `ActivationCount`: `1 -> 2`；
- `AccumulatedDamage`: `100 -> 125`；
- `PrecisionScale`: `1.5 -> 3.0`；
- `IsActive`: `false -> true`。

正式产物包含 `4` 个 UE 类型、`8` 个 exports 和 `9` 个实际 property imports。WASM SHA-256 为
`b877841255fa875a92e74210a23cd08d82bee5437c683ecbfc5c23608fb8767c`，package id 为
`a949af6d6a901c52311d09d8af81d6ffab694a36a3a456d1199ec1f121418ee7`。

- 正式 `BuildCSharpScriptTypes.ps1`：成功；
- 源码版 UE5.8 no-clean UHT/UBT：首次完整重编 `24` actions、最终增量 `4` actions，均成功；
- `AvidScript.VM.Wasmtime.TypedHost`：`1/1 Success`；
- `AvidScript.GeneratedTypes`：`2/2 Success`；
- `AvidScript.Runtime.GeneratedTypes`：`4/4 Success`。

## 当前边界

- 本小节只覆盖最常用的五种 scalar property；`byte/sbyte/short/ushort/uint/ulong` 需要增加严格的
  range/bit-preserving adapter 后再进入同一 codec 表。
- `string`、对象引用、`FVector` 等值类型和容器需要 guest linear-memory codec，不应伪装成 scalar cell。
- RepNotify、Blueprint 默认值覆写和网络复制仍在 P59.D 集中验证。
