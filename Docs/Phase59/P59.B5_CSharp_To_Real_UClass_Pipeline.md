# P59.B5 C# 到真实 UClass 的受控流水线

## 结果

新增统一入口 `Build/BuildCSharpScriptTypes.ps1`，把脚本定义类型从 C# 源码推进到真实 UE 生成模块：

```text
C# source
  -> validated binding package
  -> Roslyn frontend
  -> semantic schema 18 / 1.20
  -> deterministic UeTypeGenerator
  -> Source/AvidScriptGenerated
  -> UHT / UBT
  -> UE reflection
```

入口复用现有 binding package 解析器，并在执行每一层前后复核 SDK、source identity、package
reference、semantic schema、manifest identity 和输出文件 SHA-256。它不接受绝对或含父目录跳转的
`SourceId`，也不在脚本内固化某个 binding package hash。

## 首个真实类型集合

`Samples/CSharp/ScriptDefinedTypes/ScriptDefinedTypes.cs` 当前生成并加载了 4 个类型：

| C# 声明 | UE native shell | 已验证合同 |
| --- | --- | --- |
| `Projectile` | `AProjectile : AActor` | 属性、函数、复制、`BeginPlay` |
| `ExplosiveProjectile` | `AExplosiveProjectile : AProjectile` | 脚本继承与函数覆写 |
| `HealthComponent` | `UHealthComponent : UActorComponent` | 反射属性 |
| `EncounterSubsystem` | `UEncounterSubsystem : UTickableWorldSubsystem` | Subsystem 与反射函数 |

生成 source 内附带 `AvidScript.GeneratedTypes.Reflection` 自描述 Automation。测试按稳定 type/member
ordinal 回读 `StaticClass`、直接父类、`FProperty` 和 `UFunction`，因此后续新增样例类型不需要手写一份
并行反射清单。

## 增量与所有权

- 生成器只发布固定的 header、source 和 manifest，manifest 最后原子发布；
- 内容未变化时保持字节和时间戳，避免无意义 UHT/UBT；
- 生成文件继续由 `.gitignore` 排除，Git 保存生成器、输入与合同，不保存本机产物；
- `AvidScriptGenerated` 只依赖 Runtime/Core/Engine，Runtime 不反向依赖项目生成模块；
- 函数 thunk 只按稳定 ordinal 调用 dispatcher，不在热路径做名字反射查找。

## 当前边界

本节证明 C# 声明已经成为 UE 可加载、可反射、可继承的真实 native shell。dispatcher 目标尚未绑定到
Session-owned script instance，所以 `BeginPlay`、Tick 和普通 `UFUNCTION` 的 C# body 仍然 fail-closed
返回默认值。P59.C 将完成实例注册、生命周期路由、继承覆写和热重载迁移；在该批次完成前，不能把
本节描述成游戏逻辑执行闭环已经完成。
