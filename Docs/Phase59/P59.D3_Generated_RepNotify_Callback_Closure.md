# P59.D3 Generated RepNotify 回调闭环

## 目标

验证脚本定义 `UPROPERTY(ReplicatedUsing=...)` 不只生成可编译文本，而是形成 UE 反射元数据、生成壳层、
Runtime Session 和 C# WASM 回调之间的可执行闭环。

## 实现

`Projectile.Damage` 继续由 C# 声明复制通知：

```csharp
[UProperty(
    EditAnywhere = true,
    BlueprintReadWrite = true,
    ReplicatedUsing = nameof(OnRepDamage),
    Category = "Projectile")]
public float Damage { get; set; } = 25.0f;
```

本节增加可观察的原生状态：

```csharp
[UProperty(BlueprintReadOnly = true, Category = "Projectile")]
public int DamageRepNotifyCount { get; private set; }

[UFunction]
private void OnRepDamage()
{
    DamageRepNotifyCount += 1;
}
```

生成模块继续使用 `UPROPERTY(ReplicatedUsing=OnRepDamage)`、`DOREPLIFETIME` 和普通 UFunction 壳层。
`OnRepDamage` 的函数体不复制到 C++，而是通过既有 type/member ordinal 和 ObjectHandle 进入 Wasmtime；
计数器的读写仍由原生 UPROPERTY 作为唯一状态 owner。

## 自动验证

新增 `AvidScript.GeneratedTypes.CSharpRepNotifyInteraction`：

1. 创建真实 Game World 并 Spawn `AProjectile`；
2. 启动 Actor，确保 generated type Runtime Session 已建立；
3. 从 `AProjectile::StaticClass()` 读取 `Damage` 的 `FFloatProperty`；
4. 断言属性包含 `CPF_Net` 和 `CPF_RepNotify`；
5. 断言 `RepNotifyFunc == OnRepDamage`；
6. 通过 UE `ProcessEvent` 调用反射解析出的 `OnRepDamage`；
7. 断言 C# WASM 将 `DamageRepNotifyCount` 从 `0` 更新为 `1`。

测试没有引入按 API 手写 wrapper，也没有为 RepNotify 建立第二套调度器。
