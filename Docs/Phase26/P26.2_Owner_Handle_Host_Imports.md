# P26.2 Owner Handle Host Imports

状态: Done

## 实现

`FAvidScriptWasmHostContext` 新增 `OwnerHandle`，`UAvidScriptComponent` 在注册 owner 后把 registry、owner handle 和 Actor 写策略一起注入 runtime。

新增 WAMR imports：

```text
env.owner_get_slot() -> i32
env.owner_get_generation() -> i32
```

两个 imports 同时注册在 canonical `avidscript` 模块和现有 `env` compatibility alias 下。

## 安全行为

handler 返回数值前会检查：

- object registry 已注入。
- owner handle 的 slot/generation 非零。
- registry 能用当前 generation 解析到仍然存活的 UObject。
- slot/generation 可以由当前 i32 ABI 表示。

任一条件失败都会设置 pending host import failure；WAMR wrapper 同时设置 guest exception。raw `UObject*` 和宿主地址不会进入 guest。

## 测试

`AvidScript.Runtime.WasmActor.DirectHandlerSmoke` 覆盖有效 handle 与 stale generation，`AvidScript.Runtime.WasmActor.MissingContextSmoke` 覆盖未注入 context。
