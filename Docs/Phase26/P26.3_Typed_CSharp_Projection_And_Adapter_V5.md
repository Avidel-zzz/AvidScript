# P26.3 C# 类型投影与 Adapter v5

状态: Done

## C# API

默认样例新增：

- `[StructLayout(LayoutKind.Sequential)] readonly struct FVector`
- 只保存 slot/generation 的 `readonly struct AActor`
- 从 owner imports 构造句柄的 `UE.Self`

默认 gameplay 写法：

```csharp
UE.Self.SetActorLocation(new FVector(100.0f, 200.0f, 300.0f));
UE.Self.AddActorWorldOffset(new FVector(1.0f, 0.0f, 0.0f));
UE.Self.SetActorLocation(FVector.Zero);
```

旧 `Actor.SetLocation(...)` 与 `Actor.AddLocationOffset(...)` 继续保留。

## WASM 代码生成

adapter v5 使用四个 imports：

```text
0 actor_set_location
1 actor_add_location_offset
2 owner_get_slot
3 owner_get_generation
```

BeginPlay/Tick/EndPlay 的函数索引相应变为 4/5/6。typed statement 先调用 2/3 把 owner slot/generation 压栈，再调用 Actor import；新路径不再写死 1/1。

manifest/report 的 subset 为 `actor_lifecycle_v5`，contract 记录 `FVector`、`AActor`、`UE.Self` 和 typed methods。

## 非 slot 1 验证

source artifact 自动化先把 dummy `UWorld` 注册到 slot 1，再把目标 Actor 注册到后续槽位。BeginPlay、连续 Tick 和 EndPlay 均正确修改目标 Actor，证明 `UE.Self` 使用宿主注入句柄。
