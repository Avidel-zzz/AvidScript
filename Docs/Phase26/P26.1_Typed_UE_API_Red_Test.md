# P26.1 类型化 UE API RED 测试

状态: Done

## 测试目标

Phase26 先用测试锁定以下合同：

- C# 样例必须声明 `FVector`、`AActor`、`UE.Self`。
- typed Actor 调用必须使用宿主注入的 owner handle。
- manifest 必须升级为 `actor_lifecycle_v5` 并声明两个 owner imports。
- owner handle 缺失或 stale generation 时必须 fail closed。
- 端到端样例必须在目标 Actor 不位于 slot 1 时仍可运行。

## RED 证据

```text
error C2039: "OwnerHandle" 不是 "FAvidScriptWasmHostContext" 的成员
error C2039: "HandleOwnerGetSlotImport" 不是 "FAvidScriptWasmRuntimeInstance" 的成员
error C2039: "HandleOwnerGetGenerationImport" 不是 "FAvidScriptWasmRuntimeInstance" 的成员
```

这证明测试先描述了新的 host ABI，旧实现无法误通过。
