状态: Done

## 阶段结论

Phase26 已完成第一段类型化 UE API 闭环：

```text
UAvidScriptComponent owner
  -> object registry slot/generation
  -> owner_get_slot / owner_get_generation
  -> C# UE.Self / AActor
  -> FVector typed method
  -> Actor host import
  -> 真实 UE Actor
```

脚本作者现在可以使用 `FVector`、`AActor` 和 `UE.Self` 编写 Actor 位置写入逻辑，并继续接入 BeginPlay/Tick/EndPlay。

## 当前边界

- 已支持 Actor 位置写入，但还没有 `GetActorLocation()` typed 返回值。
- 已有 `FVector` 类型形状，但 adapter 还不支持局部向量变量和运算。
- 尚未覆盖任意 UE 反射 API、组件、Spawn、输入、Timer、碰撞事件、委托、`FRotator` 和 `FTransform`。
- 移动端尚未打包验证；当前 ABI 不暴露 raw pointer 或依赖 JIT。

下一阶段进入 typed read 与 FVector 表达式，再逐步扩展常用 Transform/组件 API 和绑定生成器。
