# P54.6D Generated Registry 与 Runtime 实施记录

## 范围

本批次把 P54.6B 生成的四类静态 call site 接入 BindingPackage、typed VM import
和 Runtime callback 生命周期。实现只修改 Task 4 owned paths；VM、GuestIr、
CSharpGuest、WasmBackend 以及 P54.6B generator/descriptor 文件均未由本任务修改。

## 实现

### Generated registry

- `FAvidScriptGeneratedBindingRegistry` 以 package 为发布单位，注册、注销和获取均限定
  Game Thread。
- `PackageHash` 与 `StableId` 必须是恰好 64 位的小写十六进制 SHA-256。
- package 内分别用两个全局集合验证 `StableId` 与 `DescriptorIdentity` 唯一性，避免
  非相邻 descriptor identity 重复漏检。
- entries 按 `StableId`、`DescriptorIdentity` 确定性排序，发布后只通过 const entry
  暴露。
- 每个 entry 仅允许与 shape 对应的一个函数指针非空。
- lease 持有共享 package state；注销先撤销 state，再从 registry 移除。旧 lease
  的 `IsActive()` 为 false，`GetEntry()` 返回空，生成模块卸载后不会调用陈旧地址。

### BindingPackage 与 typed imports

- generated descriptor 在 package load 时按 package hash、stable id、descriptor
  identity、shape 和 receiver mode 与 registry 精确连接。
- 缺失或已撤销的 generated package 使用稳定分类
  `generated_binding_unavailable`；active package 内身份、shape、receiver 或签名
  不一致使用 `generated_binding_mismatch`。
- qualified plan 直接保存 lease、immutable entry 指针和 typed import，不建立第二套
  ordinal cache。
- function、`property_get` 与 `property_set` 都进入同一 generated attachment 路径。
- `BuildTypedHostImports` 事务式检查全部 lease。任一 lease 失效时清空输出并返回
  `generated_binding_unavailable`，禁止发布 partial list。
- Runtime 在 backend `Load` 前构造 typed imports，并把自身同时作为 generic 与 typed
  dispatcher 注入；数组由 Runtime 持有到 backend `Unload` 完成。

### Receiver 与 callback epoch

- 每次 BeginPlay、Tick、EndPlay、timer、event 和 gameplay event export 调用建立独立
  callback epoch；嵌套调用使用 epoch 栈。
- Load/Unload、`SetHostContext` 与 `ClearHostContext` 均推进非零 reload/context
  epoch，并清空 Self capability。
- SelfBound 只接受与 `OwnerHandle` 完全相同的 slot/generation，并在当前
  callback/reload epoch 内缓存 weak object。
- StableBorrow 每次调用重新按 slot/generation 解析对象，并检查 generation、类型、
  ownership 和 world；不跨 callback 缓存裸指针。
- explicit null world 表示不约束 world；stale weak world 必须 fail closed，不能退化为
  null 语义。

### Guest memory 与调用安全

- property getter 在调用前短作用域借用并验证 4 字节输出，调用后重新借用并以
  little-endian 写入 i32；property setter 的第三参数是 scalar i32，不借 guest memory。
- vector 路径短作用域借用 24 字节，把输入复制到栈后释放 view；调用后重新借用并以
  little-endian 写入三个 f32 输出。
- object roundtrip 在调用前验证 8 字节输出，调用后重新借用并写入完整
  `{slot,generation}`。不会跨可能重入或触发 `memory.grow` 的 UE 函数持有 Wasmtime
  memory view。
- provider 不支持 borrow、地址/对齐无效、lease 撤销、thread/epoch/world/handle/type/
  ownership 校验失败时，专用 S1 import 直接 reject，不执行 generic fallback。
- `FallbackRequired` 计入 generated fallback counter 后转换为 reject，同一次调用不会
  双执行。

### Candidate reload

- normal path 在 journal 为空时保持 O(1)。
- generated property setter 在 thunk 前调用 `PrepareReflectedProperty`。
- generated function 按 plan 的 `ReloadEffect` 调用 `PrepareEffect`。
- `Unsupported`、BlueprintSetter 或缺少 registry 的 candidate effect 在 thunk 前
  reject。
- StableBorrow 使用 ABI 中实际 receiver handle，不误用 `OwnerHandle`。

## 测试覆盖

- registry lease 撤销、wrong thread、duplicate package、shape mismatch。
- package 内 non-adjacent descriptor duplicate、malformed package/stable SHA-256。
- call pointer shape/count 校验。
- HostContext replacement、callback/reload epoch、explicit null world 与 stale weak
  world。
- generated hit/fallback/reject 精确计数及专用 S1 fallback fail-closed。
- property journal、function journal 的实际 StableBorrow handle、unsupported effect、
  host read-only policy。
- package load 后、backend load 前撤销 lease 时 typed imports 全量失败且无 partial
  output。
