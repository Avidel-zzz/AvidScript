## 1. 范围

P54.1 建立 VM 后端身份、执行模式、制品格式、能力位、制品视图、通用 factory 和 export handle 实例归属。Runtime 生产路径不再直接硬编码 `CreateAvidScriptWamrBackend()`，默认行为仍保持 WAMR interpreter。

本批次没有启用 WAMR AOT/JIT，也没有接入 Wasmtime 执行代码。

## 2. 实现

- `AvidScriptVM/Public/AvidScriptVmBackend.h`
  - 增加 backend kind、execution mode、artifact format 和 capability；
  - 增加 backend info、selection 与 artifact view；
  - 增加通用 backend factory；
  - export handle 增加 backend instance identity。
- `AvidScriptVM/Private/AvidScriptVmBackendFactory.cpp`
  - 当前 WAMR interpreter 可创建；
  - Wasmtime 未接入时稳定返回 `backend_unavailable`；
  - 当前 WAMR AOT/JIT 请求稳定返回 `execution_mode_unavailable`。
- `AvidScriptVM/Private/AvidScriptWamrBackend.cpp`
  - 报告实际 WAMR interpreter identity；
  - 跨 backend instance handle 返回 `foreign_export`；
  - unload/reload 后旧 handle 返回 `stale_export`。
- `AvidScriptRuntime`
  - 保留默认构造；
  - 增加显式 backend selection 构造；
  - smoke result 记录实际 backend info；
  - selection/factory 错误类别原样进入 Runtime 失败结果。
