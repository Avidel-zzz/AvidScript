# Phase 54 执行分层与性能领先实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 AvidScript 建立可替换的执行后端、WAMR AOT 闭环和同 ABI 性能竞争，同时优化通用 Host crossing，最终用正式数据判断是否领先 Puerts 与 UnrealEngine-Angelscript。

**Architecture:** `AvidScriptVM` 公共层拥有 backend identity、capability、selection 与 artifact contract，具体 WAMR/Wasmtime 实现留在 Private/ThirdParty；Runtime 只通过工厂和能力协商组合后端。Canonical WASM 是源制品，AOT/JIT 是带 provenance 的派生执行层；执行成本和 Host crossing 成本分别计量。

**Tech Stack:** Unreal Engine 5.8 Source、C++20、WAMR 2.4.4、C# Roslyn frontend、WASM、PowerShell 7、CMake/Ninja、Phase 53 Puerts benchmark harness。

## Global Constraints

- 引擎固定为 `C:\UnrealEngine` 的 UE5.8 源码版。
- 人读文档使用中文，标识符、API、命令和日志原文保留英文。
- 不提交 Puerts、AngelScript、Wasmtime 下载缓存、二进制缓存、本机路径或凭据。
- 一次 `shell_command` 只执行一个逻辑命令，禁止 `;`、`&&`、`||`。
- 当前主工作区的用户改动受保护，不修改、不暂存、不提交。
- 阻塞性高风险测试随任务执行；完整 .NET、UBT、Automation 和 benchmark 在批次或阶段 Gate 集中执行。
- 不为 fixture 名称或手写 API 添加性能特例；优化必须由 descriptor、ABI kind 或通用 invocation plan 驱动。
- 没有同机正确性和统计证据前，不宣称领先 Puerts 或 AngelScript。
