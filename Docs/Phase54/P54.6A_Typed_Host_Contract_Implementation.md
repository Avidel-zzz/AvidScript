# P54.6A Typed Host Contract 与 Crossing 成本阶梯实现记录

## 状态

功能代码已完成，阶段末 UE5.8 UBT、Automation 与正式 benchmark Gate 待 P54.6F 集中执行。

## 本组目标

P54.6A 建立第一条不经过通用 `AvidScriptWasmtimeValue[]` 转换的 Wasmtime host import 路径，并把“WASM crossing 本体、通用桥接、不可变分派环境”等成本拆开测量。该组只冻结 backend-neutral ABI 与两个控制 shape，不绑定具体 UE API。

## 已实现内容

- 新增 `EAvidScriptVmTypedHostShape`、`EAvidScriptVmTypedHostStatus`、`IAvidScriptVmTypedHostDispatcher` 与 `FAvidScriptVmTypedHostImport`。
- `FAvidScriptVmLoadConfig` 可携带实例私有 dispatcher 和不可变 typed import view。
- 将 Wasmtime 私有 opaque handle 布局集中到 VM Private header，公开头不泄漏 Wasmtime 类型。
- 新增 `EmptyI32` 与 `I32PairToI32` 专用 C trampoline；warm success 直接读取和写入 `wasmtime_val_t.of.i32`，不构造通用 value array、不分配堆内存、不做运行时 shape switch。
- backend 在 load 期间校验 WASM import、binding package 与 typed metadata 的 stable id、ordinal、module/name 和 signature；typed import 作为 verified binding package 的受信子集替换 generic linker definition。
- dedicated ABI 遇到 `Rejected` 或 `FallbackRequired` 时 fail-closed，保持稳定 `host_import_failed` 诊断，不在一次调用中同时执行 fast 与 semantic 两条路径。
- 新增多实例、错误签名、重复 identity、缺失 dispatcher、拒绝 trap 等 Automation 合同。
- 新增独立 `FAvidScriptPerfCostLadder`、crossing WAT/JSON contract 和受控内核构建合同。
- 新增统一成本预算判定：`typed_empty_p95 / puerts_static_scalar_p50`、generic 与 typed 增量、immutable dispatch 与 typed 增量；70% stop-loss 边界集中在一个 API 中。

## 性能边界

typed trampoline 的每个 shape 拥有独立 Wasmtime callback 和独立 backend callback，形状选择只发生在 load/registration。热路径仍保留一次 Wasmtime host call、一次 C callback 和一次 C++ virtual dispatcher；P54.6D 会把 dispatcher 接到 immutable generated plan，P54.6E 再通过 snapshot/command buffer 降低 crossing 次数。

## 剩余风险

- P54.6A 只注册两个控制 shape；Self/property/vector/object/command buffer 的 typed C callback 在 P54.6C 扩展。
- 对象 roundtrip ABI 已预留 `guestAddress`，完整返回 slot/generation，不使用截断 handle 或隐式侧通道。
- 当前成本阶梯通过注入 driver 保持独立，P54.6F 才会把正式 Wasmtime/Puerts lane 接入并产出可比较统计。
