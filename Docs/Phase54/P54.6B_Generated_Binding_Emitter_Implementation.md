# P54.6B Generated Binding IR 与源码生成器实施记录

## 状态

P54.6B 已完成产品实现。该组把“反射绑定描述”提升为可由项目编译器消费的
Generated Binding IR，并能确定性生成项目自有 C++ 模块，为后续绕过
`ProcessEvent` 的 S1 快路径提供静态调用点。

## 已实现

- 在 `AvidScriptCore` 新增不依赖 UObject、Editor、文件系统或 Wasmtime 的
  Generated Binding IR。
- 项目 class rule 新增 `GeneratedNativeFunctions`；授权必须是已选函数的
  非通配子集，并拒绝与 `NativeDirectFunctions` 重复占有同一调用。
- descriptor 新增 `generated_native_s1`，将 shape、receiver mode、专用 import
  与 semantic fallback ordinal 纳入 canonical identity 和 package hash。
- 专用 import 使用 `avid_s1_<16 位小写 SHA-256>`，公开 C# 方法/属性外观不变。
- 支持四种生成调用形态：`I32PairToI32`、`PropertyI32GetSet`、`VectorValue`、
  `StableObjectRoundtrip`。
- 生成项目模块 `AvidScriptGeneratedBindings`，包含确定性 Build.cs、头文件、
  C++ 调用点和 manifest；模块依赖按 owner module 排序去重。
- 写盘使用同卷 staging、备份替换和失败回滚；`.uproject` 模块登记保持幂等，
  不重排无关 JSON 字段。
- 四类 thunk 均使用安全 `Cast`，类型错误返回 `Rejected`；entry 仅设置与 shape
  对应的函数指针。
- C# profile JSON 新增 schema v7 的 `generated_native_functions`。v1-v6 继续兼容，
  v6 若声明该字段会以稳定错误分类拒绝；v7 的授权进入 selection identity。
