# P54.6C Wasmtime Raw Typed ABI 实施记录

## 状态

P54.6C 已完成产品实现。Wasmtime typed host import 已从 checked value-array
回调迁移到 Wasmtime 45 的 unchecked raw ABI，减少 host crossing 中重复的类型分派、
值复制和临时结构开销。

## 已实现

- 使用 `wasmtime_linker_define_func_unchecked` 与 `wasmtime_val_raw_t` 注册 typed
  host import；functype 在加载阶段固定并验证。
- Empty、I32Pair、SelfI32Pair、SelfProperty、SelfVector、StableObjectRoundtrip、
  CommandBuffer 各自拥有固定 arity 的独立 raw trampoline，不在热路径执行 shape switch。
- raw callback 直接读取共享 args/results slot，并把单个 `i32` 结果写回 slot 0。
- 对象 roundtrip ABI 固定为
  `(selfSlot,selfGeneration,objectSlot,objectGeneration,guestAddress)->i32`；完整返回
  handle 使用 guest memory 中的 8-byte `{slot,generation}`，标量只表示状态。
- Guest IR 的 `GuestImport` 增加 `DispatchClass`：`semantic`、`generated_s1`、
  `data_lane`。新 artifact 使用 schema `2/1.1`，仍接受旧 `1/1.0`。
- C# lowering 保留 dispatch class，WASM 二进制 import section 不携带信任信息；
  runtime 仍以 binding package 与 generated registry 的联合验证结果为准。

## 剩余风险与下一步

- unchecked ABI 依赖加载阶段完整验证 arity/kind；P54.6D 必须只从受信 binding plan
  构造 typed import，不能信任 guest 自报的 `DispatchClass`。
- P54.6D 将补齐 receiver capability、对象句柄解析和 guest-memory 写回；P54.6F 再用
  正式成本阶梯证明 raw typed 路径确实降低 crossing floor。
