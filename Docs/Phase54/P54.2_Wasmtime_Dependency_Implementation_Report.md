# P54.2 Wasmtime v45 C API 依赖锁实现报告

## 状态

实现与全部要求验证完成。

本组只建立 Wasmtime v45 minimal C API 的依赖锁、安装闭环与 UBT External Module，不包含 Wasmtime backend，也未修改 VM/Runtime C++。

- 版本：`v45.0.0`
- archive：`wasmtime-v45.0.0-x86_64-windows-c-api.zip`

- archive root：`wasmtime-v45.0.0-x86_64-windows-c-api`
- 平台：`Win64`
- 许可：`Apache-2.0 WITH LLVM-exception`
- tracked `LICENSE.txt` SHA-256：`268872b9816f90fd8e85db5a28d33f8150ebb8dd016653fb39ef1f94f2686bc5`
- 链接方式：`wasmtime.dll` 与 `wasmtime.dll.lib`

## 实现范围

- 新增 JSON lock/schema，固定官方发布 URL、archive 身份、minimal layout 与安装路径。
- 新增 `ValidateLock`、`Install`、`Verify`、`Remove` 四模式安装器。
- 下载使用唯一 partial 文件，大小和 SHA-256 通过后才发布到版本隔离 cache。
- ZIP 解压拒绝路径逃逸、额外顶层 root、重复 entry、reparse/link entry 与 NTFS alternate data stream。
- 安装只复制 `min/include`、DLL、import library 与 archive 根许可证。
- marker 只记录固定身份与 canonical 内容摘要，不记录路径、用户或时间戳。
- `Verify` 拒绝缺失、多余、修改文件以及 marker/lock 身份漂移。
- `Remove` 只删除完整验证通过的版本目录，空父目录清理不越过 `installed/`。
- 新增 `Wasmtime` External Module；仅 Win64 受管布局完整时定义 `AVIDSCRIPT_WITH_WASMTIME=1`。
- `AvidScriptVM` 仅通过 Private dependency 引入 `Wasmtime`，Public 不暴露 Wasmtime header。
- architecture checker 固定 VM ownership，并拒绝 Core、Bindings、Runtime、Editor 越层依赖或泄漏。

## 自审

- tracked/untracked 路径与 brief ownership 一致。
- `installed/` 位于最终 `!Source/` 规则之后并已由 `git check-ignore` 确认。
- tracked 文件未包含 archive、header、`.lib`、`.dll`、cache、绝对本机路径、用户名、时间戳或凭据。
- UBT 未引用或链接 static `wasmtime.lib`。
- 安装 marker 未记录绝对路径。
- synthetic ZIP 合同不联网，也不读取真实用户目录。

## 剩余风险

- 当前任务只提供依赖与构建开关；Wasmtime backend、运行时选择、调用 ABI 与行为一致性属于后续任务。
- `Wasmtime.Build.cs` 只做受管布局存在性检查；内容完整性仍必须由安装器 `Verify` 提供。
- Windows 本地并发目录替换属于受信构建机上的操作系统竞态边界，当前脚本通过规范路径、reparse 拒绝、唯一 staging 与发布前复查缩小风险，但未持有目录句柄锁。
