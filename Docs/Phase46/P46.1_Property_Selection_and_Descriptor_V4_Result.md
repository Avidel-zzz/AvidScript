# P46.1 属性选择与 Descriptor v4 成果

> 状态：已完成

## 1. 已实现能力

P46.1 建立了从 UE5.8 `FProperty` 到第一等 binding descriptor 的前半条生成链：

- Profile 支持 class 范围内的属性批量 discovery、include/exclude 和 strict explicit property。
- 独立 property policy 负责 runtime 可见性，继续复用现有 reflected type policy。
- Compatibility report 区分 function/property，并记录 property candidate、accepted、rejected 数量。
- 包含属性的 descriptor 升级为 v4，写入 `binding_kind`、`ue_member` 与 `cached_property_get`。
- 函数-only descriptor 继续发布字节稳定的 v3，避免无关缓存和历史产物变化。
- Shared parser 同时兼容 v2、v3、v4，并拒绝伪造 member kind、dispatch mode 和 getter ABI。

## 2. 可扩展性

属性选择不包含逐成员白名单。Class profile 可以在固定反射边界内批量发现属性，类型资格由共享 policy 决定。新增受支持 scalar、struct 或 object 类型后，function 参数和 property getter 会共同获得该能力。

Descriptor v4 可以在同一 package 中确定性组合 `function` 与 `property_get`，ordinal、stable identity、selection hash、package hash和动态 import 仍遵循同一内容寻址规则。

## 3. 实际 UE5.8 结果

以 `/Script/Engine.Actor` 为真实反射输入：

- `CustomTimeDilation`：接受，类型为 float。
- `InitialLifeSpan`：接受，类型为 float。
- `Tags`：拒绝，当前数组未进入共享类型策略，产生 `unsupported_property_type`。
- 不存在的 strict explicit property：失败关闭，不返回部分选择。

一个 `GetActorScale3D` 函数和上述两个属性可以生成同一 v4 descriptor。属性 getter ABI 固定为 `(iii)i`，分别表示 object slot、generation 和 guest return address。

## 4. 验证

- UE5.8 `AvidScriptBindings`、`AvidScriptRuntime`、`AvidScriptEditor` no-clean 增量构建成功。
- `AvidScript.Editor.BindingSelection.Property`：2/2 Success。
- `AvidScript.Editor.BindingDescriptor`：5/5 Success，其中包含 v3 全回归与 v4 property getter。
- Architecture gate：通过。
- 所有 Automation 均确认 Found > 0、全部 Success、`TEST COMPLETE`、RequestExit status 0 与进程退出码 0。

## 5. 当前边界

P46.1 只完成选择与 descriptor。Runtime 尚未执行 `cached_property_get`，C# facade 尚未渲染普通 property；因此本阶段不能宣称 C# 已经能读取 `UPROPERTY`。P46.2 将缓存 `FProperty*` 读取 plan、复用 object registry/guest marshaller，并接入 semantic binding slice。

Setter 继续保持禁用，直到 BlueprintSetter、replication/OnRep 与候选 reload transaction policy 完成。
