# P4.2 Actor Host ABI Context

日期: 2026-07-03
状态: Done

## 1. 目标

P4.2 为 WASM runtime 增加最小 Actor host ABI。Guest WASM 现在可以链接 `avidscript.actor_get_location` 与 `avidscript.actor_set_location`, host 侧通过 AvidScript object handle 解析 UE `AActor`, 并在 host 授权后读写 Actor location。

本阶段仍不引入 D/C# toolchain, 不做外部 fixture 文件执行, 不做 Editor UI/watcher。P4.3 再把 P4.1 的外部 `.wasm` loader 与本阶段 Actor ABI 接起来。

## 2. ABI

Import module 固定为:

```text
avidscript
```

导入函数:

| Import | Signature | 语义 |
| --- | --- | --- |
| `actor_get_location` | `(slot:i32, generation:i32, out_xyz_ptr:i32) -> i32` | 解析 Actor handle, 将 `x/y/z` 以 3 个 `f32` 写入 guest memory; 成功返回 `1`, 失败返回 `0` 并设置 host import failure。 |
| `actor_set_location` | `(slot:i32, generation:i32, x:f32, y:f32, z:f32) -> i32` | 解析 Actor handle, 在 `AllowWrites` 策略下移动 Actor; 成功返回 `1`, 失败返回 `0` 并设置 host import failure。 |

Host context:

- `FAvidScriptWasmHostContext::ObjectRegistry`
- `FAvidScriptWasmHostContext::ActorWritePolicy`

默认写策略为 `ReadOnly`, 只有 host 显式设置 `AllowWrites` 时 `actor_set_location` 才会移动 Actor。

## 3. 实现内容

新增 runtime API:

- `FAvidScriptWasmHostContext`
- `FAvidScriptWasmRuntimeInstance::SetHostContext`
- `FAvidScriptWasmRuntimeInstance::ClearHostContext`
- `FAvidScriptWasmRuntimeInstance::HandleActorGetLocationImport`
- `FAvidScriptWasmRuntimeInstance::HandleActorSetLocationImport`
- `FAvidScriptWasmRuntimeInstance::SetPendingHostImportFailure`

WAMR native symbols 新增:

- `avidscript.actor_get_location` with signature `(iii)i`
- `avidscript.actor_set_location` with signature `(iifff)i`

失败路径统一进入既有 `host_import_failed` 诊断管线, 因此 guest 侧 ABI 失败会让当前 export call fail closed, 而不是静默继续。

## 4. Tests

新增 automation:

| Test | 覆盖 |
| --- | --- |
| `AvidScript.Runtime.WasmActor.ImportLinkSmoke` | WAMR 可以链接导入 `actor_get_location` / `actor_set_location` 的 guest module。 |
| `AvidScript.Runtime.WasmActor.DirectHandlerSmoke` | 直接 handler 可通过 handle 读取 Actor location, 并在 `AllowWrites` 下移动 Actor。 |
| `AvidScript.Runtime.WasmActor.MissingContextSmoke` | 缺失 host context 时 get/set 均 fail closed。 |
