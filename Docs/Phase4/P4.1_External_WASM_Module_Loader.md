# P4.1 External WASM Module Loader

日期: 2026-07-03
状态: Done

## 1. 目标

P4.1 为 Phase 4 引入最小外部 WASM 文件读取能力。Runtime 现在可以从磁盘读取 `.wasm` bytes, 并对路径为空、文件缺失、读取失败、空文件返回结构化 diagnostics。

本阶段不解析 manifest, 不执行 WASM, 不接 Actor ABI。它只把 Phase 4 后续 automation 从 embedded byte array 推进到真实文件路径。

## 2. 实现内容

新增:

- `FAvidScriptWasmModuleLoadResult`
- `FAvidScriptWasmModuleLoader::LoadFromFile`

错误分类:

| Category | 含义 |
| --- | --- |
| `module_path_invalid` | 传入路径为空。 |
| `module_file_missing` | 文件不存在。 |
| `module_file_read_failed` | 文件存在但读取失败。 |
| `module_file_empty` | 文件读取成功但内容为空。 |

成功结果记录:

- `bSucceeded`
- `ModulePath`
- `ByteSize`
