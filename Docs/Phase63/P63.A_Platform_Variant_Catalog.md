# P63.A 平台身份与变体解析

## 已实现

- module catalog 升级为 schema v2：每个逻辑 `ModuleId` 持有有序 `variants[]`；
- variant 以 `platform / architecture / configuration / backend / format` 作为唯一选择键；
- Runtime resolver 接受显式平台上下文，只允许精确匹配，不存在目标 variant 时返回
  `module_variant_not_found`；
- 发布器保留同一模块的 Development/Shipping 等独立 variant，重复发布只替换相同选择键；
- UBT staging、package receipt 与 Generated Type Cook 按当前 target 精确选择 package；
- P62 catalog schema v1 保留兼容读取，后续发布时自动归一化为 schema v2。

当前发布器仍只生成 Win64/x86_64/Wasmtime artifact。Android/arm64 variant 的依赖安装和
artifact 生成属于 P63.B-P63.C；iOS 未验证时继续 fail closed。
