# Phase 63 实施计划

## 目标

交付 backend-neutral 的多平台发布合同和 Android arm64 Wasmtime 预编译路径，为 Phase 64 真机游戏 Demo
提供可消费的模块包；iOS 保持无 JIT、未验证即拒绝的明确边界。

## 批次

### P63.A 平台身份与变体解析

- 新增平台、架构、配置和 artifact format 的规范值对象；
- catalog/package 支持有序 `variants[]` 与精确选择；
- Runtime resolver 按显式 platform context fail closed；
- 保持 P62 单平台 schema 的受控兼容读取。

### P63.B Android arm64 Runtime 依赖

- 增加 Wasmtime 45 Android arm64 lock/schema/installer；
- 扩展 `Wasmtime.Build.cs` 的 Android 静态链接与 Win64 动态库分流；
- 增加 receipt、license、hash、extra-file 与 wrong-architecture 合同；
- 未安装 Android runtime 时仅 Android target 失败，Win64 不受影响。

### P63.C 交叉预编译与发布

- 发布 profile 接受目标平台矩阵；
- 生成 `aarch64-linux-android` 预编译 artifact 与独立 package variant；
- Android Development/Shipping 均强制 `require_precompiled`；
- 加入 host inspect、determinism、tamper 和 JIT-fallback-negative 合同。

### P63.D 移动生命周期与集中 Gate

- Session 接入 pause/resume、low-memory 与 teardown generation gate；
- 验证后台恢复不复活旧 World/owner/continuation；
- 集中执行静态、托管、合同、UE5.8 no-clean UBT 与必要 Automation；
- 更新中文文档、README 边界、Gate 摘要并完成 attestation/close。

## 验收边界

P63 可以声明“Android arm64 AOT 发布路径与 UE 集成合同完成”，不能声明 Android/iOS 真机游戏已通过。
真机安装、图形/输入、后台切换、设备包体和 iOS 远程签名由 Phase 64 完成。
