# P63.B Android arm64 Wasmtime 依赖

## 已实现

- 锁定 Wasmtime 45 官方 `aarch64-android-c-api` 资产、下载地址、长度和 SHA-256；
- 锁定解包后的 `libwasmtime.a` SHA-256，并解析 `ar` 成员验证 64 位小端 AArch64 ELF；
- `InstallWasmtimeDependency.ps1` 共用 Win64 安全边界，增加 Android `tar.xz` 路径检查、
  link/special-entry 拒绝、原子安装、marker、extra-file 与篡改验证；
- `Wasmtime.Build.cs` 按 target 分流：Win64 保持 DLL/性能工具链，Android arm64 静态链接
  `libwasmtime.a`；非 arm64 Android 明确失败；
- Android 缺少受控依赖时只阻断 Android target，不影响 Win64 Editor/packaged 规则。

官方资产来自 [Wasmtime v45.0.0 release](https://github.com/bytecodealliance/wasmtime/releases/tag/v45.0.0)。
