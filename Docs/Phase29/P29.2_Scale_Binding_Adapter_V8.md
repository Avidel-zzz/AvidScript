状态: Done

## 实现

- `FAvidScriptActorBinding` 增加 Get/SetActorScale3D 与 write policy。
- WAMR 增加 `actor_get_scale` / `actor_set_scale`，读取复用 12 字节 guest scratch。
- C# `AActor` 增加 scale methods 和组合 Translation/Rotation/Scale3D 的 `FTransform` snapshot。
- adapter v8 支持 scale 的 FVector getter local、加法与 setter；imports 为 7/8，生命周期索引为 9/10/11。
- manifest 明确 `FTransform` 当前是 snapshot projection，不宣称原子 SetActorTransform。
