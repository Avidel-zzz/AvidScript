# Phase 38.3：统一 Gameplay Event 协议

Phase 38.3 建立统一的类型化事件信封，为碰撞、命中与输入接入提供可生成、可扩展的 Runtime 边界。

## 核心约束

- Runtime 只解析一个可选导出：`avid_on_gameplay_event`。
- BeginOverlap、EndOverlap、Hit、Input 是 Schema 条目，不各自复制导出缓存与分发管线。
- 旧 WASM 模块缺少该导出时按缓存 no-op 处理，不影响 BeginPlay、Tick 与旧 `avid_on_event`。
- 事件 Payload 在进入 VM 前校验，Trap 会将当前 Runtime 标记为 Faulted。

## WASM ABI

统一回调固定接收 8 个 cell：事件类型、主 ID、次 ID、对象 slot、对象 generation、向量 X、向量 Y、向量 Z。后三项按 f32 位模式传递。
