# Phase 38.4：UE Collision Delegate 接入

状态：Done

## 实现

- `UAvidScriptComponent` 只在 Runtime Session 进入 Running 后绑定 Owner 的 BeginOverlap、EndOverlap 与 Hit 委托。
- 所有碰撞回调都构造 `FAvidScriptGameplayEvent`，通过同一个 `avid_on_gameplay_event` 导出进入 WASM；没有新增逐事件导出。
- OtherActor 注册为 session 生命周期句柄，同一 Actor 重复事件复用句柄；Runtime 结束后统一释放。
- EndPlay、Trap 或其他致命事件失败都会先解除 UE 委托，再停止并卸载 Runtime。
- Faulted Session 不再伪调用 guest EndPlay，避免二次 invalid_state 覆盖原始 Trap。

## Payload 约定

- BeginOverlap、EndOverlap：ObjectHandle 指向 OtherActor，VectorValue 为事件发生时 OtherActor 的世界坐标。
- Hit：ObjectHandle 指向 OtherActor，VectorValue 为 UE NormalImpulse。
- 当前 Actor 级委托没有 body index，因此 PrimaryId、SecondaryId 保持 0；后续组件级碰撞 Schema 可扩展这两个字段。
