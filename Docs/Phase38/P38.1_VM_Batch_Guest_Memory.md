# P38.1 VM 批量 Guest Memory 协议

日期：2026-07-13
状态：完成

## 目标

把 Phase 37 的 C++ Transform Batch 扩展为稳定的 WASM 内存协议，同时保持 VM、Runtime 和 UE Binding 的职责边界。该工作是后续生成式 Binding 可复用的批量内存基础，不是逐个手写 UE API 的路线。

## 实现

AvidScriptVM 公共 HostCall 增加同步借用视图：

- InputCells：只读 uint32 单元视图。
- OutputFloats：可写 float 视图。
- ActorGetTransformBatch：批量操作的稳定 BindingId。

AvidScriptVM 私有层新增 TranslateGuestRange，统一处理：

- 零长度范围。
- 地址有效性。
- 元素对齐。
- 字节数溢出。
- WAMR app address 校验和 native address 翻译。

actor_get_transform_batch 的 ABI 为 inputAddress、count、outputAddress，返回已处理数量。单批上限为 256；每个输入对象使用 slot 和 generation 两个 uint32，每个输出 Transform 使用 9 个 float，顺序为 Location XYZ、Rotation Pitch/Yaw/Roll、Scale XYZ。

## 有价值的测试边界

删除了只对 HostCall 字段赋值后立即读回的浅层测试，改为真实 WAMR 模块行为测试：

1. Guest Data Section 写入两个对象句柄。
2. Guest 调用 actor_get_transform_batch。
3. Host Dispatcher 检查借用输入并写入输出视图。
4. Guest 从线性内存读回写入结果，再调用第二个 Host Import。
5. 由测试确认写回数据确实被 Guest 观察到。

验证用例同时覆盖：

- count 为 0 时允许空地址并提供空视图。
- count 为 257 时在 Dispatcher 前拒绝。
- 输入地址未按 uint32 对齐时拒绝。
- 输出地址确定性越界时拒绝。
- 失败结果包含 host_import_failed 与准确 import 名。
