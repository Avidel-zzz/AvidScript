依赖安装由
`Benchmarks/PuertsComparison/Scripts/Install-PuertsBenchmarkDependency.ps1`
管理。安装器使用 bare Git cache，已有固定对象时可以离线重放；`Verify`
会核对 remote、commit、plugin tree、V8 归档大小与哈希、运行时版本和 managed
marker。所有安装、复验与后续 runner manifest 显式使用同一 cache root，避免
依赖机器默认临时目录。`Remove` 只接受匹配 marker 的目录，拒绝删除身份不明
的用户安装。

## 2. UE5.8 兼容处理

固定的 Puerts `master` 提交已经包含源码版 UE 版本探测修正，本阶段不需要维护
AvidScript 私有 Puerts patch。上游 `DeclarationGenerator` 与
`ParamDefaultValueMetas` 仍引用旧 UnrealHeaderTool `Public` 目录并产生 warning，
但该目录没有进入本次 Editor runtime 模块的失败路径，也没有修改第三方源码来
掩盖 warning。

benchmark Harness 设置 `EnabledByDefault=false`，普通 AvidScript 构建不会因此
依赖 Puerts。UE5.8 UBT 中可选插件的正确显式参数是
`-EnablePlugin=AvidScriptPerfHarness`；复数形式 `-EnablePlugins` 不生效。

## 4. 阶段边界

P53.1 只证明固定 Puerts V8 backend 可在当前源码版 UE5.8 环境中编译、链接并
被独立 benchmark Harness 消费；它不代表 AvidScript 已快于 Puerts。四条 lane
的运行时正确性、采样控制器、同机数据与优化结论分别由 P53.2 至 P53.5 提供。
