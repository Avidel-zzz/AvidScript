## 2. 选择依据

`Unreal_v1.0.9` 的公开 release note 明确提到 UE5.6，但没有声明 UE5.8。官方 `master` 的固定提交日期为 2026-07-21，提交说明是改进源码版 UE 的版本判定；这与本项目使用 `C:\UnrealEngine` 源码版 UE5.8 的环境直接相关。

因此本阶段不把 release source 强行当作 UE5.8 最佳候选，而是：

- 使用较新的官方 `master` immutable commit；
- 使用官方 Unreal release 发布的 V8 9.4 backend；
- 保持 Puerts 默认 `UseV8Version = V9_4_146_24`；
- 先做无补丁 UBT；
- 只有真实编译错误证明必要时才新增最小兼容 patch。

## 3. 安全与可重放

- lock schema 固定官方 remote、commit、plugin tree、asset URL、长度和 SHA-256；
- 上游源码使用 bare cache，不创建可被中断或本地编辑污染的 checkout；
- 安装目标固定为工程内 `Plugins/Puerts`；
- 安装器采用临时 stage，验证完成后再移动到最终目录；
- 删除操作要求匹配 managed marker，拒绝删除用户手工安装；
- 第三方源码、V8 二进制和本机路径不提交到 AvidScript Git；
- 后续兼容 patch 必须以 tracked 文本保存并记录上游适用 commit。
