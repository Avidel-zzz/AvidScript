- `AvidScript.Guest.CSharp.ToolchainReportSmoke`

## What The Contract Test Proves

The contract fixture uses the same ABI that a future C# direct compiler must emit:

- export `avid_on_begin_play`
- export `avid_on_tick`
- import `env.actor_set_location`
- use `language=csharp` manifest metadata

The test loads that module through `FAvidScriptWasmReloadSession`, then verifies:

- BeginPlay moves the Actor
- Tick moves the Actor again
- runtime tick count increments

## Remaining Risk

The test proves UE and the AvidScript host runtime are ready for the direct ABI, but it does not prove the current .NET toolchain can emit that ABI. The build diagnostic is the source of truth for toolchain readiness.
