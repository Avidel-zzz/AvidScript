# P20.1 C# Profile RED 测试

## 目标

本小组先用自动化测试描述 Phase20 的目标行为: C# profile JSON 应该能被 Editor 服务读取为 `FAvidScriptEditorCSharpBuildConfig`, Editor module 也应该能从 profile path 执行“构建 direct ABI WASM -> 读取 report -> 绑定到选中 Actor”。

## RED 结果

新增测试后先运行 `AvidScriptEditor` 模块构建, 预期失败。

命令:

```powershell
& "C:\UnrealEngine\Engine\Build\BatchFiles\Build.bat" AvidTPSTemplateEditor Win64 Development "-Project=<ProjectRoot>\AvidTPSTemplate.uproject" -WaitMutex -NoHotReloadFromIDE -NoUBTMakefiles -Module=AvidScriptEditor
```

结果:

- UBT 报告 `Invalidating makefile for AvidTPSTemplateEditor (source file added)`。
- 构建按预期失败: `AvidScriptEditorCSharpProfileService.h` 尚不存在。

## 覆盖内容

- `AvidScript.Editor.CSharpProfileService.MissingProfileFailsSmoke`
  - 缺失 profile 必须 fail closed。
  - 返回 `profile_missing`。
  - 返回规范化 profile path 与 next action。

- `AvidScript.Editor.CSharpProfileService.LoadProfileSmoke`
  - 写入一个临时 C# source 和 profile JSON。
  - 验证 source/project/module/artifact/output/report/manifest/build script/configuration 映射。

- `AvidScript.Editor.Module.CSharpProfileBuildAndBindSelectedActorSmoke`
  - 写入 profile 驱动的 C# source。
  - 选中测试 Actor。
  - 调用 module profile build-and-bind API。
  - 验证生成 report, 绑定组件, 组件 manifest 指向本次 profile 产物。

## 结论

RED 阶段有效: 新测试先逼出缺失的 profile service 与 module API, 后续实现必须围绕这些验收点补齐。
