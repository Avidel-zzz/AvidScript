# P20.3 Editor Profile 入口

## 目标

把 C# profile service 接入 Editor module, 保持 Phase18 的固定 ActorLifecycle 入口不变, 额外增加一个 profile 驱动入口, 让用户后续可以从菜单触发自己的 C# 脚本构建与绑定。

## 新增 API

`FAvidScriptEditorModule` 新增:

- `GetCSharpProfileBuildAndBindEntryName()`
- `GetDefaultCSharpProfilePath()`
- `MakeCSharpProfileBuildAndBindMenuEntryConfig(...)`
- `ExecuteCSharpProfileBuildAndBinding(ProfilePath, OutBuildResult, OutBindingResult)`

菜单 entry name:

```text
AvidScript.BuildAndBindCSharpProfile
```

菜单显示文本:

```text
Build And Bind C# Profile Script
```

## 执行流程

1. 从 profile path 调用 `FAvidScriptEditorCSharpProfileService::LoadProfile(...)`。
2. profile 失败时把错误映射到 `FAvidScriptEditorCSharpBuildResult`, 不继续构建。
3. profile 成功后调用 `FAvidScriptEditorCSharpBuildService::BuildProfile(...)`。
4. 构建成功后调用 `FAvidScriptEditorComponentBindingService::ApplyCSharpReportToSelectedActor(...)`。
5. 绑定成功后, 选中 Actor 的 `UAvidScriptComponent` 指向 profile 产出的 manifest。

## 用户当前能做什么

在 Phase20 完成后, 只要创建默认 profile 文件:

```text
Saved/AvidScriptCSharpProfiles/default.csharp-profile.json
```

并让它指向一个受当前 C# source adapter 支持的 `.cs` 文件, 就可以通过 Editor 菜单入口构建 WASM 并绑定到当前选中 Actor。

## 当前限制

- 仍然没有 Slate 文件选择器。
- 没有 profile 列表或最近使用记录。
- 没有自动创建默认 profile 模板。
- C# source adapter 语法子集仍保持 Phase14-P19 的范围。

## 结论

P20.3 已补上用户入口的最小纵切。下一阶段最有价值的是把默认 profile 模板和真实 Editor UX 补齐, 让用户不必手写所有 JSON 路径。
