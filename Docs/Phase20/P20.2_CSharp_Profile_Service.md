# P20.2 C# Profile Service 实现

## 目标

把 Phase19 已有的 `FAvidScriptEditorCSharpBuildService::BuildProfile(...)` 接到一个可持久化、可由用户编辑的 JSON profile 文件上。这样用户不需要修改插件代码, 只要维护 profile JSON, 就能指定自己的 `.cs` 源文件和输出路径。

## 新增类型

- `FAvidScriptEditorCSharpProfileLoadResult`
  - `bSucceeded`
  - `ErrorCategory`
  - `ErrorMessage`
  - `NextAction`
  - `NormalizedProfilePath`
  - `BuildConfig`

- `FAvidScriptEditorCSharpProfileService`
  - `GetDefaultProfilePath()`
  - `LoadProfile(ProfilePath, OutResult)`

## 默认路径

默认 profile 文件固定为:

```text
Saved/AvidScriptCSharpProfiles/default.csharp-profile.json
```

Editor menu 在本阶段使用该路径。下一阶段可以在此基础上加文件选择器、最近使用 profile、Project Settings 列表或 profile asset。

## 支持字段

必填字段:

- `schema_version`: 当前必须为 `1`。
- `language`: 当前必须为 `csharp`。
- `source_path`: 必须指向存在的 `.cs` 文件。

可选字段:

- `project_path`
- `module_id`
- `artifact_stem`
- `output_root`
- `report_path`
- `manifest_path`
- `build_script_path`
- `dotnet_path`
- `configuration`

缺省策略:

- `project_path` 默认复用 ActorLifecycle 样例工程。
- `module_id` 默认从 source 文件名派生为 `csharp_<source_token>`。
- `artifact_stem` 默认从 source 文件名派生。
- `output_root` 默认落到 `Saved/AvidScriptCSharpGuest/Profiles/<artifact_stem>`。
- `report_path` 与 `manifest_path` 默认由 Phase19 build service helper 生成。
- `build_script_path` 默认复用 `BuildCSharpActorLifecycle.ps1`。
- `configuration` 默认 `Release`。

## 失败语义

当前 profile service 以 fail closed 为原则。已覆盖或实现的错误类别包括:

- `profile_empty`
- `profile_missing`
- `profile_read_failed`
- `profile_json_invalid`
- `profile_schema_unsupported`
- `profile_language_unsupported`
- `source_empty`
- `source_not_csharp`
- `source_missing`

这些错误会携带 `NextAction`, 方便后续接 Message Log、通知或 UI 面板。

## 结论

Phase20 已把“用户自定义 C# 脚本入口”从硬编码 ActorLifecycle 样例推进到 profile 文件驱动。此时真正的用户操作模型已经接近可用: 写 `.cs`, 写 profile, 在 Editor 里触发 build-and-bind。
