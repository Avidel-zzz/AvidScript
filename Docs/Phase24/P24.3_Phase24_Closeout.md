## 当前可用能力

用户现在可以用 C# 受限子集写出以下闭环:

```csharp
private static float ElapsedSeconds;

public static void BeginPlay()
{
    ElapsedSeconds = 0.0f;
    Actor.SetLocation(100.0f, 200.0f, 300.0f);
}

public static void Tick(float deltaSeconds)
{
    ElapsedSeconds += deltaSeconds;
    Actor.SetLocation(100.0f + 120.0f * ElapsedSeconds, 200.0f, 300.0f);
}
```

这已经具备最小“脚本内状态 + UE 生命周期 + UE Actor 交互”的 gameplay 闭环。

## 剩余风险

- parser 仍是受限 source adapter, 不是完整 C# 编译器。
- 暂不支持分支、循环、局部变量、方法调用表达式或非 float 状态。
- 当前 self actor handle 仍固定为 slot `1` / generation `1`, 后续多对象 gameplay 前需要抽象 owner/self binding。
- 打包与移动端仍未验证。
