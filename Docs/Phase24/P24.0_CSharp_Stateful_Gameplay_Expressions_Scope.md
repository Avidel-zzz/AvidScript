# P24.0 C# 状态化 Gameplay 表达式范围

## 目标

Phase24 让 C# 脚本从“无状态调用 UE binding”前进到“能在脚本里保存 float 状态并驱动 Tick 逻辑”。本阶段重点是 gameplay 闭环体验, 不是完整 C# 编译器。

## 本阶段支持

- `private static float Field;`
- `private static float Field = 1.0f;`
- `Field = expression;`
- `Field += expression;`
- Actor 调用参数中引用字段、`deltaSeconds`、数字字面量、加法、乘法。
- 字段状态跨 `Tick` 保留。

## 本阶段不支持

- 分支、循环、局部变量、方法调用表达式、class 实例、数组/集合。
- 新 UE host import。
- 打包和移动端验证。

## 预期用户价值

用户可以先用 C# 写最小的状态化游戏逻辑, 例如累计时间、移动速度、简单状态复位, 并通过现有 Editor profile 工作流绑定到 UE Actor 验证。
