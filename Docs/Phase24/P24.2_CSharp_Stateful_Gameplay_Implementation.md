# P24.2 C# 状态化 Gameplay 实现

## 实现内容

Phase24 将 `BuildCSharpActorLifecycle.ps1` 的 C# source adapter 从 `actor_lifecycle_v2` 升级为 `actor_lifecycle_v3`。

主要变化:

- 新增 `Get-CSharpStaticFloatFields`, 识别 `private static float Field;` 与 `private static float Field = 1.0f;`。
- 新增字段查找与字段表达式解析。
- 表达式支持从旧的 `deltaSeconds * 数字` 扩展为受支持表达式之间的乘法和加法。
- 方法体解析从 Actor 调用列表升级为有序生命周期语句列表。
- 支持 `Field = expression;` 与 `Field += expression;`。
- WASM 生成新增 global section, 将 C# 静态 float 字段映射为 mutable `f32` globals。
- `Field = expression` 生成 `global.set`。
- `Field += expression` 生成 `global.get`, 表达式求值, `f32.add`, `global.set`。
- Actor 调用仍复用现有 `env.actor_set_location` 与 `env.actor_add_location_offset` imports。

## ABI 影响

本阶段不新增 host import, 不修改 UE runtime C++ binding。所有状态保存在 WASM module instance 内部, 通过 mutable globals 跨 Tick 保留。

## 产物 contract

生成 manifest 的 `source.subset` 更新为:

```text
actor_lifecycle_v3
```

`adapter_contract` 新增:

```text
supported_state = private static float Field, Field = expression, Field += expression
static_float_fields = ElapsedSeconds
```

## 已知边界

当前 parser 仍是受限 source adapter, 不是完整 C# 编译器。它按分号切分生命周期语句, 适合当前样例和短期 gameplay 闭环验证; 后续如果扩展分支、循环、局部变量或诊断行列号, 应考虑把 parser 拆成更明确的 token/AST 层。
