# P24.1 C# 状态化 Gameplay RED 测试

## RED 目标

本阶段先把默认 C# 样例改成目标写法, 并让自动化测试要求:

- 样例声明 `private static float ElapsedSeconds`。
- `BeginPlay()` 中执行 `ElapsedSeconds = 0.0f`。
- `Tick(float deltaSeconds)` 中执行 `ElapsedSeconds += deltaSeconds`。
- Actor 位置使用 `Actor.SetLocation(100.0f + 120.0f * ElapsedSeconds, 200.0f, 300.0f)` 计算。
- 生成 manifest 声明 `actor_lifecycle_v3`。
- 生命周期 smoke 连续 Tick 两次, 期望 X 从 `100` 变为 `102` 再变为 `104`。
