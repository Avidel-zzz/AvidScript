# P66.B Windows 生成类型冷启动安装

## 结果

五类型 `ScriptDefinedTypes.cs` 样例通过正式 `BuildCSharpScriptTypes.ps1 -HeadlessRelease` 生成 Win64 包并安装到插件当前包指针。首轮同结构安装后，样例新增 `LaunchSpeed` UPROPERTY、`GetLaunchSpeed` UFUNCTION，并让三参数 `ConfigureLaunch` 写入新属性；正式生成链报告 `native_rebuild_required`，原生结构哈希从 `499323b4...` 变为 `3b924382...`。no-clean UBT/UHT 构建与独立 Editor 冷启动通过。`AvidScript.GeneratedTypes` Automation 8/8 覆盖新属性的反射、默认值、C# 方法写入与 float 返回，并继续覆盖 Cook 包加载、继承、生命周期、RPC 和 RepNotify。

## 修复

- 生产包加载先读取并校验规范 WASM，再用受检类型注册表准备精确的 receiver、属性、方法帧和动态派发 Host import 授权；加载后复核 WASM 哈希，避免预检和执行使用不同字节。
- 调试映射的 `defined_function_count` 计入 WASM 后端为 framed export 额外生成的函数，保持 Guest IR、调试偏移、构建合同与运行时校验一致。
- UE 将 World 标记为 teardown 后仍会调用 Actor/Component `EndPlay` 与 WorldSubsystem `Deinitialize`。仅这些原生终止回调可在其所属 Session 中完成同步 C# 逻辑；普通入口、异步恢复和失效 receiver 仍受原有 World 栅栏限制。owner 已失效时，Session 清理跳过无法安全执行的通用 `EndPlay` 导出。
- 原生生成壳的 UFUNCTION 入口原来只执行无参、单 float 参数和无参 int32 返回。现在在准备阶段按 UFunction 反射类型编译受限标量调用形状，支持有界的 bool、32/64 位整数及浮点值参数与返回值；热路径复用该形状，签名不匹配或不支持的 ref/out/复合参数使候选拒绝，而不是静默丢掉调用。本轮实际执行覆盖三参数 `float/bool/int32` 与 float 返回；其他类型组合不由本轮测试证明。
