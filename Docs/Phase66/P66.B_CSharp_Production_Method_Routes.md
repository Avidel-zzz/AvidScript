# P66.B：真实 C# 生产跨对象方法调用

## 范围与结果

本组将 [C# 方法参数帧](P66.B_CSharp_Method_Frames.md) 接入 [生产实例入口](P66.B_Production_Method_Entry.md)。同包、同 World/registry 的生成实例可以通过普通同步 C# 直接方法调用进入另一实例，再同步调用回原实例。参数、返回值、托管对象身份与 ref/out 别名保留在共享执行域中；没有通过手写 WASM 或标量测试入口替代这条语言路径。

新用例由同一份 C# 源码先在 .NET 执行，再经 Semantic、Guest IR、WASM 与生产 Host 执行。A 调用 B 的私有方法，传入 20 个显式参数，包含 UE receiver、共享引用、重叠 ref/out、12 个整数、long 和 double；B 调用 A 并递归，返回包含原对象引用的结构体。正常与每次分配后强制 GC 两种模式均要求一致结果。包重载重新准备方法路由；目标退出后，保存的弱 receiver 被拒绝，受影响共享域隔离，另一个 World 继续执行。

P66.B 保持进行中。当前是同域同步直接方法路由；虚/接口动态选择、跨 owner 绑定方法组、持久 event/await 根、完整调试和结构热重载仍待完成。跨域对象不能借此共享 Guest 堆或同步引用。不承诺完整 C#/.NET 兼容或开发效率领先。

## 编译与运行时合同

- Guest IR 升为 **9/1.8**，继续读取 1–8 版本。`GuestFramedExport.HostImportId` 可选；未设置时保留原 Guest 帧调用。设置时必须指向 `(i32, i32) -> i32` 导入，参数为帧地址与长度，成功返回 1。
- 帧 ABI 仍为版本 1，签名、参数和根布局不随 Host 传输改变。新增 `avidscript.host_call_frames` 自定义段，版本 1，记录准确的 import/export、签名散列、帧大小与参数/根偏移。旧模块不会自动获得新的 Host 能力。
- VM 层只负责有界读取自定义段及 prepared `(ii)i` 调用。Runtime 从被验证的 canonical WASM 读取方法目录，在加载前校验导入、生成类型、导出命名、布局与范围；加载后检查出口签名，并准备绑定当前代码身份的调用。
- 进入方法前核对活动实例、帧头、大小、对齐、签名、保留字节、receiver 类型与注册表。内存视图在重入前释放，原生侧仅复制 receiver 与返回根 token，避免嵌套执行扩容后继续使用旧视图。
- 同 owner 调用支持独立生成 Session；跨 owner 调用必须经过生产执行域的目标成员检查。返回根继续遵守 [显式授权](P66.B_Returned_Root_Authority.md)，保留整链失败传播和外层退出后的域清理。
- WAMR 与 Wasmtime 均支持预备 pair 导入；Wasmtime 原有 dispatcher 路径保留。部分初始化的 prepared target 必须拒绝，不能静默回退。

## 自然赋值语义

真实用例暴露了条件表达式赋值目标被错误当作值保存的问题。新增 `CSharpCapturedLocations` 在 Roslyn CFG 中区分字段位置与普通值快照：结构体字段保存可追踪借用，引用对象字段保存已求值的 receiver，写入时不重新计算接收者。复合赋值额外在 RHS 分支前保存旧左值，防止 RHS 经别名修改字段后错误读取新值。

回归覆盖捕获结构体字段、`+=` 的 RHS 写入同字段、带副作用的 receiver 只求值一次、RHS 替换 receiver 变量、嵌套结构字段和普通值快照；与 .NET 对照，并在两个 VM 的正常/强制 GC 模式执行。同步借用仍不得进入持久 async 或调试暂停状态。
