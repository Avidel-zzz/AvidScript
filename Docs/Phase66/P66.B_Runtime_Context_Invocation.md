# P66.B：共享 Runtime 的实例上下文入口

## 实现与证据层级

本组在 Runtime 层连接一个 VM/托管堆与多个原生提供的实例上下文。`PrepareContextualExportCall` 冷路径生成绑定当前代码身份的预备入口，`InvokeInContext` 在同步调用期间切换 owner、对象所有权、订阅、continuation、调试、Profiler 与反射调用上下文。正常返回或 trap 后恢复调用者。不同 Runtime 或已卸载代码的预备入口不能进入当前 VM；卸载后重新加载也不会复用旧身份。

入口要求 GameThread、有效 owner/对象代际、匹配的 registry 与 World，以及相同的 Host effect journal；暂停的调试上下文不可进入。上下文由原生调用者提供，不是 Guest 自行声明权限，也没有替代生成类型注册、方法派发、Session 暂停/隔离等上层校验。调用者仍负责在整个同步调用期间保有 Runtime 和上下文服务的所有权。

整条上下文调用链上限为 64 层、4096 次入口，返回子调用不会重置入口计数；VM 自身预算继续生效。首个失败会被保留，即使原生回调忽略内层失败，最外层仍返回失败，后续同链入口也会拒绝。已经发生的业务写入不回滚；下一次独立调用获得新计数。

嵌套反射调用使用独立的参数暂存区，保留外层缓冲区地址；切换时清空外层临时对象能力视图，并隔离 delegate output 与 continuation 结果的临时状态，避免目标消费调用者的事务。当前嵌套缓冲区按需分配，尚未做性能验收。

活动上下文链内禁止 load/unload、无作用域的 context 改写、模块 BeginPlay/Tick/EndPlay 及旧事件/continuation/debug resume 入口。旧式模块 timer 缺少实例身份，因此在此入口内明确拒绝；后续实例调度必须通过其 owner 服务接入。拒绝卸载保留 VM 与堆，必须由上层在调用结束后处理，不是自动延迟销毁。

## 双后端验证

新增 `AvidScript.Runtime.GeneratedTypes.SharedRuntimeContext`，在 Wasmtime JIT 与 WAMR Interpreter 上各执行 11 个场景。使用真实 Runtime、两个 UObject、registry、WASM 线性内存、VM global 和受追踪堆的 Host ABI，按 A→B→A 同步调用：

- 三次入口共享同一个托管对象并各自建根，最终字段为 3；每层强制 GC，内层退出不清除外层根。
- 两个引用地址指向同一线性内存位置，每层两次写入，外层最终读到 6；同一个模块 global 记录三次入口。
- WASM 的 owner import 在进入目标和返回父级后都得到正确对象；订阅服务分别路由到 A 与 B。
- 内层 trap、卸载、上下文/模块变更、外部 registry、外部代码、无效 World、owner 退休、旧 timer、深度预算与累计入口预算均有拒绝证据；被故意忽略的错误仍传播到根。
- 所有场景退出后活动帧与根为零，主动回收后没有遗留对象。独立后续调用不继承旧故障；A 退休后 B 仍可独立进入。重新加载后旧预备入口无效，新入口具有独立静态存储。

**这是 Runtime/ABI 探针，不是普通 C# 跨实例调用完成证据。** 测试构造的 WASM 明确使用堆协议和地址别名，没有把两个独立 VM 的复制结果冒充共享语言对象。

集中结果：

- Win64 Development Editor no-clean UBT 成功，使用 `-WaitMutex -NoHotReloadFromIDE`。新增 cpp 首次未被 UBT 缓存发现，使用 `-gather` 刷新索引；没有删除构建产物。之后修正测试代码的 const 指针列表推导，正常 no-clean 构建通过。
- `Build/TestAvidScriptUeReceivers.ps1`：C# receiver **10/10**，GeneratedTypes Automation **9/9**，包括双后端 22 个场景及既有 Session/Host 回归。
- 工程日志：`Saved/Logs/AvidScript_CSharpUeReceiver_20260919T200414776Z.log`；测试发现数、唯一成功数、零失败、队列完成与进程退出均核验。
- Harness audit 通过；架构检查只报告未提交输入与 Git 证据树不一致，其中包含保留的 `AvidScriptWasmReloadTypes.h`。不计为干净候选架构 Gate。

没有重跑完整 Phase Gate、Shipping、性能或移动端验收。

## 接下来接入的所有权

探针支持继续采用共享执行域候选，而不是用跨 VM 深复制替代语言引用语义。下一组按以下职责连接现有 Host/Session：

| Owner | 应持有的状态 | 尚需完成 |
| --- | --- | --- |
| 执行域 | VM、托管堆、线性内存、模块静态状态、代码版本与预备方法目录 | 生成实例 Host 实际共用同一 Runtime；按 World/包隔离；域级候选提交与故障处理 |
| 实例 | receiver、对象能力、订阅、continuation、实例生命周期与调度 | 把当前固定 Session 的 receiver/property imports 改为受检目标上下文；实例结束不销毁其他实例的执行域 |
| 调用 | 父子身份、目标版本、参数/引用、临时根与结果 | 连接已有 Router 调用链与完整参数合同；实际 C# 直接/虚/接口/委托调用保持别名 |

当前生成实例 Host 仍为每个实例创建 Session/VM；本组 API 尚未接入该生产路径。持久事件、跨 await 根、共享域热重载、跨实例调试、原生反射回调中的实际参数别名与完整 C# 端到端用例仍待完成。P66.B 保持进行中。
