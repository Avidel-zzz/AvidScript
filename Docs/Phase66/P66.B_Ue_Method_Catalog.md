# P66.B：UE 实例方法目录与签名合同

## 交付范围

本组实现 [跨实例路由设计](P66.B_Ue_Method_Routing_Design.md) 的编译期目录基础。Semantic 升至 26/1.30，新增独立 schema 1 的 `ue_method_catalog`；没有修改 Guest IR、Host ABI 或原生生成 manifest 6/1.8。P66.B 继续进行，不宣称跨实例执行、语言完整或竞品领先。

Roslyn 投影 UE 脚本类及其基类的实例方法、属性/事件访问器，保留返回类型、返回引用种类、参数次序/类型/ref kind、泛型参数数量、可访问性、函数体可用性和反射暴露标志。私有方法不会因为进入目录而成为 UFUNCTION；外部基类方法可以有目录项而没有 Guest 函数体。

目录保留 direct/base 方法身份、virtual/override/sealed 槽与接口映射，包括隐式实现、显式实现、默认接口及接口继承。封闭泛型声明类型具有独立方法身份，例如 `IValue<int>` 与 `IValue<long>` 不再共用同一个目录方法 ID；两者仍保留原始声明 ID。该身份不表示通用泛型方法专门化已经可执行。

签名使用规范化字段的 SHA-256，目录按稳定键排序。`SemanticUeMethodResolver` 提供冷路径的 direct、virtual、interface 语义选择，覆盖隐藏新虚槽、继承接口映射和显式重新实现。它返回语义描述，不负责 Runtime 权限、包身份、对象有效性、目标 Session 或函数体执行。

## 校验与兼容性

- 当前版本必须有目录；旧版本不得携带目录。Guest 保留 Semantic 25/1.29 和此前支持版本的读取，类型生成器继续要求当前版本。
- 校验目录版本、唯一排序、类型引用、签名、函数体/反射标志、覆写槽、接口闭包和路由一致性；必需字段缺失、错签名、循环接口及错目标被拒绝。
- 路由由 Roslyn 生成；读取者做结构与关联一致性校验，不重新运行完整 Roslyn 源码绑定，也不提供产物真实性认证。运行时仍必须消费既有验证链绑定的实际包和代码版本；不能把目录当成独立执行许可。
- 可达 UE 方法的引用返回暂以 `ASCG1024` 拒绝执行，避免被误降为值返回并丢失别名。目录可记录未执行的引用返回签名。
- Guest 在生成模块前拒绝无效目录，UE 类型生成器在生成原生外壳前拒绝无效目录。封闭接口的签名比较使用对应构造类型，避免把原始 `T` 与具体 `int` 混为不兼容或忽略检查。

## 集中验证

从插件目录运行固定 .NET SDK 8.0.416，`DOTNET_CLI_HOME` 指向仓库外临时目录：

```powershell
& "$env:USERPROFILE/.dotnet/dotnet.exe" run --project Tools/AvidScript.CSharpSemantic.Tests --configuration Release
& "$env:USERPROFILE/.dotnet/dotnet.exe" run --project Tools/AvidScript.CSharpGuest.Tests --configuration Release
& "$env:USERPROFILE/.dotnet/dotnet.exe" run --project Tools/AvidScript.UeTypeGenerator.Tests --configuration Release
```

| Runner | 结果 | 主要新增覆盖 |
| --- | --- | --- |
| Semantic | 308/308 | 目录专项 58 项：继承/隐藏槽、接口、封闭泛型身份、签名、确定性、缺字段及篡改拒绝 |
| CSharpGuest | 356/356 | 当前/旧版实例委托编译、真实 UE 方法输入、目录版本与篡改拒绝、引用返回执行拒绝 |
| UeTypeGenerator | 6/6 | 原有生成回归及空目录、未来版本、缺类型、伪造签名的生成前拒绝 |

本组没有 Runtime 原生代码变更，未新增 UBT、UE Automation 或性能证据。上述测试不能替代双实例运行、Blueprint、GC、网络、Cook 或人工开发体验验收。

Harness 影响分析为 `Managed`，audit 通过，当前写集的 Diff 空白检查通过。工作树架构检查仅报告证据输入与提交树不一致，其中包含保留的 `AvidScriptWasmReloadTypes.h` 用户改动；不将该结果记为干净候选架构 Gate 通过，也不为取得通过而覆盖保护文件。

## 剩余工作

方法目录尚未连接跨 Session 调用、Runtime 虚派发/接口执行或 Blueprint 组合。下一组需要统一目标实例入口、普通托管引用身份、ref/out 别名、有界同步重入及错误展开，以两个实例共享对象并执行 A→B→A 为首个验证路径。持久 event、跨 await/调试暂停根与重载生命周期随后接入；结构重载与调试关键假设的提前探针仍未执行。
