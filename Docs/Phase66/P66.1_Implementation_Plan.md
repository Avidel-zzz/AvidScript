# P66 实施计划

## 批次

| 批次 | 责任与写集 | 完成要求 |
| --- | --- | --- |
| P66.A | Semantic 语言契约与词法函数；Semantic/Guest/WASM 测试 | 静态局部函数由源代码完整编译执行；明确捕获/异步/泛型等当前边界；稳定符号、CFG、可达性和诊断 |
| P66.B | Semantic/Guest/IR 的捕获环境与一等委托 | 局部捕获读写、共享环境、lambda、方法组、delegate/event 常用组合；所有权、reload 和 teardown 边界明确 |
| P66.C | 泛型/集合、错误处理与异步组合的语言及运行时合同 | 日常玩法功能不依赖改写成受限样例；类型专门化、传播/清理和挂起语义有执行证据；不暗示全 .NET 支持 |
| P66.D | 集成样例、兼容性、集中审查和 Gate | 从普通源码验证完整语言工作流；记录真实剩余限制，更新后续结构热重载/调试方案 |

## 当前状态

P66.A 已完成首组编译器实现与托管/WASM 执行验证，详见 [局部函数结果](P66.A_Lexical_Functions.md)。
P66.B 已实现 [直接调用捕获与异步状态保存](P66.B_Direct_Capture_Results.md)、[版本化委托签名合同](P66.B_Delegate_Signature_Contract.md)、[Guest 函数引用和受检间接调用](P66.B_Indirect_Call_Results.md)、[C# 静态方法组委托](P66.B_CSharp_Method_Group_Results.md)及 [同步无捕获 lambda](P66.B_Lambda_Results.md)，均有对应验证。
共享/逃逸捕获已完成 [环境与绑定分析合同](P66.B_Closure_Plan_Results.md)、[环境堆、精确根与循环回收核心](P66.B_Managed_Heap_Results.md)、[WASM Host ABI 与调用根清理](P66.B_Managed_Heap_ABI.md)及 [Guest 受追踪引用与自动根插桩](P66.B_Guest_Managed_References.md)。[C# 闭包执行](P66.B_CSharp_Closure_Execution.md)连接共享 cell 与同步逃逸环境，[C# 内部引用](P66.B_CSharp_Borrowed_References.md)进一步支持捕获值 ref/out、结构体内部写入与委托转发。委托身份、组合/移除、结构体绑定、支持范围内的普通引用对象及 this 捕获已交付；下一步连接 UE receiver、持久回调及跨 await 生命周期，P66.B 不标记完成。
P66.C/D 与 P67-P69 尚未完成。局部能力的通过不能解释为语言完整、框架成熟或竞品领先。

[委托身份与相等](P66.B_Delegate_Identity.md)已连接单目标 `==`/`!=`；[调用列表](P66.B_Delegate_Lists.md)进一步保留顺序、重复项、最后连续匹配移除、返回值及 ref/out 共享位置。[结构体实例委托](P66.B_Bound_Value_Delegates.md)绑定独立受追踪副本。语言 event 与跨 await 生命周期仍未完成。

[普通引用类合同](P66.B_Reference_Class_Contract.md)已补 Semantic 24/1.28 的基类、构造与初始化事实以及安全读取；[普通引用对象执行](P66.B_Reference_Object_Execution.md)进一步连接支持范围内的构造、共享字段与同步实例委托，[this 捕获](P66.B_Receiver_Capture.md)连接同步闭包与原实例保活。UE receiver、持久事件/await 根和完整类语义仍未完成。

[共享内部引用](P66.B_Borrowed_Reference_Contract.md)已完成 IR 6/1.5、WASM 与双后端执行验证，C# 前端已连接同一描述符。Host ABI 保持独立，不将同步借用带入持久存储或 await；完整 ref/in/ref readonly 表达式范围继续由语言合同与执行测试扩展。

P66.B 的 [控制流分配合同](P66.B_Closure_Allocation_Results.md)已明确函数/for/块入口，现由 C# 执行 lowering 使用。P66.C 必须覆盖同步 foreach 的枚举器异常清理 CFG，不能将已有迭代变量作用域分析视为同步 foreach 可运行；既有受控 async 数组迭代另有实现与测试。

执行时保留 P65 全部现存改动和债务。每一独立可审查小节完成集中验证后按精确写集提交；生产门禁与真实开发体验分别记录。

[UE receiver 运行时校验入口](P66.B_Ue_Receiver_Authority.md)已提供双后端 Session/registry/代际/类型/World 校验，并连接 WAMR 补充导入及生成类型预备调用。下一组仍需补齐实例方法的派发事实与编译器接入；它是 UE 实例委托的前置合同，不能视为该语言能力完成。
