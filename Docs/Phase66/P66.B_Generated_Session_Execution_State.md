# P66.B：生成 Session 接入实例执行状态

## 实现

上一组只在受控 Runtime 探针中选择独立实例状态，生产生成类型 Session 仍依赖 Runtime 默认生命周期。本组使生成 Session 在候选激活时创建绑定 owner、registry、World 和代码代次的状态，BeginPlay 成功及事务提交后再发布给调度器。候选失败保留旧 Session；成功重载使旧状态失效。

生成成员的预备出口改为受检上下文出口。Tick、普通事件、Gameplay Event、continuation、委托、调试恢复和 EndPlay 使用 Session 上下文；调度计数、完整/热快照及故障隔离读取同一实例状态。旧脚本 Session 继续使用默认状态。热入口成功时保留调用者的失败输出，不额外构造完整结果。

生成 Runtime 的基准上下文只保留 registry、World 和候选 Host effect journal，不保留实例 owner、订阅、continuation 或调试服务。进入时安装实例服务，退出恢复基准。候选事务仍执行既有 prepare/commit/rollback；架构检查相应跟踪 `SetRuntimeBaseContext` 及 journal 转发，未取消事务要求。

活跃状态不允许通过 `SetHostContext` 换 registry/owner/World；先停止再绑定。缺少 registry 的生成 Session 在激活时拒绝。注销生成注册或清除上下文会退休状态，停止/重载卸载 VM 时使所有相关状态失效。退出同时清空 continuation 与 latent endpoint，避免保留已释放服务。

合法调试暂停允许当前调用返回，后续普通入口仍拒绝。调试器在恢复阶段仍处于 Resuming，专用恢复入口允许进入此状态并消费暂停帧；普通调用不共享该例外。

## 剩余边界

这次只接入生产 Session 的状态与入口，**生产 Host 仍为每个实例创建独立 VM**。它没有交付共享执行域的所有权、最后 owner 卸载、执行域故障传播、包级原子 reload、完整跨对象方法路由或持久 event/await 根。原有 Host 活动调用 teardown 拒绝后的自动延迟清理仍待实现。

下一组按 `P66.B_Instance_Execution_State.md` 的执行域合同整合 Host 所有权和包事务。共享 heap/static 可能已被失败调用修改，不能把丢弃单个实例状态当成执行域回滚。P66.B 继续进行，当前测试也不是完整语言、生产成熟度或竞品领先的验收。
