# P66.B：生产生成类型共享执行域

## 变化与合同

生产 `FAvidScriptGeneratedTypeRuntimeHost` 现在按已安装包、World 和对象注册表选择执行域；同域实例共享 Runtime、WASM 线性内存、global、托管堆、代码和生成绑定。不同 World 使用不同 VM，无 World 对象在该 Host 内归属独立的空 World 域。没有把 UObject 变成 Guest 强引用。

Session 保留自己的 owner、显式执行状态、Timer、continuation、订阅、调试和资源清理。退出先结束实例、取消资源并退休状态，只释放自己的 Runtime 租约；最后实例退出才卸载 VM。独立构造的 Session 保留原有独立 Runtime 用法。共享实例禁止私自替换模块或直接清空绑定身份，必须通过包级重载或先停止实例。

执行域不强持有 Session，活动成员由 Host 所有；Session 的强租约保留域和 Runtime。进入忙碌判断读取 Runtime 的上下文调用深度，不在每次 Guest 调用中扫描同域实例。实例登记、退出和包事务属于冷路径。

新实例进入时屏蔽同域已有实例的回调入口；完成初始化后再加入域。初始化失败可能已经修改共享状态，因此隔离已有成员并停止域，而不是卸载新实例后让其他成员继续使用已污染状态。成员执行 trap 同样使整个域拒绝新入口，活动调用退出后取消成员资源、退休状态并释放 VM；其他 World 不受影响。故障停止不运行 Guest EndPlay，失败诊断保留到各 Session。生成对象和注册仍由 Host 的显式退出/生命周期清理负责，不能把释放 VM 等同于立即删除所有 Host 实例记录。

包级 body-only reload 仍遵守全包屏障及 prepare/validate/publish。每个旧域只建立一个候选 VM，显式共享状态迁移只执行一次，域内所有实例在同一个候选 VM 准备自己的状态和回调；所有候选准备成功才发布。失败丢弃候选，保留原域；无法还原副作用或发布中失效时，先隔离活跃域再清理，避免停止过程中执行混合代次的 EndPlay。

完整反射 shape 相同的 reload 保留原不可变类型注册快照作为该包的权威身份，并更新产物；后续加入的实例与候选 Runtime 的生成 import 使用同一个快照，避免“旧对象正常、新对象被视为外来类型身份”的错误。结构变化仍要求原生重建。

## 剩余边界

这次交付共享所有权、生成实例生命周期及包重载接入。完整方法签名、C# 跨对象调用、virtual/interface 派发和生产同步 A→B→A 仍需连接；当前 Session 入口继续拒绝活动域中的普通重入，不将共享 VM 误称为完整跨实例语言能力。
