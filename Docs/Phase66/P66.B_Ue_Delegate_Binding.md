# P66.B：跨对象 UE 方法组绑定

## 冻结合同

在已交付的跨对象方法帧上，连接直接、base、virtual/interface 方法组。委托创建时求值 receiver 一次，验证目标属于可访问的注册执行域，并选定实际方法；调用时仍走生产方法帧。不能通过放宽当前 owner 的 receiver guard 让目标借用调用者上下文。

新增 `avidscript/avid_ue_receiver_type_v1`，签名 `(I)i`：输入带代际的弱 handle，成功返回注册 ordinal + 1，失败通过 typed host 拒绝。该查询只提供类型选择，不授予执行或保活权限，沿现有 generated authority 校验活动源、目标、World/registry 和状态；旧模块不声明该 import 时不增加导入。

编译器使用目录中的静态绑定/虚槽/接口映射生成有限选择函数。动态方法组在创建时选择具体实现的 thunk 与 receiver box；相同实际方法、相同 receiver 的重复绑定按现有委托身份比较，因此基类视图与接口视图可以产生相等委托，base 固定方法保持区别。普通托管对象 token 不与 UE handle 混用。

仅同域同步传递与执行在本组范围内；持久 Host 订阅、跨 await 根与活动委托迁移仍由后续生命周期组实现。不能在本组静态存储委托来模拟已经完成的持久保活。

## 验证要求

同源 .NET 与真实 C# WASM 验证跨 owner 创建、receiver 求值一次、虚覆写/interface/base、委托相等与组合移除、共享引用/ref/out、正常与强制 GC。空目标、错误域、失效目标应明确拒绝；同步重入、重载后重新绑定、其他 World 故障隔离保留。

## 实现与结果

[绑定计划及选择函数](../../Tools/AvidScript.CSharpGuest/Lowering/CSharpUeDelegateBinding.cs)复用已验证目录，将实际实现加入方法组集合；[派发可达性](../../Tools/AvidScript.CSharpGuest/Lowering/CSharpUeDispatch.cs)同时处理调用与方法引用，因此仅经覆写可达的依赖也参与编译。现有方法 thunk、委托相等与方法帧复用实际方法身份。Runtime 查询先解析活 UObject，再沿 authority 查询注册类型，并再次确认类型匹配；原 owner guard 未放宽。

真实源码用例先通过 `Choose().Apply` 绑定 B，再改变局部目标变量；与基类视图的同一覆写比较相等，组合后通过接口视图移除同一方法，并执行剩余委托。派生实现内绑定 `base.Apply`，与 `this.Apply` 比较不等，再调用基类委托。显式接口的重复绑定也比较相等。方法体继续包含 A→B→A、含引用结构返回与两个 ref 参数共享位置。

固定 SDK 8.0.416 全量 CSharpGuest **421/421**、receiver 定向 **32/32**、动态方法定向 **14/14**、新方法组定向 **15/15** 通过；最小方法组用例不依赖额外的布尔表达式或状态对象。Windows no-clean 构建成功。原生 GeneratedTypes 用例将原动态调用和新委托 fixture 分别运行：每个 fixture 包含 Wasmtime/WAMR、正常/强制 GC、基类/派生类/未注册原生子类 12 种配置，验证结果、根/帧回收、重载后重新绑定、目标退休后拒绝及其他 World 继续。

最终受控 GeneratedTypes **19/19** 通过，日志为工程 `Saved/Logs/AvidScript_CSharpUeReceiver_20260920T053236401Z.log`；编译 fixture 的 32/32、14/14、15/15、唯一完整测试队列与退出码 0 均由入口核对。没有修改 Guest IR/帧 ABI，也没有改变现有虚方法调用的选择时机；仅方法组在创建时选定实际 thunk。Harness audit、改动路径空白检查与文档链接通过；架构检查仅报告当前源码和已有受保护 header 与已提交 tree 不一致，不作为干净发布 Gate。所有 7 项受保护改动继续保留。

## 剩余范围

本组是同步方法组执行增量，不是 P66.B 完成。正常重载测试重新创建委托；未证明存量委托、挂起任务或 Host 订阅跨版本迁移。目标在绑定与调用之间退出的持久场景、事件/await 根与取消需在下一组统一验证。普通托管类接口/继承、默认接口方法及封闭泛型接口执行继续独立推进，不以本组覆盖完整语言多态。未进行新的性能对测、Shipping 或移动平台验收。
