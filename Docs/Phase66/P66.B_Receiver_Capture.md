# P66.B：普通引用对象的 this 捕获

## 实现范围

在[普通引用对象执行](P66.B_Reference_Object_Execution.md)上连接同步闭包的 receiver cell。语义层已有 receiver 身份、所属实例方法与 activation 分配合同；执行层在环境分配后写入原对象引用。闭包通过既有受追踪环境读取同一实例，不复制对象字段，也不保存未受保护的裸地址。构造函数、手写属性、lambda、局部函数和嵌套回调共用这条路径。

仅启用现有支持范围内的普通源代码引用类。UE receiver、结构体 this 捕获、未连接的 async frame、持久事件和调试暂停继续按各自合同限制。本组不改变 Semantic 24/1.28、Guest IR 6/1.5 或 Host ABI，也不把同步逃逸解释为跨 Session 保活。

## 身份与回收

只含 receiver 的捕获环境，委托比较使用原对象身份与目标函数；同一实例重复执行同一捕获表达式可比较并移除对应委托。包含局部变量或参数的环境仍比较 activation 身份，不因字段值相同而合并。不同 lambda/局部函数的目标身份保持不同。这里验证固定 Roslyn/.NET 8 参考编译下的支持用例，不声明任意编译器生成委托对象布局相同。

对象可引用自己的闭包，闭包也可持有对象。沿既有精确根和循环回收路径处理这类图：执行期间保活；普通返回或 Guest fault 后帧与根释放；后续回收清除已不可达的对象和环境。

## 验证内容

`CSharpGuestReceiverCaptureTests` 使用同一 C# 源码的 .NET 参考执行和实际 WASM：

- 构造函数捕获、返回 this、同一/不同对象的委托比较、组合与移除。
- 参数与局部状态共享、嵌套工厂、直接调用与委托共用局部函数、递归、循环局部变量。
- 属性 getter/setter、字段 ref 修改、嵌套结构体实例写入、调用方变量替换后的原实例保活。
- 普通和每次分配后强制回收两种模块，结果均须为 8191。
- 回调中发生空引用错误，错误前的写入结果须为 7；Guest 不承诺 CLR 异常类型等价。
- 两种 VM 后端检查故障诊断、零活动帧、零根及最终零存活对象。
