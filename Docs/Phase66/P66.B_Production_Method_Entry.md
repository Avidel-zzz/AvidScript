# P66.B：生产实例上下文调用入口

## 实现与边界

在[共享执行域](P66.B_Production_Execution_Domain.md)之上新增 `InvokeGeneratedInstanceExport`。这是供原生 prepared route 使用的执行入口：它接收当前代码代次的 prepared export、目标 ObjectHandle 和 VM 调用帧，不接收 Guest 自报的方法名或跨包 ordinal。普通 Session 入口仍拒绝重入；只有这个受检入口允许同步进入同域目标。

Runtime 从当前活动上下文取得弱实例权限，Session 验证来源 Runtime，执行域用完整 packed handle 的索引查找目标。目标必须是同包、同 World/registry 的已发布成员，且源/目标均在 Running 状态，没有 mutation、包级重载屏障、暂停、失效或隔离。Runtime 再验证实例状态、对象存活、World、effect journal 和 prepared code identity。入口不复制托管对象、不改变堆 token，也不把 ref 参数复制成独立值。

整个链复用 Runtime 的深度 64、累计入口 4096 限制，切换 Session 不重置预算。目标调用增加其活动深度；返回时恢复调用者的 owner、实例资源和绑定上下文。调用期间 stop、reload、clear、实例退休等操作保持禁止。

内层失败被锁存到根调用，即使原生桥接忽略返回值也不能把外层执行报告为成功。目标执行失败保留原始 export/错误类别并隔离整个域；VM/堆的释放等待最外层调用退出。失败前已发生的写入仍可由外层栈观察，不以参数回拷覆盖别名或声称回滚整个调用。

本组没有更改 Guest IR、WASM import ABI 或生成 manifest。原生 API 接受现有 VM 帧支持的全部类型组合，仍受 8 个 32-bit cell 上限约束；它不是任意 C# 签名编码器。既有生成 UFUNCTION 原生参数入口仍只有三类形状，完整方法目录、private/direct/base/virtual/interface 选择和 C# 调用 lowering 尚需接入。不能据此宣称完整 C# 跨对象调用已经交付。

## 验证

新增 `AvidScript.Runtime.GeneratedTypes.ProductionInstanceEntry`，复用真实 Wasmtime/WAMR 的堆探针，通过生产 Session 的激活、generated Dispatcher、实例权限和执行域完成 A→B→A。测试只在装载前注入原生探针 import，不替换目标选择或上下文实现。

- 混合 i32、i64 托管 token、两个指针和 f64 占满 8-cell 参数帧；两个指针指向同一位置。
- 三层调用共享一个托管对象、同一静态状态和 ref 位置，每层强制 GC；检查调用前后 owner、最终写入顺序、根/帧清空及对象可回收。
- trap、调用期间 mutation、外来代码、域外目标、owner 退休、深度/累计预算、错误帧长度与目标暂停。
- 内层失败时外层堆仍有效；最外层返回后两实例隔离、状态退休、VM 卸载，后续入口拒绝。

## 下一组：完整语言方法 ABI

不能直接把完整方法参数展开到当前 8-cell native frame。下一组应以版本化的间接参数帧连接方法目录与 prepared export：保留 receiver 身份、签名身份、返回区及结构布局；ref/out 传递已有 borrowed descriptor，值结构可复制而共享引用不得复制成新对象。调用方为整个同步链保留参数区与根，返回值含引用时必须在临时根释放前接管。

冷路径从已验证 Semantic 方法目录生成可执行路由并绑定实际 WASM 产物；直接/base、virtual、interface、方法组共用选择规则。私有方法保留独立目录，不提升为 UFUNCTION；拒绝错误签名、旧版、错包及失效代码。新产物的生产者、读取者、缓存身份与拒绝测试须同时升级。

接入后以同源 .NET 参考语义与真实 C# 双后端执行验证对象身份、包含引用的结构、ref/out 别名、实例切换与故障前写入。再连接持久 event/await 根。P66.B 保持进行中，结构热重载和完整调试仍按后续路线推进。
