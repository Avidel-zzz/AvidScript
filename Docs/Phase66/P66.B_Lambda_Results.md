# P66.B 进展：同步无捕获 lambda

## 可执行范围

成员函数中的同步无捕获 lambda 和匿名方法现在拥有独立 callable、词法身份与控制流图。创建委托不会执行其函数体；调用复用已有的名义签名检查、Guest 函数引用和 WASM `call_indirect`。支持在 Guest 内传参、返回、条件选择和嵌套工厂，不需要新增 Host import 或 CLR。

执行用例覆盖表达式与块体、显式 `static`、ref/out、匿名方法省略参数列表、属性 getter 返回 lambda、lambda 间接递归，以及 lambda 内部局部函数捕获该次调用的参数。最后一种情形仍是局部函数的直接调用捕获，并非可逃逸环境。外层常量折叠后无需捕获。

lambda 的身份采用词法 owner 与序号，空白变化不改变身份；增删或重排 lambda 可能改变序号，本次不承诺结构热重载迁移。嵌套 lambda 的 CFG 从所属 Roslyn CFG 获取，函数体独立投影，可达性继续通过方法引用传播。

## 捕获与兼容边界

捕获分析覆盖变量引用、实例接收者及调用/方法引用的传递依赖。setter 隐式 `value`、省略列表的匿名方法参数也保留所属函数信息。捕获外层激活状态的 lambda 返回 `ASCS4001`，明确需要尚未实现的受管捕获环境；直接、间接及嵌套捕获均有拒绝测试。没有将激活记录地址作为逃逸委托环境。

Semantic Schema 保持 21，Semantic Version 升至 1.25。当前缓存、prepared semantic 和脚本类型生成入口同步版本。Guest 保留 21/1.24 静态方法组的读取与执行，并拒绝把新 lambda callable 伪装成 1.24。Guest IR 保持 3/1.2，WASM ABI 无变化。

async lambda、字段初始化器中的 lambda、共享/逃逸捕获环境、绑定实例委托、多播/event、跨 await 委托状态仍未实现。函数引用仍禁止跨 Host import、入口签名或静态持久化状态传递。调试插桩验证仅证明生成签名与 WASM 有效，尚非完整调试体验验收。

复现：设置仓库外的 `AVIDSCRIPT_LOCAL_FUNCTION_WASM_DIR`，运行 `dotnet run --project Tools/AvidScript.CSharpGuest.Tests --configuration Release`（聚焦加 `-- --lambdas`），再执行 `node Tools/AvidScript.CSharpGuest.Tests/RunLambdaWasm.mjs <输出目录>/lambdas.wasm`。缓存和 prepared 合同分别运行同名 PowerShell 测试脚本；prepared 的备份清理告警来自预期故障注入。

本轮没有新增 UE 构建、Automation、PIE、热重载或 World teardown 验收。P66.B 仍未完成，下一步是共享/逃逸捕获环境与所有权，继而集成 Session、reload 和 teardown。上述结果只证明已覆盖语言路径的执行，不构成框架成熟或领先竞品的证据。
