# P66.B：生产实例调用的返回根授权

## 目的与边界

[C# 方法参数帧](P66.B_CSharp_Method_Frames.md)已能保留复杂返回值和引用别名。将它接入生产跨对象入口前，必须保证被调用方只更新明确交给它的返回根，且返回对象在被调用方退出到调用者恢复之间不会被 GC 回收。

本组将此权限接入 `InvokeGeneratedInstanceExport` 和真实 VM 的堆协议。**它是完整跨对象语言路由的前置能力，不表示 C# 跨对象、virtual/interface、持久事件或 await 已完成。** 双后端测试使用明确标注的原生路由/WASM ABI 夹具，不以手写 WASM 代替后续语言端到端验收。

## 合同

- 原生调用者显式提供返回根列表；每个 token 必须有效、属于同一堆、位于当前调用者的栈顶堆帧，而且该帧必须由当前 VM 调用创建。持久根、祖先帧、失效根和其他堆的根均拒绝；列表受堆根配额限制。重复 token 允许，保留别名。
- 授权只允许被调用方执行 `SetRoot`。`ReleaseRoot`、直接向调用者根 `Allocate`、在调用者帧或持久区域 `CreateRoot` 均不获授权。被调用方自己的帧和根继续正常工作。
- 协议先验证完整包形状和输出长度，再核对权限，最后修改堆或输出。无嵌套帧边界时沿用既有检查路径，避免普通顶层操作重复查找根。
- 授权由原生栈上的 scope 保存，包含 VM 调用深度与入口堆帧边界，不进入 Guest memory。嵌套生成入口会遮蔽外层授权；其他上下文入口也必须匹配调用深度，不能因为没有新建堆帧而继承授权。返回时恢复原 scope。
- 尚未创建自身堆帧的被调用方不能把祖先根再次转交。原生授权列表验证失败使用 `generated_invocation_roots`；协议越权使用 `RootAuthority`。错误沿现有整链失败机制传播，即使 Host 回调忽略错误，也不能恢复为成功。
- 被调用方退出仍只展开自己的帧。返回根由调用者继续持有；调用者退出后正常释放。授权不复制对象、不改变共享对象身份，也不授予对象字段之外的额外操作。

原生堆 runner **15/15**：新增当前帧授权、持久/祖先/其他堆/失效 token 拒绝、配额、重复根、未授权更新、禁止释放/分配/创建、包与输出预检、强制回收、槽复用、代际与退出释放；保留 4000 步图回收对照。

UE5.8 Win64 no-clean Editor 构建通过。`Build/TestAvidScriptUeReceivers.ps1` 的 C# fixture **25/25**、GeneratedTypes Automation **17/17** 通过。既有 ProductionInstanceEntry 用例新增 11 类场景，在 Wasmtime JIT 与 WAMR Interpreter 各执行一次：

1. 新对象写入返回根；被调用方展开后，Host 在恢复调用者之前强制 GC，返回对象和值及调用者原对象保持。
2. 无堆帧的嵌套成功调用后恢复外层授权。
3. 未提供授权与授权了另一根，均拒绝目标根更新。
4. 无效根在目标执行副作用之前拒绝。
5. 获授权的根仍不能被释放、用于直接分配或创建调用者根。
6. 无堆帧的嵌套生成入口、普通上下文入口均不能继承授权；显式再次转交祖先根也拒绝。

成功后根/帧归零，最终 GC 后对象归零；失败后整域隔离、外层返回后卸载，原错误保留。日志：工程 `Saved/Logs/AvidScript_CSharpUeReceiver_20260920T002952187Z.log`。协议测试开发中修正一处不同整数宽度共用 `auto` 声明的编译错误；该失败不计为通过。
