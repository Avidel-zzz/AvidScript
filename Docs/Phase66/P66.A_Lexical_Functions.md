# P66.A：局部函数的编译基础

## 已实现与边界

成员内 `static`、同步、非泛型、具有托管函数体的局部函数通过现有 callable/CFG 合同 lowering，支持嵌套、递归、同名词法作用域隔离、默认参数和现有 `ref/out` 调用。主源与可执行引用源使用同一条路径；可达性会剔除未使用的局部函数。

局部声明不作为外层可执行操作重复投影。受控 async 的直接分段、结构化语句、可恢复控制流均忽略声明本身，保留对同步局部函数的调用。这里并未实现 async 局部函数或完整调试暂停。

`SemanticLocalFunctionPolicy` 统一语法与操作检查。捕获/非静态、泛型、async、extern 等当前不支持的局部函数报告 `ASCS4010`；局部函数声明 WASM export 报告 `ASCS5010`。这些是暂存限制，不是 P66 的最终语言目标。

不增加 opcode、Host import 或 Runtime ABI；Semantic schema 20 / 1.22 的 callable/CFG 编码未改变。工具链缓存已有递归 C# 源码指纹，新增 policy 与 projector 改动会使旧缓存失效。局部身份使用 owner 和同名作用域序号，不使用源字符偏移，也不作为存档身份。
