# P66.B：生成实例 Host 的重入销毁保护

## 问题与实现

此前 `EndInstance` 先把实例移出 Host，再执行 teardown。当活动调用使 Session 拒绝卸载或注销时，清理仍可能释放 Session，令当前调用栈或 Router 保留失效指针。包回滚失败与 Host shutdown 的无条件清空也有同类所有权风险。

本组把实例保留在 Host 中直到 Session 与 receiver handle 都已释放。卸载前检查活动 Session/Router 调用；注销失败立即返回，保留 Session 和 handle。Host 的安装、清空、激活、结束、重载与关闭使用统一变更边界，活动调用或包事务中的重入变更明确拒绝。关闭和回滚清理只移除已完成释放的条目；存在未清理条目时保留所有权，并禁止继续激活或重载。

Router 对已被死对象清理移除的注册允许幂等 Reset；仍拒绝活动派发时注销，也不允许旧注册移除另一个实例或代次的现存路由。

## 边界

这里实现的是拒绝重入变更时的所有权安全，不是自动延迟销毁队列。调用者必须在活动调用返回后重试结束或关闭；正常空闲清理继续同步执行。Host 本身仍要求先成功 shutdown 再析构。回调内创建其他生成实例也暂时受这一变更边界限制。

测试观察器和原生 Router 回调验证真实 Host/Session 的拒绝路径，但不代表完整 C# 跨实例调用、共享 VM/堆或跨 await 根已经接通。P66.B 继续进行，下一步仍是执行域与实例上下文拆分。
