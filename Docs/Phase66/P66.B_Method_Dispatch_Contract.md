# P66.B：实例方法的派发语义合同

## 本组结果与边界

Semantic 升级为 schema 25 / semantic 1.29，保存方法声明和调用位置的派发信息，为 UE 实例委托接入提供编译依据。Guest IR 和 Host ABI 未变。本组没有启用 UE 实例委托、虚方法表或持久事件，也不将编译器能描述虚调用解释为已经能执行它。

此前普通调用 lowering 直接选择目标 Guest 函数体。对虚调用，这会丢失覆写选择。本组对当前产物中的 virtual/interface 调用明确诊断 `ASCG1024`，等待运行时路由接入；直接实例调用、静态调用、既有委托调用与 canonical UE export 保持现有路径。历史产物不含这些事实，按其原有合同读取，不据此承诺新增的派发能力。

## 合同

- `SemanticCallable.Dispatch` 保存 Roslyn 的 virtual、abstract、override、sealed 标志、直接覆写目标、原始虚方法槽及显式接口实现的成员身份。`new virtual` 创建新槽，多层 override 保留原槽。显式接口列表不等于完整接口实现映射。
- `SemanticOperation.Dispatch` 针对 invocation 和 method reference 区分 static、direct、virtual、interface、delegate，并保存槽身份与 base 访问事实。`base.M()` 和 `base.M` 方法组均为 direct；不能只依据 Roslyn method-reference 的 IsVirtual 决定行为。
- lexical capture 归一化将局部函数改为静态 callable 时，同步改写调用和方法组的派发信息。源码树、CFG、async statement、await argument 和 cancellation expression 使用一致的投影与检查。
- 新派发记录的所有字段都要求显式序列化，缺失布尔值不能静默成为 false。输入校验拒绝缺失记录、未知种类、矛盾声明、已知覆写链循环、槽不一致、非法显式接口目标及不匹配的调用路由。外部基类方法可以只有稳定身份而没有本模块可执行 callable。

这里保存的是方法派发事实；完整接口映射、受约束泛型执行、虚属性访问和运行时派发仍需对应实现与验收。不得通过固定函数体或仅允许无覆写样例替代这些能力。

## 兼容性与验证

保留 schema 24 / 1.28 与既有旧版读取。旧产物不得携带新派发记录；新产物不得剥掉派发记录后继续执行。旧版测试通过 JSON 结构遍历移除新字段，构造真实的旧合同，不只修改版本号。修复委托版本判定，使 1.28 的实例委托与 lambda 不因升级 current version 而失效。

固定 SDK 8.0.416 验证：

```powershell
dotnet run --project Tools/AvidScript.CSharpSemantic.Tests --configuration Release
dotnet run --project Tools/AvidScript.CSharpGuest.Tests --configuration Release
```

Semantic 250/250、Guest 336/336 通过，两个 runner 均退出 0。新增用例覆盖多层覆写、sealed override、new virtual、显式接口身份、base 调用/方法组、确定性序列化、字段缺失、恶意元数据、CFG 独立检查、旧 1.28 引用对象委托，以及 UE 虚调用不得降为固定函数体。

Harness 影响计划为 Managed。本组没有修改 UE 原生运行时，不重跑 UBT、UE Automation、Shipping 或性能矩阵；以上编译器证据不替代 UE 实例委托执行验收。受保护的 `AvidScriptWasmReloadTypes.h` 改动保持原样，架构检查仍不能计为 clean Gate。

下一步将本合同与 UE receiver 身份校验连接到实例委托和动态方法路由，再扩展持久事件及跨 await 的所有权。P66.B 保持进行中。
