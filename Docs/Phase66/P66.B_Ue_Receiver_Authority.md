# P66.B：UE receiver 的运行时校验入口

## 目的与边界

普通引用对象的 this 捕获已执行，但 UE 对象使用带代际的 ObjectHandle。实例委托不能只保存数字句柄：纯脚本方法可能不读取属性，因而不会触发既有属性 Host 校验。本组提供编译器后续可调用的 receiver 合同，尚未启用 C# UE 实例方法组或 this 捕获。

编译器接入还需要明确虚方法/覆写派发信息，不能把动态派发替换为固定方法体；持久事件与 await 则需要 Session 根与取消合同。这些仍属于 P66.B/C 的后续工作。

## 运行时合同

生成类型 Session 根据当前 registry 的类型 ordinal 准备 `avidscript.avid_ue_receiver_<ordinal>_require_v1`，签名为 `(i64) -> i32`。成功返回 1，失败通过既有 typed Host rejection 路径停止本次执行并隔离故障 Session。导入必须与 WASM 和 manifest 的实际需求匹配，不按名称前缀授予任意导入权限。

校验读取当前 Session 配置，要求 Game Thread、未挂起/未失效/未隔离的生命周期、有效生成类型注册、相同 owner 句柄、实际注册表解析结果与原 UObject 相同，以及相符的类型和对象存活状态。带 World 的对象还必须属于当前 Host World，且 World 未进入 teardown。SetHostContext 原有逻辑会将传入 World 规范化为 owner 的实际 World。

该入口是只读身份校验，不另建对象所有权、不强引用 UObject、不代替 Session 的 Guest 入口门禁。卸载后没有 VM 可执行；清除生成类型注册后校验也失败。类型 ordinal 的含义来自当前生成类型包，结构变化仍按既有包兼容规则处理。

## WAMR 调用路径

执行验证发现两项原有缺口并在本组连接：

- WAMR 原先没有消费 Session 的 supplemental typed imports。现支持本合同需要的 `PackedSelfPropertyI32Get` / `(I)i` 形状；其他补充形状继续明确拒绝，未宣称完整 typed import 覆盖。
- WAMR 原先拒绝 PrepareExportCall，使生成类型 Session 无法准备出口。现准备一个拥有 handle 副本的调用适配器，验证参数/返回 cell 容量并使用已有 generic Call，保留代际、预算、trap、调用根和延迟卸载处理。它不是新的 unchecked 性能路径。

WAMR 全局注册仅共享导入名称和 ABI stub；上下文及权限留在每个 VM 内。加载、重载、卸载复用现有注册计数和冲突检查；动态绑定包仍走原有完整校验，不能把 supplemental 接入变成跳过绑定包验证的通道。

## 验证
