# P66.C20：共享生成类型的语言失败回滚

## 冻结范围

C19 已接通普通 Editor workspace 的 Gameplay 配置。生成 UE 类型的正式构建仍未传递该配置，静态执行准备还拒绝所有 UE 类型声明；已有全包准备回滚使用测试注入失败，尚未证明完整普通 C# 组合自然抛错后的恢复。

本节沿正式 C# → Semantic → Guest IR → WASM → 生成类型 Host 补齐该链。源文件 `Fixtures/Phase66/GeneratedNaturalReload.cs` 同时声明 Actor 和 Component；两个类型调用相同静态状态、标准 `CancellationToken`、结果 Task、命名 catch、finally 和两次等待。候选 BeginPlay 修改真实 UProperty、建立挂起任务后由 C# `throw` 拒绝。不得改成独立 Session、手写 WASM、测试注入 trap 或省略组合能力。

## 所有权与兼容

- C# owner 继续定义 `gameplay-v1`、组合版本和能力；生成类型构建只转发配置并核对身份、源码和产物。旧参数路径保持原合同，未知配置、冲突开关、Shipping/headless 和仅生成 shell 的预览配置在发布前拒绝。
- 静态准备必须验证原始 UE 类型与方法目录，再保留声明、receiver、member identity 和反射 shape。专用静态存储属于包/World/registry 执行域，不能为每个 Actor 重建一份。
- 生成属性写入加入现有 Host effect journal；每次写入用当前调用上下文，而非 VM 首次 owner。首个写入捕获原值，同一个候选的重复写入不覆盖快照。候选准备失败和已准备 peer 逆序丢弃共同还原全包；无法还原时全包隔离，不能返回“旧包完整”。
- 语言错误继续使用源码位置和既有报告 ABI。旧 VM、heap、静态状态、实例代次与任务队列直到全包发布才退休。失败候选的 continuation、Task、帧、token 和根必须释放，候选的晚到完成不得进入旧实例。
- 成功 body-only 重载保留反射 shape；所有实例一致切换，旧任务退休，新代次重新执行生命周期。结构变化仍返回 native rebuild required。

生成域的状态表复用 Schema 2，以 `execution_domain:<module_id>` 为 owner；字段身份再包含封闭静态类型和原字段名。字段 policy、persist/transient 和 alias 仍由原 Semantic 合同决定，类型和 offset 只能从同一份静态准备计划及实际 Guest 存储解析。所有共享静态 owner 使用同一个 contract version，不同版本在构建时诊断，不能取最大值掩盖某个 owner 的版本回退。Runtime 已有仅在首个候选 VM 上迁移一次的保护；本节须用生成类型验证它，不重复实现另一份迁移机制。夹具中的 `CandidateBegins` 明确为 transient，只计本次候选生命周期；`BeginCount`、`Completed`、`Cleaned` 继续按 compatible 合同迁移。

## 必需验证

1. 真实生成绑定声明和未改写的普通源码经 `-LanguageProfile gameplay-v1` 正式生成 native shell 与 Runtime package；CLI/worker 的 Semantic、IR、WASM、state 和 debug map 一致，类型清单与执行产物保留原始哈希。错误配置不得发布。
2. 同源 .NET 对照核对 Actor/Component 的结果、静态共享、等待顺序和清理；两代代码及第 1/2/3 个 BeginPlay 的自然失败均保留来源。测试替身只用于 .NET 参考宿主，UE 执行使用生产 Host。
3. Wasmtime/WAMR 内实际 UHT 类型在同 World 共享 VM、不同 World 隔离。两个挂起时点分别检查全包拒绝后的 VM/实例身份、UProperty、静态值、任务/等待者/帧/ready 队列/根不变；恢复执行得到旧代码结果。
4. 成功全包切换、单 owner 销毁/GC、World teardown、候选后续异步错误以及最后 owner 退出均检查清理与其他 World 的隔离。不得只核对返回值，不得将 API 驱动 World 当成人工 Editor Play。

原生矩阵为两个后端 × 两个挂起时点 × 九种行为，共 36 组。行为包括原版本完成、第 1/2/3 次候选 BeginPlay 自然失败、成功发布、单 Actor 退出、Component 退出后 GC、World teardown 和发布后异步失败。观察器只读候选身份、真实属性与挂起工作，不制造失败或修改发布决定。测试通过生产 descriptor loader 读取原始 Registry 和被验证的 canonical WASM；后端选择只改变执行配置，不映射到测试类、不重写 import 或替换 bytes。

`Build/TestGeneratedNaturalReloadInEditor.ps1` 支持先在仓库外准备六份正式包，再以 `PreparedRunRoot` 校验并复用同一批源码及产物。执行包由正式构建器发布到项目内独立的 `Saved/AvidScript/GeneratedNaturalReload` 目录，核对原始类型、WASM、状态与来源身份，保留 Runtime 的项目路径限制。`PreparedExecutionRoot` 可复用这个命名空间下已有的执行包；必须同时指定有效准备目录，准备模式、其他目录和缺少准备目录均在写入前拒绝。原生执行前核对 canonical 类型身份、备份四个生成文件；测试结束后逐文件核对哈希并恢复原目标。过程复用安装 SDK、关闭本次编译 worker、检查持久 PATH，没有目录清理操作。准备模式的 `runtime_executed=false` 不算 UE 验收。

实现涉及 Guest 静态准备与生成路由、UE type generator 的原始组合合同读取、正式生成类型构建入口、Runtime 生成属性 journal 以及必要回归。先冻结受影响候选，再串行执行 .NET runner、no-clean Win64 UBT 和聚焦 Automation；复用安装 SDK，BelowNormal、单并发，不改持久 PATH，不清引擎或用户产物。

## 实现与验证

六份普通 C# 源码经 `gameplay-v1` 正式构建，保留 Semantic 56/1.65 与 IR 37/1.36；五份候选保持反射结构，并按 body-only 分类。Runtime manifest 与 debug map 使用同一个显式 `SourceId` 和源码哈希。静态准备先验证原 UE 声明和目录；旧静态 envelope 按已验证的 base 读取合同，移除声明、伪造合同或无关源码错误均拒绝。

生成类型的通用 `avid_on_begin_play` 是兼容入口，不替 UObject 执行原生生命周期。Session 记录对象实际进入过的 `BeginPlay` / `Initialize` 路由，候选准备时在新 VM 的对应实例上下文中重放。只加载 VM 不会合成这些调用，同 owner 的方法仍走既有上下文和代际校验。候选修改真实 UProperty 时先登记旧值，失败后与已准备 peer 一起回滚。

原 IR 为 `ReloadFlow` 声明一个静态初始化根槽，属于共享 VM。运行观察分别核对该槽、任务及异常根、托管帧和对象；工作完成后只有声明的域槽可保留，最后 owner 退出必须释放 VM。语言报告的类型和 UTF-16 源码位置由 Host 校验；若生成入口报告后继续 trap，保留主 VM/Host 类别与 import 身份，并附上完整语言详情。没有有效报告的 trap 不会被改判为语言异常，报告也不会保留 Guest 根或流入下一次调用。

## 剩余边界

本节验证了正式生成 Actor / Component 的共享状态、自然语言失败和 body-only 回滚。真实 Editor Play、结构热重载、完整调试、跨语言 SDK、Windows Shipping 与竞品同口径领先性仍未完成，P66.C/D 保持未完成。

C20 验证时，显式逻辑 `SourceId` 与构建报告的物理源码路径尚未在 semantic cache / prepared reader 中统一，缓存准入会安全拒绝；本节 worker 对照禁用缓存，没有把它记为缓存验证通过。后续 [C21](P66.C21_Source_Identity_Cache_Contract.md) 已分别核对两种身份，并用本节同源产物验证双缓存命中和 prepared 复用。完整玩法的默认开发流程集成继续推进。
