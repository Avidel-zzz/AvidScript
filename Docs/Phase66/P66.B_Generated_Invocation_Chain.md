# P66.B：生成实例调用链与执行代次

## 实现

生成类型 Router 现在为每次同步调用记录调用 ID、根/父调用 ID、源/目标注册 ID、目标执行代次、receiver handle、包内 type/member ordinal 和深度。返回时恢复父调用上下文；最外层返回后不再暴露活动调用。调用栈在 Router 启动时按上限预留，不在热路径按方法名称查找。

整条链最多 64 层、4096 次入口，包含最外层调用；切换目标和从子调用返回均不重置计数。拒绝发生在目标函数执行前。内层失败会保留首个失败类别，阻止该链再次进入目标，即使原生调用者忽略失败返回值，最外层也不会被报告为成功。此前已发生的业务写入不回滚。下一次独立入口使用新计数与上下文。

注册 ID 和调用 ID 在当前 Runtime 模块生命周期内单调分配，Router shutdown/startup 不重置计数；计数耗尽时拒绝，避免地址复用或重新注册造成身份碰撞。活动派发期间仍禁止注册/注销与 Router 卸载。

`IAvidScriptGeneratedTypeInstance` 增加 `GetGeneratedExecutionGeneration()`，原生实现需要提供代次。Session 每次成功提交代码替换后递增；未发布过代码时为 0，卸载后保留最后代次用于拒绝诊断。代次不授予执行权限：暂停、隔离、World、对象代际和活跃调用限制继续由原有 Session/receiver 校验负责。入口返回时再次核对代次，防止调用期间悄然更换代码。

`GetActiveInvocation` 和 `GetInvocationFailure` 提供 GameThread 上的只读上下文与失败分类，供后续目标执行和调试接入。这里的上下文记录不是持久引用，也不持有旧 VM 或旧代码版本。

## 边界

本组为既有生成实例入口建立统一调用链，不改变它的参数 ABI，也不启用跨 Session 的 C# 执行。Session 的活动调用保护仍在；方法目录中的稳定方法 ID 尚未接入 Runtime 跨包路由，包内 ordinal 不能直接跨包解释。

原生测试使用两个真实 UObject 注册目标和原生 callback，通过同一地址的两份参数验证 Router 不改写别名，并执行 A→B→A；这不是 WASM 之间共享线性内存或托管引用的证据。上一组 VM 重入探针与本组原生链的通过，也不能合并推断出完整 C# 跨实例调用已经完成。

共享执行域仍需解决 VM/堆/静态状态归属、实例上下文切换、跨 World 隔离、托管引用与 ref/out、执行失败后的资源释放，以及事件/await 根。本组链预算限制 Router 入口数，不代替 VM fuel、Host 调用次数或整条调用链的时间预算。
