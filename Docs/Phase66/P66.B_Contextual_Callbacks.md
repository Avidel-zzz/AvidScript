# P66.B：实例上下文中的 continuation 与委托回调

## 范围与结果

本组将共享 Runtime 的实例上下文入口扩展到 continuation 与预备委托回调，并接入生成类型 Session 的生产派发路径。P66.B 继续进行；生产 Host 仍为每个生成实例创建独立 Session/VM，尚未完成共享执行域、完整 C# 跨对象路由或跨 await 持久托管根。

## 实现

- `InvokeContextOperation` 统一预备代码身份、owner/World/registry、重入预算与首个失败传播；普通出口和两类回调使用相同上下文切换与恢复规则。
- continuation 入口沿 `ValidateRequiredExports` 已验证的 V2/V1 选择预备，未验证 continuation 的模块返回空入口。委托计划必须与预备出口名称一致；重载前的入口不能进入新代码。
- 嵌套回调保存并恢复 continuation 状态消费标志、结果事务、委托输出事务及临时对象权限。委托不能读取外层 continuation 的状态，返回后外层 owner 和状态仍正确。
- 回调提交结果或 ref/out 之前，检查整链失败及当前 owner 是否存活。原生调用者忽略内层失败时，外层仍失败；这不构成任意 UE 副作用回滚。
- 生成类型 Session 在候选激活时预备 continuation、订阅和 inbound handler 出口，成功提交才替换旧入口。候选准备失败保留旧 Runtime；停止和生命周期失效清空预备入口。
- 普通 Session 保留原派发路径。新增上下文 API 是受信任原生调用入口，调用者须保留 Runtime/实例服务并从对应 endpoint 提供 completion；本组未增加 completion 防伪协议。

主要文件：`Source/AvidScriptRuntime/Private/ScriptTypes/AvidScriptRuntimeContextInvocation.cpp`、`Source/AvidScriptRuntime/Private/AvidScriptWasmRuntime.cpp`、`Source/AvidScriptRuntime/Private/Session/AvidScriptRuntimeSession.cpp`。
