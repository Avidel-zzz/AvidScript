# P66.B 进展：直接调用捕获与异步状态保存

## 实现

成员内同步、非泛型局部函数无需 `static`，能够读写外层局部变量和参数。Semantic 捕获规范化对词法调用图求固定点，将直接和传递捕获显式变为 ref 参数；同一变量不复制环境副本。支持兄弟函数共享、嵌套、递归、循环作用域及捕获与显式 ref 参数别名。常量折叠为字面量；实例接收者按值传递身份，当前仅有语义合同验证，不扩大已有 Guest 类型支持范围。

调用与捕获重写同时覆盖方法体、CFG、受控 async 语句/条件/await 参数，之后重新计算 await 状态帧。没有增加 Runtime ABI、Host import 或新的 serialized schema；规范化后的产物继续使用现有 callable/参数/引用操作合同。编译缓存由工具源码指纹失效。

真实 WASM 恢复测试发现并修复了一处原有异步保存缺陷：局部变量被取地址后，最新值位于内存单元中，`EmitOutgoingState` 直接读取寄存器会保存旧值。现在显式 `local_load` 后再写入帧。修复前，捕获值 11 经过两次加 4 与两次 await 得到 4；修复后正确得到 19。该修复也适用于普通 ref 调用后挂起的局部变量。

## 验证

固定 SDK 8.0.416；一次集中回归结果：

| 检查 | 结果 | 能证明的范围 |
| --- | --- | --- |
| Semantic 全套 | 111/111 | 投影、词法/接收者合同、原有诊断与非法 ref/struct/未赋值捕获 |
| Guest 全套 | 150/150 | lowering、原有 async/ref 行为、WASM 编译和确定性 |
| 原静态局部函数 WASM | 402/402 | P66.A 执行不退化 |
| 捕获局部函数 WASM | 900/900 | 共享写入、参数捕获、传递/递归调用、ref 别名、循环、常量与重复调用 |
| 直接分段 async WASM | 80/80 | 两个不同值的激活交错恢复，80 次保存/80 次恢复 |
| CFG async WASM | 80/80 | 分支内 await，同样独立保存和恢复捕获值 |

后两项使用测试宿主实现 continuation 队列和状态字节复制，执行真实 WASM；不是 UE Session、取消、World teardown 或热重载验收。Roslyn 仍拒绝非法捕获；lambda/委托逃逸仍明确拒绝，不静默改变 C# 语义。

复现：设置 `AVIDSCRIPT_LOCAL_FUNCTION_WASM_DIR` 到外部临时目录，运行 `Tools/AvidScript.CSharpGuest.Tests`，再将生成的各 `.wasm` 路径分别传给同目录下的 `RunLocalFunctionWasm.mjs`、`RunLexicalCaptureWasm.mjs`、`RunAsyncCaptureWasm.mjs`。最后一个脚本分别检查 `async-captures-direct.wasm` 和 `async-captures-cfg.wasm`。
