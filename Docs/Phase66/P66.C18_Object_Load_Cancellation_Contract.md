# P66.C18：对象加载与取消清理的组合

C17 的真实生成包构建确认：标准 token 的声明已经可用，但 object load 与静态状态、Task、catch/finally 的组合仍被拒绝。当前异常恢复图只接纳 Timer 和 Task；对象加载被取消后直接退休 continuation，脚本没有机会执行 finally。

## 冻结范围

目标是使正式 `gameplay-v1` 入口接受该组合，并在两个 Windows VM 中验证真实 C# 产物。实现按以下三个依赖批次推进；原生接口通过不代表源码组合已经完成。

1. **原生取消恢复合同**：显式版本化 object-load import、Session 生命周期、两套 VM 的导入映射、Editor intrinsic 授权与原生正反例。
2. **编译器组合合同**：Semantic 的 producer/exception/readiness 计划、Guest IR 和独立验证器、object callback 的状态分派与结果所有权、正式生成声明和构建 admission。由对应模型 owner 定义版本及精确 base version，禁止在脚本中扩大版本数字白名单。
3. **正式产物验收**：真实绑定包、不修改的 C# 源码、同源 .NET 对照、cold/warm/worker/prepared 路径、两套 VM 的取消/成功/失败/teardown/GC 和资源计数。保留 C17 的拒绝回归，只有具备完整组合合同的产物才改变期望。

当前写集是第一批的 VM、Runtime、Editor 原生 owner、相应 Automation、本文件及 README。第二批再路由 C# / IR / emitter / build owner；第三批再冻结业务 fixture 和入口。既有七个 protected 路径保持原基线。Android、Mac、Editor 默认接入和共享类型域回滚不在本节验收范围。

## 原生 ABI 与生命周期

新增 `avidscript.avid_continuation_load_object_cancel_resume_v1(i32 utf8Reference, i32 callbackId) -> i64 continuationToken`。签名为 `(ii)I`，名称由 VM 的 `AvidScriptContinuationCancellationAbi.h` 定义。只接受 `avidscript` 模块和 v1 精确签名；无 `env` 别名。binding id 追加在枚举末尾，旧数值不变。

原 `env.continuation_load_object` 继续使用原有取消退休语义。新接口显式设置 cancel-resume，不依据版本号、回调名称或正在执行的模块推断。旧原生 Host 的新虚方法默认返回 0；不将未实现接口降级为普通加载。

- 请求前沿用 UTF-8、规范化资源路径、Game Thread、lane/activation、World/owner、registry、ownership 和配额校验。返回 0 表示未注册有效等待；非法值保持稳定 Host 诊断。
- 活跃执行域中的主动取消，仅投递一次 `Cancelled`；已排队的成功/失败结果被替换，结果的对象引用先释放。保存的 continuation 状态保留到取消回调，回调结束后释放。
- 取消源身份只在取消回调 dispatch 期间可读；即使 source 已释放或其 slot 被复用，仍读取最先获胜的原身份。直接取消的身份为 0。该值不授予 source 的访问或所有权。
- `Completed` 与 `Failed` 沿用原 callback ABI。加载失败仍提供零对象 handle 和 Failed 状态；本节不把 Host 故障、VM trap 或加载失败改写成新的可捕获 CLR 异常。
- Session/World/owner teardown、lane 退休及 prepared 丢弃只取消 producer 并释放资源，不为失效执行域调用 Guest。迟到、重复完成及过期 endpoint 不得重新入队。
- 成功回调仍按现有借用 handle 合同交接对象；取消不得产生 loaded-object 借用、retained root 或结果消费权限。

## 验证合同

第一批需要 no-clean Win64 Editor 构建，聚焦原生 Automation，检查实际测试计数、失败数、队列完成和进程退出。原生测试覆盖 open/pre-cancelled source、source 释放和复用、直接取消、ready 结果替换、状态帧、成功/失败、重复/迟到完成、prepared/World/owner/session 退休、错线程和无效请求。VM ABI 探针在 Wasmtime/WAMR 上检查完整 64 位返回值及错误 module/version/signature；它不能代替第三批的 C# 源码执行。

后续源码验收需要验证 catch/finally 中间副作用时机、Task 的 Cancelled 状态及 token 身份、object/result ownership，并拒绝篡改 producer、callback 状态分派、取消来源、base version、state frame 和资源清理的产物。普通脚本和旧对象加载接口保持原有行为。

验证串行运行、BelowNormal、最大编译并发 1；复用安装 SDK 与固定 CLI HOME，不修改用户/机器 PATH。临时探针只回收本批创建且校验过归属的产物，保留报告和哈希；此前自动审批拒绝删除的目录不重试。
