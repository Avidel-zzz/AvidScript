# P66.B：实例异步调用与恢复状态合同

## 目标与当前状态

目标是在普通方法和 UE 实例方法中自然使用等待。例如一次调用负责为某个角色延迟加分，两次调用必须分别记住各自的角色与参数：

```csharp
public class ScoreCounter
{
    public int Score;

    public async void AddLater(int amount)
    {
        await AvidContinuations.NextTickAsync();
        Score += amount;
    }
}
```

这段代码已接通 **C# → WASM → 双后端执行**。每次调用分别保存 `this`、当前参数和必要局部状态；同一对象重复调用也有独立的等待状态。普通引用类、受支持的 UE 实例方法、静态辅助方法与绑定委托均已执行验证。静态异步入口和内部共享闭包继续可用，见[异步闭包执行](P66.B_Async_Closure_Scopes.md)。

`async void` 调用先执行到第一次等待，然后把控制权交还调用者；它不提供可等待的返回值。后续 `Task`/值结果、异常传播及可组合异步调用由 P66.C 的异步合同继续推进，不能把当前入口扩展称为完整 C# async。

## 已实现的输入合同

Semantic **28/1.32** 新增 `SemanticAsyncMethod.InvocationInputs`，并允许非导出方法的 `ExportName` 为 `null`。旧 **27/1.31** 及既有受支持版本保持可读；旧版本不能夹带新调用输入，也不能用空导出名授权实例异步执行。

| 输入 | 发布形式 | 挂起后的语义 |
| --- | --- | --- |
| 实例接收者 `this` | `receiver:<method-symbol-id>` 及原始类型 | 指向调用时的同一个实例 |
| 按值参数 | 原参数符号与类型 | 保存这次调用当前的值；对象参数仍保留对象身份 |
| 捕获的参数 / 接收者 | 同时保留原始输入和词法捕获分析 | 参数通过原共享环境恢复；不可变的 `this` 另行恢复到实例存储，供直接访问与权限检查使用 |
| `ref/out/in` 等借用输入 | 拒绝 | 不让调用者栈地址跨越等待 |

当前分析支持非泛型、块体、类成员的 `async void`，包括实例方法与普通静态辅助方法；参数按值传递。原 WASM 导出入口继续要求 public static、无参数，不改变已有生命周期 Host ABI。结构体接收者、异步 lambda/局部函数、任意 awaiter 和 Task 返回值不由本组开放。

成员调用统一使用可恢复控制流，首次入口接收调用实参，恢复入口仍按 continuation token 路由。每次挂起的语义状态包含全部调用输入，与所需局部状态按符号稳定排序；这是保守的保活范围，尚未按参数最后使用位置压缩。词法捕获正规化重新计算状态时必须保留调用输入。

[合同验证器](../../Tools/AvidScript.CSharpSemantic/Validation/SemanticAsyncInvocationValidator.cs)从 callable 签名核对输入的身份、类型、数量、顺序、参数所属方法、实例接收者和版本，并检查每次挂起保留这些输入。Guest 再从控制流重算精确状态槽，拒绝缺失、重复、伪造或错误类型的状态。无效产物仍返回 `ASCG1001`；合法成员调用不再因为缺少导出名而返回 `ASCG1024`。

## 执行与生命周期

1. **语言调用与恢复。** 初次入口使用真实参数和接收者；恢复入口创建可写存储并恢复值。被捕获参数通过环境保持共享写入，`this` 保持原实例身份。普通方法、方法组与委托调用使用同一入口，不能仅为测试导出添加特殊桥接。
2. **UE 实例与生命周期。** 通过已有方法目录和实例上下文进入目标 Session。挂起状态属于发起该任务的实例及执行域；恢复重验对象代际、World 与代码代次，取消/teardown 走原 continuation owner，不延长 UObject 生命周期。跨对象调用必须保留目标归属，不能恢复到调用者或全局默认 owner。
3. **组合执行验证。** 两个对象同时调用同一方法、同一对象重复调用、参数在等待前后修改、捕获参数与 `this`、循环内多次等待、强制 GC、恢复前后取消、实例/World 销毁、失效 receiver 拒绝与重载退休。使用真实 C# → WASM，在 Wasmtime 与 WAMR 上对照结果和终态资源，不用语义分析通过替代运行证据。

上述初次调用与恢复路径已接入。标量状态复用字节帧，包含托管引用或捕获环境时使用类型化状态对象与持久根。恢复后先检查 `this`，再执行用户代码；UE 方法通过原有方法帧路由进入目标 Session，不创建单独的异步调用模型。

例如 A 调用 `B.AddLater(3)`：等待属于 B，A 退出不会取消它；B 退出、被 UObject GC 回收或所属 World 清理时，等待被取消。挂起闭包里的 UE 接收者仍是弱身份，不阻止 UObject 回收。包级重载退休旧等待，不把旧代码中的恢复位置迁入新代码。

P66.B 仍未完成。下一组是持久事件订阅，使用同一执行域、弱 UE 身份与持久根所有权。普通托管类继承/多态、对象图跨版本迁移、托管调试暂停及完整可组合异步仍在后续路线。
