# P66.B：C# 共享引用与可变结构体

## 实现范围

本组基于 `6f994c5e` 的 [IR 6/1.5 内部引用](P66.B_Borrowed_Reference_Contract.md)，把普通 C# 的同步 ref/out 接到同一位置。包含闭包环境的模块中，内部参数、调用实参、委托签名和 thunk 使用类型化 borrowed_ref；没有闭包环境的模块保留原内部地址表示，公开 Host ABI 不变。

捕获 cell 生成 `borrow_managed`，栈局部生成 `borrow_address`，结构体字段路径生成 `borrow_field`，引用参数读写使用 `borrow_load/borrow_store`。局部函数隐藏的环境参数继续传递受追踪 owner，不把环境误当作普通 ref/out。

值类型 Guest 实例方法、构造器和属性访问接收结构体内部引用，字段写入保持原位置；普通值复制仍是独立值。readonly 字段或 in 参数调用可变方法时保留防御性复制，readonly 方法则保留读取原位置的能力。SemanticSymbol 的既有 IsReadonly 标记现在也由 Roslyn 方法符号提供；不从方法名或源码字符串推断。

同时修复隐式无参结构体构造：Roslyn 明确标记为隐式、无参数且无初始化器的结构体构造复用既有 default_value 合同。显式构造器仍执行其函数体，不能把缺失 callable 一概解释为零初始化。

## 验证方式

`CSharpGuestBorrowedReferenceTests` 使用同一份普通 C# 源码完成 .NET 参考执行和 Guest 编译。Roslyn 仅作为测试工具，未加入 UE Runtime。参考程序集在可卸载上下文执行；测试输出正常和每次分配后强制回收的两个 WASM 文件。

真实源码覆盖：

- 两个 ref 参数指向同一捕获变量；写入后经回调读取相同 cell。
- 静态方法组及捕获 lambda 的引用委托调用。
- 捕获结构体的字段、方法、属性复合赋值与嵌套字段 ref 转发。
- 按值复制的独立性，以及 in 参数调用可变方法的防御性复制。
- 经 ref/out 替换委托，callee 返回后新闭包继续共享状态。

UE BorrowedReferences 在 Wasmtime JIT 与 WAMR interpreter 执行两个 C# 文件，结果均应为 **111897**，对应 .NET 参考结果；已有 IR 文件仍为 223。正常返回后帧/根归零，收集后对象归零，压力版本校验收集次数至少覆盖全部分配。两项负例拒绝捕获引用直接进入 Host，以及内部 ref 转发后再进入 Host，避免静默复制和失去重入别名。

2026-09-19 本组集中验证：Semantic **174/174**、完整 Guest **224/224**、聚焦 closures **21/21**（包含在 Guest 总数内）、WASM **112/112**、原生 heap **13/13**、Win64 Development no-clean UBT **Succeeded**、UE managed heap Automation **5/5**。运行入口为 `Build/TestAvidScriptManagedHeap.ps1 -RuntimeAutomation`，工程日志 `Saved/Logs/AvidScript_ManagedHeap_20260919T152107659Z.log` 已核对测试数、零失败、完成与退出标记。

Harness audit 通过。架构工作树探针只报告输入与 Git tree 不一致，包含受保护的 `AvidScriptWasmReloadTypes.h`，没有其他规则违规；不宣称 clean architecture Gate 通过。较早 111881 的探针发生在 readonly 接收者用例加入前，不能代替本组最终结果。

## 仍未完成

- 同步借用不能跨 Host、返回值、await、全局或持久状态。边界适配需要另行设计；本组不承诺任意可取址表达式或完整 ref/in/ref readonly 语言支持。
- 委托身份/相等、组合、多播、event、绑定实例仍待实现；本组的结构体实例方法调用不等于绑定实例委托。
- 跨 await 委托、UE 订阅持久根、活动闭包热重载迁移与调试暂停帧仍未接通。
- 没有新增性能领先、真实 PIE 编辑体验或正式 Phase Gate 结论；P66.B 保持进行中。
