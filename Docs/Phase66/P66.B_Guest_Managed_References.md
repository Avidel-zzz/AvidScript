# P66.B：Guest 受追踪引用与自动根插桩

## 范围与结果

Guest IR 已能表达模块内受追踪对象，WASM backend 自动维护调用帧根，并通过既有 [managed heap v1 ABI](P66.B_Managed_Heap_ABI.md) 执行分配、字段访问与回收。真实编译产物已在 UE Wasmtime JIT 与 WAMR Interpreter 执行，覆盖递归、间接调用、引用返回、含引用结构体的传参和返回、循环分配及 trap 清理。

这是共享/逃逸闭包的执行基础，不是 C# 闭包开放。C# Guest 仍以 `ASCG1024` 拒绝需要 `closure_environments` 分配的产物。下一步连接 Semantic 环境计划、共享 cell 读写和委托环境参数；P66.B 保持进行中。

## IR 与后端合同

- Guest Schema 升为 **4 / 1.3**；继续读取 1/1.0、2/1.1、3/1.2。旧版本不能声明新受追踪引用，未来版本拒绝。
- `managed_ref` 是名义类型，使用不透明 i64 token，`ElementTypeId` 指向非空且有界的 payload struct。允许对象图递归，值布局本身不能无限递归。只允许 null 常量，不接受数值伪造、数值转换或引用算术。
- `managed_new` 分配并原子发布到已有根；`managed_get/set` 使用声明字段身份，递归展开值字段；引用字段必须走 ReadReference/WriteReference，不能用字节写入绕过引用类型校验。`managed_collect` 显式触发回收。
- 布局按类型 ID 排序，生成确定性的配置包；配置放在静态区之后，栈起点越过配置并按 16 字节对齐。首个受追踪调用配置模块堆，后续调用复用已配置布局。
- 每个受追踪调用帧在进入时创建根；含引用的值参数复制到本帧，未赋值聚合局部先清零。调用、分配、回收和可能进入 Host 的相关路径前同步根；循环更新根当前值，不保留该寄存器所有历史分配。
- 正常返回先复制 sret 结果，再释放本帧根。PopFrame、SetRoot、CreateRoot 不触发 GC，调用者在下一危险点前同步返回值根。trap 由 VM invocation observer 清理本次进入后的帧根，保留外层调用及持久根。
- 当前采用保守的函数作用期根，不做精确活跃区间优化；每个根更新有 Host crossing，尚无该路径的性能领先证据。

## 主动拒绝的存储边界

含受追踪引用的 global、静态 data、array element、Host import/export 签名暂不支持。受追踪存储的 `address_of`、间接读写和类型转换也拒绝，避免绕过追踪的地址别名。payload 不能包含借用字符串、数组或其他未集成生命周期的 capability。

持久状态、挂起 continuation、事件/回调根、跨 reload 迁移、C# 闭包、绑定实例与多播委托仍需后续实现。当前测试不证明任意闭包、完整 .NET 语义或 trap 后继续执行安全。
