# P66.B：共享内部引用合同

## 决策

捕获变量的 ref/out 需要与栈变量使用同一内部调用合同。采用具有静态 pointee 类型的 `borrowed_ref`，保存受追踪 owner、对象内 offset 或线性内存 address；不采用 copy-in/copy-out，也不按每个字段生成不同的被调函数。后者会扩大代码量，并使间接调用、条件引用与泛型组合难以保持一致。

本合同分两步交付：先实现 Guest IR、验证器和真实 WASM 的别名/回收证据；随后连接 C# ref/out、结构体内部访问与委托调用。第一步不解除前端尚未连接的明确诊断，也不作为 P66.B 完成证据。

## IR 6 / 1.5 与表示

`borrowed_ref` 使用 memory 表示，size=16、alignment=8，`element_type_id` 指定 pointee，固定字段依次为：

| 字段 | 偏移 | 类型 | 含义 |
| --- | --- | --- | --- |
| owner | 0 | erased managed_ref | 非 null 表示堆对象；必须保活 |
| offset | 8 | i32 | 对象内字段偏移 |
| address | 12 | i32 | owner 为 null 时的栈存储地址 |

描述符不是公开结构体；用户不能读取/改写上述字段或把整数转换为描述符。pointee 可以是固定值/结构体/受追踪引用，但不能是另一个 borrowed_ref、void 或包含 borrowed_ref 的聚合。

构造与使用：`borrow_address` 指向当前调用的参数/局部存储；`borrow_managed` 指向具体 managed_ref 的字段；`borrow_field` 从结构体内部引用派生字段引用；`borrow_load/borrow_store` 根据 owner 直接访问原位置。类型、字段与 pointee 必须一致，错误版本/操作数拒绝。保留旧 raw address 操作及 IR 1–5 的读取能力。

当前只允许描述符存在于同步函数参数和局部，支持按值复制描述符及同步内部直接/间接调用。禁止进入全局、数据段、堆字段、数组、其他结构体、返回值和 Host 进出口；禁止借用描述符自身。由此栈借用不能活过创建它的函数。后续若开放 ref return，必须另做来源和生命周期证明。

## 根与执行

堆借用的 owner 是根，pointee 中的引用由对象图追踪。栈借用还必须在被调函数的安全点重新读取 pointee 内的 managed_ref：只依赖调用者进入前的根快照，会漏掉被调函数或嵌套调用通过 ref 写入的新对象。描述符默认全零仅用于内部局部初始化；使用空地址时 trap。

标量的可寻址槽、正常局部读写和回收根必须观察同一存储。调用返回、trap、递归及重入延续现有 invocation 根清理。ABI 沿用 heap v1 受检读写，不把 native 地址写入 WASM，不新增 native heap opcode。

## 验证要求

相同 cell 的两个别名、直接写后回调重读、嵌套字段、两层 ref 转发、栈与堆来源、引用值经过 ref 更新再回收、仅借用 owner 保活、异常清理、版本与伪造描述符拒绝。先用真实双后端 WASM 验证，再接普通 C# 源码；不能用 IR fixture 代替语言前端已支持的结论。
