# P66.B：当前 Session owner 的 UE 实例委托与 this 捕获

## 已连接的能力

在运行时 receiver 校验与 Semantic 25/1.29 派发事实之上，C# 现在可以对当前生成类型 owner 的直接实例方法创建委托，并在同步逃逸闭包、局部函数中捕获 this。委托支持已有的传递、调用、ref/out、相等、组合和移除；不是仅能分析语法。

UE receiver 的环境字段保存带代际的 ObjectHandle，不持有裸 UObject 指针，也不会将 UObject 变成 Guest 托管对象或阻止其销毁。新产物中的生成类型实例函数在进入方法体前调用 `avid_ue_receiver_<ordinal>_require_v1`。实例委托创建也先验证 receiver；闭包函数进入时从环境取出 this 并验证，纯脚本计算不能因为没有读取 UProperty 而绕过身份检查。

普通引用对象仍保留原来的托管对象身份。UE 方法组使用受追踪的环境盒保存 handle；同一方法、同一 handle 的两次绑定按接收者身份相等，不按两次分配的盒地址比较。只捕获 this 的环境继续按原 receiver 身份比较，混合局部变量的环境保留 activation 身份。调用过程中参数、环境和盒都由已有精确根机制保活，调用结束后可回收。

C# 将引用相等的操作数隐式转为 object；对可直接识别的 UE receiver / null 比较，lowering 保留原表达式求值顺序，比较完整 handle。支持空 UE 引用初始化与空 receiver 绑定拒绝。这不代表已支持 UE handle 与普通托管对象混存的通用 object 擦除容器。

## 仍需完成

- 授权范围仍是当前 Session owner。另一个 UObject 即使类型相同，也不能借当前实例的 Guest 状态执行方法；跨 Session 接收者必须通过后续目标路由进入自己的实例。
- virtual/interface 调用仍需运行时派发；不会把虚方法绑定成固定 Guest 函数体。不能用当前直接方法的成功代替完整覆写和 Blueprint 路由验收。
- 持久事件订阅、跨 await 根、调试暂停根和结构重载迁移仍未连接。当前逃逸是 Guest 同步调用之间的传递，不是允许 Host 保存任意 Guest 委托。
- 公共 Host export 继续禁止携带模块私有委托引用；静态字段也不能保存这些持久能力。P66.B 不标记完成。
