# P66.B：Host 选择的实例方法派发

## 实现合同

本组在同包、同 World/registry 的生产同步方法帧上连接真实 C# 虚方法和接口的实际目标选择。显式/隐式接口、覆写和 `base` 固定调用分别处理，禁止以固定声明函数体代替多态。该组是 P66.B 的执行增量，不是语言完整、成熟版或 Phase Gate。

Guest IR 10/1.9 为 Host 方法帧增加可选的 `HostDispatchTargets`：有序、唯一的 uint selector 与目标 frame export 名称。selector 在通用 IR 中是不透明的键；UE Runtime 将它解释为目标 Session 已注册的生成类型 ordinal，不向通用 IR 引入 UObject 或反射知识。旧 IR 1–9 继续读取，旧模块不能使用新字段。

- 动态表必须非空，每表最多 4096 项，全模块最多 65536 项；目标必须是同模块中已有的直接 Host frame export，禁止链式派发、自引用和静默 fallback。
- 所有目标必须具有相同名义参数类型、传递方式、返回类型和帧签名。隐藏 receiver 已由语言适配器规范化，实际函数体仍保留声明类型校验。
- 普通 Host 方法帧仍输出版本 1 元数据；包含动态表的模块输出版本 2，并携带明确的 selector/export 映射。帧 ABI 1 不变。
- 编译期合作取消的调用图包含所有可能的动态目标函数，不能只包含声明或占位函数；候选目标中的递归同样接受预算轮询。
- Runtime 冷路径解析并准备所有目标，以当前代码身份绑定；热路径通过同域成员的注册类型选择，不按名称反射查找，也不猜测 UObject 的最派生类。
- 动态选择不授予调用权限。源/目标成员状态、World/registry、代际、根授权、整链预算和故障展开继续走既有生产入口；`base` 仍绑定明确函数体。

## 验证与未完成范围

版本兼容、规范序列化、错误 selector/目标/签名及动态递归取消图由 IR/后端校验覆盖。C# 接入 Runtime、派生可达性与接口 receiver 表示，以同源 .NET 和真实生产 Host 验证虚覆写、显式/隐式接口、共享引用、ref/out、A→B→A、GC、重载和失效目标。

仅完成 IR 或目录验证不能宣称虚/接口语言调用已可用。跨 owner 方法组、默认接口方法、持久事件/await、结构热重载与完整调试仍须保持明确边界。既有路线与 P66 批次状态不变。

## 编译器接入

[CSharpUeDispatch](../../Tools/AvidScript.CSharpGuest/Lowering/CSharpUeDispatch.cs)从已验证目录推导实际目标，固定点扩展目标调用的函数、属性访问器和 imports；不把实现方法额外暴露为 Host 入口，也不把整个程序无条件标为可达。原 Semantic 产物身份保持不变。接口映射标识实现声明；若该声明有虚槽，继续通过目标注册类型的槽找到实际覆写。

UE 类的接口视图保留弱 UObject handle；隐式参考上转、null 和相等比较不会将其转换为普通托管对象 token。转换在降低操作数前检查身份，明确诊断托管对象混用与检查型向下转换，避免先出现无关的缺失 Guest 类型/构造错误。默认接口方法和虚方法组绑定仍未连接。动态声明适配器仅提供帧形状，直接执行会 trap；即使只有一个注册实现也必须经过动态路由。
