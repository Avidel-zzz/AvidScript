# P66.B 进展：环境堆、精确根与循环回收

## 实现与归属

Runtime 新增 `Private/Memory/AvidScriptManagedHeap`，不依赖 Roslyn、CLR、UE 反射或某个 VM backend。每个成功加载的 `FAvidScriptWasmRuntimeInstance` 拥有独立堆，Session 通过现有模块实例所有权管理它。候选实例和 live 实例不共享堆；卸载幂等关闭并释放堆，重新加载创建新的 owner 身份。

堆提供布局注册、零初始化分配、受检标量读写、类型化引用字段、调用帧根、持久根和非递归 mark/sweep。分配必须同时发布到已有根，避免触发回收后出现无根的新对象。多个对象可引用同一 cell；对象图支持自引用和环。普通 byte 写入不能覆盖引用字段，引用写入先验证目标 owner、代际、类型和字段边界，再修改对象。

内部 64-bit token 区分 object/root/frame 域，包含堆 owner、槽和代际。代际耗尽后退休槽，不回绕；owner 身份同样不回绕。这个编码尚未成为公开 WASM ABI。堆按单一 owner 线程使用，只有跨堆 owner 身份分配使用原子计数。

默认限制为 16 MiB 活跃 payload、16384 个对象、16384 个根、1024 个帧、1024 个布局、每对象最多 64 KiB；同时限制单布局及全部布局的引用字段数量。metadata 由对应数量上限约束，payload 预算不等于整个进程内存预算。到达对象或 payload 上限时先收集，再返回明确错误；分配失败不替换原根。回收释放 payload 缓冲区，不把历史最大容量永久留在空槽中。

帧根使用可重用的侵入链表，反复创建/删除根不会无限积累历史列表。正常出帧要求 LIFO；trap/取消适配器可通过 `UnwindToDepth` 清理嵌套帧，同时保留外层调用和持久根。该 API 已有执行测试，Guest 调用入口的自动插桩仍待接入。

## 证据

| 检查 | 本轮结果 |
| --- | --- |
| 相同产品 C++ 源码的 Win64/MSVC Release 原生 runner | 10/10 |
| 随机对象图与独立可达性 oracle 比较 | 4000 步通过 |
| 根槽完整 22-bit 代际耗尽后退休 | 通过，无回绕复活 |
| UE 5.8 canonical Editor no-clean UBT | Succeeded |
| `AvidScript.Runtime.ManagedHeap.Ownership` | 1/1，通过且进程正常退出 |

原生用例实际执行共享 cell 的读写：owner 帧退出后两个持久对象仍共享变量；释放一个根不回收共享变量，释放全部根后回收整个图。其他用例覆盖根可达的环、不可达环、自引用、失效/跨堆/错误域 token、帧回退、根槽复用、范围溢出、布局及资源预算错误。

UE Automation 覆盖模块加载失败、独立候选卸载、重复卸载及同实例重新加载；还执行真实 Session 的候选 BeginPlay WASM trap，确认回滚保留原 runtime 和原环境，随后成功提交新候选、拒绝旧环境 token 并 StopAndUnload。该证据验证堆归属与重载事务，不等于 C# 闭包已经能从 WASM 调用。

复现：`pwsh -NoProfile -File Build/TestAvidScriptManagedHeap.ps1` 编译并运行产品核心测试（Windows、CMake、VS 2022）。先完成 canonical Editor 增量构建，再加 `-RuntimeAutomation` 执行聚焦 UE 测试；脚本校验发现数、成功数、失败数、队列结束及退出标记，日志写入工程 `Saved/Logs/AvidScript_ManagedHeap_<run>.log`。

架构检查本轮仅报告 evidence 工作树与 Git tree 不一致；其中保留了既有受保护的 `AvidScriptWasmReloadTypes.h` 改动。因此没有生成 clean-tree 架构 Gate 通过结论，也未关闭 Phase。

## 尚未接入

- Semantic 环境布局到 Guest IR/受控 Host ABI 的生成、验证与注册，以及带环境的间接调用。
- 编译器自动产生的临时/参数/返回值根、共享变量的所有读写与 ref 别名重定向、各作用域进入时的分配。
- 字符串、数组、结构中引用及 UE capability 的捕获存储/生命周期；不能把栈上的引用对直接复制进堆并当作持久值。
- continuation/订阅根、自动 trap 清理、World/Object teardown 回调取消、活动闭包结构迁移及回收延迟基准。

本轮没有放开捕获 lambda 的执行诊断，P66.B 保持进行中。下一组将把已验证的堆与编译器捕获合同连接起来，形成 C# 到 WASM 的逃逸闭包执行链。
