# P66.B：事件与异步状态的持久根

## 生命周期合同

continuation 当前保存原始状态字节；读取后即清空字节，不能以此证明其中的托管引用已保活。事件订阅、挂起任务、暂停帧应由各自 owner 持有原生根租约。恢复读取不立即释放根，必须保持到本次回调完成或显式移交下一 owner；取消、准备候选丢弃、实例/World teardown 都释放租约。

第一步提供堆原生 `FPersistentRoots`：一次获取全部非空对象的持久根，失败回收已获取部分且保留输出旧租约。移动转移唯一所有权，析构及 Reset 幂等释放。堆 Close/析构先失效化生命周期哨兵，因此租约晚于 Runtime 销毁时不会访问悬挂指针，也不能在同地址新堆上复活。旧租约替换要求新旧根能够短暂同时满足配额，不能先释放旧值来掩盖失败。

该租约不暴露 root token，不为 Guest 新增 frame-zero 根创建权限；现有 Host ABI 保持不变。使用与释放遵守堆所属执行线程，不把 weak/shared 指针解释为堆可并发操作。

## 后续接入要求

Runtime 根据经过验证的状态布局提取托管引用，在复制字节与发布 continuation 状态之前原子持有根；不能信任任意 Guest 提交的偏移列表。订阅与恢复必须验证执行域和代码代次。读取状态后，生成代码重建当前调用帧根，原租约仍保持到 dispatch finalize，避免 Host 返回与 Guest 根建立之间的 GC 空窗。

先接 continuation 和取消，再接事件、跨 await 闭包以及实例异步入口；不能仅移除编译器的拒绝分支。引用恢复还需要处理共享捕获环境和方法组身份，不能把函数索引或旧堆 token 当作可跨版本迁移的状态。

当前为第一步原生根租约实现，尚未连接 continuation、事件或 C# async。P66.B 保持 implementing。

## 原生实现与验证

[堆租约](../../Source/AvidScriptRuntime/Private/Memory/AvidScriptManagedHeap.h)使用堆拥有的生命周期哨兵与租约弱引用，不延长整个 Runtime/堆的寿命。Close 和析构使哨兵失效；移动赋值先释放目标旧租约，再接管来源。租约内不公开 root token，现有 Guest frame/返回根授权没有改变。

[原生测试](../../Tools/AvidScript.ManagedHeap.Tests/AvidScriptManagedHeapTests.cpp) **18/18** 通过，包含原有 4000 步图模型对照、代际回收与协议权限，以及新增三组所有权验证：循环图跨帧保活与释放；根配额、外来/失效/错误种类 token 导致的原子失败；堆 Close、析构、同地址重建后的晚释放。获取失败保持原租约及活跃根数量，成功移动不会双重释放。

复现入口为 `pwsh -NoProfile -File Build/TestAvidScriptManagedHeap.ps1`；Windows no-clean 构建成功，`-RuntimeAutomation` 运行进一步通过 WASM 后端 **189/189**、闭包编译 **106/106** 和双后端堆 Automation **5/5**，完整队列与退出码 0 已核对，日志为工程 `Saved/Logs/AvidScript_ManagedHeap_20260920T054102708Z.log`。新增最后一个纯原生作用域析构断言后再次执行原生 **18/18**；生产代码未再变化。

本组不改变 C#、Guest IR 或公开 Host ABI，原生租约测试不替代未来的事件/await 恢复、取消与重载组合验收。架构检查只报告进行中堆源码及既有受保护 header 与提交 tree 不一致，不能当作干净发布 Gate；7 项受保护改动保留。
