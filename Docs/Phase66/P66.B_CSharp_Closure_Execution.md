# P66.B：C# 共享与逃逸闭包执行

## 本组范围

本组连接 Semantic 的环境/入口计划与实际 Guest 执行。普通同步捕获 lambda、捕获局部函数的方法组、共享变量读写、嵌套闭包和函数返回后的委托现在进入受追踪环境堆，不退回已退出的栈地址。

语言入口仍是普通 C#。捕获变量按原始 cell 身份共享；直接局部调用与委托调用访问相同环境。函数参数在激活入口初始化，for 初始化变量只在进入整个 for 时初始化，循环体变量在每次进入声明块时创建新环境；continue/break 沿真实 CFG 边处理。

委托在 Guest 内表示为名义签名的函数引用与受追踪环境引用。每个目标的绑定对象只保留其实际需要的词法环境。调用 thunk 恢复具体绑定类型后传递隐藏环境参数。没有捕获的目标使用 null 环境；所在模块没有闭包时保留原来的函数引用表示。

Roslyn 给非 static 局部函数的方法组附加的 containing-type receiver 是合成节点，即使外围方法是 static 也可能存在。投影时移除该节点，真正的 this 捕获仍由局部函数体分析并保留，不能把此修复解释为绑定实例委托已支持。

## Guest IR 5 / 1.4

- `managed_ref` 的 `element_type_id=null` 表示类型擦除后的受追踪对象身份，不是线性内存地址。
- 新增 `managed_cast`：具体引用可擦除；恢复具体类型时校验实际对象类型、所属堆与代际。null 保持 null。错误类型在 Host 拒绝并使调用失败。
- 擦除引用不能直接分配或访问字段，不能转为整数或裸地址，不能进入未追踪的持久状态/Host 参数。
- 含擦除引用的模块至少声明一种具体布局。IR 4/1.3 仍能执行已有具体引用，不能携带新擦除合同或 cast。
- 沿用 managed heap v1 的目标类型 0 与零字节 ReadBytes 校验，没有新增 native ABI 命令。

对象图包括互相引用的环境和委托，可产生循环。活动参数、局部与返回暂存由既有根插桩保护，正常返回与 trap 由调用所有者清理。离开词法作用域会释放当前环境槽；保守暂存根可能保留该槽最近一次的值至函数返回，不承诺最早回收，也不累积每次迭代的完整历史。

## 本组仍未完成的边界

- 捕获 cell 作为普通 ref/out 实参、捕获结构体的内部字段写入或实例调用，需要共享的受控引用适配。当前明确诊断，不能用修改副本再回写掩盖重入/别名问题。
- 委托相等、组合、多播、event、绑定实例仍未完成；不使用新分配绑定对象的 token 代替 C# 委托相等语义。
- 委托跨 await、持久状态、Host 回调/UE 订阅和调试暂停帧尚未接通持久根。活动闭包结构的 reload 迁移也没有实现。
- 同步 foreach 的异常清理 CFG、一般泛型、完整错误处理仍属于后续语言工作；当前堆不接受任意借用字符串/数组存储作为环境字段。
- 本组没有性能领先或完整 PIE 开发体验证据。P66.B 保持未完成，后续先补共享引用适配与委托身份，再集成持久根、回调和跨 await 生命周期。

此前[成熟度评估](P66_Developer_Leadership_Assessment.md)记录的空引用失败发生在本组修复之前：根因是闭包类型在布局计算之后加入，随后缺失值又被解引用。本组将类型加入布局前，并在委托调用降级失败时保留诊断。
