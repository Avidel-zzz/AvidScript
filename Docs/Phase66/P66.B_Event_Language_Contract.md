# P66.B：C# UE 事件 `+=` / `-=` 合同

## 开发者写法与完成条件

选中 UE 事件并生成绑定后，脚本可以直接写：

```csharp
AvidEventHandlers.OnScriptSignal handler = (actor, amount, scale) => Score += amount;
UE.Self.OnScriptSignal += handler;
UE.Self.OnScriptSignal -= handler;
```

这是已生成 UE 事件的可执行语法。普通 C# 源码经 Roslyn、Semantic、Guest IR 和 WASM，在 Windows 两后端的真实 UE 事件上验证了重复添加与逐次移除、组合委托最后匹配子序列移除、捕获变量、绑定实例方法、回调内自移除、空处理函数、`ref/out` 写回及单播最后处理函数的返回值。现有 `AvidSubscriptions.SubscribeOnScriptSignal(source, handler)` 和返回的 `AvidSubscription.Cancel()` 保持可用。错误源、显式订阅共存、回调内添加、重载及 World/Session teardown 的语言语法组合仍待验证，不能把当前局部闭环称为 P66.B 全部完成。

当前进度：生成器已输出强类型事件；Semantic 30/1.34 已验证 `+=`、`-=` 的事件身份、owner 和处理函数类型，并拒绝伪造或非生成事件。Guest helper 复用具体状态盒和委托列表。生成的 C# 事件 fixture 1/1、no-clean Editor 构建和真实 UE 聚焦 Automation 1/1 通过；后者在 Wasmtime JIT 与 WAMR Interpreter 上覆盖上述委托行为及取消后的 GC 回收。其他语义组合仍以本文完成条件为门槛。

## 语义和所有权

- `+=`、`-=` 都只求值一次事件源和右侧处理函数。空处理函数不改变订阅。错误源、跨 World、错误代际或错误签名必须拒绝，不能绑定别的 Actor。
- 同一 Session、执行域、源和事件 ordinal 最多有一个**语言事件**桥接项。它持有具体类型的状态盒；状态盒中是当前组合委托和取消 token。`+=` 按顺序追加，`-=` 使用现有 C# 委托相等与“移除最后一个匹配子序列”的规则。重复方法组、绑定接收者、同一闭包实例和组合列表必须与这些规则一致。
- UE 单播事件也只占一个桥接项；组合委托依次运行，非 `void` 时最后一个处理函数的结果写回 UE。原有单播绑定占用同一源和事件时，新语言事件添加应明确失败；不静默替换已有订阅。
- 原有显式 token 订阅与语言事件桥接分开标记。查找语言状态不能选中显式订阅，更不能移除它。不同源、事件、World 或执行域互不共享处理函数列表。
- 事件派发先取当前委托快照。处理函数在回调内添加或移除处理函数，只改变下一次派发；当前调用和被取消的状态保持根租约到回调退出。取消最后一个处理函数时解除桥接并释放根。对象 GC、Session/World teardown、候选丢弃和重载提交沿现有 owner 路径释放。
- UE 多播上各 C# 处理函数的顺序必须稳定。一个桥接项不承诺它们与其他系统独立绑定到同一 UE 多播事件的处理函数交错顺序；该边界需在用户文档明确。

## 分层实现

1. **生成接口。** 为被选中的 UE 事件在其对象代理上生成强类型 C# `event`，保留现有显式订阅接口。事件声明携带稳定事件 ID、ordinal、签名和 owner 类型合同；成员名碰撞或不支持的参数方向在生成时失败。
2. **Semantic。** 识别 Roslyn `IEventAssignmentOperation`，区分 add/remove，绑定到生成的事件合同。源表达式和处理函数表达式只投影一次。伪造事件、静态/实例不符、签名不符、非选中事件或不支持的 accessor 都给定位诊断。新增合同须升级 Semantic Schema，并保留 29/1.33 读取；旧文档不能携带新事件赋值。
3. **Guest。** 复用现有委托组合、精确身份比较与最后子序列移除逻辑。编译器生成每事件 add/remove helper，使用具体状态盒，不让用户管理堆 token。既有显式订阅的 `_state_v1` 回调 ABI 继续兼容。
4. **Guest IR / Host。** 增加版本化的语言事件状态查找及语言模式订阅操作，按 `(Runtime, Session, source handle, ordinal, concrete box type)` 校验。查找仅返回同域、同源的语言桥接状态；没有桥接时返回空。Host 必须把返回的对象保活到 Guest 帧根建立，旧 IR 不得使用新操作。首次 `+=` 创建状态盒和桥接，后续 `+=` / `-=` 原地更新其不可变委托值；最后一次 `-=` 解除桥接。订阅发布和失败回滚不能留下半绑定状态。
5. **验证。** 先固定生成源码与 Semantic/IR 正反例，再用生产生成 facade 编译 C#，最后在 Wasmtime JIT 和 WAMR Interpreter 上由真实 UE 单播/多播事件检查结果。覆盖重复添加与最后一次移除、组合列表子序列、静态/实例/捕获处理函数、回调内移除、`ref/out` 和返回值、错误源、GC、取消、重载候选及 teardown。记录自动化和真实玩法验收的不同范围。

先验证上述状态查找能安全保活到 Guest 帧，再公开生成的事件成员；不能把仅能 `+=`、`-=` 删除全部处理函数或重订阅后改变处理函数身份的捷径称为完成。
