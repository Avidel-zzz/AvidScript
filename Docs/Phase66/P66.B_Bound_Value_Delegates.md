# P66.B：结构体实例方法委托

## 冻结合同与对象模型边界

本组连接同步普通结构体实例方法组。依据 [C# 方法组转换](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/language-specification/conversions#108-method-group-conversions)，receiver 先求值一次，再复制到独立受追踪对象；被调用方法修改该对象内的结构体。原变量后续变化不改变已绑定副本，委托离开创建函数后仍可调用。复制委托共享目标，分别从同一结构体变量绑定会产生独立对象身份。

沿用委托的目标函数/环境表示、现有类型化堆、内部借用与列表相等规则，不新增 IR opcode 或原生 Host 命令。方法 thunk 从环境恢复装箱对象，以 `borrow_managed` 访问 receiver 字段并调用原 Guest 方法；不借用创建者栈，也不采用调用后回写副本。含委托字段的结构体按原值语义复制，字段内受追踪引用继续保活。

当前普通 C# class 在 GuestTypeLowerer 中尚无完整对象表示，UE 类使用 handle；本组不将两者假装成结构体复制。一般引用类、UE receiver 身份/存活检查、接口/虚调用、捕获 this、Host 实例方法、语言 event 和跨 await 仍需后续连接，P66.B 不关闭。绑定后的调试暂停继续受持久根合同限制。

## 实现与验证计划

增加编译期绑定 receiver 计划，只为实际结构体方法组建立装箱布局并启用受追踪委托 ABI。创建时校验 receiver 类型和方法签名，thunk 使用现有同步借用参数；无 bound receiver、闭包和组合的模块保持原委托表示。

空结构体此前得到零字节布局，无法成为可寻址 WASM 值或堆 payload。本组为其生成一字节内部存储字段；该字段没有 C# 可访问符号，装箱身份仍来自堆对象 token。内部字段只解决存储与复制，不把空值内容当作对象身份，也不改变 Guest IR/Host 版本。

同一 C# 源码与 .NET 对照：副本隔离、重复绑定身份、复制委托共享修改、从函数返回、ref/out 参数、组合/移除、receiver 副作用只执行一次，以及装箱结构体内的闭包字段。正常与每次分配后强制回收均进入两个真实 WASM 后端，检查返回后根/帧清理与可达图回收。另保留不支持的引用/持久使用诊断。

混合 fixture 的 .NET 预期值为 4095；纯 receiver、无闭包和无列表 fixture 为 650。另覆盖 readonly 方法、显式 delegate 构造、空结构体绑定身份；普通引用类和含借用数组字段的 receiver 明确拒绝。完整 Guest 原有结构体绑定拒绝用例随能力更新为正例，Host 委托 crossing 的拒绝仍保留。
