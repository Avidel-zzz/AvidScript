# P66.B：普通引用对象与实例委托执行

## 执行合同

本组沿 [Semantic 24/1.28 类合同](P66.B_Reference_Class_Contract.md)连接普通源代码引用类，复用已有受追踪堆、精确根和 IR 6/1.5 内部借用。对象分配得到共享身份；复制变量只复制引用，字段、参数与返回值保持别名。实例委托直接保留原对象，重复绑定同一对象/方法相等，与结构体实例委托的独立装箱副本区分。

当前启用源代码投影完整、直接继承 object、无接口/泛型/虚成员/终结器/编译器隐式实例存储、无字段或静态初始化的普通类；字段须能由现有堆布局表示。支持隐式默认构造、显式构造及 this 构造链、普通字段、手写属性访问器、实例方法、嵌套值字段、ref/out、闭包字段和同步实例委托。语义层显式投影隐式默认构造及根 object 构造身份；根初始化仅在支持的类构造上下文中为空操作，不能把未知外部构造当作成功。

object 可作为已支持实例的类型擦除引用视图；转换回具体类经过堆布局/所有权检查，错误转换失败。引用相等比较身份，空类也有独立身份与一字节内部存储。尚不承诺 new object、任意装箱、is/as 或完整 System.Object API。

## 求值、引用与回收

构造实参先求值，再分配实例并调用构造；实例方法入口检查 null，因此普通调用的实参副作用发生在 null 调用失败之前。方法组绑定在创建时检查 receiver；直接字段赋值先固定 receiver，再计算右值并写入。复合赋值、增减和嵌套字段借用固定同一位置，避免重复求值 receiver 或因右值替换变量而写错对象。

`ref Node` 指向存放对象引用的变量或字段，`ref node.Value` 指向对象内的值；两者都使用受追踪借用描述符。`in Node` 限制引用变量本身的写入，不会使所指对象的普通字段自动只读。对象可以互相引用或形成环，字段中的闭包/委托仍由既有精确根与追踪布局保活；本组不新增原生堆命令或 WASM ABI。

每个类对象方法的编译器检查与堆字段读写仍有成本，本组不提供新性能领先声明。编译时只为实际可达代码及其字段图需要的受支持类型生成对象布局。

## 验证范围

同一源码的 .NET 参考结果为 32767，包含共享写入、实例委托身份与组合/移除、构造链和引用实参、receiver 只求值一次、字段引用、in 引用行为、object 转换、循环引用、默认零初始化、空类、闭包字段与离开创建函数后的委托调用。属性 setter 捕获 value 参数也进入真实执行。

另有 7 个故障 fixture：null 普通方法、null 方法组绑定、直接字段赋值、复合赋值、ref 字段实参、嵌套值字段赋值和错误 object 转换。检查失败前的副作用计数，而不只判断发生错误。主 fixture 同时运行正常和每次分配后强制回收版本；两个 WASM 后端均检查调用根/帧归零，以及最终循环对象图可以回收。

[C# 方法组转换规范](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/language-specification/conversions#108-method-group-conversions)要求 null 实例目标绑定失败。固定 .NET 参考环境对已消费的非虚实例委托抛 ArgumentException，未消费的绑定可能被优化掉；因此 fixture 显式调用委托，并记录失败发生在后续赋值之前。Guest 当前用 trap/受检堆错误报告失败，本组不声称 CLR 异常类型和 catch 语义已实现。

不支持的初始化、继承、接口/虚派发、自动属性、终结器、Host crossing、托管引用全局状态、捕获 this、跨 await 状态和调试暂停根有明确拒绝测试。普通同步对象执行不等于持久事件/任务生命周期完成，P66.B 保持进行中。
