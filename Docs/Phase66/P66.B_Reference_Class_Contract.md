# P66.B：普通引用类的语义合同

## 范围与版本

本组为普通 C# 引用对象执行补齐前置合同，发布 **Semantic schema 24 / version 1.28**。不修改 Guest IR 6/1.5、WASM ABI 或原生堆，不把分析类声明等同于已经执行对象。P66.B 保持进行中。

`SemanticDocument.ClassTypes` 为 `Types` 中每个 `class` 提供一个描述符：基类、直接实现的接口、源声明或元数据来源、static/abstract/sealed/generic/record 特征、主构造函数与隐式无参构造、实例初始化、静态初始化、隐式实例存储、声明的虚成员及终结器。事实来自 Roslyn 符号和声明，不解析签名字符串，也不把 CLR 标志当作 C# 源级修饰符。内建 string 继续使用原 primitive 表示；UE 类型声明继续使用独立的 UE 合同。

类型列表和接口列表按稳定 ID 排序。类事实的 JSON 字段全部必填，防止缺失初始化或终结信息时默认为 false。读取者校验描述符完整性、重复 ID、基类存在、接口类型、静态/构造约束及继承环；异常输入在 Guest 规划之前返回 `ASCG1001`。元数据表示语义事实，并不替代来源验证或重新分析源码。

`IsSourceDeclared` 只表示 Roslyn 持有声明语法；引用源码未必是可执行源码，仍须分别检查 callable body 和源码投影范围。后续对象布局不能仅凭该标志就认为字段与方法已经完整投影。

旧 schema 23 / 1.27 在不携带新类事实时继续执行原有闭包合同；schema 22 仍只能读取没有分配计划的旧捕获分析。新字段不能夹带到旧版本，未知未来版本继续拒绝。

## 同批修复与执行边界

类测试暴露出 `partial class` 的重复声明会触发符号投影器异常。现仅合并 Roslyn 同一类型身份、所有声明均为 partial、投影事实一致的类型记录；成员各自保留，优先保留主源码位置。其他稳定 ID 冲突仍报错。分部声明中的字段和自动属性初始化都纳入类事实，字段式 event 的隐式存储不依赖公开字段枚举。

普通引用类分配、构造执行、字段共享身份与引用类实例委托**尚未启用**。继承/接口/虚派发、终结器、record、泛型类、主构造函数、自动属性及字段初始化不会因为本组能分析其特征就自动获得运行支持。Guest 仍对当前无法表示的类返回明确诊断。

下一组沿既有受追踪堆连接最小普通引用类：分配得到共享身份，实例字段保持别名，构造与零初始化有明确区分，null receiver 检查发生在正确位置，实例委托引用原对象。之后再连接捕获 this、持久事件与 await 根。每一步必须同时保留不支持组合的诊断，不能把对象复制成结构体来替代引用语义。
