# P30.0 SceneComponent 对象图范围

Phase 30 的目标是让 C# 脚本通过 `UE.Self.GetRootComponent()` 获得安全的 `USceneComponent` 句柄，并完成组件世界坐标读写。

本阶段建立可扩展 UObject 对象图的最小纵向闭环：

- Actor 返回 UObject 派生对象。
- UObject 使用 `{slot, generation}` 跨越 WASM ABI。
- SceneComponent 提供类型化世界坐标读写。
- WAMR 验证 guest 输出内存。
- C# v9 适配器支持直接链式调用。

组件局部变量、通用反射调用、Attach/Detach 和组件创建不在本阶段范围内。
