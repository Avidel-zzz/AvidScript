# P30.2 SceneComponent 绑定与 Adapter v9

状态：Done

## UObject 句柄返回

`FAvidScriptActorBinding::GetRootComponentHandle` 解析 Actor 的 RootComponent，并通过当前 `FAvidScriptObjectRegistry` 返回 `{slot, generation}`。注册表对同一 UObject 复用已有句柄，避免链式调用持续增加 slot。

## SceneComponent typed API

新增 `FAvidScriptSceneComponentBinding`：

- `GetWorldLocation`
- `SetWorldLocation`
- write policy、类型错误与 stale handle 诊断
- 失败读取统一归零

## WAMR ABI

新增 imports：

```text
actor_get_root_component(i32, i32, i32) -> i32
scene_component_get_world_location(i32, i32, i32) -> i32
scene_component_set_world_location(i32, i32, f32, f32, f32) -> i32
```

Host 在写入 8 字节句柄或 12 字节 FVector 前调用 `wasm_runtime_validate_app_addr`。越界时记录 import 名并以 `host_import_failed` 停止当前 guest 调用。

## C# Adapter v9

新增 handle-backed `USceneComponent` 投影，支持：

```csharp
FVector rootLocation = UE.Self.GetRootComponent().GetWorldLocation();
UE.Self.GetRootComponent().SetWorldLocation(rootLocation);
```

v9 生成 12 个 imports，生命周期导出函数索引顺延到 12/13/14。组件句柄使用 scratch 16-23，FVector 使用 scratch 24-35。
