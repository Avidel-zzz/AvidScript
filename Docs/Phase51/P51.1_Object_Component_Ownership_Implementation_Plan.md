# Phase 51 UObject/Component 所有权实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立 descriptor 驱动的 UObject/Component 构造、Session 所有权、组件查询与 Attach/Detach 闭环，并由真实 C# 脚本在 UE5.8 中使用。

**Architecture:** Profile v4 显式声明 factory policy，descriptor v7 发布稳定 factory table，Bindings package load 生成 immutable plan。Runtime Session 持有独立 ownership domain；VM 只注册五个通用 import；generated C# token 保留静态返回类型，所有项目类继续通过 profile 扩展。

**Tech Stack:** UE5.8 C++、CoreUObject/Engine、WAMR、C# / Roslyn Semantic、Guest IR、WASM、PowerShell、Unreal Automation。

## Global Constraints

- 引擎目录固定为 `C:\UnrealEngine`，使用 UE5.8 源码版。
- PC/Win64 Editor 优先；不在本阶段声明 Cook、Shipping 或移动端完成。
- 人读文档使用中文；协议字段、代码标识符和稳定诊断类别保留英文。
- 不清理 Editor Target；UBT 使用 no-clean module build。
- P51.1-P51.4 只运行阻塞性聚焦验证；完整构建和 Automation 在 P51.5 集中执行。
- 新增项目类型不能要求逐 UClass、逐 UFUNCTION WAMR wrapper 或 Runtime switch。
- Runtime 热路径禁止 class path、member name 和 reflected name lookup。
- 普通 UObject 的 Outer 不能替代 GC 强引用；Session ownership 必须显式持有。
- candidate reload 不允许 Construct、Release、Attach 或 Detach 副作用。
- 主工作区已有用户改动不得暂存、覆盖或回滚。
