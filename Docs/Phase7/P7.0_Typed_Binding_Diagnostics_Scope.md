# P7.0 Typed Binding Diagnostics Scope

日期: 2026-07-05
状态: Done

## 1. 目标

Phase 7 把 Phase 6 中硬编码在 `BuildAvidScriptActor.ps1` 里的 host binding 抽成 typed binding declaration, 并开始输出可被 Editor UI/IDE/CI 复用的 frontend diagnostics。

目标链路:

```text
Bindings/ActorHostBindings.avidscript.json
-> BuildAvidScriptActor.ps1
-> generated D import stubs
-> manifest required_imports
-> diagnostics with code/line/column
```

## 2. 小组拆分

| 小组 | 状态 | 目标 |
| --- | --- | --- |
| P7.0 | Done | 范围、spec、plan、plugin scope 和根日志建立。 |
| P7.1 | Done | 从 typed binding declaration 生成 D import 和 manifest import。 |
| P7.2 | Planned | frontend diagnostics 输出错误码和 source location。 |
| P7.3 | Planned | `.avid` sample runtime regression。 |
| P7.4 | Planned | 完整回归和文档收口。 |

## 3. Binding Declaration MVP

默认 binding 文件:

```text
Plugins/AvidScript/Bindings/ActorHostBindings.avidscript.json
```

P7.1 只声明一个 host binding:

```text
actor_set_location(slot: int, generation: int, x: float, y: float, z: float) -> int
```

## 4. Diagnostics MVP

P7.2 先输出:

```text
ASL1202 unknown_binding
ASL1203 invalid_argument_count
ASL1204 invalid_literal
```

每条 diagnostic 至少包含:

```text
code
severity
line
column
message
```
