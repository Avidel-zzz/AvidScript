# P19.1 C# Profile RED 测试

## 测试目标

本小组先用自动化测试描述 Phase 19 的目标行为: C# 构建不再只能面向固定 ActorLifecycle 样例, 而是可以接收一个自定义 source/profile, 生成独立 module id、artifact stem、report、manifest 和 WASM artifact, 并继续绑定到 Actor 的 `UAvidScriptComponent`。

## 新增测试

测试名:

```text
AvidScript.Editor.CSharpBuildService.CustomProfileSmoke
```

测试文件:

```text
Plugins/AvidScript/Source/AvidScriptEditor/Private/Tests/AvidScriptEditorCSharpBuildServiceTests.cpp
```

测试在 `Saved/AvidScriptTests/CSharpProfiles/CustomMover/CustomMoverScript.cs` 生成一个临时 C# 源文件, 配置如下 profile:

| 字段 | 值 |
| --- | --- |
| `SourcePath` | `Saved/AvidScriptTests/CSharpProfiles/CustomMover/CustomMoverScript.cs` |
| `ProjectPath` | 默认 ActorLifecycle sample `.csproj` |
| `ModuleId` | `csharp_custom_mover` |
| `ArtifactStem` | `custom_mover` |
| `OutputRoot` | `Saved/AvidScriptCSharpGuest/CustomMover` |
| `ReportPath` | `Saved/AvidScriptCSharpGuest/CustomMover/custom_mover.csharp.report.json` |
| `ManifestPath` | `Saved/AvidScriptCSharpGuest/CustomMover/custom_mover.avidscript.json` |

## RED 结果

RED 构建命令:

```powershell
& "C:\UnrealEngine\Engine\Build\BatchFiles\Build.bat" AvidTPSTemplateEditor Win64 Development "-Project=<ProjectRoot>\AvidTPSTemplate.uproject" -WaitMutex -NoHotReloadFromIDE -NoUBTMakefiles -Module=AvidScriptEditor
```

预期失败点:

- `FAvidScriptEditorCSharpBuildConfig` 缺少 `SourcePath`、`ProjectPath`、`ModuleId`、`ArtifactStem`、`ManifestPath`。
- `FAvidScriptEditorCSharpBuildResult` 缺少 profile 结果字段。
- `FAvidScriptEditorCSharpBuildService` 缺少 `BuildProfile(...)`、默认 sample path helper 和 report/manifest path helper。

这确认测试确实先约束了新的 profile API, 不是在复用旧的固定 ActorLifecycle 行为。

新增 `AvidScriptEditor` test `.cpp` 后, UBT 一度报告 target up to date。按既有流程没有清 Editor target, 而是通过 source-list invalidation 让模块级构建识别新文件。
