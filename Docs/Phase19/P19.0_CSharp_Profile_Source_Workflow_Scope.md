# P19.0 C# Profile/Source Workflow 范围

## 目标

Phase 19 将 Phase 18 的固定 ActorLifecycle 构建入口拆出可复用 profile 参数，让 C# build wrapper 和 Editor build service 能接受自定义 C# source、project、module id、artifact stem、report path 与 manifest path。

这一阶段的核心价值是把“样例能跑”推进到“下一步可以接用户自己的 C# 脚本文件”。

## 交付内容

- `BuildCSharpActorLifecycle.ps1` 保持默认 ActorLifecycle 行为，同时新增 profile 参数。
- `FAvidScriptEditorCSharpBuildService` 接收并转发 profile 参数。
- 新增自动化测试，用测试生成的 C# 源文件构建自定义 profile。
- 自定义 profile 的 report 和 manifest 必须使用自定义 `module_id` 与 artifact stem。
- 自定义 profile 生成后可继续通过现有组件绑定服务绑定到 Actor。

## 本阶段边界

- 不做 Slate 文件选择器。
- 不做 Project Settings 持久化 profile 列表。
- 不扩大 C# source adapter 的语法子集。
- 不做 mobile/package 验证。
- 当前菜单仍保留 ActorLifecycle 默认入口；通用 UI 入口留给后续阶段。

## 验收标准

- 默认 ActorLifecycle build-and-bind 行为保持兼容。
- 自定义 source/profile automation 可以生成 custom report、custom manifest 和 custom WASM artifact。
- report 的 `module_id`、`source.file`、`artifacts.manifest_file`、`artifacts.wasm_file` 反映自定义 profile。
- 自定义 report 能绑定到测试 Actor 的 `UAvidScriptComponent`。
- 完整 `AvidScript` 自动化回归通过。
